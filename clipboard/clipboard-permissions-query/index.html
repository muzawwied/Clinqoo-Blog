Cek Permissions API sebelum Menyalin ke Papan Klip Clincoo

writeText bisa ditolak tanpa pesan. Query clipboard-write dulu agar tombol salin Clincoo punya cadangan yang jelas.

Artikel ini tersedia dalam: Indonesia · English

Tombol Salin kode di halaman Clincoo kadang diam. Pengunjung mengira skrip rusak, padahal izin clipboard-write berstatus denied atau prompt tertunda.

Panggil navigator.permissions.query({name:'clipboard-write'}) jika browser mendukung. Jika state bukan granted, tampilkan instruksi pilih teks manual.

Tetap bungkus navigator.clipboard.writeText dalam try/catch. Izin yang granted masih bisa gagal di luar gestur pengguna.

Jangan minta AI menonaktifkan pintasan asli Ctrl+C. Fallback harus menambah, bukan mengganti, perilaku sistem.

Uji di HTTPS app.clincoo.buzz dan di pratinjau lokal. Perilaku izin berbeda antara konteks aman dan file://.
