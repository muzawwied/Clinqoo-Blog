Read Pasted Text from the Event, Not Only the Clincoo Clipboard API

Reading the clipboard without a paste event is often blocked. Take data from event.clipboardData when the user pastes.

This article is available in: Indonesia · English

On editor.clincoo.buzz, a Paste button that calls readText fails in Safari even on HTTPS.

Attach a paste listener on the editor area. Read event.clipboardData.getData('text/plain') and preventDefault only if you handle the format yourself.

Do not read the clipboard on page load. The browser rejects it without a gesture. Paste the error to AI, not the whole editor module.

Test on app.clincoo.buzz with Ctrl+V and the context menu. Record the result on blog.clincoo.buzz.
