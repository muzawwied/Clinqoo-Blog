Baca Teks Paste dari Event, Bukan Hanya Clipboard API Clincoo

Membaca clipboard tanpa event paste sering ditolak. Ambil data dari event.clipboardData saat pengguna menempel.

Artikel ini tersedia dalam: Indonesia · English

Di editor.clincoo.buzz, tombol Tempel yang memanggil readText gagal di Safari meski HTTPS aktif.

Pasang listener paste pada area editor. Baca event.clipboardData.getData('text/plain') lalu preventDefault hanya jika Anda menangani format sendiri.

Jangan baca clipboard saat halaman load. Browser menolak tanpa gestur. Tempel error ke AI, bukan seluruh modul editor.

Uji di app.clincoo.buzz dengan Ctrl+V dan menu klik kanan. Catat hasil di blog.clincoo.buzz.
