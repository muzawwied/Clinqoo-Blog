Copy the Clincoo Page URL with a Clear Share Button

A share button without a URL fallback fails on desktop. Use navigator.share when present, then writeText.

This article is available in: Indonesia · English

Many Clincoo pages ship a share icon that only calls navigator.share. On desktop Chrome without a native sheet, the click feels dead. Visitors never get the URL.

Detect canShare first. If it exists, send the title and location.href. Otherwise call navigator.clipboard.writeText with the canonical URL. Remember: the Clipboard API needs a secure HTTPS context such as app.clincoo.buzz.

After a successful copy, change the button label to Copied for two seconds. Do not swallow errors; show a short message if permission is denied.

Ask AI to add only the writeText fallback. Paste the existing share button in editor.clincoo.buzz. Do not override the browser Ctrl+C shortcut.

One share path plus one copy path covers desktop and phone. Test in a local HTTP preview so you see the failure message before deploy.
