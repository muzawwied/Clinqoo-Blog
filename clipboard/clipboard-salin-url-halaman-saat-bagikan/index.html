Salin URL Halaman Clincoo lewat Tombol Bagikan yang Jelas

Tombol bagikan tanpa salin URL gagal di desktop. Pakai navigator.share jika ada, lalu writeText sebagai cadangan.

Artikel ini tersedia dalam: Indonesia · English

Banyak halaman Clincoo memasang ikon bagikan yang hanya memanggil navigator.share. Di desktop Chrome tanpa menu native, klik terasa mati. Pengunjung tidak mendapat URL.

Deteksi dulu canShare. Jika tersedia, kirim title dan location.href. Jika tidak, panggil navigator.clipboard.writeText pada URL kanonis. Ingat: Clipboard API butuh konteks aman HTTPS seperti app.clincoo.buzz.

Setelah salin berhasil, ganti label tombol menjadi Tersalin selama dua detik. Jangan menelan error diam-diam; tampilkan teks singkat jika izin ditolak.

Minta AI menambah cadangan writeText saja. Tempel tombol bagikan yang ada di editor.clincoo.buzz. Jangan timpa Ctrl+C bawaan browser.

Satu jalur bagikan plus satu jalur salin menutup celah desktop dan ponsel. Uji di pratinjau HTTP lokal agar kamu melihat pesan gagal sebelum deploy.
