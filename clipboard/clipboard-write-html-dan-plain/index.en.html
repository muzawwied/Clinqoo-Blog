Copy HTML and Plain Text Together from a Clincoo Button

ClipboardItem supports text/html plus text/plain. Keep a writeText fallback.

This article is available in: Indonesian · English

A copy button on a Clincoo page often sends only plain text. That is safe, but some visitors paste into documents that need light formatting.

ClipboardItem lets write send several MIME types at once: text/plain and text/html. Supporting browsers pick the type that fits the destination app.

Do not copy raw HTML from an entire card. Limit the payload to a snippet you control, with no hidden scripts or handlers.

If ClipboardItem is missing, fall back to navigator.clipboard.writeText. Keep the same button feedback so the flow in editor.clincoo.buzz stays intact.

Test paste into notepad and into a rich-text editor. Those two results prove both the plain fallback and the HTML path work.
