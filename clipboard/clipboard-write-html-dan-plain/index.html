Salin HTML dan Teks Polos Bersamaan di Tombol Clincoo

ClipboardItem mendukung text/html plus text/plain. Sediakan cadangan writeText.

Artikel ini tersedia dalam: Indonesia · English

Tombol salin di halaman Clincoo sering hanya mengirim teks polos. Itu aman, tapi kadang pengunjung menempel ke dokumen yang butuh format sederhana.

ClipboardItem memungkinkan write dengan beberapa tipe MIME sekaligus: text/plain dan text/html. Browser yang mendukung akan memilih tipe sesuai aplikasi tujuan.

Jangan menyalin HTML mentah dari seluruh kartu. Batasi ke cuplikan yang kamu kendalikan, tanpa skrip atau event handler tersembunyi.

Jika ClipboardItem tidak ada, jatuh ke navigator.clipboard.writeText. Umpan balik tombol tetap sama agar alur di editor.clincoo.buzz tidak pecah.

Uji tempel ke notepad dan ke editor rich text. Dua hasil itu membuktikan cadangan teks polos dan HTML berjalan.
