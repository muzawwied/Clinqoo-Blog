Assert Visible Text, Not CSS Class Names, in Clincoo Tests

Utility classes change. A test that reads the button label survives a style refactor.

This article is available in: Indonesia · English

On editor.clincoo.buzz, tests that depend on class btn-primary break when design tokens change. Users never see the class name.

Find the button by role and accessible name, then click. Assert the status text that appears matches the UI copy.

Do not assert raw innerHTML. Compare normalized textContent.

Paste the test snippet to AI and ask to swap the class selector for getByRole. Do not ask for a full suite rewrite.

This flow is used when checking the app.clincoo.buzz preview and pages on blog.clincoo.buzz.
