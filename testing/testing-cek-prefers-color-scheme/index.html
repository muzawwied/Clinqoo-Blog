Uji Tampilan Gelap dan Terang dengan prefers-color-scheme di Clincoo

Halaman yang hanya terlihat benar di tema sistemmu akan gagal saat pengunjung memakai mode sebaliknya.

Artikel ini tersedia dalam: Indonesia · English

Banyak template Clincoo memakai CSS variables untuk latar dan teks. Jika kamu hanya menguji di mode gelap laptopmu, kontras di mode terang bisa jatuh di bawah ambang WCAG. MDN prefers-color-scheme adalah sinyal yang harus kamu putar sebelum rilis.

Di Chrome DevTools buka Rendering > Emulate CSS prefers-color-scheme, pilih light lalu dark. Cek hero, form, tombol, dan placeholder. web.dev meminta rasio kontras 4.5:1 untuk teks body dan 3:1 untuk teks besar serta komponen UI.

Jangan andalkan filter invert. Warna merek yang dibalik sering pecah. Tulis dua blok :root dan data-theme atau media prefers-color-scheme: dark dengan token yang eksplisit.

Uji juga saat pengguna mengunci tema lewat tombol di halaman. Preferensi manual harus mengalahkan media query. Screenshot kedua mode sebelum deploy.

Minta AI hanya menambahkan token warna yang kurang, bukan mengganti seluruh stylesheet. Setelah edit, ulangi emulate light dan dark sampai tidak ada teks yang nyaris lenyap di latar.

Sumber: MDN prefers-color-scheme, web.dev prefers-color-scheme, WCAG contrast minimum.
