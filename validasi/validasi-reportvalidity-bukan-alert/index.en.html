Use reportValidity on Clincoo forms, not alert

alert blocks the page and does not point at the field. reportValidity shows the browser message on the input.

This article is available in: Indonesia · English

On editor.clincoo.buzz, validation that calls alert closes the phone keyboard and does not focus the bad field.

Call form.reportValidity() after custom checks. Pair setCustomValidity with an empty string once the value is valid.

Ask AI to replace alert with reportValidity and focus the first failing field.

Test on app.clincoo.buzz in Chrome and Firefox. Note the message on blog.clincoo.buzz.
