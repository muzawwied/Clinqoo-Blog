Mark Failed Fields with aria-invalid on Clincoo Forms

Red color alone is not enough. aria-invalid, aria-describedby, and a live region tell screen readers.

This article is also available in: Indonesia · English

A red border on a failed input is invisible to some visitors. A screen reader does not announce color. Without attributes, the error is decoration.

In editor.clincoo.buzz, when validation fails set aria-invalid="true" on the field. Wire the message with aria-describedby to the error text id. Remove the attribute or set false when the field is valid again.

For a summary at the top of the form, use role="alert" or aria-live="polite" on the message container. Do not announce on every keystroke; announce on submit or blur.

Move focus to the first failed field after submit. That is faster than forcing the user to tab from the logo down to the error.

Clincoo does not attach ARIA automatically on custom forms. Those attributes are part of the HTML you write. Test with a keyboard and, if you can, a short screen-reader pass.
