Tandai Field Gagal dengan aria-invalid di Form Clincoo

Warna merah saja tidak cukup. aria-invalid, aria-describedby, dan live region memberitahu pembaca layar.

Artikel ini tersedia dalam: Indonesia · English

Border merah pada input gagal terlihat oleh sebagian pengunjung. Pembaca layar tidak mengumumkan warna. Tanpa atribut, error hanya dekorasi.

Di editor.clincoo.buzz, saat validasi gagal set aria-invalid="true" pada field. Hubungkan pesan lewat aria-describedby ke id teks error. Hapus atribut atau set false saat field valid lagi.

Untuk ringkasan di puncak form, pakai role="alert" atau aria-live="polite" pada wadah pesan. Jangan menggandakan pengumuman di setiap keystroke; umumkan saat submit atau saat field diblur.

Fokus ke field pertama yang gagal setelah submit. Itu lebih cepat daripada memaksa pengguna tab dari logo sampai ke error.

Clincoo tidak memasang ARIA otomatis pada form kustom. Atribut itu bagian dari HTML yang kamu tulis. Uji dengan keyboard dan, jika bisa, pembaca layar singkat.
