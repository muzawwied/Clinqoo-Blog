Use novalidate plus Custom Messages on a Clincoo Form

Native browser tooltips vanish on outside click. novalidate plus text under the field is more reliable.

This article is also available in: Indonesia · English

Built-in browser validation shows a short bubble. That bubble differs per engine, cannot be styled, and disappears when the user clicks outside the field.

Add the novalidate attribute on the form in editor.clincoo.buzz. Keep required, type, minlength, and pattern as the source of truth. Script that reads validity, not script that rewrites every rule.

On submit, call form.checkValidity(). If it fails, preventDefault, then write text into an element under the input. setCustomValidity helps if you still want the native API.

Do not drop HTML constraints just because you wrote JS. Without native attributes, a field with script disabled becomes wild. novalidate holds back the bubble, not the rules.

Test with JS off in preview if you can. The form should still refuse an empty submit via attributes. Clincoo deploys static HTML; client checks still need a server backup.
