State Clear minlength and maxlength on Clincoo Forms

A password or code without limits surfaces errors too late. Set minlength, maxlength, and name the numbers in the label.

This article is also available in: Indonesia · English

Visitors type an eight-character password and only then learn the minimum is twelve. Or they paste a 40-character code into a field that silently trims via maxlength.

In editor.clincoo.buzz, set minlength and maxlength on inputs that truly have a limit. Put the same numbers in the label or hint: Password 12–64 characters.

Do not rely on maxlength alone with no message. Browsers cut keystrokes without explanation. If truncation is harmful, raise the limit or show remaining characters.

ValidityState.tooShort and tooLong are ready to use. Custom copy: Password too short, minimum 12 characters. Avoid too short with no number.

Keep client limits aligned with what the server or webhook accepts. Clincoo does not sync the two. A mismatch passes preview and fails after release.
