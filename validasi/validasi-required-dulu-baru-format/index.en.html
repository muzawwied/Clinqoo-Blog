Check Required Fields before Format Rules on a Clincoo Form

Do not show a format error on an empty field. Check required first, then email, URL, or phone patterns.

This article is also available in: Indonesia · English

A Clincoo form often shows Invalid email format on a still-empty input. The visitor just opened the page. That message misses the point and makes the form feel harsh.

In editor.clincoo.buzz, order the rules: empty first, length next, then pattern. The Constraint Validation API exposes valueMissing before typeMismatch. Use the same order in custom scripts.

Write two separate messages. Empty: Enter an email so we can send confirmation. Format: Accepted example: name@domain.com. One field, two rules, two sentences.

Do not run a regex on an empty string. It always fails and overwrites the required message. A guard if (!value) return 'required' is enough.

Test in preview: leave the field empty and submit, then type a single dot. The two paths must differ. Clincoo does not rank errors for you. You choose the order.
