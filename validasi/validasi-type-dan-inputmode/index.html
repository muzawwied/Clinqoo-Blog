Samakan type dan inputmode pada Isian Form Clincoo

type mengatur validasi dan keyboard. inputmode mengatur papan tombol tanpa mengubah nilai. Pakai keduanya dengan tepat.

Artikel ini tersedia dalam: Indonesia · English

Field telepon bertipe text memaksa keyboard huruf di ponsel. Field angka bertipe number menolak plus dan spasi yang sering ada di nomor nyata.

Di editor.clincoo.buzz, pilih type sesuai makna: email, url, tel, text. Untuk nomor pesanan atau kode pos, type=text plus inputmode=numeric menjaga nilai tetap string dan membuka papan angka.

Jangan pakai type=number hanya karena isinya digit. Number membuang nol di depan, menolak pemisah, dan menampilkan spinner yang jarang diinginkan pada kode.

inputmode tidak memvalidasi. Ia hanya saran keyboard. Validasi tetap lewat pattern, minlength, atau skrip. Keduanya saling lengkapi, bukan pengganti.

Uji di pratinjau HP: fokus ke email, tel, dan kode. Keyboard harus beda. Clincoo tidak memilih inputmode otomatis. Atribut itu kerjaan penulis form.
