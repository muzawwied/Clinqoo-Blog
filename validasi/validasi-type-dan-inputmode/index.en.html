Match type and inputmode on Clincoo Form Fields

type drives validation and some keyboards. inputmode drives the keypad without changing the value. Use both on purpose.

This article is also available in: Indonesia · English

A phone field with type=text forces a letter keyboard on phones. A numeric field with type=number rejects plus signs and spaces that real numbers often include.

In editor.clincoo.buzz, pick type by meaning: email, url, tel, text. For order numbers or postal codes, type=text plus inputmode=numeric keeps the value a string and opens a number pad.

Do not use type=number just because the content is digits. Number strips leading zeros, rejects separators, and shows steppers that codes rarely want.

inputmode does not validate. It only hints the keyboard. Validation still comes from pattern, minlength, or script. They complement each other; one does not replace the other.

Test on a phone preview: focus email, tel, and a code field. The keyboards should differ. Clincoo does not pick inputmode for you. That attribute is the form author's job.
