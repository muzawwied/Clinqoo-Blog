Audit Image Alt Text and File Weight on a Clincoo Page

Empty alt and a 4 MB PNG slip past design review. Check attributes and file size before release.

This article is also available in: Indonesia · English

A Clincoo hero uses a 4000px studio photo as PNG. LCP is slow and the alt is just image1.

In editor.clincoo.buzz, list every img. Write alt that explains the image job. Decorative images may have an intentional empty alt, not a filename.

Swap photo PNGs for WebP or JPEG. Set width and height so the layout does not jump.

Send filenames plus sizes to AI and ask for a format suggestion. Refuse compression that wrecks an SVG logo.

Clincoo uploads files as they are. Auditing alt and weight keeps app.clincoo.buzz fast and readable.
