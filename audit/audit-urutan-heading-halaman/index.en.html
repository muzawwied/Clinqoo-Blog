Audit H1–H3 Heading Order on a Clincoo Page

Jumping from H1 to H3 or using two H1s on one page breaks the outline. Audit headings before release.

This article is available in: Indonesia · English

Search engines and screen readers map a page from its headings. In a Clincoo project, run a simple audit: open one page, list every H1 through H3, and check that levels rise one step at a time.

A common leftover from templates is an H1 in the logo and another in the hero. Keep one H1 that states the page topic. Section titles use H2, card titles use H3 — do not swap them just because the font size looks nicer.

Do not rely on CSS classes for meaning. Large text inside a div leaves the outline empty. Use real heading tags, then style size in CSS.

Check Clincoo preview and DevTools. If the heading list reads like a sensible table of contents, the audit passes. Save a small change, then repeat on services and contact pages.

Heading audits take minutes, not hours. Do them before deploy so sitemap structure and accessibility stay aligned.
