Link the Clincoo Wallet to Your Web Wallet with a PIN, Not a Pasted Token

The ClincooPay link is verified with a PIN on the wallet server. The connection token is stored per account, never pasted into chat.

This article is available in: Indonesia · English

ClincooPay connects your Clincoo wallet balance with your own web Wallet. You create the link from the wallet page: enter the wallet address and PIN, and Clincoo verifies both directly with the wallet server.

Once the PIN matches, Clincoo stores a connection token for your account. You never need to paste tokens, API keys, or secrets into chat.

To disconnect, open the ClincooPay settings and choose unlink. The web wallet balance stays intact; only the mirrored connection is removed.

If the PIN is rejected, double-check it inside your Wallet app. A failed verification never leaves a half-made connection, so it is safe to retry.

All verification happens server-side on app.clincoo.buzz. The client only submits the address and PIN; Clincoo never stores your PIN.
