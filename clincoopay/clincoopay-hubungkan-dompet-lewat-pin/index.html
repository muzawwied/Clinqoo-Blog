Hubungkan Dompet Clincoo ke Web Wallet lewat PIN, Bukan Menempel Token

Koneksi ClincooPay diverifikasi dengan PIN di server wallet. Token koneksi tersimpan per akun, bukan ditempel manual ke chat.

Artikel ini tersedia dalam: Indonesia · English

ClincooPay menghubungkan saldo dompet Clincoo dengan web Wallet milik Anda. Koneksi dibuat dari halaman dompet: masukkan alamat wallet dan PIN, lalu Clincoo memverifikasi keduanya langsung ke server wallet.

Setelah PIN cocok, Clincoo menyimpan token koneksi milik akun Anda di database. Anda tidak perlu menempel token, API key, atau secret apa pun ke dalam chat.

Untuk memutus koneksi, buka pengaturan ClincooPay dan pilih putuskan. Saldo web wallet tetap utuh; hanya hubungan salinannya yang hilang.

Kalau PIN ditolak, cek kembali PIN di aplikasi Wallet Anda. Kegagalan verifikasi tidak membuat koneksi setengah jadi, jadi aman dicoba ulang.

Seluruh verifikasi berlangsung server-side di app.clincoo.buzz. Klien hanya mengirim alamat dan PIN, tidak pernah menyimpan PIN Clincoo.
