Two-Way ClincooPay Sync: Your Web Wallet Is the Source of Truth

Clincoo reads the live balance from your web wallet and writes delta mutations with a unique txid, so no transaction is ever counted twice.

This article is available in: Indonesia · English

ClincooPay does not duplicate your balance. Your web Wallet is the source of truth, and Clincoo only reads it live.

When something changes, Clincoo sends a delta mutation to the web wallet instead of overwriting the number. The balance moves relative to its previous value.

Each mutation carries a unique txid. The wallet server rejects a repeated txid, so a mutation sent twice never adds the balance twice.

If the wallet connection fails, Clincoo shows that failure honestly. Never guess the balance from memory; always read it from the wallet page.

Transfers between Clincoo users go through the same path: the PIN is verified, the delta is sent with a txid, and both sides see a fresh balance.
