ClincooPay

Cara kerja dompet Clincoo: top-up invoice, hubungkan web wallet lewat PIN, saldo sinkron dua arah, dan langganan dari saldo, serta gateway QRIS per proyek: aktivasi, API pembuatan QR, cek status, webhook, dan tarik saldo.

Hubungkan Dompet Clincoo ke Web Wallet lewat PIN, Bukan Menempel Token

Koneksi ClincooPay diverifikasi dengan PIN di server wallet. Token koneksi tersimpan per akun, bukan ditempel manual ke chat.

Top-up Clincoo dengan Invoice Xendit: dari QRIS sampai Virtual Account

Alur top-up: ketik nominal dengan keypad, pilih metode, bayar invoice, dan saldo masuk otomatis saat status PAID.

Saldo ClincooPay Sinkron Dua Arah: Web Wallet Jadi Sumber Kebenaran

Clincoo membaca saldo live dari web wallet dan menulis mutasi delta dengan txid unik, sehingga tidak ada transaksi ganda.

Bayar Langganan Clinqoo Langsung dari Saldo ClincooPay

Paket langganan lunas dari saldo dompet, dan batas paket divalidasi server-side, bukan hanya di tampilan.

Simpan Riwayat Transaksi Clinqoo sebagai Bahan Audit Saldo

Setiap top-up dan transfer meninggalkan jejak order dengan status dan txid. Riwayat ini penentu saat saldo terasa keliru.

ClincooPay Gateway: Terima QRIS di Situs Hasil Deploy-mu

ClincooPay kini menjadi payment gateway: aktifkan sekali per proyek, terima QRIS, dana masuk ke saldo ClincooPay.

Membuat QR Pembayaran ClincooPay dari Situs Deploy-mu

Satu POST ke /api/pay dengan kunci publik proyek menghasilkan QR QRIS siap tampilkan ke pembeli.

Mengecek Status Pembayaran ClincooPay

Polling status transaksi dengan order_id: pending, paid, atau expired — langsung dari halaman publik.

Memasang Webhook Pembayaran ClincooPay

Terima notifikasi otomatis saat pembayaran sukses: pasang URL webhook di halaman Integrasi & Webhook.

Menarik Saldo ClincooPay dan Membaca Log Transaksi

Saldo dari pembayaran sukses bisa ditarik kapan saja mulai Rp 10.000. Semua riwayat tercatat di halaman Pembayaran.
