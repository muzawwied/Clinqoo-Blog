How to Set One Canonical URL with rel=canonical

A URL with and without a trailing slash, or with a utm parameter, is often treated as a different page. In editor.clincoo.buzz add a rel=canonical link that points to the single address you want indexed.

Pick one address shape

Decide https, lowercase, and whether the trailing slash stays. Every copy points at that shape, including the same page in preview.

Do not canonicalize to a 404

The canonical must return 200 and the same content. Check on app.clincoo.buzz before deploy. Do not point an article at the homepage if it has its own URL.

Match the sitemap

The sitemap URL matches the canonical. Keep the pattern on blog.clincoo.buzz so each new page does not repeat a variant.
