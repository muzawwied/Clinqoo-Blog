Short, Clear URL Slugs in a Clincoo Project

Folder and file names become the public path after deploy. Avoid index2.html and spaces.

This article is available in: Indonesia · English

After a Clincoo deploy, the path follows the file tree. halaman-saya/index.html is easier to remember than page_final_v3.html.

Use lowercase, hyphens, and words people type. Avoid spaces, stacked underscores, and temporary names.

If you rename a folder after the site is shared, old links break. Plan the slug before the first release.

Ask the AI to name new files by topic, not to rewrite the whole tree.

A speakable URL helps SEO and client messages. Clincoo does not shorten paths for you.
