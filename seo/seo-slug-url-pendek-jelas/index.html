Slug URL Pendek dan Jelas di Proyek Clincoo

Nama folder dan file menjadi path publik setelah deploy. Hindari index2.html dan spasi.

Artikel ini tersedia dalam: Indonesia · English

Setelah deploy Clincoo, path mengikuti struktur file. halaman-saya/index.html lebih mudah diingat daripada page_final_v3.html.

Pakai huruf kecil, tanda hubung, dan kata yang orang ketik. Hindari spasi, underscore beruntun, dan nama sementara.

Jika kamu mengubah nama folder setelah situs sudah dibagikan, tautan lama putus. Rencanakan slug sebelum rilis pertama.

Minta AI menamai file baru sesuai topik, bukan rewrite seluruh pohon folder.

URL yang bisa diucapkan membantu SEO dan pesan ke klien. Clincoo tidak menyingkat path untukmu.
