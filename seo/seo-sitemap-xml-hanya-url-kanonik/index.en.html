How to Build a sitemap.xml That Lists Only Canonical URLs

A sitemap full of 404s or parameters makes search waste crawl budget. In editor.clincoo.buzz list only URLs you actually want indexed.

One loc per page

Each loc uses https, lowercase, and the same shape as rel=canonical. Do not include /index.html if the canonical omits that filename.

Leave out drafts and previews

noindex pages and the draft folder stay out of the sitemap. Change lastmod only when the content actually changes, not on every save.

Link it from robots.txt

Add a Sitemap: line in robots.txt after deploy from app.clincoo.buzz. A pattern lives on blog.clincoo.buzz.
