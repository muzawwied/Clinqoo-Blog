How to Lazy-Load Images Below the Fold

Downloading every image at once slows the heading. In editor.clincoo.buzz images below the fold may use loading="lazy". The first visible image should not.

Separate the hero from the rest

The hero, logo, and first-screen image do not use lazy. Gallery images, lower cards, and footer art use loading="lazy". Keep width and height so the box does not jump when the file arrives.

Do not lazy-load the LCP image

The largest first-screen image, if deferred, is recorded late. If you are unsure, leave the browser default on that one top image.

Check the preview

On app.clincoo.buzz open the network panel, reload, and scroll. Lower images should download only as they approach. Keep this check on blog.clincoo.buzz.
