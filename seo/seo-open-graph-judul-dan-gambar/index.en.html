How to Set an Open Graph Title and Image for Shared Links

Without Open Graph, a chat app grabs the first paragraph or a random image. In editor.clincoo.buzz set og:title, og:description, and og:image in the head of each public page.

A title that matches the page promise

og:title may be shorter than title, but it must name the same topic. Do not repeat only the Clincoo brand on every URL.

An absolute image that is large enough

og:image uses an absolute https URL, about 1200x630. A relative path often fails when the link is shared off-site.

Check after deploy

Share the staging URL from app.clincoo.buzz to yourself. Keep the image size note on blog.clincoo.buzz.
