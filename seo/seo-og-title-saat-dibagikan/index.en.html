Fill Open Graph so Shared Clincoo Links Look Clean

When a link is shared in chat, the preview uses og:title and og:description. Fill both.

This article is available in: Indonesia · English

Many Clincoo pages only have a plain title. Chat apps then show a filename or a blank domain.

Add og:title, og:description, og:url, and og:image if you have a logo. The text may match the page title if it is specific.

Ask the AI to insert Open Graph meta in one file. Refuse a layout rewrite or extra share scripts.

Test by pasting the deploy URL in a private chat. If the card is still wrong, check the chat app cache, not only the file.

Clincoo ships the meta as written. A clean link card is work you do before release.
