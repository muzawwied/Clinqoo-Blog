How to Set the html lang Attribute on a Bilingual Page

Without lang, a search engine guesses the language from the first words. In editor.clincoo.buzz set html lang=id on the Indonesian version and lang=en on the English version.

One primary language per URL

Do not mix long paragraphs of two languages on the same page. A Clincoo brand snippet can stay, but the main copy follows lang.

Pair it with hreflang

alternate links for hreflang=id and hreflang=en point at each URL. x-default points at the version new visitors get.

Check in preview

On app.clincoo.buzz inspect the html element. The pattern note lives on blog.clincoo.buzz.
