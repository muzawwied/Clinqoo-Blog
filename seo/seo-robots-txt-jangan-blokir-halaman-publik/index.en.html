How to Write a robots.txt That Does Not Block Public Pages

A single Disallow: / closes the whole site. In editor.clincoo.buzz write a robots.txt that only closes the draft folder, not the homepage and articles.

Allow pages you want indexed

User-agent: * then Allow: / for public content. Disallow only paths such as /preview/ or /draft/. Do not block the CSS and images those pages use.

Separate robots.txt and noindex

robots.txt stops a fetch, it is not a remove-from-index order. A page already indexed that you want hidden needs a noindex meta, and must still be fetchable.

Test before deploy

Open /robots.txt in the app.clincoo.buzz preview. Keep the safe pattern on blog.clincoo.buzz.
