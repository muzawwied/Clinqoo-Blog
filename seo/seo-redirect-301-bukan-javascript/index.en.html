Redirect Old Clincoo URLs with 301, Not JavaScript

A location.href redirect is too late for crawlers. Use a server 301; keep meta refresh only as backup.

This article is available in: Indonesia · English

When a slug changes on editor.clincoo.buzz, crawlers still request the old URL. JS redirects are often ignored.

Set a 301 from the old path to the canonical. Make sure the chain ends at 200.

Paste the old slug list to AI and ask for redirect rules, not a window.location script.

Test with curl -I on app.clincoo.buzz. Document the slug map on blog.clincoo.buzz.
