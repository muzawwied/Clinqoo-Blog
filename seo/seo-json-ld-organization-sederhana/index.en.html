Add Simple Organization JSON-LD on a Clincoo Site

Structured data helps search engines understand the brand. Add a short Organization JSON-LD block on the Clincoo home page.

This article is available in: Indonesia · English

Title and meta description do not describe the organization. An Organization JSON-LD block on the home page states name, url, and logo without changing the visible layout.

Paste one script type="application/ld+json" in the head or before the home page body close. Set @context to schema.org, @type Organization, name to the brand, url to the Clincoo production domain, and logo to a PNG in assets. Do not invent an address or phone you have not verified.

One block on the home page is enough for a small site. Do not copy five conflicting schema types. Validate with the Rich Results Test after you deploy the subdomain, not only in the editor.

Keep the JSON-LD name aligned with the brand title and visible text. A different name in markup and in the hero makes the entity look uncertain.

Update the url if you move domains. JSON-LD that still points at an old subdomain or a preview page fights the canonical link you already set.
