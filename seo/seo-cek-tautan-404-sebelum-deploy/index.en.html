How to Check Internal Links for 404 before Deploy

A link to a renamed file still looks blue, then ends in a 404. In editor.clincoo.buzz collect internal hrefs and open each one in preview before deploy.

Separate internal and outbound

An href that starts with / or has no protocol belongs to the site. An https href to another domain is noted separately. Do not treat a failed outbound link as a deploy bug.

Match folder and case

index.html in another folder needs the right path. One capital letter is enough for a 404 on a case-sensitive host. The trailing slash should match canonical.

Check the preview

On app.clincoo.buzz click each main link. Expect status 200 before the deploy button. Keep the checklist on blog.clincoo.buzz.
