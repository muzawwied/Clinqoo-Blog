Internal Links between Pages in a Clincoo Project

Pages that never link to each other stay hard to find. Connect home, services, and contact.

This article is available in: Indonesia · English

Many Clincoo projects have extra HTML that opens only if someone guesses the path. The navbar points at one page; the rest are orphans.

Add the same relative links in the menu: home, content, contact. Use meaningful link text, not click here.

After you add a page, update the menu in every layout that uses it. One shared navbar file is safer than copied markup.

Ask the AI only to insert a menu item, not to design a new scripted nav.

Internal links help visitors and search engines crawl the site you deploy from Clincoo.
