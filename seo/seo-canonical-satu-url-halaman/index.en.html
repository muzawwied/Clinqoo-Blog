Set a Canonical so Each Clincoo Page Has One URL

If a page opens at several paths, pick one canonical URL before you share it.

This article is available in: Indonesia · English

After a Clincoo deploy, the same page may open with and without index.html. Search engines can treat those as two documents.

Add a rel=canonical link in the head that points at the URL you want to promote. Match the link you send to clients.

Do not let the AI add a canonical to an example domain or another page. Name the file and the full URL.

After release, view page source on the subdomain. The canonical should be https and free of random query parameters.

Clincoo does not write canonicals for you. One URL per piece of content is your decision.
