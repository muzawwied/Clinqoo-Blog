How to Set Image Width and Height so the Layout Does Not Jump

An image without dimensions pushes the text below it when the file arrives. In editor.clincoo.buzz set width and height to the real ratio, not a random pair.

Use the intrinsic size

If the photo is 1200×800, write width="1200" height="800". CSS may shrink it with max-width: 100% and height: auto. Do not drop the attributes just because the layout already uses percent.

Do not fake the ratio

Width 100 and height 100 on a wide photo reserves the wrong box, then corrects itself. The attribute ratio must match the file. A decorative image still needs an empty alt, not missing dimensions.

Check the preview

On app.clincoo.buzz reload on a slow network. Text under the image should not shift. Keep this pattern on blog.clincoo.buzz.
