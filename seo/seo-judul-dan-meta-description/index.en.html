Write a Title and Meta Description before You Deploy from Clincoo

Search engines read the tab title and the description. Fill both on every Clincoo page.

This article is available in: Indonesia · English

A freshly deployed Clincoo page often still uses a generic title such as Index or the file name. Tab labels and search results see that before the hero.

Fill the title element with a short, specific phrase that includes the project name. Write a one or two sentence meta description of the page, not an empty slogan.

Ask the AI only to add title and meta in the head of the page you name. Do not let it rewrite the whole layout.

After deploy, view page source on the subdomain. Make sure each URL has a unique title. Duplicate titles make search results look the same.

Basic SEO on Clincoo is the HTML you control. There is no hidden panel that fills meta for you.
