How to Order Headings Without Skipping Levels

Headings are an outline, not a font size. On editor.clincoo.buzz do not jump from h1 to h4 just to get smaller text.

Drop one level when you enter a subsection

After an h2, details use h3. Return to h2 for a new topic at the same level.

Do not use a heading as a button label

Button text stays a span or the button label. Headings are only for sections. Test the outline in the preview on app.clincoo.buzz.

Match the heading language to the body

A heading that promises steps must be followed by steps. Note the pattern on blog.clincoo.buzz.
