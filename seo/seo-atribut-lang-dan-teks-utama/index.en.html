Set the HTML lang to Match Clincoo Page Copy

The lang attribute on the html element helps screen readers and search engines. Match it to the text.

This article is available in: Indonesia · English

Templates often leave lang=en while the copy is Indonesian, or the reverse.

Change the lang attribute on the page you release. If you keep a separate English file, that file uses lang=en.

Do not mix long passages of two languages with no marker. Readers and crawlers need a clear primary language.

Ask the AI only to change lang and check the title. Do not let it translate the whole site unasked.

Clincoo does not detect language at deploy. Markup follows what you save.
