Cara Jaga URL Publik Huruf Kecil tanpa Parameter Pelacak

URL /Harga dan /harga?utm=x sering dianggap dua halaman. Di editor.clincoo.buzz tautan internal memakai huruf kecil, tanda hubung, dan tanpa parameter pelacak.

Satu bentuk kanonis

Pilih /harga/ atau /harga, lalu pakai bentuk itu di semua tautan dan canonical. Jangan campur huruf besar di menu. Parameter utm boleh pada tautan kampanye keluar, bukan pada href internal.

Canonical menunjuk bentuk bersih

Jika pengunjung datang dengan query pelacak, canonical tetap ke URL tanpa query. Jangan menaruh utm di canonical.

Cek di preview

Di app.clincoo.buzz klik menu dan baca href. Semuanya huruf kecil dan tanpa query. Contoh pola ada di blog.clincoo.buzz.
