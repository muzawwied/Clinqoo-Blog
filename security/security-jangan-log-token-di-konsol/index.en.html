Do Not Log Tokens or Cookies in the Clincoo Console

Leftover console.log ships to production. Anyone who opens DevTools can read a session key.

This article is available in: Indonesia · English

In editor.clincoo.buzz, debug leftovers often stay: console.log(token), console.log(document.cookie), or a full user JSON. That file deploys to app.clincoo.buzz.

Open the public page, then DevTools, Console tab. If a session object or Bearer string appears, remove that call before release. Replace it with a short status that has no secret value.

Search the project for console.log, console.debug, and debugger. Keep only logs that name a step, such as form sent.

When you ask an AI for help, paste the error text, not the token. Tell the assistant to refuse any suggestion that prints all of localStorage.

Clincoo publishes the HTML and JS you save. The console is not a secret archive.
