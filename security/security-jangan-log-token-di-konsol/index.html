Jangan Log Token atau Cookie di Console Clincoo

console.log sisa debug ikut terbit. Pengunjung yang membuka DevTools bisa membaca kunci sesi.

Artikel ini tersedia dalam: Indonesia · English

Di editor.clincoo.buzz, sisa debug sering tertinggal: console.log(token), console.log(document.cookie), atau JSON user lengkap. File itu ikut deploy ke app.clincoo.buzz.

Buka halaman publik, lalu DevTools, tab Console. Jika objek sesi atau string Bearer muncul, hapus panggilan itu sebelum rilis. Ganti dengan pesan status pendek tanpa nilai rahasia.

Cari di proyek: console.log, console.debug, dan debugger. Kecualikan log yang hanya menulis nama langkah, misalnya form terkirim.

Saat minta bantuan AI, tempel pesan error, bukan nilai token. Minta asisten menolak saran yang mencetak localStorage utuh.

Clincoo menerbitkan HTML dan JS yang kamu simpan. Log konsol bukan tempat arsip rahasia.
