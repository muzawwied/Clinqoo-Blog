Set Cookie Clincoo dengan SameSite dan Secure

Cookie sesi tanpa SameSite dan Secure mudah ikut terbawa permintaan silang. Tulis atributnya di tempat cookie dibuat.

Artikel ini tersedia dalam: Indonesia · English

Form login atau preferensi di app.clincoo.buzz kadang menulis document.cookie tanpa atribut. Browser lama mengirim cookie itu ke permintaan pihak ketiga.

Jika cookie harus ada, tulis Secure dan SameSite=Lax untuk sesi biasa, atau Strict jika tidak perlu ikut navigasi dari situs lain. Tambahkan HttpOnly hanya jika cookie dibuat server, bukan dari JS.

Jangan simpan token API di cookie yang bisa dibaca skrip halaman. Simpan preferensi tampilan saja di klien.

Uji di Application, panel Cookies, setelah pratinjau. Kolom Secure dan SameSite harus terisi. Minta AI meninjau satu baris set cookie, bukan seluruh auth.

Atribut cookie tidak menggantikan validasi server. Ia mengurangi permintaan yang tidak kamu maksud.
