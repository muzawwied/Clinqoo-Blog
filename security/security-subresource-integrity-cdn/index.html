Pasang Subresource Integrity pada Skrip CDN Clincoo

Skrip dari CDN bisa berubah tanpa kamu sadari. Atribut integrity menolak berkas yang hash-nya tidak cocok.

Artikel ini tersedia dalam: Indonesia · English

Halaman Clincoo kadang memuat font loader atau pustaka kecil dari CDN. Jika domain itu disusupi, skrip baru ikut jalan di situsmu.

Hitung hash SHA-384 berkas, lalu tulis integrity sha384- dan crossorigin anonymous pada tag script atau link. Pin versi di URL, jangan pakai latest.

Saat rilis, buka Network di pratinjau app.clincoo.buzz. Jika konsol menulis integrity mismatch, jangan hapus atribut. Ganti hash setelah kamu unduh berkas resmi.

Minta AI menghitung langkah SRI, bukan menempel CDN acak. Tolak rewrite yang menambah tiga pustaka baru.

SRI tidak melindungi skrip inline. Untuk itu, andalkan CSP dan review sebelum deploy.

MDN Subresource IntegritySRI lets browsers verify that fetched resources are delivered without unexpected manipulation.
