Add Subresource Integrity to Clincoo CDN Scripts

A CDN script can change without you noticing. The integrity attribute rejects a file whose hash does not match.

This article is available in: Indonesia · English

A Clincoo page sometimes loads a font loader or a small library from a CDN. If that domain is compromised, the new script runs on your site.

Hash the file with SHA-384, then set integrity sha384- and crossorigin anonymous on the script or link tag. Pin the version in the URL; do not use latest.

On release, open Network in the app.clincoo.buzz preview. If the console reports an integrity mismatch, do not delete the attribute. Replace the hash after you download the official file.

Ask the AI for the SRI steps, not a random CDN paste. Refuse a rewrite that adds three new libraries.

SRI does not cover inline scripts. For those, rely on CSP and a review before deploy.
