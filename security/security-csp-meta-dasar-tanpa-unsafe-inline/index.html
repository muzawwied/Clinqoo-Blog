Pasang CSP Dasar di Meta tanpa unsafe-inline di Clincoo

Content-Security-Policy menahan skrip asing. Mulai ketat, longgarkan hanya domain yang benar-benar dipakai.

Artikel ini tersedia dalam: Indonesia · English

Halaman hasil editor.clincoo.buzz sering memuat satu skrip analitik plus embed. Tanpa CSP, browser menerima skrip dari domain mana pun yang berhasil tertempel di HTML.

Tambah meta Content-Security-Policy di head: default-src self, script-src self, style-src self unsafe-inline dulu hanya jika CSS inline masih ada, img-src self data https. Hindari script-src unsafe-inline kecuali tidak ada jalan lain.

Uji di Chrome DevTools tab Console. Pelanggaran CSP muncul sebagai error jelas. Salin pesan itu ke asisten AI di app.clincoo.buzz beserta cuplikan head.

Kalau widget pihak ketiga putus, izinkan domain itu satu per satu — jangan kembali ke wildcard. Deploy ulang ke blog.clincoo.buzz setelah meta stabil.
