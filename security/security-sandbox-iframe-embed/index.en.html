Sandbox Iframe Embeds on Clincoo Pages

A map or video embed without sandbox can run scripts and open popups. Limit permissions per widget.

This article is available in: Indonesia · English

Templates in editor.clincoo.buzz often paste map, video, or form iframes. Without a sandbox attribute, that document is nearly a page of its own.

Start with an empty sandbox, then add only tokens you need: allow-scripts for a video player, allow-popups only if the widget fails without it. Do not combine allow-scripts and allow-same-origin unless the vendor documents it.

Test the preview at 360px and desktop. If the embed is blank, read the console error, then add one token. Do not remove sandbox.

Ask the AI to explain each token before you apply it. Refuse a suggestion that copies an admin iframe or a third-party login page.

An embed is still third-party content. Sandbox limits the blast radius if the widget script changes.
