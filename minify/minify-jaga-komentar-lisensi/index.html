Jaga Komentar Lisensi saat Minify CSS dan JS Clincoo

Komentar lisensi di berkas vendor wajib tetap ada. Penghapusan buta saat minify bisa melanggar syarat pakai library.

Artikel ini tersedia dalam: Indonesia · English

Banyak template Clincoo memuat library CSS atau JS dengan komentar lisensi di baris pertama. Alat minify yang menghapus semua komentar ikut membuang pemberitahuan itu.

Sebelum memadatkan berkas di editor.clincoo.buzz, tandai file vendor. Jangan minify file pihak ketiga jika lisensinya meminta komentar tetap utuh.

Jika kamu tetap minify, pilih opsi yang menyimpan komentar berawalan /*! atau @license. Uji pratinjau setelahnya agar selector dan fungsi tidak ikut terpotong.

Simpan salinan sumber di folder terpisah. Saat library diperbarui, bandingkan komentar lisensi lama dan baru sebelum menimpa berkas produksi.

Minta asisten AI hanya merapikan berkas milikmu, bukan vendor.min.js. Satu file vendor yang diubah diam-diam sulit dilacak saat audit.

Clincoo menayangkan file yang kamu unggah. Menjaga komentar lisensi adalah bagian dari rilis yang rapi, bukan detail kosmetik.
