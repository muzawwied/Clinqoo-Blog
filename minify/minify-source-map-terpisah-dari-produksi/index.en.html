Keep Source Maps Out of the Clincoo Production Bundle

A published source map exposes the original source. Keep maps local and do not upload them to public hosting.

This article is available in: Indonesia · English

After minify on editor.clincoo.buzz, .map files often ride along in the upload folder. Visitors can then open source that was not cleaned.

Generate source maps only for the local build. Remove the sourceMappingURL comment from production files before deploy.

Do not commit maps to a public repository. Add *.map to the upload ignore list, then check the file list in the deploy package.

If a production stack trace needs a trail, send the map to an internal error tool, not to the same CDN as public assets.

Test the page on app.clincoo.buzz and confirm Network does not load a .map. Record this rule on blog.clincoo.buzz.
