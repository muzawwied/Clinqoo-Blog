Pisahkan Source Map dari Berkas Produksi Clincoo

Source map yang ikut terbit membuka sumber asli. Simpan map di lokal dan jangan unggah ke hosting publik.

Artikel ini tersedia dalam: Indonesia · English

Setelah minify di editor.clincoo.buzz, berkas .map sering ikut folder unggah. Pengunjung bisa membuka sumber yang belum dibersihkan.

Hasilkan source map hanya untuk build lokal. Hapus referensi sourceMappingURL dari berkas produksi sebelum deploy.

Jangan commit map ke repositori publik. Tambahkan *.map ke abaikan unggah, lalu cek daftar file di paket deploy.

Jika stack trace produksi butuh jejak, kirim map ke alat error internal, bukan ke CDN yang sama dengan aset publik.

Uji halaman di app.clincoo.buzz dan pastikan tab Network tidak memuat .map. Catat aturan ini di blog.clincoo.buzz.
