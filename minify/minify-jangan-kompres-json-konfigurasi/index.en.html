Do Not Minify Clincoo JSON Config Files

Config JSON run through a minifier often breaks on comments or trailing commas. Keep it intact and valid.

This article is available in: Indonesia · English

On editor.clincoo.buzz, one pipeline sometimes swallows manifest.json, article data, and scripts. JSON is not a JS minify target.

A JSON parser rejects comments and trailing commas. A minifier that treats the file as JS can change the shape or drop keys.

Split the step: minify only .js and .css. Copy .json as-is after a JSON.parse check.

Test app.clincoo.buzz after the build. If the article list is empty, compare the source JSON with the output.

When stuck, send the AI the JSON fragment that failed to parse, not the whole compressed bundle.
