Jangan Minify Berkas JSON Konfigurasi Clincoo

JSON konfigurasi yang digabung minify sering pecah karena komentar atau koma akhir. Biarkan utuh dan valid.

Artikel ini tersedia dalam: Indonesia · English

Di editor.clincoo.buzz, pipeline yang sama kadang menelan manifest.json, data artikel, dan skrip. JSON bukan target minify JS.

Parser JSON menolak komentar dan koma di akhir. Minifier yang menganggap berkas itu JS bisa mengubah struktur atau menghapus kunci.

Pisahkan langkah: minify hanya .js dan .css. Salin .json apa adanya setelah dicek JSON.parse.

Uji app.clincoo.buzz setelah build. Jika daftar artikel kosong, bandingkan berkas JSON sumber dan hasil.

Saat stuck, kirim ke AI potongan JSON yang gagal parse, bukan seluruh bundle yang sudah dikompres.
