Keep CSS Custom Properties Intact when Minifying Clincoo

Minifiers that rename --brand-color break themes and dark mode. Compress values, do not rename variables.

This article is available in: Indonesia · English

Custom properties such as --brand-color and --card-gap are a contract across CSS files. If a minifier renames those tokens, every rule that uses var(--brand-color) stops working even though the file is smaller.

In a Clincoo project, tokens are reused across pages and media queries. One renamed token can break contrast, radius, and dark mode at once. Check minify output: names that start with -- must stay the same.

Safe compression covers whitespace, non-license comments, and repeated values. Do not enable “mangle CSS variables” unless you also rewrite every HTML and JS reference to the same tokens.

After minify, open the Clincoo preview and toggle theme if you have one. Odd button colors or collapsed spacing usually mean a missing token. Diff the source against the minified file.

Keep the source CSS. A packed file is hard to edit when you add a new token. Minify is a release step, not daily work in the editor.
