Jaga Custom Properties CSS saat Minify Clincoo

Alat minify yang merename --warna-merek memutus tema dan dark mode. Padatkan nilai, jangan ganti nama variabel.

Artikel ini tersedia dalam: Indonesia · English

Custom properties seperti --warna-primer dan --spasi-kartu adalah kontrak antara file CSS. Kalau alat minify merename token itu, setiap aturan yang memakai var(--warna-primer) berhenti bekerja meski file lebih kecil.

Di proyek Clincoo, token biasanya dipakai ulang di beberapa halaman dan di media query. Satu nama yang berubah memutus kontras, radius, dan dark mode sekaligus. Periksa output minify: nama yang diawali -- harus tetap sama.

Yang aman dipadatkan adalah spasi, komentar non-lisensi, dan nilai yang berulang. Jangan aktifkan opsi “mangle CSS variables” kecuali kamu juga menulis ulang seluruh HTML dan JS yang mereferensikan token yang sama.

Setelah minify, buka pratinjau Clincoo lalu toggle tema jika ada. Jika tombol berubah warna aneh atau spacing runtuh, bandingkan berkas sumber dengan hasil padat dan cari token yang hilang.

Simpan berkas CSS sumber. File yang sudah dipadatkan sulit dilacak saat token baru ditambah. Minify adalah langkah rilis, bukan cara kerja harian di editor.
