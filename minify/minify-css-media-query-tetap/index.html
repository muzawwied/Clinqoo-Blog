Jaga Media Query saat Minify CSS Clincoo

Alat minify yang merapikan @media secara salah memutus layout HP. Uji breakpoint setelah padatkan.

Artikel ini tersedia dalam: Indonesia · English

Template Clincoo hampir selalu memakai @media untuk navigasi dan grid. Minify yang menggabungkan atau memindahkan blok @media bisa membuat menu desktop muncul di ponsel, atau sebaliknya.

MDN menjelaskan media queries sebagai syarat terpisah dari aturan biasa. Jangan biarkan alat menghapus kurung, operator and, atau nilai min-width. Satu karakter hilang cukup untuk membatalkan seluruh breakpoint.

web.dev menekankan uji pada lebar yang nyata. Setelah minify style.css di editor.clincoo.buzz, buka pratinjau HP, tablet, dan desktop. Cek hamburger, kolom kartu, dan ukuran huruf.

Tolak saran AI yang “menyederhanakan” beberapa @media menjadi satu. Penghematan baris tidak sebanding dengan layout yang pecah di app.clincoo.buzz.

Jika ragu, minify hanya di luar blok @media. Simpan sumber CSS. Kembalikan file utuh bila pratinjau mobile tidak sama dengan sebelum minify.
