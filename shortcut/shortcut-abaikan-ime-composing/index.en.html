Ignore Clincoo Shortcuts while the IME Is Still Composing

Enter or Esc while an IME is open commits a half-finished character. Check event.isComposing before running a shortcut.

Artikel ini tersedia dalam: Indonesia · English

The Clincoo editor accepts languages that use an IME: Japanese, Korean, Chinese, or accented Latin. An Enter-to-submit shortcut often swallows the IME candidate before the user picks a character.

On keydown, return early if event.isComposing or event.keyCode === 229. Only after the IME closes should you save, search, or close a modal. Do not preventDefault while composing.

Test with an IME keyboard in editor.clincoo.buzz: type one syllable, press Enter to confirm, then Enter again for the action. The action must run only on the second press.

Document this on the shortcut help page. People typing non-Latin languages need to know why the first Enter does not submit the form.

Clincoo runs the listener you save. Respecting the IME keeps input on app.clincoo.buzz intact without disabling shortcuts for everyone else.
