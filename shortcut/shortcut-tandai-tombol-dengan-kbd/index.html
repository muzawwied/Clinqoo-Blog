Tandai Nama Tombol Shortcut Clincoo dengan Elemen kbd

Teks 'Ctrl + S' polos sulit dipindai. Elemen kbd menandai kombinasi tombol untuk pembaca dan CSS.

Artikel ini tersedia dalam: Indonesia · English

Halaman bantuan shortcut di situs Clincoo sering menulis kombinasi sebagai teks biasa. Pembaca layar tidak membedakannya dari kalimat, dan mata sulit menemukan tombol di paragraf panjang.

Bungkus setiap nama tombol dengan kbd. Contoh: Ctrl + S. Semantik ini sudah ada di HTML; kamu hanya perlu gaya CSS kecil agar menyerupai tuts.

Jangan meniru bentuk tuts hanya dengan span tanpa makna. Jika kamu butuh aria-keyshortcuts di kontrol sungguhan, pasang atribut itu terpisah — kbd untuk dokumentasi, atribut untuk widget.

Uji kontras background kbd terhadap teks. Di mode gelap, border tipis lebih aman daripada bayangan tebal yang memecah fokus.

Dokumentasi yang memakai kbd konsisten memudahkan terjemahan English/Indonesia: nama tombol tetap, kalimat di sekitarnya yang berubah.
