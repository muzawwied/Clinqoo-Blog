Mark Clincoo Shortcut Key Names with the kbd Element

Plain Ctrl + S text is hard to scan. The kbd element flags key combos for readers and CSS.

This article is available in: Indonesia · English

Clincoo shortcut help pages often write combos as plain text. Screen readers do not separate them from sentences, and eyes miss keys in a long paragraph.

Wrap each key name in kbd. Example: Ctrl + S. The semantics already exist in HTML; you only need light CSS so keys look like keys.

Do not fake keycaps with meaningless spans. If a real control needs aria-keyshortcuts, set that attribute separately — kbd is for docs, the attribute is for widgets.

Check kbd background contrast against body text. In dark mode, a thin border is safer than a heavy shadow that steals focus.

Consistent kbd markup also helps bilingual pages: key names stay put while the surrounding sentence changes.
