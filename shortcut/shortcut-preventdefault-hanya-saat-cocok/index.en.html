Call Clincoo Shortcut preventDefault Only when the Combo Actually Matches

preventDefault on every keydown kills normal typing. Limit it to the combination you handle.

This article is available in: Indonesia · English

A Clincoo shortcut listener that calls event.preventDefault() at the top of the handler stops letters from appearing in inputs. Users think the editor is broken.

In editor.clincoo.buzz, check event.key, metaKey, and ctrlKey first. Only if the combo matches, call preventDefault and run the action.

Ignore event.repeat so holding a key does not fire the action many times. Also skip INPUT, TEXTAREA, or contenteditable unless the shortcut is meant for that field.

Ask AI to add one guard in the existing listener. Do not generate a new keymap that overrides Ctrl+C or Ctrl+V.

Test typing in the contact form. Selective shortcuts keep app.clincoo.buzz editable from the keyboard.
