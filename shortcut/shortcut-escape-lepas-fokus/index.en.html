Release Clincoo Editor Focus with Escape without Closing the Tab

Escape that both closes a modal and blurs focus leaves users lost. One action per press.

This article is available in: Indonesia · English

On editor.clincoo.buzz, Escape closes a panel then blurs to body. Users lose the caret.

If an overlay is open, Escape only closes it. Otherwise blur the active element.

Do not call window.close. Paste the handler order to AI.
