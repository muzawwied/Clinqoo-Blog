Ask Clincoo AI to Shrink Images without Breaking Layout

Name the image path, the display width, and the desired format. The AI can suggest width, height, and lazy loading.

This article is available in: Indonesia · English

An oversized hero image often makes the Clincoo preview slow. Name the file in the assets folder and the width where it is shown.

Ask the AI to add width and height that match the ratio, plus loading="lazy" for images below the fold.

Do not ask for a mass conversion of the whole project in one request. Do one image, check the preview, then continue.

If the AI suggests an external URL, reject it. Keep assets in the project so deploy does not depend on a hotlink.

After the swap, compare file size before and after. Note the numbers in chat so the next change stays measurable.
