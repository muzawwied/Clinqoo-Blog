One AI Session per Clinqoo Project, with No Mixed Context

The AI chat is attached to the active project, carries the last few messages of context, and its quota is counted per account on the server.

This article is available in: Indonesia · English

Every Clinqoo project has its own AI conversation. Files and instructions from one project never leak into another.

The AI carries context from the last few messages, so follow-ups like fix it again still land without you repeating everything.

Chat quota is counted per account per day on the server. You do not need your own API key; the model and its cost are handled by Clinqoo.

If the daily quota runs out, wait for the reset. Do not split one big request into many chats to dodge the limit.

Start a new project for a genuinely different idea. A long, mixed conversation makes the AI lose direction faster.
