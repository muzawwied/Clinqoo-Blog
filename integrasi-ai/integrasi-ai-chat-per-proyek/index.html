Satu Sesi AI per Proyek di Clinqoo, Konteksnya Tidak Tercampur

Chat AI melekat pada proyek aktif, membawa konteks beberapa pesan terakhir, dan kuotanya dihitung per akun di server.

Artikel ini tersedia dalam: Indonesia · English

Setiap proyek Clinqoo punya percakapan AI-nya sendiri. File dan instruksi di proyek satu tidak bocor ke proyek lain.

AI membawa konteks dari beberapa pesan terakhir percakapan, jadi permintaan lanjutan seperti perbaiki lagi tetap nyambung tanpa Anda mengulang semuanya.

Kuota chat dihitung per akun per hari di server. Anda tidak perlu menyiapkan API key sendiri; model dan biayanya sudah urusan Clinqoo.

Kalau kuota harian habis, tunggu resetnya. Jangan memecah satu permintaan besar menjadi banyak chat untuk mengakali batas.

Mulai proyek baru untuk ide yang benar-benar berbeda. Percakapan yang panjang dan campur aduk membuat AI kehilangan arah lebih cepat.
