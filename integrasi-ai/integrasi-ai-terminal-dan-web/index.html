AI Clinqoo Bisa Menjalankan Terminal Linux dan Membaca Halaman Web

Tool terminal persisten, pencarian web, pembaca URL, dan screenshot memperluas kemampuan AI di luar file proyek.

Artikel ini tersedia dalam: Indonesia · English

AI Clincoo bisa menjalankan perintah di terminal Linux miliknya. Sesi bertahan beberapa menit, jadi file dan tool yang terpasang tetap ada untuk perintah berikutnya.

Ini bergua untuk menguji API eksternal, memasang paket, atau memverifikasi logika dengan data nyata sebelum ditulis ke file proyek.

AI juga bisa mencari di web dan membaca isi sebuah URL. Gunakan ini untuk data terbaru, bukan memaksa AI menebak dari ingatannya.

Saat Anda ingin melihat tampilan sebuah situs, AI bisa mengambil screenshot-nya. Screenshot jelas lebih berguna daripada deskripsi panjang.

Terminal ini terisolasi: ia tidak melihat file workspace atau secret platform. AI akan meminta isi file tertentu bila diperlukan di dalam terminal.
