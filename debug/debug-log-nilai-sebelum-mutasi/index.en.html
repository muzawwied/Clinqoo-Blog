Log Clincoo State Values before Mutation

Changing an object then printing it makes the log lie. Copy the value before you change it.

This article is available in: Indonesia · English

On editor.clincoo.buzz, console.log(obj) after obj.x = 2 also shows the new value on the earlier log row.

Print JSON.stringify or copy primitives before mutation. Do not trust a live object expand in the Console.

One log before setState is enough. Do not spam logs in a render loop. Paste two log lines to AI.

Test the save flow on app.clincoo.buzz. Record the log pattern on blog.clincoo.buzz.
