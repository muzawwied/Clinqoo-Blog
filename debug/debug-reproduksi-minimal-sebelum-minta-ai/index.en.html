Minimal Reproduction of a Clincoo Bug before You Ask the AI

Write the short steps that always trigger the bug. Without a reproduction, you and the AI fix different symptoms.

This article is available in: Indonesia · English

Many AI chats start with “the button is broken.” That is not a report. A useful report names the page, the gesture, and the visible result—including any console message.

Open the Clincoo preview. Repeat the bug until you can write three lines: open this URL, click this element, see this result. If a fourth step is random, isolate it in a private window first.

Copy the full red error from the Console or the Network status. Paste it to the AI with the file named in the stack. Do not ask for a full script.js rewrite.

After the AI proposes a patch, rerun the same steps. If the bug vanishes only after a hard refresh, the cause is cache or an asset path, not click logic.

A minimal reproduction saves tokens and prevents regressions. Clincoo runs the files you save; the step list is the contract between you, the browser, and the assistant.
