Pakai light-dark() dan color-scheme untuk Token Clincoo

Mode gelap yang hanya menukar hex di media query mudah drift. color-scheme plus light-dark() menjaga pasangan warna tetap berpasangan.

Artikel ini tersedia dalam: Indonesia · English

Halaman Clincoo yang mendukung tema gelap sering menduplikasi seluruh palet di media query prefers-color-scheme. MDN color-scheme: light dark memberitahu browser untuk mewarnai kontrol formulir native sesuai tema.

Fungsi CSS light-dark(warnaTerang, warnaGelap) memilih nilai berdasarkan skema yang aktif. Simpan token: --teks: light-dark(#111, #f4f4f4); --latar: light-dark(#fff, #121212);

Uji di sistem terang dan gelap plus mode paksa di DevTools. Kontras teks body harus lolos AA. Jangan andalkan warna semata untuk status sukses atau error.

Jika AI menulis hex baru di komponen, kembalikan ke token light-dark agar kartu, header, dan footer tidak pecah.

Dokumentasikan pasangan token di komentar CSS. Satu sumber kebenaran lebih aman daripada tiga file tema terpisah.

Sumber: MDN light-dark(), MDN color-scheme, web.dev color-scheme.
