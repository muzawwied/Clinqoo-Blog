Use light-dark() and color-scheme for Clincoo Tokens

Dark mode that only swaps hex inside a media query drifts easily. color-scheme plus light-dark() keeps pairs together.

Indonesia · English

Clincoo pages that support a dark theme often duplicate the whole palette in a prefers-color-scheme media query. MDN color-scheme: light dark tells the browser to paint native form controls for the theme.

The CSS light-dark(lightColor, darkColor) function picks a value from the active scheme. Store tokens: --teks: light-dark(#111, #f4f4f4); --latar: light-dark(#fff, #121212);

Test in light and dark system settings plus DevTools forced mode. Body text contrast must pass AA. Do not rely on color alone for success or error status.

If the AI writes a new hex on a component, put it back on a light-dark token so cards, header, and footer stay aligned.

Document token pairs in a CSS comment. One source of truth is safer than three separate theme files.

Sources: MDN light-dark(), MDN color-scheme, web.dev color-scheme.
