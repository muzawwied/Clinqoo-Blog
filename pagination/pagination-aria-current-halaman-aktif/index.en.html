Mark the Active Clincoo Page with aria-current

A pager without aria-current makes a screen reader count links with no position.

This article is available in: Indonesia · English

On editor.clincoo.buzz, page 3 looks bold visually but is not announced to a screen reader.

Set aria-current="page" on the active link. Leave the others unset. Wrap the pager in a labeled nav.

Paste the pager markup to AI. Ask for ARIA attributes, not a new design.

Test Tab plus a screen reader on app.clincoo.buzz. Write the checklist on blog.clincoo.buzz.
