Clamp a Clincoo Page Number beyond the Total

A page=99 URL on a 3-page list must not become a silent 404.

This article is available in: Indonesia · English

An old link to editor.clincoo.buzz?page=99 still opens after projects were deleted.

If the API returns totalPages, move to min(page, totalPages). Do not render an empty list with no explanation.

Update the URL after the clamp so a refresh does not repeat the wild number.

Ask AI for one clamp function. Test a broken link on app.clincoo.buzz. Write the rule on blog.clincoo.buzz.
