Pick Offset or Cursor for a Clincoo Project List

Offset is easy but jumps when new rows arrive. A cursor stays stable on a changing list.

This article is available in: Indonesia · English

A project list on app.clincoo.buzz shifts if page=2 uses offset while a new draft is inserted on top.

Use offset only for rarely changed archives. For the editor.clincoo.buzz feed, store the last item id as a cursor.

Do not mix both modes on one endpoint. Paste the API query to AI and ask for one schema.

Test: add a new item then change page. Order must not jump. Note it on blog.clincoo.buzz.
