Pilih Offset atau Cursor untuk Daftar Proyek Clincoo

Offset mudah tapi meloncat saat data baru masuk. Cursor lebih stabil untuk daftar yang sering berubah.

Artikel ini tersedia dalam: Indonesia · English

Daftar proyek di app.clincoo.buzz bergeser jika page=2 memakai offset sementara draf baru disisip di atas.

Pakai offset hanya untuk arsip yang jarang berubah. Untuk feed editor.clincoo.buzz, simpan id cursor item terakhir.

Jangan campur dua mode di satu endpoint. Tempel query API ke AI dan minta satu skema.

Uji: tambah item baru lalu pindah halaman. Urutan tidak boleh loncat. Catat di blog.clincoo.buzz.
