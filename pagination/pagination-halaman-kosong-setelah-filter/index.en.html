Handle an Empty Clincoo Page after a Tight Filter

A filter that leaves page=5 with no rows looks like a data bug.

This article is available in: Indonesia · English

A user on editor.clincoo.buzz opens page 5 then tightens the filter. The API returns an empty array.

If the total changes and the page is out of range, reset to page 1 or the last valid page.

Show a short empty state, not an endless spinner. Explain that the filter is too tight.

Paste the filter handler to AI. Test on app.clincoo.buzz and note it on blog.clincoo.buzz.
