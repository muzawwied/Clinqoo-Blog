Tangani Halaman Kosong Clincoo setelah Filter Ketat

Filter yang meninggalkan page=5 tanpa baris terlihat seperti bug data.

Artikel ini tersedia dalam: Indonesia · English

Pengguna di editor.clincoo.buzz membuka halaman 5 lalu mempersempit filter. API mengembalikan array kosong.

Jika total berubah dan page di luar jangkauan, reset ke halaman 1 atau ke halaman terakhir yang valid.

Tampilkan empty state singkat, bukan spinner abadi. Jelaskan bahwa filter terlalu ketat.

Tempel handler filter ke AI. Uji di app.clincoo.buzz dan catat di blog.clincoo.buzz.
