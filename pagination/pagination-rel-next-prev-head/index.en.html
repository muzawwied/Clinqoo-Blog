Add rel=next and rel=prev in the Clincoo List Head

A list page without rel next/prev makes crawlers treat each page URL as an unordered document.

This article is available in: Indonesia · English

Clincoo template archives on page=2 are often indexed with no link to page=1. Crawlers miss the order.

Add link rel=prev and rel=next in the head for the current page number. Drop the unused rel at the ends.

Keep existing query params. Do not invent a canonical that strips filters.

Ask AI: paste the head HTML plus the page URL. Request only the two rel links.

Check on editor.clincoo.buzz then the blog.clincoo.buzz sitemap so inner pages are not orphans.
