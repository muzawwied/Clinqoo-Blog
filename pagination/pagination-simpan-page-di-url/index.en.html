Keep the Clincoo Page Number in the URL Query

A page 4 that vanishes on refresh forces users to start over.

This article is available in: Indonesia · English

On editor.clincoo.buzz, changing page only mutates JS state. A refresh returns to page 1.

Write ?page=4 or ?cursor=id in the URL. Read the query on load. Do not rely on tab memory alone.

Paste the list router to AI. Ask for URL sync, not a new library.

Test sharing an app.clincoo.buzz link in another tab. Note the result on blog.clincoo.buzz.
