Simpan Nomor Halaman Clincoo di Query URL

Halaman 4 yang hilang saat refresh membuat pengguna mengulang dari awal.

Artikel ini tersedia dalam: Indonesia · English

Di editor.clincoo.buzz, ganti halaman hanya mengubah state JS. Refresh mengembalikan ke halaman 1.

Tulis ?page=4 atau ?cursor=id di URL. Baca query saat load. Jangan andalkan memory tab saja.

Tempel router daftar ke AI. Minta sinkron URL, bukan library baru.
