Fitur Database Clincoo: Simpan Data Langsung dari Backend Function

Backend function di Clincoo tidak hanya menjalankan logika — setiap function otomatis punya Database bawaan: objek db siap pakai untuk menyimpan data yang bertahan permanen, tanpa setup server database, tanpa koneksi eksternal, dan tanpa konfigurasi apa pun. Data terisolasi per akun: function-mu hanya pernah melihat data milik akunmu sendiri, di app.clincoo.buzz.

Ringkasan kemampuan

KemampuanKeterangan
Siap pakai tanpa setupObjek db sudah tersedia otomatis di dalam kode function — tidak ada server untuk diatur, tidak ada kredensial untuk disimpan.
Lima operasi intiget, set, del, list, dan count untuk membaca, menulis, menghapus, dan memantau data.
Data permanenData bertahan setelah function selesai dan tetap ada saat dipanggil ulang kapan pun.
Nilai fleksibelSimpan string atau objek JSON — hasil get dikembalikan sebagai nilai aslinya.
Baca batch dengan prefixlist(prefix) mengambil sekumpulan data sekaligus, cocok untuk koleksi seperti pesan, pesanan, atau log.
Pemantauan kuotacount() menampilkan pemakaian baris dan penyimpanan, lengkap dengan batas paketmu.
Terisolasi per akunData satu akun tidak pernah tercampur dengan akun lain.

Cara pakai: contoh kode

Tidak perlu import apa pun — db langsung bisa dipakai dengan await. Contoh counter pengunjung:

export default async function (args) {
  const total = ((await db.get('kunjungan')) || 0) + 1;
  await db.set('kunjungan', total);
  return { total_kunjungan: total };
}

Menyimpan dan membaca koleksi data dengan prefix:

export default async function (args) {
  await db.set('pesan:001', { nama: args.nama, isi: args.isi });
  const daftar = await db.list('pesan:'); // 200 entri terbaru
  return { jumlah: daftar.length };
}

Lima operasi database

OperasiFungsiHasil
db.get(kunci)Membaca satu data berdasarkan kuncinya.Nilai yang tersimpan, atau null bila belum ada.
db.set(kunci, nilai)Menyimpan atau menimpa satu data; nilai bisa string atau objek JSON.true bila berhasil.
db.del(kunci)Menghapus satu data.true bila berhasil.
db.list(prefix)Mengambil koleksi data yang kuncinya berawalan prefix.Maksimal 200 entri terbaru (diurut dari yang terakhir diubah).
db.count()Memantau pemakaian penyimpanan akunmu.Jumlah baris, ukuran, batas paket, dan nama paket.

Batasan dan kuota paket

Setiap data punya batas wajar: kunci maksimal 512 karakter dan nilai maksimal 100 KB per data. Kapasitas total mengikuti paket langgananmu — rincian harga ada di artikel Paket dan Harga Clincoo.

PaketKapasitas barisPenyimpanan total
Starter500 baris2 MB
Pro5.000 baris25 MB
Bisnis50.000 baris100 MB

Kalau kuota penuh, operasi set mengembalikan pesan yang jelas — cukup hapus data lama atau upgrade paket untuk kapasitas lebih besar.

Tips performa

  • Gunakan prefix pada kunci (misal pesan:001) supaya koleksi mudah dibaca dengan list(prefix).
  • Baca batch dengan list, bukan loop get satu-satu — list mengambil banyak data dalam satu panggilan.
  • Simpan angka ringkas atau agregat saat menulis data, bukan menghitung ulang semua saat membaca.
  • Pantau pemakaian lewat count() sebelum mendekati batas paket.
  • Untuk data sementara, hapus dengan del begitu tidak dipakai supaya kuota tetap lega.

Pertanyaan yang sering muncul

Apakah saya perlu setup database sendiri?

Tidak. Database bawaan langsung tersedia di dalam function — cukup pakai objek db di kode.

Apakah data hilang setelah function selesai?

Tidak. Data tersimpan permanen dan tetap ada pada pemanggilan berikutnya.

Nilai seperti apa yang bisa disimpan?

String dan objek JSON. Nilai yang disimpan sebagai objek dikembalikan sebagai objek ketika dibaca.

Bagaimana kalau kuota paket sudah penuh?

Operasi simpan akan menolak dengan pesan yang jelas. Hapus data lama atau upgrade paket — pemakaian bisa dicek dengan count().

Bisakah function membaca data akun lain?

Tidak. Isolasi per akun membuat setiap function hanya pernah melihat data akunnya sendiri.
