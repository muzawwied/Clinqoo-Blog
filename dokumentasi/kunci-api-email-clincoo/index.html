Kunci API Email Clincoo: Kelola Akses dan Identitas Pengirim

2026-10-05

Tab Kunci API di Pengaturan proyek (Email → Kunci API) adalah tempat mengelola akses Clincoo Email API: melihat dan menyalin kunci proyek, membuat ulang kunci, menonaktifkannya, serta mengatur identitas pengirim — nama tampilan dan alamat yang muncul di email penerima.

Melihat dan menyalin kunci

Setelah fitur email proyek aktif, kunci API tampil langsung di tab ini. Tombol Salin menyalinnya ke papan klip dalam satu ketukan — tanpa perlu membuka pengaturan apa pun. Satu kunci mewakili seluruh proyeknya: cukup satu kunci untuk semua request kirim email dari situs deploy-mu.

Buat ulang dan nonaktifkan

Ada dua tombol pengelolaan di samping kunci:

  1. Buat ulang kunci — mengganti kunci dengan yang baru. Lakukan saat kunci lama diduga bocor, atau sekadar rotasi berkala. Kunci lama langsung berhenti berlaku, jadi perbarui nilai kunci di situs deploy-mu.
  2. Nonaktifkan — memutus sementara semua pengiriman lewat API tanpa menghapus kunci. Cocok saat kamu ingin menjeda pengiriman tanpa mengubah konfigurasi; aktifkan kembali kapan saja.

Identitas pengirim

Bagian identitas pengirim mengatur siapa yang muncul sebagai pengirim email-mu:

  1. Nama tampilan — nama yang tampil di kotak masuk penerima, misalnya nama brand-mu.
  2. Alamat pengirim — harus berdomain @clincoo.buzz. Ketersediaan alamat dicek langsung saat kamu mengetik: hijau berarti tersedia, merah berarti sudah dipakai.

Tekan Simpan Pengirim untuk menerapkan. Kalau kamu tidak mengatur identitas khusus, email tetap terkirim dengan identitas bawaan dari nama proyekmu.

Praktik aman menyimpan kunci

  1. Simpan kunci sebagai variabel lingkungan, bukan hardcoded di kode.
  2. Jangan pernah menuliskan kunci ke repositori — ikuti panduan jangan commit kunci API.
  3. Rotasi kunci saat ada keraguan, dan nonaktifkan dulu bila situs-mu sedang tidak mengirim email.

Contoh pemakaian

Kunci dipakai di header Authorization: Bearer setiap request ke Clincoo Email API. Panduan lengkap kirim email dari situs deploy — lengkap dengan contoh request — ada di artikel Mengirim Email dari Situs Deploy.

Pertanyaan umum

Apakah satu kunci bisa dipakai untuk proyek lain?

Tidak. Kunci terisolasi per proyek — setiap proyek punya kunci dan identitas pengirimnya sendiri.

Kunci saya hilang atau lupa disimpan, bagaimana?

Buka tab Kunci API — kunci selalu tampil di sana. Kalau ragu keamanannya, gunakan Buat ulang kunci untuk menggantinya.

Kenapa alamat pengirim harus @clincoo.buzz?

Alamat @clincoo.buzz menjaga agar email dari proyekmu terkirim dengan identitas yang konsisten dan terverifikasi.

Apa bedanya nonaktifkan dengan buat ulang kunci?

Nonaktifkan hanya menjeda pengiriman — kunci tetap sama dan bisa diaktifkan lagi. Buat ulang mengganti kuncinya, jadi situs deploy-mu harus memakai kunci baru.
