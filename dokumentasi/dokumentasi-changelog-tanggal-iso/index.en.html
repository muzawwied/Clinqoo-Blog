Write Clincoo Changelogs with ISO Dates, Not "yesterday"

A note that says 'just updated' cannot be sorted. YYYY-MM-DD makes page history searchable.

This article is available in: Indonesia · English

Notes in a Clincoo project often say "update hero" with no date. A week later nobody remembers whether the CTA changed before or after an ad campaign.

Use one CHANGELOG.md file or a changelog.html page. Each entry starts with YYYY-MM-DD, then one working sentence: what changed and in which file. Avoid relative words like yesterday or last night.

ISO dates sort lexicographically. You can search 2026-09 in editor.clincoo.buzz and see September releases immediately. Teammates opening the GitHub repo do not have to guess a timezone.

Ask AI to prepend a new entry, not rewrite the whole log. Paste the page title and slug so links stay intact.

Dated documentation cools debates about who changed the footer. When you deploy to app.clincoo.buzz, copy the same date into the commit message.
