Integrasi & Plugin Clincoo: Hubungkan AI Agent ke Alat Kerja Favorit

Halaman Integrasi Clincoo — berjudul Plugin — adalah pusat kendali untuk menyambungkan Clincoo dengan alat dan platform kerja favorit Anda: GitHub, GitLab, Notion, dan Google Calendar. Setelah terhubung, AI Agent Clincoo bisa memakai alat-alat itu langsung dari chat: menganalisis kode dan me-review Pull Request, mengirim jawaban AI ke halaman Notion pilihan Anda, sampai melihat jadwal dan membuat event Google Calendar — semua tanpa berpindah aplikasi.

Artikel ini merangkum lengkap isi fitur Integrasi: daftar plugin beserta kemampuannya, izin yang diminta, cara menghubungkan dan memutus koneksi, fitur Eksport ke Git, pencarian dan filter kategori, hingga kelebihan dan manfaatnya.

Cara menghubungkan dan memutuskan plugin

  1. Buka menu Integrasi di Clincoo. Semua kartu plugin tampil di daftar — gunakan pencarian atau filter kategori bila daftarnya panjang.
  2. Tekan Hubungkan pada kartu plugin. Modal koneksi terbuka dan menampilkan izin yang diminta di bagian "Clincoo AI akan bisa:" supaya Anda tahu persis akses yang diberikan.
  3. Lanjutkan ke halaman login resmi platform terkait dan setujui izinnya. Untuk GitLab: daftarkan aplikasinya sekali di akun GitLab Anda, lalu tempel Application ID (hanya tersimpan di perangkat ini).
  4. Kembali ke Clincoo — kartu kini menampilkan badge hijau Terhubung. Sejak itu AI Agent bisa memakai alat tersebut langsung dari chat.
  5. Memutus koneksi bisa kapan saja: buka kartu → Putuskan → konfirmasi. Anda selalu bisa menghubungkan ulang kapan pun.

Izin dan keamanan

Clincoo memakai OAuth resmi dari setiap penyedia — Anda tidak pernah mengetik password GitHub, Notion, atau Google ke dalam Clincoo. Izin yang diminta selalu ditampilkan sebelum Anda menyetujui, dan memutus koneksi langsung mencabut akses AI Agent ke alat tersebut.

PluginIzin yang diminta
GitHubMembaca dan mengelola repositori publik & private; membuat, memperbarui, dan me-review Pull Request; menghapus repository yang sudah tidak digunakan
GitLabAkses project untuk eksport workspace; Application ID hanya tersimpan di perangkat ini
NotionMembaca daftar halaman Notion yang Anda beri akses; membuat halaman baru berisi jawaban AI atas perintah Anda
Google CalendarMelihat jadwal dan event di Calendar Anda; membuat event baru atas permintaan; mengubah atau menghapus event atas permintaan

Eksport ke Git

Eksport ke Git mengirim file workspace proyek Clincoo Anda ke GitHub atau GitLab: pilih platform (GitHub atau GitLab), isi alamat repo (mis. username/nama-repo), lalu kirim. Cocok untuk backup, melacak riwayat perubahan, dan berkolaborasi dengan developer di luar Clincoo. Fitur ini berstatus premium — ikon mahkota pada tombolnya membuka daftar paket Clincoo.

Manfaat untuk alur kerja Anda

  • Review Pull Request dan analisis kode tanpa keluar dari ruang kerja Clincoo.
  • Jawaban AI tersimpan rapi sebagai halaman Notion yang bisa dibaca tim Anda.
  • Jadwal dan event diatur lewat percakapan — cukup minta AI membuat atau menggeser meeting.
  • Workspace proyek ter-backup ke Git dengan riwayat perubahan yang jelas.
  • Seluruh alat kerja berada dalam satu halaman kelola, dengan status koneksi yang terpantau.

Siap mencoba? Buka menu Integrasi di Clincoo dan sambungkan alat pertama Anda.
