Clincoo Integrations & Plugins: Connect Your AI Agent to Your Favorite Tools

The Clincoo Integrations page — titled Plugin — is the control center for connecting Clincoo to your favorite work tools: GitHub, GitLab, Notion, and Google Calendar. Once connected, the Clincoo AI Agent can use those tools straight from chat: analyzing code and reviewing Pull Requests, sending AI answers to your chosen Notion page, even viewing your schedule and creating Google Calendar events — all without leaving the app.

This guide covers the full Integrations feature: the plugin list and what each one can do, the permissions requested, how to connect and disconnect, the Export to Git feature, search and category filters, plus its advantages and benefits.

Connecting and disconnecting a plugin

  1. Open the Integrations menu in Clincoo. All plugin cards are listed — use the search or category filters if the list is long.
  2. Press Connect on a plugin card. The connection modal opens and shows the requested permissions under "Clincoo AI will be able to:" so you know exactly what access you are granting.
  3. Continue to the provider's official login page and approve the permissions. For GitLab: register the application once in your GitLab account, then paste the Application ID (stored only on your device).
  4. Return to Clincoo — the card now shows a green Connected badge. From that moment the AI Agent can use the tool straight from chat.
  5. Disconnect anytime: open the card → Disconnect → confirm. You can always reconnect later.

Permissions and security

Clincoo uses official OAuth from each provider — you never type your GitHub, Notion, or Google password into Clincoo. Requested permissions are always shown before you approve, and disconnecting immediately revokes the AI Agent's access to that tool.

PluginRequested permissions
GitHubRead and manage public & private repositories; create, update, and review Pull Requests; delete repositories that are no longer used
GitLabProject access for workspace export; the Application ID is stored only on this device
NotionRead the list of Notion pages you grant access to; create new pages containing AI answers to your prompts
Google CalendarView schedules and events in your Calendar; create new events on request; edit or delete events on request

Export to Git

Export to Git sends your Clincoo project's workspace files to GitHub or GitLab: pick the platform, enter the repository address (e.g. username/repo-name), and send. Great for backups, tracking change history, and collaborating with developers outside Clincoo. This is a premium feature — the crown icon on its button opens the Clincoo plan list.
