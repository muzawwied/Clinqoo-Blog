Server MCP Clincoo: Kelola Proyek dari AI Eksternal

Server MCP Clincoo mengubah setiap proyek Clincoo menjadi server Model Context Protocol (MCP). Artinya, aplikasi AI eksternal favoritmu — Claude Desktop, Cursor, Windsurf, atau klien MCP lain — bisa membaca dan mengelola workspace proyek itu secara langsung: membuka file, menulis kode, memperbaiki bug, sampai mem-publish situs, semua sesuai izin yang kamu tentukan. Setiap perubahan tersinkronisasi real-time ke workspace Clincoo, tanpa ekspor-impor manual.

Artikel ini merangkum lengkap isi fitur Server MCP: cara mengaksesnya, izin yang tersedia, daftar tools untuk AI, cara memasang token ke klien, serta kelebihan dan manfaatnya.

Apa itu MCP dan cara kerjanya

MCP (Model Context Protocol) adalah protokol terbuka yang menyatukan aplikasi AI dengan sumber data dan alat kerja. Clincoo bertindak sebagai penyedia server: proyekmu memaparkan sekumpulan tools — membaca file, menulis file, deploy, dan sebagainya — lalu aplikasi AI eksternal yang kamu sambungkan menjadi "klien" yang boleh memanggil tools tersebut.

Alurnya sederhana: aktifkan Server MCP di halaman pengaturan proyek, salin endpoint dan token akses, tempel ke pengaturan MCP aplikasi AI kamu, dan sejak itu AI eksternal bisa bekerja pada proyek Clincoo sesuai izin yang kamu nyalakan. Kamu tetap memegang kendali penuh: izin bisa diubah kapan saja, token bisa dibuat ulang, dan seluruh akses bisa diputus dalam satu klik.

Cara mengaktifkan Server MCP

  1. Pastikan paket akunmu Bisnis — pengelolaan Server MCP tersedia untuk paket Bisnis.
  2. Buka proyek yang mau disambungkan, lalu masuk ke Pengaturan → Server MCP.
  3. Ketuk Aktifkan Server MCP. Clincoo membuat endpoint dan token akses khusus proyek ini.
  4. Atur izin yang dibutuhkan di bagian Konfigurasi Akses, salin endpoint dan token, lalu tempel ke aplikasi AI eksternalmu.
  5. Pantau pekerjaan AI di panel Aktivitas Terbaru dan ubah izin kapan pun sesuai kebutuhan.

Memasang ke aplikasi AI eksternal

Halaman Server MCP menyediakan tiga format siap pakai: Endpoint MCP, Token Akses, serta URL + Token gabungan untuk aplikasi yang hanya menyediakan satu kolom URL. Untuk Claude, Cursor, atau Windsurf, tempel blok konfigurasi berikut ke pengaturan MCP (misalnya file mcp.json):

{
  "mcpServers": {
    "clincoo": {
      "url": "https://app.clincoo.buzz/mcp?project=ID-PROYEK",
      "headers": { "Authorization": "Bearer TOKEN-AKSESMU" }
    }
  }
}

Klien yang belum mendukung server remote bisa memakai wrapper mcp-remote — petunjuk singkatnya tersedia di halaman Server MCP tepat di bawah blok konfigurasi. Jangan pernah membagikan token aksesmu; siapa pun yang memegang token bisa memakai izin yang kamu aktifkan.

Manajemen token dan keamanan

  • Tampilkan/sembunyikan token — token sengaja disamarkan; ketuk ikon mata untuk melihatnya penuh.
  • Buat ulang token — token lama langsung tidak berlaku; tempel token baru ke klien AI kamu.
  • Putuskan semua akses — mencabut token secara permanen. Semua koneksi AI eksternal ke proyek ini berhenti seketika.
  • Aktivitas Terbaru — panel ini mencatat operasi terbaru yang dilakukan AI eksternal, lengkap dengan opsi hapus riwayat.
  • Prinsip least privilege — nyalakan hanya izin yang memang dibutuhkan. Izin baca saja sudah cukup untuk AI yang bertugas meninjau kode.

Jika paketmu turun dari Bisnis, server yang sudah terhubung tetap berjalan normal — yang terkunci hanyalah halaman pengelolaannya, sampai kamu upgrade kembali.

Kelebihan dan manfaat

  • Bekerja dari editor AI favorit tanpa kehilangan konteks — Cursor, Windsurf, atau Claude langsung membaca proyek Clincoo-mu, tanpa salin-tempel file bolak-balik.
  • Sinkronisasi real-time — setiap file yang diubah AI eksternal langsung muncul di workspace dan live preview Clincoo.
  • Izin granular per operasi — kamu memilih persis apa yang boleh dan tidak boleh dilakukan AI, per proyek.
  • Activity log transparan — semua aksi AI eksternal tercatat, jadi kamu selalu tahu apa yang terjadi pada proyekmu.
  • Tidak menghabiskan kuota chat — izin Chat AI Clincoo memakai jalur khusus yang terpisah dari kuota percakapan paketmu.
  • Satu sumber kebenaran — workspace Clincoo tetap tempat kerja utama; asisten AI Clincoo dan AI eksternal bekerja pada file yang sama.

Butuh langkah pertama yang lebih ringan? Mulai dari izin baca saja, amati aktivitasnya di panel, lalu nyalakan izin lanjutan begitu kamu yakin. Jika kendala muncul, cek Pusat Bantuan atau buat ulang token lalu sambungkan kembali klienmu.
