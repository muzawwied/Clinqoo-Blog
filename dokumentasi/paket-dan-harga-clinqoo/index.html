Paket dan Harga Clincoo: Starter, Pro, dan Bisnis

Clincoo punya tiga paket yang dirancang mengikuti perjalananmu: mulai gratis, naik saat kebutuhan bertambah. Artikel ini merangkum ketiganya secara jujur, tanpa bintang kecil tersembunyi.

Starter — Gratis

  • Hingga 3 proyek aktif
  • 1 kolaborator per proyek
  • Chat AI di setiap proyek (50 pesan per bulan)
  • 3 template proyek siap pakai
  • Tugas terjadwal dan notifikasi
  • Deploy web 5x per bulan

Pro — Rp49.000 per bulan

  • Hingga 10 proyek aktif
  • Hingga 5 kolaborator per proyek
  • Semua fitur Starter: chat AI, template, tugas terjadwal
  • Chat AI hingga 500 pesan per bulan (maksimal 50 per hari)
  • Deploy web hingga 25x per bulan
  • Impor repository GitHub ke workspace

Bisnis — Rp129.000 per bulan

  • Semua fitur Pro
  • Hingga 50 proyek aktif
  • Hingga 20 kolaborator per proyek
  • Kontrol akses dan keamanan proyek lanjutan
  • Deploy web tanpa batas

Upgrade, downgrade, dan pembayaran

Paket diatur dari halaman Langganan di akunmu. Upgrade bisa dilakukan kapan saja, dan fitur premium langsung terbuka setelah pembayaran dikonfirmasi. Saat fitur premium dikunci ikon mahkota, kamu bisa melihat daftar paket lengkap dengan mengetuk ikonnya. Tagihan tersedia pilihan bulanan atau tahunan.

Pilih paket sesuai kebutuhan nyata: kebanyakan orang mulai dari Starter, lalu naik ke Pro saat proyek atau timnya melebihi batas gratis. Tidak perlu berlangganan hanya untuk mencoba — semua fitur dasar bisa dieksplorasi dulu di paket gratis.
