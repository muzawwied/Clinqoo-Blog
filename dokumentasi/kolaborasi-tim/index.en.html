Team Collaboration in Clincoo

Collaboration lets several people work on the same project: invite members by email with a clear division of roles, so everyone knows what they can work on.

Inviting members

  1. Open the project you want to share.
  2. Go to the Collaboration page from the project settings.
  3. Enter the email of the member you want to invite.
  4. Set their access rights to fit the team.
  5. Send the invitation — the member receives an email with a link to join.

Once joined, members can open the project from their own dashboard and work on the same files as you.

Working cleanly as a team

  • Agree on file areas from the start — two people editing the same file at the same time tends to overwrite each other.
  • Discuss big changes before making them.
  • The AI assistant understands the same workspace, so every member can use it to make sense of code written by someone else.

If an invitation never arrives or a member cannot open the project, the fix is in Common Issues and Solutions.
