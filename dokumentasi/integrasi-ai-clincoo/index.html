Integrasi AI Clincoo: Model, Secret, dan API per Proyek

Halaman Integrasi AI di pengaturan proyek Clincoo — berlabel "AI Router: model dan secret per proyek" — adalah pusat kendali AI untuk satu proyek. Dari sini kamu mengatur model default yang dipakai fitur AI proyekmu, mengelola secret API, mencoba koneksi, sampai memantau log pemakaian, biaya, dan analitiknya. Semua lewat satu halaman.

Artikel ini membedah seluruh isi halaman tersebut: Clincoo Open API, pengaturan model default, siklus secret, contoh pemanggilan, uji koneksi, log pemakaian, hingga analitik dan kredit API.

Clincoo Open API: format kompatibel OpenAI

Inti dari halaman ini adalah Clincoo Open API: API bawaan Clincoo yang formatnya kompatibel dengan OpenAI. Artinya, aplikasi atau SDK yang sudah ditulis untuk OpenAI (mis. pustaka openai) umumnya bisa langsung diarahkan ke Clincoo cukup dengan mengganti base URL menjadi https://app.clincoo.buzz/v1 dan memakai secret proyek — tanpa menulis integrasi dari nol.

Dua endpoint utamanya: /v1/chat/completions untuk panggilan chat (generatif) dan /v1/models untuk melihat daftar model yang tersedia. Semua model dikelola dan disediakan Clincoo di server — kamu tidak perlu memasang API key penyedia lain, tidak perlu mengurus infrastruktur model, cukup satu secret Clincoo.

Model yang dipilih sebagai Model Default dipakai oleh fitur-fitur AI di proyek tersebut. Selain model default, semua model lain tetap bisa dipanggil langsung lewat secret proyek — cukup tulis id modelnya (mis. clincoo/glm-5.2) di parameter model saat memanggil API.

Secret API: kunci unik per proyek

Setiap proyek Clincoo memiliki secret yang berbeda. Secret inilah "kunci" yang dipakai aplikasi eksternal untuk memanggil Clincoo Open API atas nama proyekmu, dikirim sebagai header Authorization: Bearer ke endpoint /v1/chat/completions.

Empat aksi yang tersedia di halaman ini untuk mengelola secret:

  • Buat Secret Baru — untuk proyek yang belum punya secret; secret langsung bisa dipakai.
  • Salin — menyalin secret ke clipboard untuk dipasang di aplikasimu.
  • Ganti Secret — menurunkan secret lama dan mengeluarkan yang baru; aksi rotasi bila secret dicurigai bocor.
  • Cabut — menonaktifkan secret; panggilan yang memakai secret itu akan ditolak.

Karena secret memberi akses penuh ke kuota AI proyekmu, simpan di tempat aman: jangan di-hardcode di frontend atau repo publik. Praktik yang benar adalah menyimpannya sebagai variabel environment atau secret di sisi server aplikasimu.

Contoh pemanggilan dan Uji Koneksi

Halaman ini menyediakan Contoh Pemanggilan (cURL) yang formatnya otomatis mengikuti secret dan model yang sedang dipilih — tinggal salin, tempel di terminal, dan jalankan. Panggilan memakai header Authorization: Bearer dengan secret proyek, persis seperti contoh berikut:

curl https://app.clincoo.buzz/v1/chat/completions \
  -H "Authorization: Bearer <SECRET_PROYEK_ANDA>" \
  -H "Content-Type: application/json" \
  -d '{ "model": "clincoo/auto", "messages": [{ "role": "user", "content": "Halo!" }] }'

Belum yakin secret dan endpoint berjalan? Tekan Uji Koneksi: Clincoo mengirim satu panggilan kecil ke Clincoo Open API memakai secret proyek dan menampilkan hasilnya langsung — tanpa perlu membuka terminal.

Log Pemakaian

Semua panggilan ke Clincoo Open API untuk proyekmu tercatat di Log Pemakaian. Kamu bisa memfilter berdasarkan status (Semua, Sukses, Gagal) dan mengekspor riwayat ke format CSV atau JSON untuk dianalisis lebih lanjut. Kalau belum ada panggilan, halaman menampilkan status kosong hingga log pertama tercatat.

Analitik & Pemakaian dan kredit API

Bagian Analitik & Pemakaian merangkum performa dan konsumsi AI proyekmu dari log yang tercatat:

  • Ringkasan — total permintaan, total token, dan total biaya dalam dolar.
  • Kredit API — kredit terpakai hari ini dan bulan ini; kredit harian direset tiap hari dan kredit bulanan tiap awal bulan.
  • Status permintaan — perbandingan panggilan sukses vs gagal.
  • Pemakaian harian — grafik 14 hari terakhir.
  • Latensi rata-rata per model dan pemakaian per model — untuk melihat model mana yang paling sering dan paling cepat menjawab.

Kelebihan fitur Integrasi AI

Kontrol biayaKredit API harian dan bulanan membuat pemakaian terukur dan terbatas.

Manfaat untuk alur kerjamu

  • Tambahkan kemampuan AI ke aplikasi eksternal (backend, bot, otomasi) lewat API yang sudah dikenal luas formatnya.
  • Ganti model default proyek kapan saja tanpa mengubah kode panggilan — atau panggil model lain per-request lewat parameter model.
  • Rotasi secret secara rutin dengan aksi Ganti dan Cabut untuk menjaga keamanan.
  • Pantau biaya dan performa tiap model, lalu putuskan kombinasi model yang paling efisien untuk proyekmu.
