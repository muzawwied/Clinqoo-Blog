Link the Issue to the Commit When Closing a Clincoo Fix

A 'fix bug' commit message cannot be traced. Include the issue number or the page slug that changed.

This article is available in: Indonesia · English

Clincoo project Git history is full of short messages. Six months later nobody knows which commit fixed the form.

Write the page slug plus a one-line summary. If there is an issue, mention its number in the commit message.

Do not mix unrelated fixes in one commit. One intent makes revert easier on editor.clincoo.buzz.

When you ask AI for help, paste the commit hash and message. Do not ask AI to read the whole diff with no issue context.

Clincoo on blog.clincoo.buzz refers to pages by slug; a commit that contains that slug can be audited.
