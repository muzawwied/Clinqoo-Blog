Database Clincoo: Tabel Data dan API per Proyek

Halaman Database di pengaturan proyek Clincoo adalah tempat menyimpan dan mengelola data aplikasimu dalam tabel yang rapi — bisa diakses lewat API kapan saja. Setiap proyek Clincoo punya database terpisah, jadi data antar proyek tidak pernah bercampur, dan aplikasi yang kamu deploy bisa membaca-menulis datanya lewat kunci akses sendiri.

Artikel ini membedah seluruh isi halaman tersebut: aktivasi database, membuat tabel, mengisi data, kunci akses dari aplikasi, contoh pemakaian API, hingga grafik ringkasan.

Aktifasi dan konsep satu database per proyek

Database di Clincoo aktif per proyek: buka tab Database di pengaturan proyek, klik Aktifkan Database sekali, dan fitur langsung siap dipakai — tanpa setup server, tanpa konfigurasi tambahan. Kalau tabel yang kamu cari tidak muncul, cek nama proyek di bagian atas halaman: karena setiap proyek punya database terpisah, tabel proyek lain memang tidak terlihat di sini.

Membuat tabel dan mengisi data

Alur pemakaiannya dirancang empat langkah dari nol sampai aplikasimu terhubung:

  1. Buat tabel. Klik Buat tabel, beri nama, lalu tentukan kolomnya — misal tabel pengguna dengan kolom nama dan email.
  2. Isi data. Buka tabelnya, lalu tambah, ubah, atau hapus baris kapan saja — datanya langsung tersimpan.
  3. Buat kunci akses. Di bagian Akses dari aplikasi, buat kuncinya dan simpan di tempat aman.
  4. Sambungkan aplikasimu. Tempel kunci sebagai Bearer token di kode aplikasi — contoh pemakaian lengkap tersedia tepat di bawah kuncinya.

Akses dari aplikasi: kunci API

Aplikasi yang kamu deploy mengakses database proyek lewat kunci API. Kunci dikirim sebagai Bearer token di header Authorization pada setiap request. Buat kuncinya dari halaman Database, simpan di tempat aman, lalu tempel ke kode aplikasimu.

Kunci bisa diganti kapan saja lewat tombol Ganti kunci — dan begitu diganti, kunci lama otomatis berhenti berlaku. Ini pola rotasi yang sehat: kalau kunci dicurigai bocor, ganti kuncinya dan aplikasi tinggal diperbarui dengan kunci baru.

Contoh pemakaian API

Dua endpoint utama di bawah https://app.clincoo.buzz/v1/db: /v1/db/tables untuk mengelola tabel, dan /v1/db/rows untuk membaca dan menulis baris data. Contoh membaca data persis seperti yang ditampilkan di halaman Database:

fetch('https://app.clincoo.buzz/v1/db/rows?table=nama', {
  headers: { Authorization: 'Bearer KUNCI_PROYEK_ANDA' }
})

Contoh di halaman Database otomatis menampilkan kunci proyekmu yang sedang aktif, jadi tinggal salin dan jalankan.

Grafik ringkasan database

Halaman ini juga menampilkan Grafik yang terisi otomatis dari tabel dan barismu, tanpa setup apa pun:

  • Baris per tabel — total baris tersimpan di tiap tabel.
  • Tabel dibuat per hari — aktivitas pembuatan tabel.
  • Komposisi baris per tabel — porsi baris tiap tabel dari total.
  • Sebaran tabel: kolom vs baris — posisi tiap tabel berdasarkan ukurannya.
  • Aktivitas per hari — jumlah tabel dan baris yang lahir tiap hari.

Setiap grafik punya tombol Simpan untuk mengunduhnya sebagai gambar — praktis untuk laporan atau dokumentasi tim.

Manfaat untuk alur kerjamu

  • Simpan data aplikasi deploy-mu (form, pesanan, profil pengguna) tanpa membangun backend database sendiri.
  • Kelola data lewat UI yang rapi — buat tabel, ubah baris, hapus data, semuanya dari browser.
  • Baca-tulis data dari kode aplikasi dengan beberapa baris fetch saja.
  • Pantau pertumbuhan data tiap proyek lewat grafik yang terisi otomatis.

Buka tab Database di pengaturan proyek Clincoo untuk mulai menyimpan data aplikasimu.
