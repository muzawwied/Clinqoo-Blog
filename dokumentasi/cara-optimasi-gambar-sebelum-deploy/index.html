Cara Optimasi Gambar Sebelum Deploy

Gambar penuh dari kamera sering lebih besar daripada seluruh HTML dan CSS. Perkecil sebelum deploy supaya preview dan situs tayang sama-sama cepat.

Ubah ukuran ke lebar tampilan

Hero selebar 1200 piksel tidak perlu file 4000 piksel. Ekspor ulang mendekati lebar maksimum yang benar-benar ditampilkan. Simpan foto sebagai WebP atau JPEG, ikon datar sebagai SVG, bukan PNG besar.

Tulis ukuran dan alt

Isi atribut width dan height agar layout tidak meloncat saat gambar masuk. alt menjelaskan isi gambar untuk pembaca layar dan untuk saat file gagal dimuat. Alt kosong hanya untuk gambar murni dekoratif.

Jangan muat gambar yang tersembunyi

Gambar di bawah lipatan bisa loading="lazy". Gambar hero jangan lazy, karena itu yang dilihat pertama. Cek tab Network: satu gambar di atas 500 KB biasanya masih bisa diperkecil tanpa beda visual yang jelas.

Setelah file ringan, simpan di folder aset proyek lalu deploy dari app.clincoo.buzz. Ulangi cek di halaman publik, bukan hanya di preview editor.
