How to Set a Heading Hierarchy

A heading is the page outline, not a way to make text bigger. In the HTML file of an editor.clincoo.buzz project, use one h1 for the page title, h2 for sections, and h3 for subsections.

Do not skip levels

After an h2, continue to h3, not straight to h4. Visual size belongs in CSS. If a sentence only needs to be bold, use strong or a text class, not a heading.

Keep the h1 close to the title

The h1 should be close to the title tag in head, but it does not have to be identical. The title is for the tab and search results; the h1 is for someone who already opened the page. Keep the meta description short, one or two sentences.

Check preview and outline

In live preview, scroll and confirm there is only one main title. The Clincoo AI assistant can flag skipped levels — paste the head and body snippet, not the whole project, if the page is long.
