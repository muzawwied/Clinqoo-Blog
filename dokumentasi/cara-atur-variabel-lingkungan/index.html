Cara Mengatur Variabel Lingkungan Proyek

Variabel lingkungan menyimpan secret di luar file yang diunduh pengunjung. HTML dan JS statis tetap publik setelah deploy, jadi kunci yang ditempel di situ sama saja dibagikan.

Tambahkan variabel

  1. Buka pengaturan proyek di editor.clincoo.buzz atau minta asisten AI menambahkan env var.
  2. Beri nama huruf besar dengan garis bawah, misalnya MAIL_API_KEY. Jangan pakai spasi.
  3. Tempel nilainya sekali. Jangan mengirim nilai yang sama ke chat umum atau ke file README.

Pakai nilainya tanpa membocorkannya

Kode server atau perintah terminal boleh membaca variabel itu. File index.html yang dikirim ke browser tidak boleh. Kalau layanan harus dipanggil dari halaman statis, lewatkan panggilan lewat endpoint yang memegang secret, bukan lewat kunci di frontend.

Uji lalu deploy ulang

  • Minta asisten menguji bahwa secret terisi, tanpa mencetak isinya ke log.
  • Kalau nilai baru tidak terbaca, simpan ulang lalu deploy lagi — proses yang sudah jalan masih memegang nilai lama.
  • Putar kunci di penyedia layanan jika nilai itu pernah tertulis di file publik.
