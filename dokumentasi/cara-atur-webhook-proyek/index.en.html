How to Set Up Project Webhooks in Clincoo

Webhooks are how Clincoo tells your deployed site about events automatically — an incoming QRIS payment or a finished deploy — without you checking manually. This guide covers registering and managing them on app.clincoo.buzz.

Add an endpoint URL

In your project Settings, open the Webhook tab and click Add. Enter a URL that is ready to receive requests — it must be HTTPS, for example https://yoursite.com/webhook/pay. You can register more than one URL and remove any of them from the same list at any time.

Pick a delivery method

Each URL has a GET or POST method option. Pick the one your endpoint handler expects — for payment notifications, Clincoo sends the data as JSON in the POST body.

ClincooPay payment notifications

When a buyer completes a QRIS payment on your deployed site, Clincoo sends a payment.paid notification to your project payment webhook URL. The payload contains order_id, amount, description, status, and paid_at. Answer quickly and process the data in the background — do not block until timeout.

Deploy event notifications

The same tab has a deploy notification setting. Enable it so your endpoint also receives a notice when the project build finishes, so your system knows when a new version is live.

If notifications never arrive, start with Common Problems before changing anything. Payload details and the payment API flow are in the ClincooPay API reference.
