Mengenal Workspace Clincoo: Dashboard, Proyek, dan Editor

Workspace Clincoo dirancang supaya semua yang kamu butuhkan untuk membangun situs berada satu layar. Artikel ini menjelaskan masing-masing bagiannya dan untuk apa dipakai.

Dashboard proyek

Dashboard adalah beranda akunmu. Dari sini kamu membuat proyek baru (dari template, upload ZIP, atau impor GitHub), membuka proyek lama, dan melihat ringkasan aktivitas. Kartu proyek menampilkan nama, waktu terakhir diubah, dan akses cepat ke editor.

Editor kode

Editor berisi file explorer di kiri untuk berpindah folder dan file, tab dokumen di atas untuk berpindah antar file yang terbuka, dan area kode dengan syntax highlighting di tengah. Klik kanan file di explorer untuk mengganti nama, menduplikasi, atau menghapus. Upload file dan folder baru lewat tombol impor di menu editor.

Live preview

Panel Live preview menampilkan hasil situsmu secara langsung. Setiap kali file disimpan, preview bisa dimuat ulang untuk melihat perubahan terbaru. Gunakan preview untuk memastikan tampilan sudah benar sebelum deploy.

Chat AI

Panel chat adalah tempat berdiskusi dengan asisten AI: minta penjelasan kode, saran perbaikan, atau penulisan fitur baru. Chat terhubung dengan konteks proyek sehingga AI mengerti file yang sedang kamu kerjakan. Detail cara pakainya di artikel Asisten AI Clincoo.

Menu pengaturan

Menu di pojok kiri atas membuka pengaturan akun dan proyek: profil, keamanan, environment, domain kustom, hingga zona bahaya untuk menghapus akun. Menu ini juga jalan menuju halaman langganan untuk upgrade paket.

Dengan lima bagian ini, alur kerja di Clincoo selalu sama: buat atau buka proyek, edit di editor, cek di live preview, lalu deploy. Selanjutnya: pelajari asisten AI di artikel berikut.
