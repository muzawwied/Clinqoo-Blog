Understanding the Clincoo Workspace: Dashboard, Projects, and Editor

The Clincoo workspace is designed so that everything you need to build a site lives on one screen. This article walks through each part and what it is for.

Project dashboard

The dashboard is your account home. From here you create new projects (from a template, a ZIP upload, or a GitHub import), reopen existing ones, and review recent activity. Project cards show the name, last modified time, and quick access to the editor.

Code editor

The editor has a file explorer on the left for moving between folders and files, document tabs at the top for switching between open files, and a syntax-highlighted code area in the middle. Right-click a file in the explorer to rename, duplicate, or delete it. New files and folders can be imported from the editor menu.

Live preview

The Live preview panel renders your site as visitors will see it. Every time you save a file, the preview can be reloaded to reflect the latest changes. Use it to confirm everything looks right before deploying.

AI chat

The chat panel is where you talk to the AI assistant: ask for code explanations, suggest fixes, or request new features. The chat is connected to your project context so the AI understands the files you are working on. See the article The Clincoo AI Assistant for details.

Settings menus

The menu at the top left opens account and project settings: profile, security, environment, custom domain, and the danger zone for deleting your account. It is also the path to the subscription page for plan upgrades.

With these five parts, the Clincoo workflow is always the same: open or create a project, edit in the editor, check in live preview, then deploy. Next up: the AI assistant article.
