Record Browser and OS Version When Reporting Clincoo

A broken layout on old Safari does not mean the CSS is wrong in Chrome. Save a short user agent in the release note.

This article is available in: Indonesia · English

A Clincoo page looks fine on your laptop and breaks on a client device. Without the browser version you tweak Grid that is not the cause.

Write the browser name, version number, and OS. One line in the README or page changelog is enough.

Retest on editor.clincoo.buzz with the same device before marking it done. Do not rely only on DevTools device mode.

Paste that version line to AI. Do not ask for a large polyfill before you know the target browser.

Clincoo on app.clincoo.buzz stays one codebase; version notes stop speculative fixes.
