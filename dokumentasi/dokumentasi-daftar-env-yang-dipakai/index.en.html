List Env Vars Used by a Clincoo Page

A page that works in the editor dies after deploy if env is undocumented. Write variable names, not values.

This article is available in: Indonesia · English

Clincoo API fetches fail after release because the key exists only on a local machine. A README without an env list makes people redo setup.

Make a sample file: variable name, one-sentence purpose, and whether it is required. Never write the real secret.

Match the name on app.clincoo.buzz with what the script reads. One typo makes the value silently undefined.

Paste the env name list to AI when you are stuck. Do not paste production values.

Clincoo on editor.clincoo.buzz still runs without public keys; what must be documented is the name the script expects.
