Deploy Situs ke Internet dan Pakai Domain Sendiri

Menerbitkan situs adalah momen terbaik dari setiap proyek. Artikel ini menjelaskan cara deploy di Clincoo, aturan kuotanya, dan cara memakai domain sendiri.

Cara deploy

Dalam proyek, buka menu Build & Deployment lalu klik deploy. Clincoo akan membangun situs dari file proyekmu dan menerbitkannya ke internet lewat jaringan Cloudflare. Setiap proyek mendapat alamat online sendiri yang bisa dibagikan ke siapa saja.

Kuota deploy

Deploy dibatasi per paket agar infrastruktur tetap sehat: Starter 5x deploy web per bulan, Pro hingga 25x per bulan, dan Bisnis tanpa batas. Untuk situs yang sudah stabil, kamu tidak perlu deploy ulang setiap kali mengedit — gunakan live preview dulu, lalu deploy saat benar-benar siap diterbitkan.

Domain kustom

Alamat bawaan bagus untuk mulai, tapi domain sendiri membuat situsmu terlihat serius. Fitur domain kustom tersedia di menu pengaturan proyek: masukkan domainmu, atur record DNS sesuai petunjuk, dan Clincoo akan menghubungkannya ke situsmu dengan HTTPS otomatis. Penanda ikon mahkota di menu menandakan fitur premium — paket gratis sudah termasuk satu domain, sisanya termasuk fitur berbayar.

Tips sebelum deploy

  • Cek live preview di ukuran layar HP dan desktop.
  • Pastikan semua tautan dan gambar memakai jalur relatif agar tidak putus setelah diterbitkan.
  • Beri nama file utama index.html supaya situs terbuka otomatis.

Setelah deploy, alamat situsmu aktif dan siap dibagikan. Kalau ada masalah, lihat artikel Masalah Umum dan Cara Mengatasinya di Pusat Bantuan.
