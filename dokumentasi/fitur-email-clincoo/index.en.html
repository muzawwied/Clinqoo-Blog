Clincoo Email Feature: Complete Guide to Sending Email, Broadcast, and Audience

The Clincoo Email feature lets every Clincoo project send real email — announcements, newsletters, and automated notifications from the sites you deploy — without setting up SMTP, signing up for a third-party service, or touching any server configuration. Everything is managed from one place: the Email page in your project settings.

Once activated, the feature gives you a delivery log, mass broadcast, audience management, delivery metrics, and API keys — all isolated per project and tied to your plan quota. This guide summarizes the full set of capabilities, specifications, advantages, and benefits in a single page.

How to activate Email for a project

Activation is per project and free. Open Project Settings → Email, then click Activate Email. Once active, every sub-page is ready to use and the log starts recording each delivery. Inactive projects only show the activation button — there is no configuration to fill in first.

Core capabilities

Send a broadcast

Broadcast is the way to send one email to many recipients at once from inside Clincoo. The form lives on its own page so the history list stays tidy:

  • Subject and body are written in HTML — links, images via URL, and text formatting are supported.
  • Recipients can be typed directly, separated by commas, spaces, or new lines.
  • A live counter tracks recipients; the maximum is 50 recipients per broadcast.
  • The Import from Audience button pulls audience contacts into the form automatically — merged and de-duplicated.
  • Broadcast history records the subject, recipient count, and result; Send again refills the form with the previous recipients.

Manage your audience

The audience is the project's contact book: each contact stores a name and an email address. You can add contacts one by one, paste an address list to import in bulk, edit entries, or delete contacts. Imports validate every address automatically and drop invalid or duplicate ones. The contact limit follows your account plan:

Monitor delivery metrics

The Metrics page summarizes your project's email health: Sent and Failed cards across the full history, quota used this month with the remaining balance, plus charts for delivery status, the daily trend of the last 14 days, hourly activity, top recipients, and most popular subjects. It tells you which messages resonate and when your audience is most active.

API keys for deployed sites

A site you have deployed can send its own email through the Clincoo API — order confirmations or signup notifications, for example. Keys are created on the API Keys page: shown masked, revealed and copied when needed, regenerated without losing history, and revocable at any time. See the full usage guide in Sending Email from a Deployed Site.

Sender name

By default, email is sent from the official Clincoo Mail address on behalf of your project. You can set a custom display name per project so recipients recognize the sender — your brand or store name, for example. A sender name may not imitate the identity of another brand or person.

Security and privacy

  • API keys belong to your project only — regenerate or revoke them at any time from the API Keys page without affecting other projects.
  • Email data — log, audience, and broadcast history — is isolated per project.
  • Every recipient address is validated automatically, and duplicates are removed before sending.
  • Plan quotas prevent excessive sending that risks being flagged as spam by recipient inbox providers.
  • Activation is opt-in per project: a project without Email active uses no quota and cannot send anything.

Frequently asked questions

Do I need my own domain?

No. The default official Clincoo Mail sender works out of the box from activation, with a display name you can configure.

What if my audience is larger than 50?

Split recipients into consecutive broadcasts — for example the first 50, then the next 50 using Send again. The per-broadcast limit keeps delivery reliable all the way to the inbox.

When does the monthly quota reset?

At the start of each month. Remaining quota is always visible on the Metrics page and the main Email page.

How do I send email automatically from my deployed site?

Use the API key from the API Keys page and follow the steps in Sending Email from a Deployed Site.

If a send fails, check the Clincoo Help Center — most issues come down to an exhausted quota or an invalid recipient address, both clearly visible on the Metrics page and the log.
