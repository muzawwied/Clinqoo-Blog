Cara Memakai Terminal di Editor Clincoo

Terminal di editor.clincoo.buzz menjalankan perintah Linux di sesi proyek. Sesi bertahan beberapa menit antar-perintah, lalu alat yang terpasang di sesi itu hilang kalau sesi berakhir.

Perintah yang aman untuk pemula

  1. pwd menunjukkan folder tempat kamu berdiri.
  2. ls menampilkan file di folder itu. Bandingkan dengan panel file editor.
  3. cat index.html mencetak isi file. Berguna kalau preview dan file di panel terasa tidak sama.

Jangan menjalankan perintah yang merusak

Hindari rm -rf, memindahkan root proyek, atau menginstal paket global yang tidak kamu pahami. Kalau sebuah tutorial menyuruh menempel satu baris panjang, pecah dulu dan tanyakan apa yang diubah. Asisten AI bisa menjalankan perintah, tetapi kamu yang menyetujui.

Hentikan proses yang menggantung

Kalau server lokal tidak kembali ke prompt, tekan Ctrl+C sekali. Itu mengirim sinyal berhenti, bukan menghapus file. Setelah prompt kembali, jalankan lagi dengan port yang sama hanya jika proses lama sudah mati.

Salin keluaran error lengkap — baris terakhir biasanya penyebabnya — sebelum membuka chat bantuan.
