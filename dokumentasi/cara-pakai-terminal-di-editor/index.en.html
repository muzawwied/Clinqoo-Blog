How to Use the Terminal in the Clincoo Editor

The terminal in editor.clincoo.buzz runs Linux commands in the project session. The session lasts a few minutes between commands, and tools installed in that session disappear when it ends.

Commands that are safe for beginners

  1. pwd shows the folder you are standing in.
  2. ls lists files in that folder. Compare it with the editor file panel.
  3. cat index.html prints the file. Useful when the preview and the panel file feel out of sync.

Do not run destructive commands

Avoid rm -rf, moving the project root, or installing a global package you do not understand. If a tutorial says to paste one long line, split it first and ask what it changes. The AI assistant can run commands, but you approve them.

Stop a process that is stuck

If a local server does not return to the prompt, press Ctrl+C once. That sends a stop signal; it does not delete files. When the prompt returns, start it again on the same port only if the old process is already gone.

Copy the full error output — the last line is usually the cause — before you open a help chat.
