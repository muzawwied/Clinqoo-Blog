Ambil Screenshot Clincoo dengan URL Terlihat

Gambar tanpa address bar membuat slug dan query hilang. Sertakan URL lengkap saat meminta bantuan.

Artikel ini tersedia dalam: Indonesia · English

Screenshot crop ke tombol saja memaksa orang menebak halaman. Query string dan hash sering jadi penyebab bug di app.clincoo.buzz.

Ambil jendela penuh atau pastikan address bar terlihat. Tempel URL mentah di catatan, bukan hanya gambar.

Blokir data pribadi sebelum unggah. Jangan kirim token di query ke chat publik.

Beri AI URL plus screenshot. Jangan minta AI menebak rute dari piksel tombol.
