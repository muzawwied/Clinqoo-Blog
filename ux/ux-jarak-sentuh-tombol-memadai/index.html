Jarak Sentuh Tombol yang Memadai di Situs Clincoo

Tombol yang saling menempel mudah salah ketuk di ponsel. Beri padding dan jarak antar target.

Artikel ini tersedia dalam: Indonesia · English

Navbar padat dan footer tautan kecil sering lolos pratinjau desktop. Di ponsel, jari mengenai dua tautan sekaligus.

Pakai padding pada tautan, bukan hanya pada teks. Target sentuh sekitar 44px lebih aman.

Minta AI merapikan jarak di satu file CSS, bukan menambah pustaka gesture.

Uji di pratinjau sempit editor.clincoo.buzz. Jika dua tautan bertabrakan, naikkan gap.

Clincoo men-deploy CSS apa adanya. Ukuran sentuh adalah pekerjaan UX sebelum rilis.
