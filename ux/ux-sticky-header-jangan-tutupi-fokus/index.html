Sticky Header Clincoo Jangan Tutupi Fokus Keyboard

Header menempel yang menutupi tautan saat Tab membuat navigasi keyboard gagal. Sisihkan ruang gulir dengan scroll-margin.

Artikel ini tersedia dalam: Indonesia · English

Banyak template Clincoo memakai header sticky. Saat pengguna menekan Tab, tautan di bawah header terfokus tetapi tertutup batang navigasi. Target fokus harus tetap terlihat.

MDN scroll-margin-top pada heading dan tautan memberi jarak gulir sebesar tinggi header. Contoh: a, h2 { scroll-margin-top: 5rem; } sesuaikan dengan tinggi batang asli.

Uji dengan keyboard saja: Tab dari logo ke tautan pertama di body. Jika ring fokus terpotong, naikkan margin, jangan matikan outline. web.dev merinci pola fokus yang aman.

Header yang terlalu tinggi di ponsel merampas viewport. Pertimbangkan header lebih pendek setelah gulir, tetapi tetap jaga tombol menu minimal 44px.

Minta AI hanya menambah scroll-margin pada heading dan target jangkar, bukan menghapus position sticky tanpa alasan.
