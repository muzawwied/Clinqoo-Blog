Pilih 301 untuk Pindah Permanen, 302 untuk Uji Sementara

Kode status pengalihan menentukan apakah mesin pencari mengganti URL lama. Jangan pakai 302 untuk pindah slug permanen.

Artikel ini tersedia dalam: Indonesia · English

Saat folder slug di editor.clincoo.buzz diganti, tautan lama tetap hidup di bookmark dan hasil pencarian. Pengalihan yang salah membuat dua URL bersaing.

Gunakan 301 jika path lama tidak akan kembali. Mesin pencari akan memindahkan sinyal ke URL baru. Gunakan 302 hanya saat menguji halaman musiman atau A/B singkat.

Di hosting statis, cek apakah aturan _redirects atau _headers mendukung kode status. Jangan andalkan meta refresh jika host menyediakan pengalihan HTTP.

Setelah deploy, buka DevTools Network. Pastikan respons pertama adalah 301 atau 302, lalu satu hop ke tujuan, tanpa rantai.

Catat daftar slug lama di README proyek Clincoo agar pengalihan tidak hilang saat template diganti.
