Map an Old Clincoo Slug to the New Slug, Do Not Leave a Silent 404

Changing a slug without a redirect map breaks links already shared. One old-to-new object is enough for a moved page.

This article is available in: Indonesia · English

On app.clincoo.buzz, a page slug often changes when a section name is cleaned up. Visitors who saved the old URL get a 404 even though the content still exists.

Make a small object, for example { 'harga-lama': 'harga' }. When a route is missing, check the map before showing the not-found page.

Redirect with replace, not push, so the back button does not bounce onto the dead slug. Keep a valid filter query.

Do not build a chain: A to B then B to C. Point A straight to C. Chains are harder to trace and slower to load.

Ask AI to add one map entry, not to rewrite the router. Test the old URL in editor.clincoo.buzz and keep a single canonical on blog.clincoo.buzz.
