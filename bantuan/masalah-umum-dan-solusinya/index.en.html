Common Problems and How to Fix Them

Nine out of ten issues in Clincoo share the same causes and have quick fixes. Here are the most frequent ones and their solutions.

Login fails or the Google/GitHub button does not respond

Make sure your browser is not blocking popups — Clincoo OAuth login opens in a new window. If blocked, allow popups for app.clincoo.buzz and try again. For email login, use the password reset option on the sign-in page if you forgot it.

Live preview does not show changes

Changes appear after the file is saved and the preview is reloaded. If you still see the old version, the browser is probably caching: refresh the preview, or clear the site cache for app.clincoo.buzz.

Deploy fails or errors out

First check your plan's deploy quota (Starter 5x, Pro 25x per month). If you still have quota, check your main file name — it must be index.html — and make sure no file is too large. Try deploying again a little later if the trouble persists.

The deployed site shows an old version

The delivery network (CDN) sometimes keeps the old version for a few minutes. Wait briefly and reload, or open the site in incognito mode. If the old version lasts more than an hour, redeploy from Clincoo.

The AI answers off-target or edits files you did not ask about

Reject that suggestion, then ask again with more specific context: name the file and the outcome you expect. One problem per conversation yields far more accurate answers. Full habits in The Clincoo AI Assistant.

A project disappeared from the dashboard

Deleted projects can be restored from the dashboard trash as long as they have not been permanently removed. If a project was permanently deleted, recovery is not available — so review twice before confirming deletion.

Still stuck?

If none of the above solves it, report it through the help menu in the app. Include: what you did, what happened, any error message, and your device type. The more complete your report, the faster the issue can be traced.
