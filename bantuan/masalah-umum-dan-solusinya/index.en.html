Common Problems and How to Fix Them

Nine out of ten issues share the same causes and have quick fixes. Here is the summary — details for each case follow below.

Login fails or the OAuth button does not respond

Clincoo's Google/GitHub login opens in a new window. If popups are blocked, the button feels dead even though it is not. Allow popups for app.clincoo.buzz and try again. For email login, use the password reset option on the sign-in page if you forgot it.

Live preview does not show changes

Changes appear after the file is saved and the preview reloaded. If you still see the old version, it is probably browser cache: refresh the preview, or clear the site cache for app.clincoo.buzz.

Deploy fails or errors out

  1. Check your deploy quota (Starter 5x, Pro 25x per month).
  2. Make sure your main file is named index.html — not Index.html or home.html.
  3. Make sure no file is too large to upload.
  4. Wait a moment and try again; momentary hiccups rarely last.

The deployed site shows an old version

The delivery network (CDN) sometimes keeps the old version for a few minutes. Wait briefly and reload, or open the site in incognito mode. If the old version lasts more than an hour, redeploy from Clincoo.

The AI answers off-target or edits files you did not ask about

Reject that suggestion, then ask again with more specific context: name the file and the outcome you expect. One problem per conversation yields far more accurate answers. Full habits in The Clincoo AI Assistant.

A project disappeared from the dashboard

Deleted projects can be restored from the dashboard trash as long as they have not been permanently removed. After permanent deletion, recovery is not available — so always review twice before confirming deletion.

Still stuck?

Report it through the help menu in the app, including: what you did, what happened, any error message, and your device type. The more complete your report, the faster the issue can be traced.
