Gagal login atau tombol OAuth tidak merespons

Login Google/GitHub Clincoo terbuka di jendela baru. Kalau popup terblokir, tombol terasa mati padahal tidak. Izinkan popup untuk app.clincoo.buzz lalu coba lagi. Untuk login email, gunakan opsi reset sandi di halaman masuk kalau sandi terlupa.

Live preview tidak menampilkan perubahan

Perubahan tampil setelah file disimpan dan preview dimuat ulang. Kalau masih versi lama, kemungkinan besar cache browser: muat ulang preview dengan tombol refresh, atau bersihkan cache situs untuk app.clincoo.buzz.

Deploy gagal atau error

  1. Cek kuota deploy di paketmu (Starter 5x, Pro 25x per bulan).
  2. Pastikan file utama situs bernama index.html — bukan Index.html atau home.html.
  3. Pastikan tidak ada file yang terlalu besar untuk diunggah.
  4. Tunggu sebentar lalu coba deploy ulang; gangguan sesaat jarang berlangsung lama.

Situs yang dideploy tampil versi lama

Jaringan pengiriman (CDN) kadang menyimpan versi lama beberapa menit. Tunggu sebentar lalu muat ulang, atau buka alamat situs dalam mode penyamaran. Kalau versi lama bertahan lebih dari satu jam, deploy ulang dari Clincoo.

AI menjawab melenceng atau mengubah file yang tidak diminta

Tolak saran itu, lalu ajukan ulang dengan konteks lebih spesifik: sebutkan nama file dan hasil yang diharapkan. Satu masalah per obrolan menghasilkan jawaban jauh lebih akurat. Pola lengkapnya di artikel Asisten AI Clincoo.

Proyek hilang dari dashboard

Proyek yang dihapus bisa dipulihkan dari sampah (trash) selama belum dihapus permanen. Setelah dihapus permanen, pemulihan tidak tersedia — karena itu selalu tinjau dua kali sebelum konfirmasi hapus.

Masih bermasalah?

Laporkan lewat menu bantuan di aplikasi dengan menyertakan: apa yang kamu lakukan, apa yang terjadi, pesan error jika ada, dan jenis perangkat. Semakin lengkap laporanmu, semakin cepat masalah bisa ditelusuri.
