Pusat Bantuan · No. 08

Masalah Umum dan Cara Mengatasinya

Sembilan dari sepuluh masalah di Clincoo punya penyebab yang sama dan perbaikan yang cepat. Berikut daftar yang paling sering terjadi beserta solusinya.

Gagal login atau tombol Google/GitHub tidak merespons

Pastikan popup tidak diblokir browser — login OAuth Clincoo terbuka di jendela baru. Kalau popup terblokir, izinkan popup untuk app.clincoo.buzz lalu coba lagi. Untuk login email, gunakan opsi reset sandi di halaman masuk kalau sandi terlupa.

Live preview tidak menampilkan perubahan

Perubahan tampil setelah file disimpan dan preview dimuat ulang. Kalau masih tampil versi lama, kemungkinan browser menyimpan cache: muat ulang preview dengan tombol refresh, atau bersihkan cache situs untuk app.clincoo.buzz.

Deploy gagal atau error

Periksa dulu batas kuota deploy di paketmu (Starter 5x, Pro 25x per bulan). Kalau kuota masih ada, cek nama file utama situs — harus index.html — dan pastikan tidak ada file yang terlalu besar. Coba deploy ulang beberapa saat kemudian kalau gangguan berlanjut.

Situs yang dideploy tampil versi lama

Jaringan pengiriman (CDN) kadang menyimpan versi lama beberapa menit. Tunggu sebentar lalu muat ulang, atau buka alamat situs dalam mode penyamaran. Kalau versi lama bertahan lebih dari satu jam, deploy ulang dari Clincoo.

AI menjawab melenceng atau mengubah file yang tidak diminta

Tolak saran itu, lalu ajukan ulang dengan konteks lebih spesifik: sebutkan nama file dan hasil yang diharapkan. Satu masalah per obrolan menghasilkan jawaban yang jauh lebih akurat. Etika lengkapnya di artikel Asisten AI Clincoo.

Proyek hilang dari dashboard

Proyek yang dihapus bisa dipulihkan dari sampah (trash) di dashboard selama belum dihapus permanen. Kalau proyek tidak sengaja dihapus permanen, pemulihan tidak tersedia — karena itu tinjau dua kali sebelum konfirmasi hapus.

Masih bermasalah?

Kalau semua di atas tidak menyelesaikan masalah, laporkan lewat menu bantuan di aplikasi. Sertakan: apa yang kamu lakukan, apa yang terjadi, pesan error jika ada, dan jenis perangkat. Semakin lengkap laporanmu, semakin cepat masalah bisa ditelusuri.
