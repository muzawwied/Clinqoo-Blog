Cara Merapikan Struktur Folder Proyek

Deploy Clincoo memakai file di proyekmu apa adanya. Kalau nama dan folder tidak konsisten, gambar hilang hanya di situs live padahal preview terasa benar.

Satu pintu masuk

File utama harus bernama index.html di akar proyek, huruf kecil semua. Home.html atau Index.HTML tidak dibaca sebagai halaman depan.

Folder yang cukup

Pola yang aman untuk situs kecil: css/style.css, js/app.js, dan img/ untuk gambar. Dari index.html, tautan ditulis relatif: css/style.css, bukan jalur komputer lokal seperti C:/Users/.

Huruf besar kecil

Nama file di server peka huruf. Foto.JPG dan foto.jpg adalah file berbeda. Samakan ejaan di tag img dan nama unggahan.

Sebelum deploy dari editor, buka tiap tautan di preview. Kalau satu gambar pecah, perbaiki jalurnya dulu. Proyek rapi juga memudahkan AI menunjuk file yang tepat saat kamu minta bantuan.
