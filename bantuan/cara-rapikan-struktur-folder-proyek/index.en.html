How to Organize a Project Folder

A Clincoo deploy publishes the files in your project as they are. If names and folders are inconsistent, images vanish only on the live site even when preview looked fine.

One entry file

The main file must be named index.html at the project root, all lowercase. Home.html or Index.HTML is not treated as the front page.

Enough folders

A safe layout for a small site: css/style.css, js/app.js, and img/ for images. From index.html, links stay relative: css/style.css, not a local computer path such as C:/Users/.

Letter case

File names on the server are case-sensitive. Foto.JPG and foto.jpg are different files. Match the spelling in the img tag and the uploaded name.

Before you deploy from the editor, open each link in preview. If one image breaks, fix that path first. A tidy project also helps the AI point at the right file when you ask for help.
