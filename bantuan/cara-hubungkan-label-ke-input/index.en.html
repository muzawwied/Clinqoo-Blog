How to Connect a Label to a Form Input

A placeholder is not a label. In a form you build at editor.clincoo.buzz, each input needs a name that stays visible.

Pair for and id

label for="email" must point at input id="email". Clicking the label text moves focus into the field. An id must be unique on the page. Do not reuse the same id on two inputs.

Wrap or associate

Wrapping the input inside the label also connects them without for. Pick one method and stay consistent. For a checkbox, a label beside it makes the click target larger.

Do not rely on the placeholder

A placeholder disappears while the user types. Add a label, and use aria-describedby only for extra help. Test with Tab. When it works, deploy from app.clincoo.buzz.
