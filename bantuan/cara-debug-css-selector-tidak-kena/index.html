Cara Debug CSS yang Selektorya Tidak Kena

Kalau class sudah ditulis tapi tampilan tidak berubah di editor.clincoo.buzz, selektor biasanya kalah, salah ketik, atau file CSS belum terhubung.

Cek apakah file CSS termuat

Di tab Network, saring CSS. Status 404 berarti path di tag link salah. Path relatif dihitung dari file HTML, bukan dari folder tempat kamu mengira file itu berada. Simpan kedua file lalu muat ulang preview.

Lihat aturan yang menang

Klik kanan elemen, pilih Inspect, lalu buka tab Styles. Aturan yang dicoret berarti ditimpa. Aturan di bawah yang lebih spesifik, atau yang memakai !important, biasanya pemenangnya. Samakan spesifisitas, jangan langsung menambah !important.

Cocokkan nama class

Bandingkan huruf class di HTML dan CSS, termasuk tanda hubung. .tombol-utama tidak sama dengan .tombol_utama. Pseudo-class seperti :hover hanya aktif saat kursor di atas elemen, jadi uji dengan mengaktifkan state :hover di panel Styles.

Setelah ketemu aturan pemenang, salin selektor dan nama file ke chat AI Clincoo. Sertakan potongan HTML dan CSS yang bersangkutan, bukan hanya kalimat "CSS tidak jalan".
