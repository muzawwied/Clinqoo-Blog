Cara Perbaiki Gambar yang Pecah di Preview

Ikon gambar pecah hampir selalu salah jalur, bukan file yang rusak. Di editor.clincoo.buzz klik gambar, lihat src di panel elemen, lalu bandingkan dengan nama file di pohon proyek.

Samakan jalur relatif

Dari index.html di akar, src="images/hero.jpg" mencari folder images di sebelah index.html. Dari halaman di folder tentang, jalur yang sama mencari tentang/images/hero.jpg. Naik satu folder dengan ../images/hero.jpg.

Huruf besar dan ekstensi

Hero.JPG dan hero.jpg adalah file berbeda di banyak server. Ekstensi .jpeg tidak sama dengan .jpg. Spasi di nama file lebih aman diganti tanda hubung, lalu src diperbarui.

Cek file benar-benar ada

Kalau file belum diunggah, unggah dulu baru simpan HTML. Setelah deploy dari app.clincoo.buzz, buka URL gambar langsung. Status 404 berarti jalur di situs tayang masih salah.
