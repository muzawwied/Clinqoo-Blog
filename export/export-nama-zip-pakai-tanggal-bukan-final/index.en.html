Name Clincoo Export Zips with a Date, Not final.zip

The name final.zip overwrites yesterday's copy. Include the date and project slug.

This article is available in: Indonesia · English

Downloads from editor.clincoo.buzz are often saved as final.zip. The next day the same filename overwrites a copy you still need.

Use the pattern project-YYYYMMDD-HHmm.zip. Lowercase, no spaces. Keep it in an export folder, not mixed on the Desktop.

Do not overwrite an old zip on a fresh download. If the name collides, add a -2 suffix, then note which file was uploaded.

Ask AI to build the name from the slug and local WIB time. Do not ask AI to pack environment secrets into the zip.

Put a sample name on blog.clincoo.buzz so the team stops hunting for final-final-real.
