Catat Daftar File setelah Mengunduh Ekspor Proyek Clincoo

Setelah unduh zip Clincoo, tulis daftar file penting agar pindah host tidak kehilangan aset atau halaman.

Artikel ini tersedia dalam: Indonesia · English

Ekspor dari Clincoo biasanya berupa arsip statis: HTML, CSS, JS, gambar, dan favicon. Banyak orang langsung unggah ke host baru tanpa memeriksa isi. File yang tertinggal baru ketahuan setelah halaman 404 di produksi.

Buka zip di komputer. Tulis daftar singkat: index.html, halaman lain, folder aset, robots.txt, dan berkas font. Bandingkan dengan pohon file di editor.clincoo.buzz. Selisih nama atau huruf besar-kecil sering mematahkan tautan di Linux hosting.

Simpan daftar itu di README atau catatan proyek. Saat mengunggah lewat Git, daftar yang sama menjadi checklist commit. GitHub Docs menekankan bahwa repositori harus berisi semua file yang dibutuhkan build atau tayang, bukan hanya halaman beranda.

Setelah unggah, buka setiap path dari daftar di browser. Jangan hanya menguji beranda. Gambar hero, CSS, dan skrip form adalah kandidat paling sering hilang karena path relatif berubah.

Daftar file membuat ekspor bisa diaudit. Clincoo memberi salinan; tanggung jawab kelengkapan ada pada Anda sebelum DNS dipindah.
