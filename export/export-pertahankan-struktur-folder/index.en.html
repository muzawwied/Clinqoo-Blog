Keep Folder Structure when Exporting a Clincoo Project

Lifting files out of subfolders breaks relative CSS, JS, and image paths. Unzip and upload the Clincoo tree intact.

This article is available in: Indonesia · English

A Clincoo export zip usually has index.html at the root plus an assets folder. If you move HTML to the host root without that folder, stylesheets and the logo break.

After download from editor.clincoo.buzz, extract into one working folder. Do not flatten every file to one level. Paths like ../assets/seo.css depend on folder depth.

Test locally: open index.html in the browser from the unzipped folder. If CSS is missing, check href and src before you change hosts.

Ask AI to review relative links in index.html and inner pages. Paste the zip file list so AI does not suggest absolute paths on your machine.

Clincoo does not rewrite paths when you move hosts. The same folder tree as the export is the safest path to app.clincoo.buzz or other static hosting.
