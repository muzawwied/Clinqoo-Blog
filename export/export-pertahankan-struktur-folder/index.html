Pertahankan Struktur Folder saat Ekspor Proyek Clincoo

Mengangkat file dari subfolder merusak path relatif CSS, JS, dan gambar. Unzip lalu unggah utuh seperti struktur Clincoo.

Artikel ini tersedia dalam: Indonesia · English

Zip ekspor Clincoo biasanya berisi index.html di akar plus folder assets. Jika kamu memindahkan HTML ke root hosting tanpa folder itu, stylesheet dan logo pecah.

Setelah unduh dari editor.clincoo.buzz, ekstrak ke satu folder kerja. Jangan satukan semua file ke satu tingkat. Path seperti ../assets/seo.css mengandalkan kedalaman folder.

Uji lokal: buka index.html di peramban dari folder hasil unzip. Jika CSS hilang, cek atribut href dan src, bukan langsung ganti host.

Minta AI meninjau tautan relatif di index.html dan halaman dalam. Tempel daftar file zip agar AI tidak mengusulkan path absolut ke mesinmu.

Clincoo tidak menulis ulang path saat kamu pindah host. Struktur folder yang sama dengan ekspor adalah cara paling aman ke app.clincoo.buzz atau hosting statis lain.
