Use flex: 1 1 0 so Clincoo Columns Share Space

flex: 1 uses content basis, so a long text column swallows space. A basis of 0 splits free space evenly.

This article is available in: Indonesia · English

On editor.clincoo.buzz, two columns with flex: 1 are often unequal because the automatic basis follows the content.

Use flex: 1 1 0 on both children, plus min-width: 0 if text is long. Free space is then shared equally.

Do not mix flex: 1 and a fixed pixel width on siblings that should match. That doubles the rule.

Check the Flexbox overlay in DevTools. A basis of 0 shows as growing space, not as content width.

Test on app.clincoo.buzz at 360px. Write this pattern on blog.clincoo.buzz so layouts are not guessed again.
