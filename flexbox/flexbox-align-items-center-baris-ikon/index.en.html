Use align-items: center on Clincoo Flexbox Icon Rows

Icons and text in one Clincoo row look uneven when flex items have different heights. Align them with align-items: center.

This article is available in: Indonesian · English

Nav bars, social buttons, and card labels often use display:flex. The default align-items value is stretch. A 20px SVG next to 1rem text will not share a baseline.

Set align-items:center on the flex parent. Children of different heights sit on the cross-axis center. Add gap instead of per-child margin so spacing stays even when the row wraps on a narrow screen.

If only one child must shift, use align-self on that child. Do not add random padding just to nudge an icon. MDN explains the main and cross axes; web.dev shows the same icon-row pattern.

Test in Clincoo preview at 150 percent text zoom. Icons with align-items:center stay aligned. Icons that lean on line-height still drift.

A tidy icon row clarifies visual hierarchy without JavaScript. One parent property is easier to maintain than negative margins on every SVG.
