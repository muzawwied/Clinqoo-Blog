Pakai flex-wrap: nowrap pada Toolbar Horizontal Clincoo

Toolbar ikon yang wrap jadi dua baris merusak tinggi header. Nowrap plus overflow-x auto menjaga satu garis di Clincoo.

Artikel ini tersedia dalam: Indonesia · English

Baris tombol di header proyek Clincoo sering memakai display:flex. Jika wrap aktif, ikon turun ke baris kedua saat layar sempit dan header menjadi tinggi ganda.

Di editor.clincoo.buzz, set flex-wrap: nowrap pada wadah toolbar. Tambahkan overflow-x: auto agar tombol ekstra bisa digeser, bukan dipaksa mengecil sampai tak terbaca.

Jangan gabungkan nowrap dengan flex-shrink: 1 pada label panjang. Label akan menyusut hingga ellipsis tanpa ruang sentuh. Tetapkan min-width pada tombol utama.

Minta AI memisahkan aturan toolbar dari kartu yang memang harus wrap. Tempel CSS header yang sekarang memakai flex-wrap: wrap.

Clincoo merender CSS yang kamu simpan. Toolbar satu garis lebih mudah dipakai di HP tanpa mengubah grid halaman.
