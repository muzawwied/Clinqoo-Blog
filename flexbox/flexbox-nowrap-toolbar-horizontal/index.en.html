Use flex-wrap: nowrap on a Horizontal Clincoo Toolbar

An icon toolbar that wraps onto two rows breaks header height. Nowrap plus overflow-x auto keeps one line in Clincoo.

This article is available in: Indonesia · English

Button rows in a Clincoo project header often use display:flex. If wrap is on, icons drop to a second row on a narrow screen and the header doubles in height.

In editor.clincoo.buzz, set flex-wrap: nowrap on the toolbar container. Add overflow-x: auto so extra buttons scroll instead of shrinking until they are unreadable.

Do not mix nowrap with flex-shrink: 1 on long labels. Labels shrink to an ellipsis without a usable tap target. Set min-width on primary buttons.

Ask AI to split toolbar rules from cards that should wrap. Paste the header CSS that currently uses flex-wrap: wrap.

Clincoo renders the CSS you save. A single-line toolbar is easier to use on a phone without changing the page grid.
