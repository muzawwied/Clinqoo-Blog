Set min-width 0 pada Item Flex Clincoo yang Menyimpan Teks

Item flex default min-width:auto menolak menyusut. Teks panjang mendorong layout keluar viewport.

Artikel ini tersedia dalam: Indonesia · English

Kartu judul panjang di editor.clincoo.buzz memaksa baris flex melebihi layar. Overlay DevTools menunjukkan item tidak boleh lebih kecil dari konten.

Tambah min-width:0 dan overflow-wrap pada item yang memuat teks. Jangan andalkan flex-shrink saja.

Tempel kelas item ke AI. Minta satu aturan, bukan rewrite layout. Uji 320px di app.clincoo.buzz.

Catat pola ini di blog.clincoo.buzz agar judul panjang tidak merusak header.
