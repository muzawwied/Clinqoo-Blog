Add a Skip Link to Main Content on a Clincoo Site

Keyboard users should not tab through the whole menu. A skip link to main content must appear on focus.

This article is available in: Indonesia · English

A long menu in editor.clincoo.buzz forces keyboard users to tab many times before the content. A skip link cuts that path.

Place the first link in the body pointing at the main content id, such as #isi. Hide it visually, then show it on :focus with a fixed position at the top.

The target must be focusable. On main, add tabindex=-1 so focus actually moves after the click, not only the scroll position.

Test in the app.clincoo.buzz preview: load the page, press Tab once, confirm the link is visible, then Enter moves focus to the content heading.

If the skip link never appears, paste the :focus CSS into AI and ask for one fix. Do not ask it to rebuild the navbar.
