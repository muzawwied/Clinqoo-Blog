Pasang Skip Link ke Konten Utama di Situs Clincoo

Pengguna keyboard tidak perlu menekan Tab belasan kali melewati menu. Tautan lompat ke konten utama harus muncul saat fokus.

Artikel ini tersedia dalam: Indonesia · English

Menu panjang di editor.clincoo.buzz memaksa pengguna keyboard menekan Tab berulang sebelum sampai ke isi. Skip link memotong jalur itu.

Letakkan tautan pertama di body menuju id konten utama, misalnya #isi. Sembunyikan secara visual, lalu tampilkan saat :focus dengan posisi tetap di atas halaman.

Elemen tujuan wajib bisa difokuskan. Pada main, tambahkan tabindex=-1 agar fokus benar-benar pindah setelah tautan diklik, bukan hanya scroll.

Uji di pratinjau app.clincoo.buzz: muat halaman, tekan Tab sekali, pastikan tautan terlihat, lalu Enter memindahkan fokus ke judul konten.

Jika skip link tidak muncul, tempel CSS :focus ke AI dan minta satu perbaikan. Jangan minta merombak seluruh navbar.
