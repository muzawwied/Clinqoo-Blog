Close the Mobile Menu with Escape on a Clincoo Site

A hamburger menu that closes only from the icon traps keyboard users. Listen for Escape, then return focus to the menu button.

This article is available in: Indonesia · English

A mobile menu in the editor.clincoo.buzz preview often closes only when the icon is clicked again.

Add a keydown listener on the document while the menu is open. If event.key is Escape, close the panel and call preventDefault.

After closing, return focus to the button that opened the menu. The user should not have to find that button with Tab.

Test on app.clincoo.buzz without a mouse: open the menu, press Escape, confirm the panel is gone and focus is back.

Do not close the menu on every key. Escape is for cancel, not for choosing a link.
