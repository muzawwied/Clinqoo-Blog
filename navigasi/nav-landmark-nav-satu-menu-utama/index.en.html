Use One nav Landmark for the Main Menu on a Clincoo Site

Several unnamed nav elements confuse screen readers. One labeled main menu is enough for most sites.

This article is available in: Indonesia · English

Clincoo templates sometimes wrap the header, footer, and sidebar in <nav> elements. A screen reader then offers three landmarks with the same name. Visitors cannot tell which one is the main menu.

Keep a single <nav aria-label="Main menu"> in the header. Footer links can stay inside <footer> without a second nav, or use a second nav with a different aria-label such as "Footer links". Never leave two unnamed navs.

Landmarks help keyboard jumps. A skip link to #main is still needed, but a short landmark list is easier to remember than a row of anonymous navs. Check tab order in the editor.clincoo.buzz preview.

If AI adds a nav inside a card or a slider, remove that landmark. A list of links in a <ul> is enough. The navigation role belongs only to blocks that actually navigate the site.

Before you ship a subdomain, open a screen reader or the DevTools accessibility pane. Confirm that only the landmarks you planned appear. Clear HTML structure lasts longer than a CSS class that only changes looks.
