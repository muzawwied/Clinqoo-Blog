Mark the Active Menu Item with aria-current on Clincoo Sites

A CSS class alone is not enough for screen readers. Put aria-current="page" on the menu link for this page.

Indonesia · English

Many Clincoo templates only add class="active" to the menu link. The color changes, but a screen reader never hears that this is the current page.

MDN specifies aria-current="page" as the signal for the active navigation item. Set it on the link that matches the URL, not on every item.

Do not rely on JavaScript that marks every link and forgets to clear it on a static site. On Clincoo static pages, write the attribute in each page HTML.

Test with Tab and a screen reader in preview. The active link must stay tappable, stay contrasted, and be announced as the current page.

One nav landmark, one link set, one aria-current. An honest menu beats an underline animation.
