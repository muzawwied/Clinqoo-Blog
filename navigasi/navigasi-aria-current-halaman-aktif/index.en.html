Mark the Active Clincoo Page with aria-current

A menu that only bolds the active link confuses screen readers. Use aria-current=page.

This article is available in: Indonesia · English

The sidebar on editor.clincoo.buzz often marks the active page with color alone. Keyboard users never hear the difference.

On the open link, set aria-current="page". Other links must not have that attribute. Do not put aria-current on a wrapping div.

Match the pathname, not the button text. A query such as ?lang=en must not make every item look inactive.

Visual style can stay, but do not rely on color alone. Ask AI to add the attribute, then test with Tab on app.clincoo.buzz.

Document the pattern on blog.clincoo.buzz so new templates do not repeat a menu without state.
