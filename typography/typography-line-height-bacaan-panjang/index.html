Naikkan Line-Height pada Teks Bacaan Panjang Clincoo

Teks padat di kartu blog sulit dibaca di ponsel. Pisahkan line-height judul dan paragraf.

Artikel ini tersedia dalam: Indonesia · English

Banyak template Clincoo memakai line-height 1.2 untuk semua teks. Paragraf di blog.clincoo.buzz lalu terasa sesak di layar sempit.

Di editor.clincoo.buzz, set heading ke 1.2–1.3 dan body ke 1.5–1.7. Jangan wariskan satu nilai dari body ke h1.

Uji di pratinjau mobile: jika baris saling menempel, naikkan line-height body saja, bukan font-size global.

Minta AI mengusulkan token tipografi, bukan rewrite CSS lengkap app.clincoo.buzz.

Clincoo tetap memakai font merek; yang diubah hanya jarak baris bacaan.
