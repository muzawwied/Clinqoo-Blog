Use text-wrap: balance on Clincoo Headings

Uneven two-line titles make category cards look sloppy. text-wrap: balance evens lines without manual breaks.

Indonesia · English

Card titles and hero h1 often wrap so the last line holds a single word. MDN explains that text-wrap: balance asks the layout engine to even line lengths on short blocks such as headings.

Practical Clincoo use: h1, card h2, and modal titles get text-wrap: balance. Do not put it on long paragraphs; the cost rises and the gain is small. web.dev suggests balance for titles.

Test at 320px with a long Indonesian title. If it still looks lopsided, lower font-size or shorten copy instead of inserting manual breaks that fail on desktop.

text-wrap: pretty prefers avoiding orphans at the end of a paragraph. Combine it with a 60-75 character measure so line length stays comfortable.

Ask the AI only to add text-wrap on existing heading selectors. Do not rewrite all typography. Check overflow on category cards after preview.

Sources: MDN text-wrap, MDN text-wrap-style, web.dev CSS text-wrap: balance.
