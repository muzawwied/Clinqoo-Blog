Turn Off a Stale Service Worker when Testing a Clincoo Preview

An old SW serves yesterday HTML. A CSS fix looks broken until you unregister the worker.

This article is available in: Indonesia · English

On editor.clincoo.buzz, preview still shows the old header even after the file changed.

Open Application → Service Workers. Unregister, then hard-refresh. In Network the document must come from the server, not (from ServiceWorker).

Do not ask AI to rewrite the header before the old SW is gone.

Retest on app.clincoo.buzz. Write the unregister steps on blog.clincoo.buzz.
