Capture a Full-Page Screenshot when Reviewing a Clincoo Preview

A first-fold crop hides footer overflow. Record the full page height before you ask for help.

This article is available in: Indonesia · English

On editor.clincoo.buzz, the hero looks fine but the footer menu clips on a 1366px screen.

In the DevTools Command Menu pick Capture full size screenshot. Inspect the bottom and sides.

Send the full image to AI, not only the hero crop.

Repeat on app.clincoo.buzz. Store an example on blog.clincoo.buzz.
