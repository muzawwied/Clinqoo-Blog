Check Mixed Content on a Clincoo HTTPS Preview

HTTP images or scripts on an HTTPS page get blocked. Preview looks broken with no obvious UI error.

This article is available in: Indonesia · English

On editor.clincoo.buzz, an http:// CDN icon vanishes after the site uses HTTPS.

Open the console and search Mixed Content. Switch every asset to https:// or a relative path.

Paste one blocked URL to AI, not the whole HTML file.

Repeat on app.clincoo.buzz and link the asset list on blog.clincoo.buzz.
