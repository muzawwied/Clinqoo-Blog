Kunci aspect-ratio Gambar dan Iframe Clincoo agar Layout Tidak Loncat

Media tanpa rasio membuat kartu meloncat saat file selesai dimuat. Cadangkan kotak dengan aspect-ratio sebelum src tiba.

Artikel ini tersedia dalam: Indonesia · English

Loncatan layout di halaman Clincoo sering berasal dari gambar atau iframe yang belum punya ukuran. Browser belum tahu tinggi media, jadi teks di bawahnya naik, lalu tiba-tiba turun ketika file selesai.

Properti CSS aspect-ratio memberi kotak cadangan. Untuk foto 3:2 tulis aspect-ratio: 3 / 2 pada bungkus atau pada img. Untuk video 16:9, bungkus iframe dengan rasio itu dan biarkan iframe absolute mengisi kotak.

Kalau kamu tahu lebar-tinggi asli, atribut width dan height pada img juga membantu browser menghitung rasio sebelum CSS tiba. Kombinasikan dengan width: 100%; height: auto agar tetap responsif.

Jangan mengunci tinggi dengan px mati pada media yang harus mengecil di HP. px mati memotong gambar atau meninggalkan celah besar. Rasio menjaga bentuk; lebar mengikuti kolom.

Lazy-load tidak meniadakan kebutuhan rasio. Justru saat loading="lazy", kotak cadangan lebih penting karena media muncul belakangan. Tanpa rasio, lazy-load terasa seperti halaman yang terus bergeser.

Uji di pratinjau Clincoo: matikan cache, muat ulang, dan perhatikan judul serta tombol di bawah hero. Jika mereka tidak bergeser saat gambar datang, rasio sudah bekerja.
