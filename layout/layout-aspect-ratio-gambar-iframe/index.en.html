Lock aspect-ratio on Clincoo Images and Iframes so Layout Does Not Jump

Media without a ratio makes cards jump when the file finishes loading. Reserve the box with aspect-ratio before src arrives.

This article is available in: Indonesia · English

Layout jumps on a Clincoo page often come from images or iframes that have no size yet. The browser does not know the media height, so text below rises, then drops when the file arrives.

The CSS aspect-ratio property reserves the box. For a 3:2 photo set aspect-ratio: 3 / 2 on the wrapper or the img. For 16:9 video, wrap the iframe in that ratio and let the iframe fill the box.

If you know the intrinsic width and height, width and height attributes on img also help the browser compute the ratio before CSS arrives. Combine them with width: 100%; height: auto so the image stays responsive.

Do not lock media height with a dead px value that must shrink on phones. Dead pixels crop the image or leave a large gap. The ratio keeps the shape; width follows the column.

Lazy-load does not remove the need for a ratio. When loading="lazy" is set, the reserved box matters more because media appears late. Without a ratio, lazy-load feels like a page that keeps shifting.

Test in Clincoo preview: disable cache, reload, and watch the heading and button under the hero. If they do not move when the image arrives, the ratio is doing its job.
