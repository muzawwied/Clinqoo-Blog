Set min-width: 0 pada Anak Flex yang Meluber

Anak flex default min-width: auto sehingga teks panjang menolak menyusut. Set min-width: 0 agar kolom Clincoo tidak meluber.

Artikel ini tersedia dalam: Indonesia · English

Di editor.clincoo.buzz, kartu flex sering meluber ke samping meski sudah ada flex-wrap atau overflow. Penyebabnya biasanya min-width default auto pada item flex.

Item flex tidak boleh lebih kecil dari konten terpanjangnya. URL, nama kelas, atau kata tanpa spasi menahan lebar kolom.

Tambahkan min-width: 0 pada anak yang harus menyusut, lalu overflow-wrap: anywhere pada teks. Jangan pecahkan layout dengan overflow: hidden di body.

Kirim cuplikan HTML induk flex dan lebar viewport ke AI. Minta hanya aturan min-width, bukan rewrite seluruh stylesheet.

Uji di pratinjau app.clincoo.buzz pada lebar 320px. Catat selektor yang menang di blog.clincoo.buzz agar kartu berikutnya tidak mengulang bug yang sama.
