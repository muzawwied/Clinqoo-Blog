Set min-width: 0 on Flex Children That Overflow

Flex children default to min-width: auto, so long text refuses to shrink. Set min-width: 0 so Clincoo columns do not overflow.

This article is available in: Indonesia · English

On editor.clincoo.buzz, flex cards often spill sideways even with flex-wrap or overflow. The usual cause is the default min-width: auto on flex items.

A flex item may not shrink below its longest content. A URL, class name, or unspaced word holds the column width.

Add min-width: 0 on the child that must shrink, then overflow-wrap: anywhere on the text. Do not fix the layout with overflow: hidden on body.

Send the parent flex HTML snippet and the viewport width to AI. Ask only for the min-width rule, not a full stylesheet rewrite.

Test the preview on app.clincoo.buzz at 320px. Record the winning selector on blog.clincoo.buzz so the next card does not repeat the bug.
