Pakai clamp untuk Lebar dan Ukuran Hero Clincoo, Bukan px Mati

Hero 1200px atau font 64px pecah di HP. clamp() menyesuaikan tanpa media query bertingkat.

Artikel ini tersedia dalam: Indonesia · English

Hero situs Clincoo sering ditulis dengan lebar dan ukuran font tetap karena terlihat pas di laptop editor. Di ponsel, 64px memaksa judul turun tiga baris dan tombol CTA terdorong keluar lipatan. Angka mati memindahkan pekerjaan ke media query yang mudah terlupa.

Fungsi CSS clamp(min, preferred, max) memberi batas bawah, nilai yang tumbuh dengan viewport, dan batas atas. Contoh: font-size: clamp(1.5rem, 4vw + 1rem, 3rem) menjaga judul terbaca di HP tanpa meraksasa di monitor lebar.

Terapkan pola yang sama pada padding hero dan max-width konten di dalamnya. Jangan mengunci height hero ke piksel. Biarkan tinggi mengikuti teks, tombol, dan jarak, lalu batasi hanya jika desain benar-benar butuh lantai minimum.

Uji di tiga lebar: 360px, 768px, dan 1280px. Jika judul, subjudul, dan satu CTA tetap dalam satu pandangan tanpa scroll horizontal, clamp sudah bekerja. Jika masih pecah, turunkan nilai max, bukan menambah breakpoint baru.

Simpan nilai clamp di variabel CSS agar hero, kartu, dan section memakai tangga yang sama. Konsistensi token lebih mudah diaudit daripada sepuluh angka acak di berkas style.
