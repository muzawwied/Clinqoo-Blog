Tutup Spinner Clincoo di blok finally setelah Fetch

Spinner yang hanya hilang di cabang sukses akan macet saat error. finally selalu jalan.

Artikel ini tersedia dalam: Indonesia · English

Pola umum di proyek Clincoo: tampilkan spinner, await fetch, lalu sembunyikan spinner. Jika throw terjadi, spinner tidak pernah hilang.

Pakai try { const r = await fetch(url); … } catch (e) { tampilkan error; } finally { spinner.hidden = true; tombol.disabled = false; }

finally berjalan setelah return di try maupun setelah throw. Jangan taruh logika bisnis di finally, hanya pembersihan UI.

Jika ada beberapa spinner, tutup yang sama yang kamu buka di awal fungsi, bukan semua spinner di halaman.

Uji dengan URL yang menolak CORS atau status 500. Spinner harus hilang dan pesan error terlihat tanpa reload.

Clincoo menjalankan skrip yang kamu simpan. finally menjaga pratinjau app.clincoo.buzz tidak terkunci pada overlay memuat.
