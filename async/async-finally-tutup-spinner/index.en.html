Hide the Clincoo Spinner in finally after Fetch

A spinner hidden only on the success path sticks when an error throws. finally always runs.

Artikel ini tersedia dalam: Indonesia · English

A common Clincoo pattern: show a spinner, await fetch, then hide the spinner. If a throw happens, the spinner never leaves.

Use try { const r = await fetch(url); … } catch (e) { show the error; } finally { spinner.hidden = true; button.disabled = false; }

finally runs after a return in try and after a throw. Do not put business logic in finally, only UI cleanup.

If there are several spinners, hide the same one you opened at the start of the function, not every spinner on the page.

Test with a CORS-blocked URL or status 500. The spinner must disappear and the error message must show without a reload.

Clincoo runs the script you save. finally keeps the app.clincoo.buzz preview from locking on a loading overlay.
