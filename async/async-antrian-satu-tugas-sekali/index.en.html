Queue Clincoo Async Jobs so Only One Runs at a Time

Two parallel uploads overwrite the same file. A serial queue keeps order.

Artikel ini tersedia dalam: Indonesia · English

Autosave and image upload on a Clincoo site can run together and overwrite a file version.

Build a small queue: an array of promises and enqueue(fn) that waits for the previous job before running fn.

Do not use Promise.all to write the same file. all is fine for parallel reads, not for dependent writes.

If a new job makes the old one irrelevant, abort the old one with AbortController, then enqueue the new job.

Test in editor.clincoo.buzz: trigger save twice in a row. Logs should show the second job starting after the first finishes.

Clincoo runs the JS you save. A serial queue keeps the app.clincoo.buzz preview from corrupting due to a write race.
