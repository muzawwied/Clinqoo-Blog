Debounce Input Pencarian Clincoo sebelum Fetch

Setiap ketikan memicu fetch menumpuk respons. Tunggu jeda singkat sebelum request baru.

Artikel ini tersedia dalam: Indonesia · English

Di editor Clincoo, kolom cari yang memanggil fetch pada setiap event input membuat jaringan sibuk dan hasil muncul tidak berurutan.

Simpan timer di luar handler. Pada input, clearTimeout lalu setTimeout 250–400 ms yang baru memanggil fungsi async pencarian.

Gabungkan debounce dengan AbortController: saat timer baru jalan, batalkan fetch lama supaya respons usang tidak menimpa daftar.

Jangan debounce klik tombol kirim. Debounce hanya untuk ketikan; klik tetap langsung fetch dengan loading flag.

Uji di editor.clincoo.buzz: ketik cepat lima huruf. Hanya satu request terakhir yang boleh selesai dan merender hasil.

Clincoo menjalankan JS yang kamu simpan. Debounce menjaga pratinjau app.clincoo.buzz tetap responsif saat pengguna mengetik.
