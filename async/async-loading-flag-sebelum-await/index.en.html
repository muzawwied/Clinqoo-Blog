Set a Clincoo Loading Flag before await Fetch

Without a flag the button can be clicked twice. Set loading true first, then await.

Artikel ini tersedia dalam: Indonesia · English

Many Clincoo scripts call fetch straight from a click. A double click sends two requests and corrupts form state.

At the start of the handler: if (loading) return; loading = true; disable the button; then await fetch. In finally, loading = false and enable again.

Show 'Loading…' text or aria-busy on the results container so screen readers know work is still running.

Do not rely on disabled alone if the button is swapped for another element. A JS variable flag is the source of truth.

Test in editor.clincoo.buzz with three fast clicks. Only one request should go out.

Clincoo runs the JS you save. A loading flag keeps the app.clincoo.buzz preview from stacking async work.
