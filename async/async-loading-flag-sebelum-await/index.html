Pasang Flag Loading Clincoo sebelum await Fetch

Tanpa flag, tombol bisa diklik dua kali. Set loading true dulu, baru await.

Artikel ini tersedia dalam: Indonesia · English

Banyak skrip Clincoo memanggil fetch langsung dari klik. Klik ganda mengirim dua request dan merusak state form.

Di awal handler: if (loading) return; loading = true; nonaktifkan tombol; baru await fetch. Di finally, loading = false dan aktifkan lagi.

Tampilkan teks 'Memuat…' atau atribut aria-busy pada wadah hasil supaya pembaca layar tahu proses masih jalan.

Jangan andalkan disabled saja jika tombol diganti elemen lain. Flag di variabel JS adalah sumber kebenaran.

Uji di editor.clincoo.buzz dengan klik cepat tiga kali. Hanya satu request yang boleh keluar.

Clincoo menjalankan JS yang kamu simpan. Flag loading menjaga pratinjau app.clincoo.buzz tidak menumpuk operasi async.
