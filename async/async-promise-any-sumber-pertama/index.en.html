Take the First Successful Clincoo Source with Promise.any

Promise.all waits for every request. Promise.any uses the first resolve so the preview does not wait on a slow CDN.

Artikel ini tersedia dalam: Indonesia · English

Clincoo scripts often hit a primary CDN and a local assets copy. Promise.all only finishes after both respond, so one slow host blocks the whole card.

Use Promise.any([fetch(primary), fetch(fallback)]). The value is the first Response that fulfills. If every request rejects, catch AggregateError and show one line in the preview.

Do not mix Promise.any with an unbounded Promise.race. race also settles on the first reject; any ignores failures until nothing remains. That is what you want when one host 404s and the other is healthy.

Test in editor.clincoo.buzz with a bad primary URL and a good fallback. The card must fill from the fallback without a reload. Check Network so the losing request does not overwrite the DOM.

Clincoo runs the JS you save. Promise.any keeps app.clincoo.buzz responsive when one source fails, without changing await flow elsewhere.
