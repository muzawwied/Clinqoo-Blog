Stop Looping Animation When prefers-reduced-motion Is On

A looping hero animation distracts people who asked for less motion. Disable the loop with a media query instead of deleting all CSS.

This article is available in: Indonesia · English

On editor.clincoo.buzz, a hero that spins forever still runs when the operating system asks for reduced motion. Vestibular users can get dizzy from a preview card alone.

Add @media (prefers-reduced-motion: reduce) and set animation: none and transition: none on decorative elements. Keep focus color changes so keyboard users still see a cue.

Do not delete the whole stylesheet. Separate an .is-decorative class from motion that explains status, such as an upload spinner on app.clincoo.buzz.

When asking AI for help, paste the keyframes snippet and request a reduce variant only. Do not ask it to rewrite the page.

Test in DevTools by emulating prefers-reduced-motion. Note the pattern on blog.clincoo.buzz if other templates share it.
