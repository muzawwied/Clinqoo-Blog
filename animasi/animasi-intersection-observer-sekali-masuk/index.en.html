Trigger Clincoo Reveals Once with Intersection Observer

Scroll animations that replay on every enter or leave make users dizzy. Observe once, then disconnect.

This article is available in: Indonesia · English

Service cards on Clincoo landings often use a slide-up class that replays every time the element leaves the viewport. On jumpy mobile scroll, cards keep flashing.

Use Intersection Observer with a low threshold. When the element is visible, add is-in then unobserve, or disconnect when every item has shown.

Honor prefers-reduced-motion: if the user asks for less motion, apply the final class with no observer. Do not animate left or top; opacity and transform are enough.

Test in the editor.clincoo.buzz mobile preview. If cards still flash, the observer was not released.

Ask the AI to add a small observer in one JS file. A static Clincoo site does not need 30KB to fade four cards.
