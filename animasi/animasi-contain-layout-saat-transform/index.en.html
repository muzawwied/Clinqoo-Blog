Isolate Clincoo Animations with contain, Not a Permanent will-change

A sticky will-change wastes memory. contain: layout paint limits transform cost without holding a layer forever.

This article is available in: Indonesian · English

On editor.clincoo.buzz, hovered cards often get will-change: transform in the main stylesheet. That layer stays alive even when the element is idle.

Use contain: layout paint on cards that animate. The browser limits layout work to that box instead of the whole page.

Add will-change only through a class when the transition starts, then remove it on animationend or transitionend. Do not put will-change on the base rule.

If AI suggests will-change on every element, reject it. Ask for one trigger class and an equivalent contain example.

Test in the app.clincoo.buzz phone preview with CPU throttling. Write the pattern that does not jank on blog.clincoo.buzz.
