Pakai View Transitions untuk Pindah Halaman Clincoo

Transisi halaman yang halus tidak butuh pustaka slider. View Transitions API cukup untuk situs Clincoo statis.

Artikel ini tersedia dalam: Indonesia · English

Banyak template Clincoo menambahkan library animasi halaman hanya supaya beranda terasa "mahal". File tambahan itu membebani unduhan pertama, padahal browser modern sudah punya View Transitions API untuk memudar atau menggeser antar dokumen.

Mulai dari yang paling ringan: aktifkan @view-transition { navigation: auto; } di CSS. Pengunjung yang browsernya mendukung mendapat fade antar halaman tanpa JavaScript. Pengunjung lain tetap pindah halaman seperti biasa — tidak ada tombol yang tertahan.

Kalau satu elemen harus tetap terlihat (logo di header, kartu produk yang diklik), beri view-transition-name yang sama di halaman asal dan tujuan. Jangan beri nama pada puluhan elemen; setiap nama membuat snapshot ekstra dan mudah bentrok saat AI menyalin template.

Hormati prefers-reduced-motion. Jika sistem operasi meminta gerakan minim, matikan navigasi otomatis. Uji di pratinjau Clincoo: klik menu, tombol kembali, dan tautan internal. Transisi yang bagus tidak menunda klik dan selesai di bawah 300 ms.

Jangan gabungkan View Transitions dengan slider hero yang loop tanpa henti. Satu jenis gerak di satu waktu membuat merek terasa tenang dan cepat.
