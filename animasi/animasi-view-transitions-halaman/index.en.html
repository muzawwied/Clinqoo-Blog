Use View Transitions for Clincoo Page Changes

Smooth page changes do not need a slider library. The View Transitions API is enough for a static Clincoo site.

This article is available in: Indonesia · English

Many Clincoo templates add a page-animation library just so the home page feels expensive. That extra file taxes the first download, while modern browsers already ship a View Transitions API to fade or slide between documents.

Start light: enable @view-transition { navigation: auto; } in CSS. Visitors whose browsers support it get a fade between pages with no JavaScript. Everyone else still navigates normally — no button gets stuck.

If one element should stay visible (the header logo, a product card that was clicked), give the same view-transition-name on the source and destination pages. Do not name dozens of elements; each name creates an extra snapshot and collides when AI copies a template.

Honor prefers-reduced-motion. If the OS asks for less motion, turn automatic navigation off. Test in Clincoo preview: click the menu, the back button, and internal links. A good transition does not delay the click and finishes under 300 ms.

Do not mix View Transitions with a hero slider that loops forever. One kind of motion at a time keeps the brand calm and fast.
