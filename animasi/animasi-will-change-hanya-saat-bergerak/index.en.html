Use will-change Only while a Clincoo Element Is Actually Moving

will-change: transform on every card wastes memory. Set it on hover or an animation class, then remove it.

This article is available in: Indonesia · English

will-change hints that an element will animate. The hint helps, but if you set it permanently on dozens of cards the browser prepares layers that never move.

On a Clincoo page, apply will-change only to elements that actually move: a sliding modal, a hover scale, or a one-shot hero fade. After the transition ends, remove it with a CSS class or the transitionend event.

Honor prefers-reduced-motion. If the user asked for less motion, do not prepare animation layers. Disable non-essential transitions in that media query.

Test on a mid-range phone. A gallery where every card has will-change often makes scrolling heavy even if the animation is “only 200ms”. The DevTools performance panel shows extra layers.

Prefer transform and opacity. Moving top, left, or width triggers layout. Short-lived transform plus will-change is enough for a static landing UI.
