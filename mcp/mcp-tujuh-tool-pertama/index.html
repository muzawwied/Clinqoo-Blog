Tujuh Tool Server MCP Clinqoo: dari Info Akun sampai Agent Mode

get_me, list_projects, saldo dompet, riwayat transaksi, agent task, status agent, dan notifikasi.

Artikel ini tersedia dalam: Indonesia · English

Server MCP Clinqoo membuka tujuh tool. get_me mengembalikan info akun yang sedang login lewat token Anda.

list_projects menampilkan seluruh proyek, sedangkan get_wallet_balance dan list_wallet_transactions menampilkan saldo dan riwayat ClincooPay.

Untuk pekerjaan panjang, start_agent_task memulai Agent Mode Clinqoo di latar belakang langsung dari editor AI Anda.

get_agent_status memantau kemajuan dan events agent task tersebut, dan list_notifications membawa notifikasi terbaru akun.

Ketujuh tool ini membaca data lewat API resmi Clinqoo, jadi aturan kuota dan izin akun Anda tetap berlaku.
