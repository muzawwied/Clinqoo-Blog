Seven Tools on the Clinqoo MCP Server: from Account Info to Agent Mode

get_me, list_projects, wallet balance, transactions, agent tasks, agent status, and notifications.

This article is available in: Indonesia · English

The Clinqoo MCP server exposes seven tools. get_me returns the account info for the token you are logged in with.

list_projects shows all your projects, while get_wallet_balance and list_wallet_transactions show your ClincooPay balance and history.

For long jobs, start_agent_task kicks off Clinqoo Agent Mode in the background straight from your AI editor.

get_agent_status tracks that task's progress and events, and list_notifications brings in your latest notifications.

All seven tools read through the official Clinqoo API, so your account's quota and permission rules still apply.
