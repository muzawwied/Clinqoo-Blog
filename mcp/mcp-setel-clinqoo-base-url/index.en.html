Set CLINQOO_BASE_URL before Using MCP Tools

MCP tools call the Clincoo API. If the host is wrong, get_me fails even when the token is correct.

This article is available in: Indonesia · English

The Clincoo MCP server reads CLINQOO_BASE_URL from the editor config environment. The default points at the repo host, not always your account host.

Match it to the host you use when logging in at app.clincoo.buzz. Do not put the blog.clincoo.buzz URL in this variable.

After changing the env, restart the editor. The old server process keeps the previous value until it is started again.

Test with get_me. If the account identity comes back, the base URL is correct. Only then move on to list_projects.

Do not paste a URL that contains a token into chat. Name the variable and ask the AI editor to run the tool.
