Uji Koneksi MCP Clinqoo dengan get_me Sebelum Tool Lain

Panggil get_me dulu. Jika identitas akun tidak kembali, tool proyek dan dompet hanya akan gagal dengan pesan yang membingungkan.

Artikel ini tersedia dalam: Indonesia · English

Setelah mendaftarkan server di .cursor/mcp.json, minta editor AI menjalankan get_me. Respons harus memuat identitas akun Clinqoo Anda.

Jika tool tidak muncul, cek path build/index.js dan bahwa proses server benar-benar jalan. Restart editor setelah mengubah konfigurasi.

Kesalahan token biasanya terlihat di sini, bukan di list_projects. Perbaiki CLINQOO_TOKEN sebelum mencoba Agent Mode.

Cocokkan nama akun di get_me dengan akun yang login di app.clincoo.buzz. Token dari akun lain akan mengedit proyek yang salah.

Baru setelah get_me berhasil, lanjut ke list_projects atau get_wallet_balance. Urutan ini memisahkan masalah koneksi dari masalah data.
