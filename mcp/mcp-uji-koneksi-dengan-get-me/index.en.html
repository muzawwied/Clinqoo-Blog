Test the Clinqoo MCP Connection with get_me Before Other Tools

Call get_me first. If the account identity does not come back, project and wallet tools will only fail with a confusing message.

This article is available in: Indonesia · English

After registering the server in .cursor/mcp.json, ask the AI editor to run get_me. The response should include your Clinqoo account identity.

If the tool does not appear, check the build/index.js path and that the server process is actually running. Restart the editor after config changes.

Token errors usually show up here, not in list_projects. Fix CLINQOO_TOKEN before trying Agent Mode.

Match the account name from get_me with the account logged in at app.clincoo.buzz. A token from another account will edit the wrong project.

Only after get_me succeeds, move on to list_projects or get_wallet_balance. This order separates connection problems from data problems.
