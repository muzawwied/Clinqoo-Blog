Do Not Paste a Clinqoo Token into the Prompt, Leave It in the MCP Env

A token inside chat can land in conversation logs. The MCP server already reads CLINQOO_TOKEN from the environment.

This article is available in: Indonesia · English

The AI editor does not need to see the token value. Put it in the MCP config env, then ask for the tool to run.

If you pasted an Authorization header into chat for debugging, delete that message afterward and rotate the session by logging out of Clinqoo.

Do not ask the AI to repeat the token in its answer. Ask it to mention only the variable name, for example that CLINQOO_TOKEN is set.

Do not commit an mcp.json that holds a secret. Add it to .gitignore or use a system env outside the repo.

To check that the connection is alive, use get_me. That tool proves the token is valid without printing the secret on screen.
