Jangan Tempel Token Clinqoo ke Prompt, Biarkan di Env MCP

Token di isi chat bisa masuk log percakapan. Server MCP sudah membaca CLINQOO_TOKEN dari environment.

Artikel ini tersedia dalam: Indonesia · English

Editor AI tidak perlu melihat nilai token. Cukup tulis di env konfigurasi MCP, lalu minta tool dijalankan.

Jika Anda menempel Authorization ke chat untuk debug, hapus pesan itu setelah selesai dan putar sesi dengan logout di Clinqoo.

Jangan minta AI mengulang token di jawaban. Minta ia hanya menyebut nama variabel, misalnya CLINQOO_TOKEN sudah terpasang.

Berkas mcp.json yang berisi rahasia jangan di-commit. Tambahkan ke .gitignore atau pakai env sistem di luar repo.

Untuk cek apakah sambungan hidup, gunakan get_me. Tool itu membuktikan token valid tanpa menampilkan rahasianya di layar.
