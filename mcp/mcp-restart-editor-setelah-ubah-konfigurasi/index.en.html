Restart the Editor after Changing Clincoo mcp.json

Changes to the build path, env, or server name are not picked up until the MCP process starts again.

This article is available in: Indonesia · English

The .cursor/mcp.json file is read when the editor starts the MCP server. Save the file and restart; saving alone is not enough.

Make sure command points at node and the args point at build/index.js from npm run build inside the mcp-server folder.

If Clincoo tools do not appear, check the MCP server log in the editor panel. A bad path usually shows up as a failed spawn.

Do not duplicate a server entry with the same name. One Clincoo entry is enough, with CLINQOO_TOKEN and CLINQOO_BASE_URL in env.

After the restart, ask for get_me. Tools that appear without an account identity mean the process is alive, but the token or host is still wrong.
