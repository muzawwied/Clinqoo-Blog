Server MCP

Restart Editor setelah Mengubah mcp.json Clincoo

Perubahan path build, env, atau nama server tidak terbaca sampai proses MCP dijalankan ulang.

Artikel ini tersedia dalam: Indonesia · English

Berkas .cursor/mcp.json hanya dibaca saat editor memulai server MCP. Simpan file lalu restart, jangan hanya menyimpan.

Pastikan command menunjuk node dan argumen menunjuk build/index.js hasil npm run build di folder mcp-server.

Jika tool Clincoo tidak muncul, cek log server MCP di panel editor. Path salah biasanya terlihat sebagai gagal spawn.

Jangan menduplikasi entri server dengan nama sama. Satu entri Clincoo cukup, dengan env CLINQOO_TOKEN dan CLINQOO_BASE_URL.

Setelah restart, minta get_me. Tool yang muncul tanpa identitas akun berarti proses hidup, tetapi token atau host masih salah.
