Jalankan Agent Mode Clinqoo di Latar Belakang lewat MCP

Mulai tugas agent dari editor AI, lalu pantau eventsnya tanpa membuka aplikasi Clinqoo.

Artikel ini tersedia dalam: Indonesia · English

Agent Mode Clinqoo mengerjakan tugas besar seperti membangun atau memperbaiki proyek tanpa Anda menunggu di depan layar.

Dengan server MCP, tugas itu dimulai lewat start_agent_task dari Cursor, Claude Desktop, atau editor AI lain.

Ketik permintaannya seperti Anda menulis di chat Clinqoo. Server mengirimnya sebagai tugas latar belakang ke akun Anda.

Pantau lewat get_agent_status. Ia mengembalikan status terbaru beserta events, sehingga Anda tahu langkah mana yang sedang dikerjakan.

Pola yang rapi: mulai tugas, lanjutkan pekerjaan lain, lalu cek status beberapa menit kemudian sebelum mengambil hasilnya.
