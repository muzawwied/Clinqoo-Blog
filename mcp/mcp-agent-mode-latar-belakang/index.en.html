Run Clinqoo Agent Mode in the Background over MCP

Start an agent task from your AI editor, then follow its events without opening the Clinqoo app.

This article is available in: Indonesia · English

Clinqoo Agent Mode handles big jobs like building or fixing a project without you waiting in front of the screen.

With the MCP server, those jobs start through start_agent_task from Cursor, Claude Desktop, or any other AI editor.

Write the request the way you would in the Clinqoo chat. The server submits it as a background task on your account.

Follow it with get_agent_status. It returns the latest status plus events, so you know which step is being worked on.

A clean pattern: start the task, do something else, then check the status a few minutes later before picking up the result.
