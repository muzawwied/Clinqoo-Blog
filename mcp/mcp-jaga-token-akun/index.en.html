Protect Your Session Token When Connecting Clinqoo MCP

The token used by the MCP server is a full account key. Keep it in the environment, never commit it to a repo.

This article is available in: Indonesia · English

The Clinqoo MCP server uses your account session token via the CLINQOO_TOKEN variable. That token is as strong as being logged in.

Grab the token from the browser's local storage after logging into Clinqoo, or from the Authorization header in the devtools network tab.

Put the token in your editor's MCP config env, not directly in code. Do not share that config file publicly either.

If a token leaks, kill the session by logging out of Clinqoo. The old token dies and you simply reconnect with a fresh one.

Before committing, check .cursor/mcp.json and similar config files. Variable names may enter logs; their values may not.
