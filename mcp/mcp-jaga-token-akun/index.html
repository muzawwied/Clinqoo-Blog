Jaga Token Sesi saat Menyambungkan MCP Clinqoo

Token yang dipakai server MCP adalah kunci akun penuh. Simpan di environment, jangan pernah commit ke repo.

Artikel ini tersedia dalam: Indonesia · English

Server MCP Clinqoo memakai token sesi akun Anda lewat variabel CLINQOO_TOKEN. Token ini sama kuatnya dengan login.

Ambil token dari penyimpanan lokal browser setelah login ke Clinqoo, atau dari header Authorization di tab network devtools.

Letakkan token di env konfigurasi MCP editor Anda, bukan langsung di kode. Berkas konfigurasi pun jangan dibagikan ke publik.

Jika token bocor, putuskan sesinya dengan logout dari Clinqoo. Token lama mati dan Anda tinggal menyambungkan ulang dengan token baru.

Sebelum commit, periksa isi .cursor/mcp.json dan berkas config sejenis. Nama variabel boleh masuk log, nilainya tidak.
