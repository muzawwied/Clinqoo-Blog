Kendalikan Akun Clinqoo dari Cursor lewat Server MCP

Server MCP Clinqoo membuat editor AI eksternal bisa melihat proyek, saldo, dan notifikasi akun Anda.

Artikel ini tersedia dalam: Indonesia · English

MCP adalah Model Context Protocol, cara standar untuk menghubungkan AI assistant dengan sumber data dan alat eksternal.

Clinqoo menyediakan server MCP di folder mcp-server pada repo. Ia berjalan lokal di komputer Anda dan berbicara dengan API Clinqoo.

Untuk memasangnya, jalankan npm install lalu npm run build di dalam folder mcp-server. Hasilnya ada di build/index.js.

Daftarkan server itu di berkas konfigurasi MCP editor Anda, misalnya .cursor/mcp.json untuk Cursor atau claude_desktop_config.json untuk Claude Desktop.

Gunakan variabel CLINQOO_BASE_URL bila host API Anda berbeda. Nilai bawaan menunjuk ke host repo Clinqoo.
