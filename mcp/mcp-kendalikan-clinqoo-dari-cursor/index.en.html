MCP Server

Control Your Clinqoo Account from Cursor via the MCP Server

The Clinqoo MCP server lets external AI editors see your projects, balance, and notifications.

This article is available in: Indonesia · English

MCP is the Model Context Protocol, a standard way to connect AI assistants with external data sources and tools.

Clinqoo ships its MCP server in the mcp-server folder of the repo. It runs locally on your machine and talks to the Clinqoo API.

To install it, run npm install and then npm run build inside the mcp-server folder. The result lands in build/index.js.

Register the server in your editor's MCP config, for example .cursor/mcp.json for Cursor or claude_desktop_config.json for Claude Desktop.

Set the CLINQOO_BASE_URL variable if your API host differs. The default points at the Clinqoo repo host.
