Hapus Skrip Demo Vendor dari Template Clincoo sebelum Rilis

Template sering membawa slider, chat dummy, dan analitik contoh. Cabut yang tidak kamu pakai.

Artikel ini tersedia dalam: Indonesia · English

Banyak template Clincoo menyertakan berkas JS vendor untuk slider, popup newsletter, atau pixel iklan peraga. File itu tetap terunduh di pratinjau meski blok HTML-nya sudah kamu hapus.

Buka folder assets atau js di editor.clincoo.buzz. Cari nama seperti vendor.js, slider.min.js, atau analytics.example.js. Hapus tag script yang merujuk file itu dari index.html dan halaman lain, baru hapus berkasnya.

Cek konsol setelah dihapus. Error bahwa objek tidak terdefinisi berarti masih ada inisialisasi di file lain. Perbaiki satu pemanggilan, jangan menambahkan polyfill baru hanya untuk membungkam error.

Minta AI mendaftar tag script dan menjelaskan fungsi masing-masing. Jangan izinkan merapikan semua JS sekaligus. Yang kamu butuhkan adalah daftar yang aman dihapus dan yang wajib tinggal untuk menu mobile.

Clincoo menayangkan setiap request yang masih tertulis di HTML. Template yang bersih dari demo vendor lebih cepat, lebih aman, dan tidak mengirim data ke domain asing tanpa sengaja.
