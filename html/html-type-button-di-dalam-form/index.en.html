Set type=button on Buttons Inside a Clincoo Form

A button without type inside a form submits. A help button becomes a silent submit.

This article is available in: Indonesian · English

In HTML, a button inside a form defaults to submit. A 'see example' button on editor.clincoo.buzz can send a half-filled form.

Add type="button" on buttons that only open a panel, copy text, or switch a tab.

Keep a single type="submit" button for send. Place it at the end of the form so Enter still makes sense.

Do not use a div with onclick as a button. A real button can take Tab focus and is read by screen readers.

Test the preview on app.clincoo.buzz: clicking a secondary button must not reload the page. A reload should happen only on submit.
