Hubungkan label Form Clincoo ke input lewat for dan id

Placeholder bukan label. Tanpa for/id, pembaca layar dan klik teks tidak memfokuskan field.

Artikel ini tersedia dalam: Indonesia · English

Form kontak di template Clincoo sering menaruh teks di placeholder dan membiarkan input tanpa id. Placeholder hilang saat pengguna mengetik, dan klik pada kata “Email” di samping field tidak memindahkan fokus. Itu gagal akses dan gagal UX.

Pola yang benar: satu label dengan atribut for yang sama dengan id input. Bungkus juga input di dalam label jika tata letaknya memungkinkan, tetapi for/id tetap lebih tahan saat CSS memisahkan teks dan field.

Jangan andalkan title atau aria-label sebagai pengganti pertama. Label terlihat membantu semua orang, termasuk pengguna yang memperbesar teks. aria-labelledby berguna untuk field kompleks, bukan pengganti label biasa.

Uji dengan Tab dan dengan klik pada teks label. Fokus harus masuk ke kontrol. Di pratinjau Clincoo, perbesar teks 200 persen: label tidak boleh terpotong atau bertumpuk menutupi input.

Samakan pola ini di setiap form — newsletter, checkout, dan pencarian. Konsistensi membuat review akses berikutnya lebih cepat.
