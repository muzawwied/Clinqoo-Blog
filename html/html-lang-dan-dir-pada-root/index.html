Setel lang dan dir pada Elemen html

Tanpa lang, pembaca layar dan terjemahan browser salah menebak halaman Clincoo. Dir menata teks RTL jika perlu.

Artikel ini tersedia dalam: Indonesia · English

Di berkas index halaman Clincoo, buka tag html dan tulis lang="id" untuk versi Indonesia. Halaman Inggris memakai lang="en".

Atribut dir="ltr" cukup untuk ID dan EN. Jika nanti ada bahasa Arab, ganti dir pada dokumen itu saja, bukan di CSS global.

Jangan menaruh lang hanya di satu paragraf. Mesin terjemahan dan SEO membaca root. Canonical blog.clincoo.buzz juga mengikuti bahasa folder.

Minta AI meninjau head dan tag html saja. Jangan minta rewrite seluruh body app.clincoo.buzz.

Cek di pratinjau editor.clincoo.buzz: judul, meta, dan lang harus selaras sebelum deploy.
