Set lang and dir on the html Element

In the Clincoo page index file, open the html tag and write lang="id" for Indonesian. English pages use lang="en".

dir="ltr" is enough for ID and EN. If you later add Arabic, change dir on that document only, not in global CSS.

Do not put lang on a single paragraph only. Translation engines and SEO read the root.

Ask AI to review the head and html tag only. Do not ask it to rewrite the whole app.clincoo.buzz body.

Check in the editor.clincoo.buzz preview: title, meta, and lang must match before you deploy.
