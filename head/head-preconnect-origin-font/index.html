Tambah preconnect untuk Origin Font di Head Clincoo

Font dari origin lain menunggu handshake TLS. preconnect memangkas jeda teks kosong.

Artikel ini tersedia dalam: Indonesia · English

Kalau proyek Clincoo memuat font dari fonts.googleapis.com atau origin CDN lain, browser harus DNS lookup lalu TLS sebelum unduhan dimulai. Teks sempat tampil fallback.

Tambahkan dan preconnect ke origin CSS font di head, sebelum stylesheet font.

Jangan preconnect ke puluhan domain. web.dev menekankan hanya origin yang benar-benar dipakai di halaman itu. Preconnect berlebih justru merebut koneksi.

MDN menjelaskan rel=preconnect dan atribut crossorigin wajib untuk font karena permintaan font bersifat CORS anonymous.

Uji di pratinjau Clincoo dengan Network throttling. Kalau font lokal sudah di folder proyek, preconnect tidak diperlukan — tautkan file itu saja dari editor.clincoo.buzz.
