Add preconnect for Font Origins in the Clincoo Head

Fonts from another origin wait on a TLS handshake. preconnect shortens the blank-text gap.

This article is also available in: Indonesia · English

When a Clincoo project loads fonts from fonts.googleapis.com or another CDN, the browser must DNS-lookup and complete TLS before the download starts. Text flashes in a fallback face.

Add and a preconnect to the font CSS origin in the head, before the font stylesheet.

Do not preconnect dozens of domains. web.dev says hint only origins the page actually uses. Extra preconnects steal sockets.

MDN documents rel=preconnect and the required crossorigin attribute on font requests because they use anonymous CORS.

Test in the Clincoo preview with Network throttling. If fonts already live in the project folder, skip preconnect and link those files from editor.clincoo.buzz.
