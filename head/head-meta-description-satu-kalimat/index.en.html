Write a One-Sentence Meta Description in the Clincoo Head

An empty or overly long description lets search snippets pick random sentences.

This article is also available in: Indonesia · English

In the Clincoo editor many pages have a solid title but an empty meta description. Search engines then grab a random body sentence, often a nav label or button text.

Write one 120–160 character description that states what the page is about, not a keyword list. Place it in the head after the title, matching Clincoo templates.

Do not copy the home description onto every subpage. Identical snippets make search results indistinguishable even when titles are unique.

MDN and the HTML living standard treat description as a document summary. web.dev notes that honest snippets improve clicks without misleading visitors.

After adding the tag, open preview and View Source. Confirm there is only one description per page before you deploy from editor.clincoo.buzz.
