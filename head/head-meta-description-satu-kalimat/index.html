Tulis Meta Description Satu Kalimat di Head Clincoo

Description yang kosong atau terlalu panjang membuat cuplikan hasil cari tidak terkendali.

Artikel ini tersedia dalam: Indonesia · English

Di editor Clincoo, banyak halaman punya title bagus tetapi meta description kosong. Mesin pencari lalu mengambil kalimat acak dari body, sering potongan navigasi atau teks tombol.

Isi satu meta description 120–160 karakter yang menjelaskan isi halaman, bukan daftar kata kunci. Letakkan di head setelah title, sama seperti template resmi Clincoo.

Jangan salin description beranda ke setiap subhalaman. Cuplikan yang sama membuat tab hasil pencarian tidak bisa dibedakan, meski title sudah unik.

MDN dan dokumentasi HTML WHATWG memperlakukan description sebagai ringkasan dokumen. web.dev menekankan cuplikan yang jujur meningkatkan klik tanpa menipu pengunjung.

Setelah menambah description, buka pratinjau dan cek View Source. Pastikan hanya satu tag description per halaman sebelum deploy dari editor.clincoo.buzz.
