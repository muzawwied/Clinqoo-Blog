Pasang Favicon lewat Link Rel Icon di Head Clincoo

Tanpa favicon, tab browser menampilkan ikon kosong dan merek situs tidak dikenali.

Artikel ini tersedia dalam: Indonesia · English

Proyek Clincoo yang baru sering lupa menautkan favicon. Tab browser lalu menampilkan dokumen generik, padahal logo sudah ada di folder akar.

Tambahkan di head setiap halaman HTML. Path harus sama dengan file yang benar-benar ada di proyek.

Satu ukuran PNG 32×32 atau 192×192 sudah cukup untuk tab. Apple touch icon dan manifest bisa menyusul; jangan biarkan AI menambahkan puluhan ukuran sekaligus.

MDN mendokumentasikan rel=icon dan type MIME. web.dev menyarankan ikon sederhana yang tetap terbaca di tab kecil.

Cek pratinjau Clincoo: ikon harus muncul di tab. Kalau 404, perbaiki href sebelum publish di editor.clincoo.buzz.
