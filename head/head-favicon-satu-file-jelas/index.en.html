Put a Clear Favicon in the Clincoo Project Head

A tab without an icon is hard to spot. One favicon link in the head is enough to start.

This article is also available in: Indonesia · English

Many Clincoo projects lose the favicon after AI rewrites the head. Browser tabs then show a blank icon.

Add an icon PNG link to /logo.png in editor.clincoo.buzz. Confirm the file path exists in the repo.

Do not point the icon at a temporary preview URL. The favicon must follow the public domain.

Ask AI to add one icon link only. Paste the head instead of replacing every asset file.

Clincoo does not invent an icon for you. A saved favicon keeps tabs recognizable on app.clincoo.buzz.
