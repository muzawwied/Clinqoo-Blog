Pasang Favicon Jelas di Head Proyek Clincoo

Tab tanpa ikon sulit dikenali. Satu tautan favicon di head sudah cukup untuk mulai.

Artikel ini tersedia dalam: Indonesia · English

Banyak proyek Clincoo kehilangan favicon setelah AI menulis ulang head. Tab browser tampil ikon kosong.

Tambah tautan icon PNG ke /logo.png di editor.clincoo.buzz. Pastikan path file ada di repo.

Jangan tautkan ke URL pratinjau sementara. Favicon harus ikut domain publik.

Minta AI hanya menambah satu tautan icon. Tempel head, bukan mengganti seluruh berkas aset.

Clincoo tidak membuat ikon otomatis. Favicon yang tersimpan menjaga tab dikenali di app.clincoo.buzz.
