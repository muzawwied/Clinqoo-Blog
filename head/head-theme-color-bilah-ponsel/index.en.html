Set theme-color so the Phone Bar Matches Clincoo

The theme-color meta paints the mobile browser bar. Match it to the Clincoo project header color.

This article is available in: Indonesia · English

In the Clincoo page head add a theme-color meta with the header color, for example #0f766e. Place it after viewport.

Do not pick a color that fails contrast with status icons. Test in the app.clincoo.buzz device preview.

If the site has a dark mode, add two metas with prefers-color-scheme. Do not use one color for both modes.

theme-color does not replace the body background. The body still needs its own color so content does not flash white.

Ask AI to insert only that meta tag. Paste the head snippet, not the whole HTML.
