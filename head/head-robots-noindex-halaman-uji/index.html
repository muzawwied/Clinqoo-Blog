Pakai noindex pada Halaman Uji di Head Clincoo

Halaman draft yang terindeks menyaingi URL resmi. Tandai uji dengan robots noindex.

Artikel ini tersedia dalam: Indonesia · English

Folder uji di repo Clincoo kadang terbit tanpa meta robots. Mesin cari lalu menampilkan draf di atas halaman resmi.

Tambah meta robots noindex, nofollow pada halaman uji di editor.clincoo.buzz.

Jangan menaruh noindex di halaman produksi. Hapus tag itu saat draf dipromosikan jadi URL kanonis.

Minta AI hanya menambah meta robots di file uji. Tempel head draf, bukan index produksi.

Clincoo menayangkan file apa adanya. noindex menjaga draf tidak menyaingi tautan di blog.clincoo.buzz.
