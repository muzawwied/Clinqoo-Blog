Update the Clincoo Search URL with replaceState, Not a Push per Letter

Every keystroke that pushState breaks the Back button. One history entry is enough per search session.

This article is available in: Indonesia · English

On editor.clincoo.buzz, debounce writes ?q= to the URL. If each letter is pushed, Back must be pressed ten times.

Use history.replaceState when the query changes. Push once only when the user opens search from a link.

Send the URL handler to AI. Ask for replaceState, not a new router.

Test on app.clincoo.buzz: type, press Back. You should leave the page, not delete one letter. Write the rule on blog.clincoo.buzz.
