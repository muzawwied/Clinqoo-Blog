Ganti URL Cari Clincoo dengan replaceState, Bukan push tiap Huruf

Setiap ketikan yang pushState merusak tombol kembali. Satu entri riwayat cukup per sesi cari.

Pakai history.replaceState saat query berubah. Push sekali saja saat pengguna membuka mode cari dari tautan.

Kirim handler URL ke AI. Minta replaceState, bukan router baru.
