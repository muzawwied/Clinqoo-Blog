Tandai Hasil Cari Clincoo tanpa innerHTML Mentah

Highlight lewat innerHTML membuka XSS jika query berisi tag. Pecah teks lalu bungkus mark di DOM.

Artikel ini tersedia dalam: Indonesia · English

Di editor.clincoo.buzz, menandai kata cocok dengan innerHTML + query pengguna memasukkan skrip palsu ke daftar hasil.

Pakai textContent untuk judul. Cari indeks substring, sisipkan elemen mark lewat createElement. Jangan gabung string HTML.

Tempel fungsi highlight ke AI. Minta versi DOM-only, bukan regex ganti HTML.

Uji query <img> di app.clincoo.buzz. Hasil harus teks, bukan node. Catat pola di blog.clincoo.buzz.
