Highlight Clincoo Search Hits without Raw innerHTML

Highlighting via innerHTML opens XSS if the query contains tags. Split text and wrap mark nodes in the DOM.

This article is available in: Indonesia · English

On editor.clincoo.buzz, marking hits with innerHTML plus the user query injects fake markup into the result list.

Use textContent for the title. Find substring indexes, insert mark elements with createElement. Do not concatenate HTML strings.

Paste the highlight function to AI. Ask for a DOM-only version, not a regex HTML replace.

Test a <img> query on app.clincoo.buzz. Hits must stay text, not nodes. Record the pattern on blog.clincoo.buzz.
