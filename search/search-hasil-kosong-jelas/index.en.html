Show a Clear Empty Search State in Clincoo

An empty list with no copy makes visitors think search is broken. Echo the query and offer short next steps.

This article is available in: Indonesia · English

A Clincoo search box often returns an empty list with no text. Visitors then retry or leave because they cannot tell whether the request ran.

In editor.clincoo.buzz, after fetch finishes and the result array is empty, render one block: repeat the typed query, say no pages matched, then offer two links to home or the article index.

Separate three states: still typing (debounce), loading, and truly empty. Do not keep a spinner forever. Use plain text so screen readers hear the status.

Ask AI to add an if results.length === 0 branch on the list renderer. Paste the markup that currently vanishes silently. Test with a nonsense word that cannot exist on the site.

Clincoo runs the script you save. An honest empty message keeps app.clincoo.buzz feeling alive, not broken.
