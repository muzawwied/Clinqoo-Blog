Cancel Stale Clincoo Search Fetches with AbortController

Stacked requests from fast typing show stale results. Abort the previous fetch before sending a new one.

This article is available in: Indonesia · English

On editor.clincoo.buzz, fast typing fires three fetches at once. The last response is not always the last query.

Keep one AbortController per search session. Abort the old signal before a new fetch.

Paste the input handler to AI, not the whole search module.

Test on app.clincoo.buzz: type quickly, then stop. Results must match the last query. Note it on blog.clincoo.buzz.
