Focus the Clincoo Search Box with the Slash Key

Keyboard visitors want to jump to search without a mouse. Catch / outside fields, then focus the search input.

This article is available in: Indonesia · English

Docs sites often use / to focus search. Clincoo templates frequently skip this shortcut, so users tab a long way.

In editor.clincoo.buzz, attach keydown on document. If the key is / or k plus a modifier you choose, and the target is not an input, textarea, or contenteditable, preventDefault and focus input[type=search].

Do not steal / while someone is typing in a contact form. Escape should return focus to the body so the keyboard flow stays predictable.

Ask AI to add the shortcut listener plus field exceptions. Paste the header that has a search input and no keyboard handler.

Clincoo runs the script you save. One key makes search on app.clincoo.buzz feel like a tool, not decoration.
