Keep the Clincoo Search Query in the URL

Search results that live only in memory vanish when shared. Write q= into the URL so the link can be reopened.

This article is available in: Indonesia · English

Many Clincoo templates store the query only in a JavaScript variable. When a visitor copies the URL, the recipient sees an empty search page.

In editor.clincoo.buzz, after debounce finishes, call history.replaceState with ?q= plus encodeURIComponent. On load, read URLSearchParams, refill the box, and run search.

Do not pushState on every letter. replaceState keeps the back button on the previous page, not on each keystroke. Drop the parameter when the query is cleared.

Ask AI to sync q in the URL on the input handler and on DOMContentLoaded. Paste the search function that currently ignores location.search.

Clincoo runs the script you save. A query in the URL makes search on app.clincoo.buzz shareable and retestable.
