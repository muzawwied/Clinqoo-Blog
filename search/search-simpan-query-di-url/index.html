Simpan Kata Kunci Cari Clincoo di Parameter URL

Hasil cari yang hanya hidup di memori hilang saat dibagikan. Tulis q= di URL agar tautan bisa dibuka ulang.

Artikel ini tersedia dalam: Indonesia · English

Banyak template Clincoo menyimpan query hanya di variabel JavaScript. Saat pengunjung menyalin URL, penerima melihat halaman cari kosong.

Di editor.clincoo.buzz, setelah debounce selesai, panggil history.replaceState dengan ?q= plus encodeURIComponent. Saat halaman dimuat, baca URLSearchParams dan isi ulang kotak plus jalankan pencarian.

Jangan pushState setiap huruf. replaceState menjaga tombol kembali tetap ke halaman sebelumnya, bukan ke setiap ketikan. Hapus parameter jika query dikosongkan.

Minta AI menambah sinkronisasi q di URL pada handler input dan pada DOMContentLoaded. Tempel fungsi cari yang sekarang tidak membaca location.search.

Clincoo menjalankan skrip yang kamu simpan. Query di URL membuat hasil cari di app.clincoo.buzz bisa dibagikan dan diuji ulang.
