Use FAQPage Schema Only When the FAQ Is Visible in Clincoo

FAQ JSON-LD that is not on the page can be rejected. Write the same questions in HTML and in the schema.

This article is available in: Indonesia · English

Some Clincoo templates paste FAQPage so a rich result might appear. If the questions are not visible on the page, that markup is misleading.

Copy question and answer text from the block that actually renders. Do not write an FAQ only inside the JSON-LD script.

One page, one primary type. If Article is already there, FAQ is only an addition for the Q&A section, not a replacement for the article title.

Test in the app.clincoo.buzz preview: view source and confirm the Question count matches the items on the page.

Ask AI to align the HTML text and the JSON-LD, not to invent questions you do not want to show.
