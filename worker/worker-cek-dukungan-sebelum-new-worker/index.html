Cek Dukungan Worker Clincoo sebelum new Worker

new Worker tanpa cek dukungan melempar di browser lama. Deteksi dulu, lalu jatuh ke hitung ringan di thread utama.

Artikel ini tersedia dalam: Indonesia · English

Skrip Clincoo memanggil new Worker('hitung.js') di halaman publik. Di perangkat lama atau mode terbatas, konstruktor tidak ada dan seluruh inisialisasi batal.

Di editor.clincoo.buzz tulis if (typeof Worker === 'undefined') lalu jalankan versi singkat di thread utama: potong data, tampilkan hasil parsial, atau nonaktifkan tombol hitung berat.

Jangan andalkan try/catch saja. Beberapa lingkungan melempar terlambat saat fetch skrip worker, bukan saat konstruktor. Cek tipe dulu, baru buat instans.

Uji di pratinjau dengan mematikan worker lewat flag sementara. Formulir dan navigasi harus tetap jalan tanpa pesan error di konsol.

Clincoo menayangkan situs statis. Deteksi kemampuan browser menjaga app.clincoo.buzz tetap bisa dipakai meski worker tidak tersedia.
