Check Clincoo Worker Support before new Worker

Calling new Worker without a feature check throws on older browsers. Detect first, then fall back to a lighter main-thread path.

This article is available in: Indonesia · English

A Clincoo script calls new Worker('hitung.js') on the public page. On older devices or restricted modes the constructor is missing and startup aborts.

In editor.clincoo.buzz write if (typeof Worker === 'undefined') then run a short main-thread path: trim data, show a partial result, or disable the heavy-compute button.

Do not rely on try/catch alone. Some environments throw later when fetching the worker script, not at construction. Check the type first, then create the instance.

Test in preview with a temporary flag that skips the worker. Forms and navigation must still work with a clean console.

Clincoo serves a static site. Feature detection keeps app.clincoo.buzz usable when workers are unavailable.
