Jangan Akses window atau localStorage dari Worker Clincoo

Worker tidak punya DOM. Membaca window atau localStorage melempar ReferenceError dan mematikan tugas.

Artikel ini tersedia dalam: Indonesia · English

Salin kode halaman ke worker di editor.clincoo.buzz sering membawa localStorage.getItem. Itu tidak ada di konteks worker.

Kirim data yang dibutuhkan lewat postMessage dari tab utama. Simpan token hanya di halaman app.clincoo.buzz, bukan di worker.

Jika AI menempel snippet yang memakai document, potong dulu. Worker hanya boleh hitung, parse, atau transform data.

Uji dengan satu postMessage berisi objek polos. Jika worker crash, buka tab Sources ke worker, bukan hanya konsol utama.

Clincoo di blog.clincoo.buzz memisahkan UI dan hitung: worker tidak menyentuh penyimpanan browser.
