One Clincoo Worker Instance for One Kind of Task

Creating a new worker on every click stacks threads. Reuse the same instance for the same kind of work.

This article is available in: Indonesia · English

A Clincoo export button calls new Worker on every click. Five clicks mean five threads still alive.

Create the worker once when the page is ready. Store it. postMessage the next job to the same instance.

If the task kinds differ (resize vs sort), two instances are fine, not twenty. terminate unused ones.

Check the Performance tab in preview. After ten clicks the worker count must not be ten.

Clincoo does not merge workers for you. One instance in your script keeps editor.clincoo.buzz lean on threads.
