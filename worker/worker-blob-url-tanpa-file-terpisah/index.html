Buat Worker Clincoo dari Blob URL jika Tanpa File Terpisah

Hosting statis kadang menolak worker lintas folder. Blob URL menanam skrip di halaman yang sama.

Artikel ini tersedia dalam: Indonesia · English

new Worker('./worker.js') gagal di beberapa pratinjau Clincoo jika MIME file salah atau path relatif menembus folder lain. Pesan di konsol: failed to load worker script. Halaman tetap jalan, pekerjaan berat tidak pernah mulai.

Bungkus isi worker sebagai string atau template literal, buat Blob dengan type 'text/javascript', lalu URL.createObjectURL(blob). new Worker(url) memuat skrip dari origin halaman yang sama. Setelah worker siap, URL.revokeObjectURL agar tidak menumpuk blob.

Cara ini cocok untuk worker pendek: urut, hash, atau filter daftar. Untuk worker panjang, tetap lebih jelas punya file terpisah di repo Clincoo agar bisa diuji sendiri. Blob adalah cadangan saat file terpisah diblokir.

Jangan menanam rahasia di string worker. Siapa pun bisa baca sumber halaman statis. Uji di editor.clincoo.buzz bahwa onmessage tetap menerima hasil setelah Blob URL dicabut.

Situs di app.clincoo.buzz adalah file statis. Blob URL menghindari ketergantungan path worker yang rapuh tanpa menambah server.
