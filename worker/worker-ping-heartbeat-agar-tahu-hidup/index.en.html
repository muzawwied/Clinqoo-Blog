Send a Ping Heartbeat so a Clincoo Worker Looks Alive

A stuck worker sends no error. A periodic ping tells busy apart from dead.

This article is available in: Indonesia · English

A long task in editor.clincoo.buzz can freeze without onerror. The UI waits for a result that never arrives.

The worker replies pong every N seconds. If the page gets no pong, show task not responding on app.clincoo.buzz.

Do not treat a late pong as a network failure. Heartbeat is liveness only, not percent progress.

Ask AI to write two listeners: ping on the page and pong in the worker. Paste the interval you chose; do not guess.

Clincoo on blog.clincoo.buzz uses a heartbeat so the spinner does not spin on a silent worker.
