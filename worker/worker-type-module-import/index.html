Pakai type module pada Worker Clincoo agar import Berjalan

import di worker klasik gagal. type: 'module' menyelaraskan dengan skrip ES di editor.

Artikel ini tersedia dalam: Indonesia · English

Banyak template Clincoo memakai import/export di skrip halaman. Menyalin fungsi yang sama ke worker.js klasik memicu SyntaxError: Cannot use import statement outside a module. Pekerjaan tidak pernah jalan.

Buat worker dengan new Worker(url, { type: 'module' }). Di file worker, import fungsi murni — pengurut, parser, hasher — dari modul yang sama dipakai halaman. Jangan import modul yang menyentuh document; worker modul tetap tanpa DOM.

Path import harus relatif ke file worker, bukan ke halaman. Uji di pratinjau editor.clincoo.buzz. Jika modul 404, periksa folder assets dan ekstensi .js yang wajib di specifier.

Module worker mendukung top-level await. Tetap kirim hasil lewat postMessage, bukan mengandalkan return konstruktor. Pasang onerror seperti worker biasa.

Situs statis app.clincoo.buzz menayangkan file apa adanya. type: 'module' menjaga satu sumber kebenaran untuk logika, tanpa bundler dan tanpa menyalin fungsi ke dua file.
