Pakai SharedWorker Clincoo agar Banyak Tab Berbagi Hitung

Dedicated Worker per tab menggandakan kerja. SharedWorker satu proses untuk semua tab situs.

Artikel ini tersedia dalam: Indonesia · English

Pengunjung Clincoo membuka tiga tab pratinjau. Tiap tab membuat Dedicated Worker dan CPU naik tiga kali.

Pakai new SharedWorker(url). Semua tab terhubung lewat port. Hitung sekali, kirim hasil ke port yang minta.

Tangani onconnect di worker. Simpan daftar port. Jangan asumsikan hanya satu tab.

Uji buka dua tab app.clincoo.buzz. Task Manager harus menunjukkan satu worker bersama, bukan dua.

Clincoo menayangkan situs statis. SharedWorker di skripmu menjaga editor.clincoo.buzz hemat saat banyak tab.
