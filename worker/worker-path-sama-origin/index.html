Letakkan File Worker Clincoo di Origin yang Sama

Worker lintas origin ditolak browser. Path relatif yang salah setelah publish juga gagal diam-diam.

Artikel ini tersedia dalam: Indonesia · English

new Worker('https://cdn.lain/worker.js') di proyek Clincoo ditolak. Konsol menulis SecurityError atau NetworkError.

Simpan worker.js di folder yang sama dengan halaman, atau path relatif yang tetap benar setelah publish ke app.clincoo.buzz.

Cek header Content-Type text/javascript. Hosting yang mengirim text/html membuat worker gagal parse.

Buka tab Network di pratinjau editor.clincoo.buzz. Request worker harus 200 dari origin yang sama.

Clincoo tidak menambal CORS worker. Path yang benar di skripmu menjaga worker hidup setelah deploy.
