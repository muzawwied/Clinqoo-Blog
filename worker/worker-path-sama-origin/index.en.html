Keep the Clincoo Worker File on the Same Origin

A cross-origin worker is blocked. A wrong relative path after publish also fails quietly.

This article is available in: Indonesia · English

new Worker('https://other-cdn/worker.js') in a Clincoo project is blocked. The console writes SecurityError or NetworkError.

Keep worker.js in the same folder as the page, or a relative path that stays valid after publish to app.clincoo.buzz.

Check the Content-Type header is text/javascript. Hosting that sends text/html makes the worker fail to parse.

Open the Network tab in the editor.clincoo.buzz preview. The worker request must be 200 from the same origin.

Clincoo does not patch worker CORS. A correct path in your script keeps the worker alive after deploy.
