Isi opsi name saat new Worker di Clincoo agar Debug Mudah

Beberapa worker tanpa nama terlihat sama di DevTools. Opsi name membedakan hitung, resize, dan antrean.

Artikel ini tersedia dalam: Indonesia · English

Proyek Clincoo menjalankan tiga worker sekaligus. Di panel Threads semuanya tampil sebagai skrip generik, jadi stack error sulit dilacak.

Di editor.clincoo.buzz panggil new Worker(url, { name: 'clincoo-hitung' }). Nama muncul di DevTools dan di self.name di dalam worker.

Samakan nama dengan tugas, bukan dengan nama file saja. File yang dipakai ulang untuk dua peran tetap bisa dibedakan lewat name.

Saat onerror, sertakan name di log ke konsol pratinjau. Jangan kirim name ke pengunjung; itu hanya untuk debug.

Clincoo tidak mengubah DevTools browser. Nama yang kamu set di skrip membuat audit di app.clincoo.buzz lebih cepat sebelum deploy.
