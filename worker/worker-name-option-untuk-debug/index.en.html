Set the name option on new Worker in Clincoo for easier debug

Several unnamed workers look identical in DevTools. The name option separates compute, resize, and queues.

This article is available in: Indonesia · English

A Clincoo project runs three workers at once. In the Threads panel they all look like generic scripts, so error stacks are hard to follow.

In editor.clincoo.buzz call new Worker(url, { name: 'clincoo-hitung' }). The name shows in DevTools and as self.name inside the worker.

Match the name to the task, not only the filename. A reused file for two roles can still be told apart by name.

In onerror, include name in the preview console log. Do not show the name to visitors; it is for debug only.

Clincoo does not change browser DevTools. The name you set in script makes audits on app.clincoo.buzz faster before deploy.
