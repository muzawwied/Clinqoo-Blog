Jangan Campur importScripts dengan Worker Module Clincoo

Worker type module menolak importScripts. Pilih satu model: import ES atau skrip klasik, jangan keduanya.

Artikel ini tersedia dalam: Indonesia · English

Berkas worker Clincoo dibuat dengan type: 'module' lalu memanggil importScripts('util.js'). Browser melempar dan pekerjaan tidak pernah mulai.

Di editor.clincoo.buzz pilih satu gaya. Modul: new Worker(url, { type: 'module' }) dan import { hitung } from './util.js'. Klasik: Worker tanpa type module dan importScripts.

Util bersama harus diekspor sesuai gaya itu. Jangan mengandalkan variabel global dari importScripts di dalam modul.

Cek konsol pratinjau saat worker gagal diam. Pesan tentang importScripts di module worker adalah tanda campuran model.

Situs statis Clincoo menayangkan file apa adanya. Konsistensi modul membuat app.clincoo.buzz tidak tergantung tebakan browser.
