Bedakan Dedicated Worker dan Service Worker di Clincoo

new Worker dan navigator.serviceWorker menyelesaikan masalah berbeda. Menukar keduanya merusak cache dan hitung.

Artikel ini tersedia dalam: Indonesia · English

Hitung markdown di editor.clincoo.buzz butuh Dedicated Worker. Cache offline butuh Service Worker. Jangan pakai satu berkas untuk keduanya.

Dedicated Worker mati bersama tab. Service Worker hidup lintas kunjungan app.clincoo.buzz dan bisa menyimpan respons.

Jika AI menyarankan self.skipWaiting di worker hitung, tolak. Itu API service worker, bukan worker biasa.

Uji: Dedicated Worker tidak punya caches API. Jika kode memanggil caches.open, Anda salah konteks.

Clincoo di blog.clincoo.buzz memisahkan worker hitung dan service worker agar pratinjau tidak men-cache HTML usang.
