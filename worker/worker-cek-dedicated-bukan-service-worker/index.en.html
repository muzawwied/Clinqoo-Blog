Tell Dedicated Workers from Service Workers in Clincoo

new Worker and navigator.serviceWorker solve different problems. Swapping them breaks cache and compute.

This article is available in: Indonesia · English

Markdown compute in editor.clincoo.buzz needs a Dedicated Worker. Offline cache needs a Service Worker. Do not use one file for both.

A Dedicated Worker dies with the tab. A Service Worker lives across visits to app.clincoo.buzz and can store responses.

If AI suggests self.skipWaiting in a compute worker, reject it. That is a service worker API, not a regular worker.

Test: a Dedicated Worker has no caches API. If the code calls caches.open, you are in the wrong context.

Clincoo on blog.clincoo.buzz splits compute workers and service workers so preview does not cache stale HTML.
