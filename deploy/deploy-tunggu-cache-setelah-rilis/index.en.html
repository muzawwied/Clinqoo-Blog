Wait for Cache after a Clincoo Deploy before Sharing the Link

A new site can still show an old version in the browser.

Indonesia · English

After deploy succeeds, the CDN can keep old files briefly. That is normal.

Open the public URL in a private tab or hard-refresh.

If the old version remains, check the project and that the file was saved.

Only then share the link.
