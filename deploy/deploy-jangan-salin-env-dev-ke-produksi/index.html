Jangan Salin Berkas Env Dev ke Produksi

URL, kunci, dan flag debug dari lokal sering ikut terbit. Bandingkan nama variabel, bukan menyalin isi.

Artikel ini tersedia dalam: Indonesia · English

Rilis dari editor.clincoo.buzz gagal diam-diam jika URL API masih mengarah ke localhost.

Buat daftar nama variabel yang wajib ada di produksi. Isi nilai hanya di lingkungan rilis, bukan dari berkas dev.

Tolak rilis jika ada flag DEBUG, token uji, atau domain pratinjau di konfigurasi produksi.

Jangan tempel seluruh berkas env ke chat AI. Sebut nama variabel yang kosong dan minta AI mengecek daftar, bukan nilainya.

Setelah terbit, buka app.clincoo.buzz dan pastikan request pergi ke host produksi, bukan host dev.

Catat perbedaan env yang disengaja di blog.clincoo.buzz supaya rilis berikutnya tidak menyamakan keduanya.
