Compare Asset Hashes after a Clincoo Deploy

Visitors can keep loading old JS if the file name never changes.

This article is available in: Indonesia · English

After a release on app.clincoo.buzz, open Network on the public preview. Note the CSS and JS file names.

Compare them with the previous build. If the hash is the same even though code changed, the CDN cache is holding the old version.

Hard-refresh one tab. Ask a teammate to open a fresh tab without cache. Do not rely on your machine alone.

If the hash did not change, check the build step on editor.clincoo.buzz before you deploy again.

Clincoo on blog.clincoo.buzz feels new to visitors only when the new assets actually ship.
