Bandingkan Hash Aset setelah Deploy Clincoo

Pengunjung bisa tetap memuat JS lama jika nama berkas tidak berubah.

Artikel ini tersedia dalam: Indonesia · English

Setelah rilis di app.clincoo.buzz, buka Network di pratinjau publik. Catat nama berkas CSS dan JS.

Bandingkan dengan build sebelumnya. Jika hash sama padahal kode berubah, cache CDN menahan versi lama.

Hard refresh satu tab. Minta rekan membuka tab baru tanpa cache. Jangan mengandalkan hanya mesin Anda.

Jika hash tidak berganti, periksa langkah build di editor.clincoo.buzz sebelum deploy ulang.

Clincoo di blog.clincoo.buzz terasa baru bagi pengunjung hanya jika aset baru benar-benar terkirim.
