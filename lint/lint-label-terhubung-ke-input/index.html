Pastikan Setiap Input Clincoo Punya Label yang Terhubung

Placeholder bukan label. Samakan for dan id agar form bisa dipakai keyboard dan pembaca layar.

Artikel ini tersedia dalam: Indonesia · English

Input tanpa label yang terhubung lolos pratinjau visual Clincoo, tapi gagal untuk pembaca layar dan klik target yang luas.

Atribut for pada label harus sama dengan id input. Placeholder bukan pengganti nama field yang bisa diumumkan.

Lint HTML atau pemeriksa aksesibilitas menandai label yang hilang sebelum deploy. Perbaiki pasangan itu, jangan menyembunyikan teks dengan CSS saja.

Untuk grup radio, bungkus dengan fieldset dan legend. Satu label umum tidak cukup menjelaskan setiap pilihan.

Uji dengan klik teks label di editor.clincoo.buzz. Jika fokus tidak pindah ke kontrol, id dan for belum cocok.
