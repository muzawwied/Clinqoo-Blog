Turn a New Lint Rule On as a Warning First

A new rule set to error stops deploy. Start as a warning, fix the hits, then raise it.

This article is available in: Indonesia · English

On editor.clincoo.buzz, turning a new lint rule on as an error often blocks preview because dozens of old files fail.

Set that rule to warning in config. Record the hit count, fix the file you are editing, and do not disable the whole file.

After findings on the publish path are gone, raise it to error. Leave old files on a temporary list with a reason and a removal date.

Ask AI to fix one warning per file. Paste the lint message and the snippet. Do not ask AI to disable the plugin.

Run the same check before deploy on app.clincoo.buzz. Write the rule name and the date it became an error on blog.clincoo.buzz.
