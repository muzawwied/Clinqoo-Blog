Cegah Atribut HTML Ganda sebelum Deploy Halaman Clincoo

Atribut yang ditulis dua kali membuat browser memilih nilai tak terduga. Rapikan dulu.

Artikel ini tersedia dalam: Indonesia · English

Saat menempel cuplikan dari AI ke editor Clincoo, atribut class atau id sering muncul dua kali pada satu tag. Parser HTML memakai nilai terakhir; pratinjau bisa terlihat benar sementara selector CSS merujuk nilai pertama.

Buka DevTools, pilih elemen, dan baca panel Elements. Kalau ada class ganda atau style dobel, gabungkan nilainya menjadi satu atribut. Jangan biarkan dua id pada elemen yang sama.

Validator W3C menandai atribut duplikat sebagai error. Jalankan cek itu pada HTML yang diekspor sebelum menayangkan subdomain. MDN menegaskan id harus unik di seluruh dokumen.

Minta AI merapikan satu file: hapus atribut dobel, gabungkan class, jangan ubah markup lain. Tempel hasil ke pratinjau, lalu lint tautan dan heading.

Halaman di app.clincoo.buzz lebih mudah di-debug jika setiap tag punya satu sumber kebenaran untuk class, id, dan aria-label.
