Tampilkan Aturan Panjang Sandi di Form Clincoo

Validasi sandi yang hanya gagal setelah kirim membuat pengguna menebak aturan. Pakai minlength dan teks bantuan sebelum submit.

Sertakan Token CSRF pada Form Login Clincoo

POST login tanpa token CSRF bisa dipicu dari situs lain. Hidden field plus SameSite menahan permintaan silang.

Logout Clincoo Harus Hapus Sesi di Klien dan Server

Menyembunyikan UI login belum cukup. Hapus cookie, token memori, dan sesi server saat keluar.

Batasi Percobaan Login Clincoo per Alamat

Form login tanpa batas percobaan memudahkan tebak sandi. Rate limit dan jeda progresif menahan brute force.

Setel Cookie Sesi Clincoo HttpOnly dan SameSite

Cookie sesi yang bisa dibaca skrip rentan XSS. HttpOnly, Secure, dan SameSite=Lax menahan token.

Setel autocomplete pada Form Login Clincoo

Tanpa autocomplete=username dan current-password, manajer sandi tidak mengisi form.

Jangan Taruh Token Auth di Query URL Clincoo

Token di URL bocor lewat riwayat, referrer, dan log. Pakai header atau cookie HttpOnly.

Pakai Pesan Error Login yang Umum di Clincoo

Email tidak ditemukan versus sandi salah membantu penyerang enumerasi akun.

Peringatkan sebelum Sesi Clincoo Kedaluwarsa

Sesi mati tanpa peringatan menghapus draf yang belum tersimpan. Beri waktu perpanjang.

type=text permanen menampilkan sandi. Toggle singkat membantu tanpa membocorkan isi.
