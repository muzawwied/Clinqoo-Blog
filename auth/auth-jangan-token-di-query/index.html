Jangan Taruh Token Sesi di Query URL Clincoo

Token di query ikut tersimpan di riwayat, log server, dan header Referer. Pindahkan ke header atau cookie yang tidak dibaca skrip.

Artikel ini tersedia dalam: Indonesia · English

Tautan berbagi dari app.clincoo.buzz kadang menyisipkan access_token di query. URL itu masuk riwayat browser dan log analytics.

Kirim sesi lewat header Authorization atau cookie HttpOnly Secure SameSite. Jangan letakkan rahasia di hash jika skrip halaman masih bisa membacanya.

Jika tautan undangan wajib membawa kode sekali pakai, buat kode pendek yang kedaluwarsa dan tukar di server. Jangan kirim token sesi penuh.

Saat minta AI memperbaiki login, tempel pesan error tanpa nilai token. Minta contoh header, bukan contoh URL berisi rahasia.

Cek Network di editor.clincoo.buzz: request dokumen tidak boleh menampilkan token di kolom query. Catat temuan di blog.clincoo.buzz.
