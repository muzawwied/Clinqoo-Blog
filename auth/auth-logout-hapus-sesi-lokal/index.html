Logout Clincoo Harus Hapus Sesi di Klien dan Server

Menyembunyikan UI login belum cukup. Hapus cookie, token memori, dan sesi server saat keluar.

Artikel ini tersedia dalam: Indonesia · English

Banyak template hanya mengarahkan ke /login saat tombol Keluar diklik. Cookie sesi app.clincoo.buzz masih hidup, jadi tombol Kembali di peramban membuka editor lagi.

Kirim permintaan logout ke server yang menghapus sid di penyimpanan sesi, lalu Set-Cookie dengan Max-Age=0 untuk nama cookie yang sama, Path=/ , dan Secure. Tanpa itu, klien hanya pura-pura keluar.

Di klien, kosongkan variabel token di memori, hapus kunci localStorage yang terkait akun, dan ganti halaman dengan location.replace agar riwayat tidak menyimpan URL terlindungi.

Uji di editor.clincoo.buzz: masuk, buka halaman privat, logout, lalu tekan Kembali. Halaman harus minta login ulang, bukan menampilkan draf lama.

Minta AI meninjau handler klik Keluar saja. Tempel fungsi logout sekarang plus nama cookie agar saran tidak menghapus preferensi tema yang tidak terkait sesi.
