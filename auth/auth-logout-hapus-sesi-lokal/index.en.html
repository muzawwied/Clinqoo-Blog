Clincoo Logout Must Clear Client and Server Session

Hiding the logged-in UI is not enough. Clear the cookie, in-memory token, and server session on sign-out.

This article is also available in: Indonesia · English

Many templates only send people to /login when they click Keluar. The app.clincoo.buzz session cookie still lives, so the Back button opens the editor again.

Send a logout request that deletes the sid in session storage, then Set-Cookie with Max-Age=0 for the same cookie name, Path=/, and Secure. Without that, the client only pretends to leave.

On the client, drop in-memory tokens, remove account keys from localStorage, and navigate with location.replace so history does not keep a protected URL.

Test in editor.clincoo.buzz: sign in, open a private page, log out, then press Back. The page must ask for login again instead of showing the old draft.

Ask AI to review only the Keluar click handler. Paste the current logout function and the cookie name so the suggestion does not wipe theme prefs that are unrelated to the session.
