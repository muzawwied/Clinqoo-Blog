Setel mode cors secara Eksplisit pada Fetch Clincoo

mode no-cors menyembunyikan body dan status. Pakai mode cors jika Anda perlu membaca JSON.

Artikel ini tersedia dalam: Indonesia · English

Fetch ke API dari editor.clincoo.buzz dengan mode: 'no-cors' menghasilkan opaque response. JSON.parse gagal diam-diam.

Pakai mode: 'cors' (default untuk URL lintas origin yang Anda kendalikan) lalu cek res.ok sebelum res.json().

Jika preflight gagal, perbaiki header server. Jangan ganti ke no-cors hanya agar Promise resolve.

Uji di app.clincoo.buzz dan tempel status plus header ke AI. Catat langkah di blog.clincoo.buzz.
