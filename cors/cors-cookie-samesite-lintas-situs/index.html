Samakan SameSite Cookie dengan Kredensial CORS Clincoo

Cookie SameSite=Lax tidak terkirim pada fetch lintas situs. Sesuaikan SameSite dan CORS credentials.

Artikel ini tersedia dalam: Indonesia · English

Login di app.clincoo.buzz tidak mengirim cookie ke API lain jika SameSite=Lax dan fetch credentials: include.

Untuk API lintas situs yang sah, set SameSite=None; Secure dan Access-Control-Allow-Credentials: true plus origin pasti.

Jangan pakai wildcard origin bersama cookie. Browser menolak kombinasi itu.

Tempel Set-Cookie dan header CORS ke AI. Uji di editor.clincoo.buzz lalu catat di blog.clincoo.buzz.
