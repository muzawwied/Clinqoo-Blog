Align Cookie SameSite with Clincoo CORS Credentials

SameSite=Lax cookies are not sent on cross-site fetch. Match SameSite and CORS credentials.

This article is available in: Indonesia · English

A login on app.clincoo.buzz will not send the cookie to another API if SameSite=Lax and fetch uses credentials: include.

For a legitimate cross-site API, set SameSite=None; Secure plus Access-Control-Allow-Credentials: true and a concrete origin.

Do not use a wildcard origin with cookies. The browser rejects that pair.

Paste Set-Cookie and CORS headers to AI. Test on editor.clincoo.buzz and record it on blog.clincoo.buzz.
