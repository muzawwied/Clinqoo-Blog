Show Reading Progress Without Taxing Clincoo Scroll

A reading bar helps long articles. Compute scrollY against document height; do not run a heavy per-pixel listener.

This article is available in: Indonesia · English

Clincoo tutorials can run long. Visitors want to know how much is left without opening a table of contents.

A thin bar in the header is enough. Update its width from scrollY / (scrollHeight - clientHeight). Wrap the update in requestAnimationFrame so you do not force layout on every scroll event.

Do not write a percentage string into the DOM on every pixel. Change a CSS custom property such as --progress and let CSS draw the bar.

Hide the indicator on very short screens or when prefers-reduced-motion makes a growing bar distracting.

Test in Clincoo preview: scroll slowly, jump to the footer, then return to the top. The bar should hit 0% and 100% at the correct ends.
