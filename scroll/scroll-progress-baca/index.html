Tampilkan Progress Baca Tanpa Membebani Scroll Clincoo

Indikator baca membantu artikel panjang. Hitung rasio scrollY terhadap tinggi dokumen, jangan pasang listener berat per pixel.

Artikel ini tersedia dalam: Indonesia · English

Artikel tutorial Clincoo bisa panjang. Pengunjung ingin tahu sisa bacaan tanpa membuka daftar isi.

Satu bilah tipis di header cukup. Perbarui lebarnya dari rasio scrollY / (scrollHeight - clientHeight). Bungkus pembaruan di requestAnimationFrame agar tidak memaksa layout setiap event scroll.

Jangan menulis ke DOM teks persentase di setiap pixel. Ubah atribut CSS custom property, misalnya --progress, lalu biarkan CSS menggambar bilah.

Matikan indikator di layar sangat pendek atau saat prefers-reduced-motion jika animasi lebar terasa mengganggu.

Uji di pratinjau Clincoo: gulir pelan, loncat ke footer, lalu kembali ke puncak. Bilah harus 0% dan 100% di ujung yang benar.
