Pakai id Unik untuk Anchor Scroll di Halaman Clincoo

Dua heading dengan id yang sama membuat tautan lompat ke target pertama. Audit id sebelum merilis daftar isi.

Artikel ini tersedia dalam: Indonesia · English

Daftar isi di template Clincoo gagal jika dua bagian memakai id yang sama. Browser selalu menuju elemen pertama.

Cari document.querySelectorAll('[id]') di konsol editor.clincoo.buzz. Catat id yang dobel, lalu ganti slug bagian di markup.

Jangan mulai id dengan angka. Hindari spasi. Samakan href tautan dengan id di app.clincoo.buzz.

Tempel daftar id ke AI. Jangan minta perbaiki scroll jika masalahnya duplikat id.

Clincoo di blog.clincoo.buzz merujuk halaman lewat slug; id di dalam halaman harus unik seperti slug itu.
