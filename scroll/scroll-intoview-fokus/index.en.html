Use scrollIntoView when Focusing Clincoo Forms

Off-screen validation errors stay invisible. scrollIntoView brings the failing field into view.

This article is available in: Indonesia · English

Long Clincoo forms often show an error above the first field. The user is already at the submit button and never sees that message.

After validation fails, call field.scrollIntoView({ block: 'center', behavior: 'smooth' }) then field.focus(). That order keeps screen readers and eyes aligned.

Use block: 'nearest' when the field is almost visible so the page does not jump too far.

Do not compute a manual offset with getBoundingClientRect unless a header cannot be handled by scroll-margin. The native API survives resize better.

Test in preview: submit an empty form and confirm the first invalid field lands mid-screen, not under the phone keyboard.
