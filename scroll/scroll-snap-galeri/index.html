Pakai CSS Scroll Snap untuk Galeri Clincoo

Carousel buatan sendiri mudah macet. scroll-snap-type menahan kartu di tengah tanpa library.

Artikel ini tersedia dalam: Indonesia · English

Galeri produk di Clincoo sering berupa deretan kartu horizontal. Kalau pengguna berhenti di sela dua kartu, tampilan terasa setengah jadi.

Setel kontainer dengan overflow-x: auto dan scroll-snap-type: x mandatory. Setiap kartu memakai scroll-snap-align: start atau center.

Tambahkan scroll-padding jika ada gutter. Ini mencegah kartu pertama menempel ke tepi layar HP.

Jangan pasang library carousel jika snap CSS sudah cukup. Library menambah JS, merusak gestur native, dan sulit diaudit di pratinjau Clincoo.

Uji geser dengan jari dan dengan tombol keyboard. Snap yang baik tetap bisa diakses tanpa pointer.
