Reading Progress with Scroll-Driven Animations on Clincoo

A per-pixel scroll listener taxes long articles. animation-timeline: scroll() drives a reading bar with CSS in supporting browsers.

This article is available in: Indonesia · English

A progress bar on a Clincoo article is usually computed from scrollY. Without throttling, layout and paint run too often, especially on phones.

In editor.clincoo.buzz, try a CSS approach: the indicator uses animation-timeline: scroll() and scaleX from 0 to 1. Supporting browsers bind the animation to scroll position without script on the critical path.

Provide a fallback. Wrap the new rules in @supports (animation-timeline: scroll()). Older browsers can keep a cheap listener or hide the bar.

Respect prefers-reduced-motion. A static indicator or no animation is safer for users who request reduced motion.

Measure in preview before adding this to every template. Support is still growing; do not make it the only way to mark reading progress.
