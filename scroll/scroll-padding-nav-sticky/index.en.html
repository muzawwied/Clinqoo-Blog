Use scroll-padding with a Sticky Nav on Clincoo

scroll-margin fixes a single target. scroll-padding on html or an overflow container fixes the global offset for hash navigation on a Clincoo site.

This article is available in: Indonesia · English

A sticky header in editor.clincoo.buzz often covers a section title when a visitor clicks a #id link. Many people patch each heading with scroll-margin-top. That works, but new headings are easy to miss.

Add html { scroll-padding-top: 4.5rem; } or a value matching the header height. This property pads the document scrollport so the browser places the target below the nav, not at the viewport edge.

If a panel scrolls instead of the window, put scroll-padding on that container. MDN distinguishes scroll-padding (container) from scroll-margin (item). Do not mix them without a preview test.

Keep the padding value in sync with header height on the phone breakpoint. A shorter header on small screens needs a smaller value so you do not leave a large empty gap.

Jump to several headings, including ones near the footer. Make sure keyboard focus and skip links honor the same offset.
