Control Overflow Scroll in Clincoo Containers

Two scroll axes confuse users. Set overflow-x and overflow-y on purpose, plus overscroll-behavior so gestures do not leak to the page.

This article is available in: Indonesia · English

Modals, tables, and sidebars on Clincoo sites often have a fixed height. If overflow stays auto on both axes, users drag diagonally and lose rows.

Pick one axis. Wide tables: overflow-x: auto; overflow-y: hidden. Tall lists: the reverse. Keep keyboard focus inside the scrollable container.

Add overscroll-behavior: contain on the panel. Without it, a gesture at the end of the list pulls the page behind the modal.

Do not set overflow hidden on body when a modal opens if you can lock scroll with a class on html. Hidden on body wrecks position when the modal closes.

Ask AI to touch only the offending container CSS. Paste the panel markup and current overflow rules so the fix does not leak into global layout.
