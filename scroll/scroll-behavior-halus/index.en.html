Enable scroll-behavior: smooth on a Clincoo Site

Hash #id jumps feel abrupt. One CSS line for scroll-behavior makes in-page movement smoother without heavy JavaScript.

This article is available in: Indonesia · English

Tables of contents and back-to-top buttons on Clincoo sites often use hash links. Without a setting, the browser jumps instantly and visitors lose their previous position context.

In editor.clincoo.buzz, add html { scroll-behavior: smooth; } to global CSS. This property animates in-document navigation, including clicks on #section links.

Respect motion preferences. Wrap the rule in @media (prefers-reduced-motion: no-preference) so users who request reduced motion still get an instant jump.

Do not mix CSS smooth scrolling with JavaScript window.scrollTo animation in the same file. One mechanism is enough. Test in desktop and phone preview.

If a sticky header covers the heading, combine this with scroll-margin-top. Smooth only controls how you move, not the final offset.
