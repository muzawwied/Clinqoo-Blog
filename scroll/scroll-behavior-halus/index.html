Aktifkan scroll-behavior: smooth di Situs Clincoo

Lompatan tautan #id terasa kasar. Satu baris CSS scroll-behavior membuat pergerakan halaman lebih halus tanpa JavaScript berat.

Artikel ini tersedia dalam: Indonesia · English

Daftar isi dan tombol "kembali ke atas" di situs Clincoo sering memakai tautan hash. Tanpa pengaturan, browser meloncat instan. Pengunjung kehilangan konteks posisi sebelumnya.

Di editor.clincoo.buzz, tambahkan html { scroll-behavior: smooth; } pada CSS global. Properti ini mengatur animasi scroll untuk navigasi dalam dokumen, termasuk klik tautan #bagian.

Hormati preferensi gerak. Bungkus aturan dengan @media (prefers-reduced-motion: no-preference) agar pengguna yang meminta gerakan minimal tetap mendapat lompatan langsung.

Jangan campur smooth CSS dengan animasi JavaScript pada window.scrollTo di file yang sama. Satu mekanisme cukup. Uji di pratinjau desktop dan HP.

Kalau header sticky menutup heading, gabungkan dengan scroll-margin-top. Smooth hanya mengatur cara bergerak, bukan offset akhir.
