Set the Right autocomplete and name on Clincoo Forms

The browser autofills only when name and autocomplete match standard tokens. A random name leaves the field empty.

This article is available in: Indonesian · English

A contact form on app.clincoo.buzz often does not autofill because the email input uses name="field1" and no autocomplete.

Use name="email" and autocomplete="email" for mail. For a person's name, use autocomplete="name".

Do not set autocomplete="off" on fields that are really credentials or contact data. That blocks the password manager.

Ask the AI to match autocomplete tokens to the field type, not only to add a placeholder.

Clincoo does not guess what an input means. The right attributes let a form in editor.clincoo.buzz fill without retyping.
