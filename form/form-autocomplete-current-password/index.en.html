Set autocomplete=current-password on Clincoo Sign-in Forms

A password field without an autocomplete token makes password managers fill the wrong box. Use current-password on Clincoo sign-in forms.

This article is available in: Indonesia · English

Sign-in forms in Clincoo projects often use type=password only. Browsers and password managers need an autocomplete token to know this is an existing password, not a new one.

In editor.clincoo.buzz, set autocomplete="username" on the email or username field and autocomplete="current-password" on the sign-in password field. Account-creation forms use new-password.

Do not set autocomplete=off on the whole sign-in form. That forces retyping and breaks a safer flow. Use off only for one-time fields such as OTP when needed.

Ask AI to tell login forms apart from change-password forms. Paste the form markup that currently has no autocomplete attribute.

Clincoo renders the HTML you save. The right tokens make autofill work on app.clincoo.buzz without extra script.
