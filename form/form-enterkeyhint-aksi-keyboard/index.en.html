How to Set enterkeyhint So the Keyboard Action Is Clear

The mobile keyboard uses a generic Enter label when the input gives no hint. enterkeyhint changes that label to search, go, done, or send. In editor.clincoo.buzz set this attribute on fields whose main action is clear.

Match the form button

A search field uses enterkeyhint="search". A message form uses send. A middle wizard field uses next, and the last field uses done. Do not put search on a form that does not search.

The hint does not replace type

type="search" and inputmode still shape the keyboard. enterkeyhint is only the action-key label. Keep the form wired to a submit button so Enter actually submits, not just relabels the key.

Check at phone width

Preview on app.clincoo.buzz on a touch device. If the label does not change, note the browser on blog.clincoo.buzz before adding a special script.
