How to Use a Hidden Input Without Storing a Secret

A hidden input is still in the HTML and anyone who views source can read it. In editor.clincoo.buzz use it only for a marker that is safe to expose.

What you may store

A safe example: name="sumber" value="halaman-harga" so you know which form was submitted. Do not put a payment key, password, or session token in the hidden value.

Unique name and POST

Give it a name that does not clash with another field. A form that carries this value should use method post so the value is not stuck on a shared URL.

Check before deploy

On app.clincoo.buzz view the preview source and search for type="hidden". If a string must not be public, move it to a server environment variable, not the page.
