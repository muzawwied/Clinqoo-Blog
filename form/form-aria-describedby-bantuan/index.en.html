Wire Clincoo Form Help Text with aria-describedby

Hint text under a Clincoo field is invisible to screen readers unless you bind it with aria-describedby.

Indonesia · English

Clincoo contact forms often have a small line under an input: date format, an email example, or why the field is required. Sighted users see it. A screen reader only announces the label unless you attach that text to the control.

Give the hint paragraph an id, such as id="email-help". On the input, set aria-describedby="email-help". If a separate error message exists, join the ids: aria-describedby="email-help email-error". The id order is the spoken order.

Do not keep the hint only in the placeholder. Placeholders vanish while typing and are often low contrast. The label stays required; describedby adds context, it does not replace the field name.

Test with Tab in preview, then with a phone screen reader. Make sure a dynamically shown error keeps the same id or updates the attribute. Do not let the AI copy one describedby id onto every input — each hint needs a unique id.

One id link turns the hint, the error, and the input into a single unit. Without it, keyboard visitors finish the form without hearing the rule you already wrote under the box.
