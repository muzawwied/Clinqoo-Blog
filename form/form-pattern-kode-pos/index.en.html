Use pattern for a Postal Code on a Clincoo Form

A postal-code field that accepts random letters breaks the address. Constrain the format with the pattern attribute, then test in preview.

This article is available in: Indonesia · English

In editor.clincoo.buzz a free-text input is often used for a postal code. Visitors type a word, then the address fails to match.

Set a pattern for the country, such as five digits for Indonesia. Add a title that explains the format, because the browser pattern message is often unclear.

Do not rely on pattern alone. Check again in the submit handler: empty, too short, and a matching value. pattern does not run in every old browser.

Ask the AI for one regex on one field. Refuse a check that rejects spaces if the official format uses a separator.

Keep a valid example on blog.clincoo.buzz. Clincoo ships the markup you save in app.clincoo.buzz, so a bad pattern shows up immediately in preview.
