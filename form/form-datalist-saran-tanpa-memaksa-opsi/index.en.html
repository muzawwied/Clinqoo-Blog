How to Use datalist for Suggestions Without Forcing an Option

A select forces one option. If the visitor may type their own value, use an input plus datalist in editor.clincoo.buzz.

Connect list and id

Give the datalist a unique id, for example id="kota-saran". The input uses list="kota-saran". Each suggestion is an option value. Do not reuse that datalist id on the same page.

Still validate on the server

A datalist is only a browser suggestion. People can still submit free text. On a Clincoo contact form, check length and characters where the data is received, not only in the option list.

Check the preview

On app.clincoo.buzz type two letters: suggestions should appear, and a value outside the list should still submit. Keep the label connected with for.
