Cara Pakai datalist untuk Saran tanpa Memaksa Opsi

Select memaksa satu opsi. Kalau pengunjung boleh mengetik sendiri, pakai input plus datalist di editor.clincoo.buzz.

Hubungkan list dan id

Beri datalist id unik, misalnya id="kota-saran". Input memakai list="kota-saran". Setiap saran adalah option value. Jangan mengulang id datalist di halaman yang sama.

Tetap validasi di server

Datalist hanya saran di browser. Pengguna tetap bisa mengirim teks bebas. Di form kontak Clincoo, cek panjang dan karakter di sisi yang menerima data, bukan hanya di daftar option.

Cek di preview

Di app.clincoo.buzz ketik dua huruf: saran harus muncul, dan nilai di luar daftar tetap bisa dikirim. Label tetap terhubung lewat for.
