Check Clincoo Form Validity with checkValidity, Not alert

alert breaks the flow and does not point at the field. Use checkValidity, then reportValidity.

This article is available in: Indonesian · English

Forms on editor.clincoo.buzz often call alert('fill this first') after submit. The reader never learns which field is empty.

On submit, call event.preventDefault() only when form.checkValidity() is false. Then form.reportValidity() so the browser marks the input.

Set required, type, and minlength in HTML. Clear custom messages with setCustomValidity('') when the input changes.

Do not rely on novalidate without a replacement. If novalidate is on, show error text next to the field, not a dialog.

Test the preview on app.clincoo.buzz with the keyboard only. Tab should land on the failed field, not on an alert popup.
