Prevent a Double Submit on Enter in a Clincoo Form

Enter on the last field often sends the form twice. Lock the button after the first send and ignore the second submit.

This article is available in: Indonesian · English

On editor.clincoo.buzz a contact form sometimes sends twice because Enter fires submit and the button click is counted as well.

On the first submit, set the button disabled and change the label to Sending. Keep a submitting flag in a variable, not only on the HTML attribute.

If submitting is already true, call preventDefault and return. Do not rely on disabled alone: a fast Enter can slip through before the DOM updates.

Ask AI to add that lock in one handler. Reject a fix that removes the Enter listener, because the keyboard must still be able to send the form.

Test on app.clincoo.buzz with repeated Enter. blog.clincoo.buzz only publishes the markup; the lock must be proven in the send preview.
