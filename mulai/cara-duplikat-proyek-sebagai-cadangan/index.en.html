How to Duplicate a Project as a Backup

A layout experiment or a template swap can break a page that already works. Duplicate the project in app.clincoo.buzz first so a copy stays unchanged.

Copy before you edit

Open the project list, select the deployed project, then use duplicate or copy. Name it with a date, for example shop-backup-2026-10-03. Do not overwrite the original.

Check the copy

Open the copy in editor.clincoo.buzz. Confirm index.html, CSS, and images came along. Run live preview. If an image breaks, its relative path still points at the old folder — move the asset into the same folder in the copy.

Do not deploy the copy to the main domain

The custom domain stays on the original project. Deploy the copy only to a preview URL. After the experiment works, move the changes back to the main project, or switch the domain on purpose.

A git commit on the original is still useful, but a project duplicate is a second net if you have not committed yet.
