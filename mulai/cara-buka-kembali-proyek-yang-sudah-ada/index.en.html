Getting Started

How to Reopen an Existing Project

A project does not vanish when you close the tab. Sign in again at app.clincoo.buzz with the same account — Google, GitHub, or email — then open the project list.

Pick the project, not a new template

The new-project button copies a template. To continue, click the name of the project you already have. If the list is empty, you may be signed in with another account.

Save before switching files

In editor.clincoo.buzz, press save before closing the tab. Live preview shows the draft; the public address changes only after deploy. Do not judge the live site from preview alone.

If the project is missing

Reload the list, check the free-plan limit of 3 active projects, and make sure a team invite did not open someone else's workspace. A deleted project does not come back from this page.
