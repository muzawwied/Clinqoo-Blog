How to Link CSS and JavaScript

A plain page usually means CSS or JS did not load, not that the browser rejected the file. Paths resolve from the HTML file open in editor.clincoo.buzz.

Put the link in head

Use link rel="stylesheet" href="style.css" when both files share a folder. If CSS lives in a css folder, href="css/style.css". A leading slash looks from the site root, not from a folder on your laptop.

Put the script before the closing body

script src="script.js" at the end of body waits until HTML is parsed. defer on a script in head is also safe for files that need the DOM. Do not use an inline onclick and also add a listener in the file, or the button can run twice.

Prove the file loaded

In the Network panel, style.css and script.js should be status 200. A 404 means the name or folder is wrong. After fixing the path, save the HTML and reload the preview. Deploy from app.clincoo.buzz only ships files that exist in the project, so a missing upload stays 404 on the public site.

If the console says Unexpected token, the linked JS file may actually be a 404 HTML page. Open the script URL in a new tab to confirm.
