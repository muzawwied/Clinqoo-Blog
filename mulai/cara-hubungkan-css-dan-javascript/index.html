Cara Hubungkan CSS dan JavaScript

Halaman polos biasanya berarti CSS atau JS tidak termuat, bukan karena browser menolak file. Path dihitung dari lokasi file HTML yang sedang dibuka di editor.clincoo.buzz.

Letakkan link di head

Gunakan link rel="stylesheet" href="style.css" jika kedua file satu folder. Jika CSS ada di folder css, href="css/style.css". Href yang diawali garis miring mencari dari akar situs, bukan dari folder proyek di laptopmu.

Letakkan script sebelum tutup body

script src="script.js" di akhir body menunggu HTML selesai diurai. defer pada script di head juga aman untuk file yang butuh DOM. Jangan memakai onclick inline sambil juga menambah listener di file, atau tombol bisa jalan dua kali.

Buktikan file termuat

Di panel Network, style.css dan script.js harus status 200. 404 berarti nama atau folder salah. Setelah memperbaiki path, simpan HTML lalu muat ulang preview. Deploy dari app.clincoo.buzz hanya mengirim file yang ada di proyek, jadi file yang tidak diunggah tetap 404 di situs publik.

Kalau konsol menulis Unexpected token, file JS yang tertaut mungkin sebenarnya HTML 404. Buka URL skrip di tab baru untuk memastikannya.
