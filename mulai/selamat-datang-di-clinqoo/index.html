Selamat Datang di Clincoo

Clincoo adalah ruang kerja web untuk membuat, menyunting, dan menerbitkan website dalam satu tempat: editor kode profesional, asisten AI, template siap pakai, terminal terintegrasi, dan tombol deploy. Kamu tidak perlu memasang apa pun di komputer — cukup browser.

Artikel ini adalah peta jalan singkat dari nol sampai situs pertamamu tayang di internet.

Fitur inti dalam sekilas

FiturUntuk apa
Editor kodeMenyunting file HTML, CSS, dan JavaScript dengan editor profesional lengkap dengan live preview.
Asisten AIMenjelaskan konsep, menulis dan mengubah kode, mengelola file, sampai membantu deploy.
TemplateMembuat situs baru dalam hitungan detik tanpa mulai dari nol.
TerminalMenjalankan perintah Linux langsung dari browser untuk pekerjaan teknis.
DeployMenerbitkan situs ke internet dengan HTTPS otomatis, satu klik.
KolaborasiMengundang anggota tim untuk mengerjakan proyek yang sama.

Lima langkah sampai situs pertamamu

  1. Buat akun di app.clincoo.buzz dengan Google, GitHub, atau email.
  2. Klik proyek baru, lalu pilih template yang paling dekat dengan kebutuhanmu — portofolio, landing page bisnis, atau toko sederhana.
  3. Buka file di editor dan ubah isinya. Tekan simpan, dan live preview di samping langsung menampilkan perubahannya.
  4. Bicara pada asisten AI kalau macet: minta ia menjelaskan kode yang membingungkan atau menuliskan komponen yang kamu butuhkan. Panduannya ada di artikel Asisten AI Clincoo.
  5. Kalau sudah beres, tekan deploy. Dalam beberapa menit situsmu online dengan alamat sendiri — dan kamu bisa memasang domain kustom milikmu.

Kuota yang perlu kamu tahu sebagai pengguna baru: paket gratis sudah mencakup 3 proyek aktif, 50 pesan AI per bulan, dan 5 deploy per bulan. Rincian semua paket ada di artikel Paket dan Harga Clincoo.

Setelah situs pertama tayang

Dari sini kamu bisa mengembangkan ke arah mana pun: belajar konsep web lewat praktek, mengundang rekan lewat fitur kolaborasi tim, atau sekadar memoles desain sampai pas. Kalau menemui kendala, mulai dari Pusat Bantuan — hampir semua masalah umum sudah terjawat di sana.
