Selamat Datang di Clincoo: Panduan Memulai dari Nol

Clincoo adalah ruang kerja untuk membuat dan menerbitkan website: editor kode, asisten AI, template siap pakai, dan deploy ke internet dalam satu tempat. Panduan ini ditulis untuk kamu yang baru pertama kali membuka app.clincoo.buzz dan bingung mulai dari mana.

1. Buat akun

Buka app.clincoo.buzz lalu pilih Masuk dengan Google atau Masuk dengan GitHub. Tidak perlu mengisi formulir panjang — akun langsung jadi begitu login berhasil. Kamu juga bisa mendaftar dengan email dan mengatur sandi sendiri.

2. Kenali workspace

Setelah masuk, kamu akan berada di dashboard. Dari sini semua hal bisa diakses: daftar proyek, chat AI, dashboard, editor kode, sampai pengaturan akun. Di layar lebar, tampilannya berupa split view — chat di kiri, ruang kerja di kanan.

3. Buat proyek pertama

Klik Proyek baru lalu pilih salah satu: mulai dari template siap pakai, dari file ZIP, atau dari repository GitHub (fitur paket Pro ke atas). Untuk percobaan pertama, template adalah cara tercepat — kamu langsung dapat struktur situs yang bisa diedit.

4. Edit dan minta bantuan AI

Buka proyek lalu masuk ke editor. Di sanalah semua file situsmu tinggal: HTML, CSS, JavaScript, dan gambar. Kalau bingung apa yang harus diubah, tanya asisten AI lewat chat — misalnya "ganti warna tombol jadi hitam" atau "bikin halaman tentang". AI akan menuliskan kode yang kamu tinjau sebelum diterapkan.

5. Deploy ke internet

Saat situs siap, gunakan menu Build & Deployment untuk menerbitkannya. Clincoo memberi alamat online untuk setiap proyek, dan kamu bisa memasang domain sendiri untuk tampil lebih profesional. Detail lengkapnya ada di artikel Deploy Situs ke Internet dan Pakai Domain Sendiri.

Yang perlu kamu tahu sejak awal

  • Paket gratis (Starter) sudah cukup untuk belajar: sampai 3 proyek aktif, chat AI 50 pesan per bulan, dan deploy web 5x per bulan.
  • AI di Clincoo adalah asisten, bukan pembuat situs otomatis — kamu tetap pemegang kendali.
  • Setiap perubahan bisa dilihat lewat Live preview sebelum diterbitkan.

Sisanya bisa dipelajari sambil jalan. Selamat membangun — dan kalau tersesat, buka kategori Pusat Bantuan di blog ini.
