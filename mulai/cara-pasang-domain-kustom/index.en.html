Getting Started

How to Attach a Custom Domain

Attach a custom domain only after the default deploy URL already looks right. Do not point a domain at an empty project. Manage the site from editor.clincoo.buzz and the account from app.clincoo.buzz.

Start from a live deploy

  1. Open the project in the Clincoo editor and confirm the latest deploy succeeded.
  2. Copy the default HTTPS URL, open it in a private tab, and check the title and images.
  3. Only then open domain settings on the account.

Add the DNS records

In the registrar panel, create the records Clincoo asks for — usually a CNAME for a subdomain such as www, or an A/ALIAS record for the apex. Do not leave two records fighting over the same hostname.

  • The hostname must match the Clincoo screen exactly, with no spaces.
  • Remove old records that still point that name at a previous host.
  • Save, return to Clincoo, and run the check again.

Wait, then test

DNS propagation can take minutes or a few hours. If the check fails, wait and retry — extra clicks do not speed up DNS. When it is active, open the domain in a private tab and confirm the HTTPS lock.

If deploy has never succeeded, finish the first-deploy article on blog.clincoo.buzz before touching DNS.
