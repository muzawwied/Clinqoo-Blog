Cara Menyimpan File dan Mengecek Live Preview

Di editor.clincoo.buzz, perubahan baru tampil di preview setelah file disimpan. Titik di tab atau tanda belum tersimpan berarti browser masih menjalankan salinan lama.

Simpan file yang sedang dibuka

  1. Selesai mengedit, tekan simpan atau pintasan Ctrl+S (Command+S di Mac).
  2. Tunggu tab kehilangan tanda belum tersimpan sebelum menilai tampilan.
  3. Kalau kamu mengubah CSS di file terpisah, simpan file itu juga — menyimpan HTML saja tidak menulis ulang stylesheet.

Muat ulang preview dengan benar

Kalau warna atau teks tidak berubah, muat ulang panel preview. Untuk CSS yang bandel, hard reload di browser (Ctrl+Shift+R) membersihkan cache preview. Jangan menyalin aturan yang sama ke dua file; browser memakai yang terakhir dimuat dan hasilnya terlihat acak.

Cek lebar yang dipakai pengunjung

  • Desktop: sekitar 1280px, pastikan navigasi tidak terpotong.
  • Ponsel: sekitar 390px, pastikan teks tidak meluber ke samping.
  • Kalau hanya satu lebar yang rusak, catat lebarnya sebelum minta bantuan.

Biasakan satu perubahan, satu simpan, satu cek. Pola itu membuat regresi mudah diurutkan mundur.
