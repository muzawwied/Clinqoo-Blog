Getting Started

How to Save a File and Check Live Preview

In editor.clincoo.buzz, a change shows in the preview only after the file is saved. A dot on the tab or an unsaved mark means the browser is still running the old copy.

Save the file you have open

  1. When the edit is done, press save or the Ctrl+S shortcut (Command+S on a Mac).
  2. Wait until the tab loses the unsaved mark before you judge the layout.
  3. If you edited CSS in a separate file, save that file too — saving the HTML does not rewrite the stylesheet.

Reload the preview the right way

If a color or sentence does not change, reload the preview panel. For stubborn CSS, a hard reload (Ctrl+Shift+R) clears the preview cache. Do not copy the same rule into two files; the browser uses whichever loads last, and the result looks random.

Check the widths visitors actually use

  • Desktop: about 1280px, and make sure the nav is not cut off.
  • Phone: about 390px, and make sure text does not overflow sideways.
  • If only one width breaks, note that width before you ask for help.

Get used to one change, one save, one check. That pattern makes a regression easy to undo.
