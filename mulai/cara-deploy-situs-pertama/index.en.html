Getting Started

How to Deploy Your First Site from the Editor

Deploy copies the saved project files to HTTPS hosting. Unsaved edits are not included. The free plan includes a few deploys per month, so check once before pressing the button again.

Check before you press deploy

  1. Open the project in editor.clincoo.buzz and save every tab.
  2. Make sure index.html is in the root. Without it, visitors get a blank page or a 404.
  3. Keep secrets out of public files. An API key must not be written in JavaScript the browser downloads.
  4. Reload the preview once more and click the main links.

Publish and open the address

Press deploy in the editor, or ask the AI assistant to publish the active project. When it finishes, copy the URL and open it in a private tab. If you still see the old version, wait a moment and reload — a CDN sometimes holds the previous copy.

Attach a custom domain only after the default URL looks right. Quota details live in the plans documentation, and the account is managed at app.clincoo.buzz.

If deploy fails

  • Read the failure message as written; do not just click again.
  • Fix the file it names, save, then deploy once more.
  • If the quota is spent, wait for the next period or upgrade — extra clicks do not add allowance.
