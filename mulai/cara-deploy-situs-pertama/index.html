Cara Deploy Situs Pertama dari Editor

Deploy menyalin file proyek yang sudah disimpan ke hosting ber-HTTPS. Yang belum disimpan tidak ikut. Paket gratis mencakup beberapa deploy per bulan, jadi cek dulu sebelum menekan tombol berulang.

Cek sebelum menekan deploy

  1. Buka proyek di editor.clincoo.buzz dan simpan semua tab.
  2. Pastikan ada index.html di root. Tanpa file itu, pengunjung mendapat halaman kosong atau 404.
  3. Lepaskan secret dari file publik. Kunci API tidak boleh tertulis di JavaScript yang diunduh browser.
  4. Muat preview sekali lagi dan klik tautan utama.

Terbitkan dan buka alamatnya

Tekan deploy di editor atau minta asisten AI menerbitkan proyek aktif. Setelah selesai, salin URL yang diberikan dan buka di tab penyamaran. Kalau yang tampil masih versi lama, tunggu sebentar lalu muat ulang — CDN kadang menahan salinan sebelumnya.

Domain kustom dipasang setelah URL bawaan sudah benar. Rincian kuota ada di dokumentasi paket, dan akun dikelola di app.clincoo.buzz.

Kalau deploy gagal

  • Baca pesan gagal apa adanya, jangan hanya mengulang klik.
  • Perbaiki file yang disebut, simpan, lalu deploy lagi.
  • Kalau kuota habis, tunggu periode berikutnya atau naik paket — mengulang klik tidak menambah jatah.
