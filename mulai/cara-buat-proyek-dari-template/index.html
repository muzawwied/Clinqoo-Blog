Cara Membuat Proyek dari Template

Template di app.clincoo.buzz adalah situs kecil yang sudah jadi: HTML, CSS, dan JavaScript tersusun, tinggal kamu ganti isinya. Ini cara paling aman untuk proyek pertama karena strukturnya sudah valid.

Pilih template yang dekat dengan tujuan

  1. Masuk ke akun Clincoo, lalu klik proyek baru.
  2. Bandingkan portofolio, landing page, dan halaman bisnis. Pilih yang paling dekat, bukan yang paling ramai animasinya.
  3. Beri nama proyek yang pendek dan tanpa spasi, misalnya studio-raya, supaya URL deploy nanti mudah dibaca.

Ganti isi, jangan ganti struktur dulu

Buka index.html di editor. Ganti judul, paragraf, dan tautan. Biarkan tag dan nama class apa adanya sampai preview terlihat benar. Gambar diganti lewat atribut src atau file di folder gambar, bukan dengan menempel file besar ke tengah HTML.

Kalau satu bagian membingungkan, tanyakan asisten AI di editor.clincoo.buzz dengan menyebut nama file. Minta penjelasan dulu, baru minta ubahan kecil.

Simpan dan cek sebelum lanjut

Tekan simpan, lihat live preview, lalu gulir sampai bawah di lebar desktop dan ponsel. Kalau preview kosong, jangan ganti template — baca konsol dulu. Proyek yang sudah tersimpan tetap ada di daftar proyek meski kamu menutup tab.
