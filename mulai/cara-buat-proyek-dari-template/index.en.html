Getting Started

How to Create a Project from a Template

A template on app.clincoo.buzz is a small finished site: HTML, CSS, and JavaScript already arranged, waiting for your content. It is the safest first project because the structure is already valid.

Pick a template close to the goal

  1. Sign in to Clincoo, then click new project.
  2. Compare portfolio, landing page, and business page. Choose the closest match, not the one with the busiest animation.
  3. Name the project short and without spaces, for example studio-raya, so the later deploy URL is easy to read.

Replace content, not structure yet

Open index.html in the editor. Replace the title, paragraphs, and links. Leave tags and class names alone until the preview looks right. Swap images through the src attribute or a file in the images folder, not by pasting a large file into the middle of the HTML.

If a section is confusing, ask the AI assistant in editor.clincoo.buzz and name the file. Ask for an explanation first, then a small edit.

Save and check before moving on

Hit save, look at the live preview, then scroll to the bottom at desktop and phone width. If the preview is blank, do not switch templates — read the console first. A saved project stays in the project list even if you close the tab.
