Cara Commit Git Pertama di Proyek

Commit adalah catatan perubahan yang bisa kamu kembalii. Di terminal editor.clincoo.buzz cukup tiga perintah untuk commit pertama yang berguna.

Cek apa yang berubah

Jalankan git status. File merah berarti belum dilacak atau belum masuk staging. Jangan commit node_modules, file .env, atau cadangan editor. Kalau file itu muncul, tambahkan namanya ke .gitignore lalu ulangi git status.

Pilih file yang masuk

git add index.html style.css menambah file tertentu. git add . mengambil semua yang tidak diabaikan. Setelah itu git status harus menampilkan file hijau di area staged. Kalau ada yang tidak sengaja masuk, git restore --staged nama-file mengeluarkannya tanpa menghapus isi file.

Tulis pesan yang menjelaskan

git commit -m "tambah hero dan tautan halaman tentang" lebih berguna daripada "update". Satu commit untuk satu maksud. Kalau git menolak karena identitas kosong, isi user.name dan user.email hanya di repo ini, lalu commit lagi.

Setelah commit, git log --oneline menunjukkan riwayat. Deploy tetap lewat tombol deploy di app.clincoo.buzz, bukan otomatis dari commit.
