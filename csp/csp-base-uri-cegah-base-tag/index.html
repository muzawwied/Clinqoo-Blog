Cara Pakai base-uri supaya tag base tidak dibajak

Tag base mengubah tujuan semua URL relatif. Skrip yang menyisipkan base ke host lain bisa mengalihkan formulir dan aset tanpa menyentuh tiap tautan. Di editor.clincoo.buzz setel base-uri 'self' atau 'none' pada header deploy, lalu cek pratinjau app.clincoo.buzz.

Pilih none jika base tidak dipakai

Halaman yang tidak punya tag base lebih aman dengan base-uri 'none'. 'self' hanya jika base ke origin sendiri memang diperlukan.

Ini bukan pengganti script-src

base-uri tidak memblokir skrip. Pasangkan dengan script-src yang sudah membatasi nonce atau hash.

Dokumentasikan pilihan

Tulis arahan final di blog.clincoo.buzz agar perubahan template tidak menambah tag base diam-diam.
