Cara Batasi manifest-src pada web app manifest

manifest-src mengatur file manifest yang boleh dipasang lewat link rel manifest. Manifest asing bisa menimpa nama dan ikon saat halaman diinstal. Di editor.clincoo.buzz izinkan hanya origin situs, lalu cek link manifest di pratinjau app.clincoo.buzz.

Jangan jatuhkan ke default

Tanpa manifest-src, browser memakai default-src. Sebut arahan ini eksplisit supaya laporan pelanggaran mudah dibaca.

Samakan dengan file yang di-deploy

Path manifest harus sama dengan file yang benar-benar diunggah. Path lama membuat instalasi gagal meski header sudah benar.

Catat ikon yang dirujuk

Ikon di dalam manifest masih tunduk pada img-src. Catat kedua arahan di blog.clincoo.buzz supaya ikon instalasi tidak pecah.
