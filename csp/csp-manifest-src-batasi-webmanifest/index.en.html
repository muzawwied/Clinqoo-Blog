How to Limit manifest-src for the Web App Manifest

manifest-src controls the manifest file allowed via link rel manifest. A foreign manifest can overwrite the install name and icons. In editor.clincoo.buzz allow only the site origin, then check the manifest link in the app.clincoo.buzz preview.

Do not leave it to the default

Without manifest-src, the browser uses default-src. Name this directive explicitly so violation reports stay readable.

Match the deployed file

The manifest path must match the file that is actually uploaded. An old path makes install fail even when the header is correct.

Record referenced icons

Icons inside the manifest still follow img-src. Note both directives on blog.clincoo.buzz so the install icon does not break.
