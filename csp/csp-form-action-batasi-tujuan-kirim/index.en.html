How to Limit form-action to Real Form Targets

form-action controls where a form may be submitted. script-src does not close this gap: a page with a locked script policy can still have an action pointing at another host. On editor.clincoo.buzz allow only the receiver origins you use, then test a submit in the app.clincoo.buzz preview.

Include a path only if you must

An origin is usually enough. A path in form-action goes stale when routes change. Update the policy with the route, not after a user report.

Do not confuse it with navigate-to

form-action is specifically for form submissions. Ordinary link navigation uses other directives. Do not loosen form-action just because an internal link failed.

Keep the receiver list

Record form-action origins on blog.clincoo.buzz so a new integration does not send fields before the header is updated.
