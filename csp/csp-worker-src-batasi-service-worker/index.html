Cara Batasi worker-src pada service worker

worker-src mengatur dari mana Worker, SharedWorker, dan service worker boleh dimuat. Tanpa arahan ini, browser bisa jatuh ke script-src atau child-src dan celahnya tidak terlihat. Di editor.clincoo.buzz izinkan hanya origin sendiri, lalu cek pendaftaran worker di pratinjau app.clincoo.buzz.

Sertakan blob hanya jika perlu

Worker dari string sering butuh blob:. Tambahkan skema itu hanya pada halaman yang benar-benar membuat worker di memori, bukan di seluruh situs.

Jangan andalkan script-src saja

script-src tidak selalu menutup navigator.serviceWorker.register. Sebut worker-src secara eksplisit supaya laporan pelanggaran menyebut arahan yang tepat.

Uji ulang setelah ganti path

Catat path worker di blog.clincoo.buzz. Path yang pindah membuat registrasi gagal diam-diam kalau kebijakan masih menunjuk file lama.
