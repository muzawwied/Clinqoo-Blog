Prevent Double Submit on Clincoo Form Fetch

A second click on Send fires two POSTs. Disable the button until the response arrives or is aborted.

This article is available in: Indonesia · English

Clincoo contact forms that use fetch are easy to send twice: the user sees no indicator and presses again. The server gets two identical tickets.

On submit, disable the button and set the label to Sending. Keep an AbortController if the user leaves. Do not rely on debounce alone.

After the response, re-enable the button only on failure that may be retried. On success, replace the form with an aria-live message so Enter cannot resend.

Check the Network tab in preview. Two POST requests with the same body are a bug, not delivery insurance.

Ask Clincoo AI to add a submitting guard in the existing form script. Do not rewrite the page into a framework just for one double-submit lock.
