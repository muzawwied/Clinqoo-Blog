Cegah Submit Ganda saat Fetch Form Clincoo

Klik dua kali pada Kirim membuat dua POST. Nonaktifkan tombol sampai respons datang atau dibatalkan.

Artikel ini tersedia dalam: Indonesia · English

Form kontak di situs Clincoo yang memakai fetch mudah terkirim dua kali: pengguna tidak melihat indikator, lalu menekan lagi. Server menerima dua tiket identik.

Saat submit, set tombol disabled dan teks Mengirim. Simpan AbortController jika pengguna pindah halaman. Jangan mengandalkan debounce saja.

Setelah respons, hidupkan lagi tombol hanya jika gagal dan boleh dicoba. Jika sukses, ganti form dengan pesan aria-live agar tidak terkirim ulang lewat Enter.

Cek tab Network di pratinjau. Dua permintaan POST dengan body sama adalah bug, bukan jaminan sampai.

Minta AI Clincoo menambah penjaga submitting di skrip form yang ada. Jangan ganti seluruh halaman jadi framework hanya untuk satu kunci ganda.
