Tangani Offline dan Kegagalan Jaringan pada Fetch Clincoo

fetch yang gagal karena offline sering tampil sebagai error JS mentah. Beri pesan dan tombol coba lagi.

Artikel ini tersedia dalam: Indonesia · English

Di pratinjau Clincoo, form kontak yang memanggil API terlihat baik saat Wi-Fi stabil. Di lapangan, pengunjung bisa kehilangan jaringan tepat saat menekan kirim.

Bungkus fetch dengan try/catch. Kegagalan jaringan melempar TypeError, bukan respons HTTP. Jangan anggap itu sama dengan status 500.

Deteksi navigator.onLine sebagai petunjuk awal, tetapi tetap tangani error fetch: onLine bisa true saat DNS gagal.

Tampilkan pesan singkat di dekat tombol: tidak tersambung, coba lagi. Jangan mengosongkan isi form yang sudah diketik.

Nonaktifkan tombol kirim selama permintaan berjalan, lalu aktifkan lagi saat gagal. Hindari antrean fetch ganda dari klik berulang.

Uji dengan mode offline di DevTools sebelum rilis. Minta AI menambahkan cabang error jaringan, lalu verifikasi teksnya dalam bahasa halaman.
