Jangan tampilkan stack server ke pengguna, simpan di log

Pesan exception mentah membocorkan path dan query. Tampilkan kode singkat, simpan stack di log internal.

Artikel ini tersedia dalam: Indonesia · English

Respons gagal dari API Clincoo kadang mengembalikan stack lengkap. Itu berguna di konsol lokal, berbahaya di halaman publik.

Petakan status 500 ke kalimat tetap plus kode referensi. Jangan render body mentah ke DOM.

Di Network, salin request id, bukan seluruh HTML error. Kirim id itu saat minta bantuan di editor.clincoo.buzz.

Minta AI merancang pemetaan kode error. Tolak saran yang menampilkan process.env atau path server.

Uji endpoint app.clincoo.buzz dengan body rusak. UI hanya menampilkan gagal diproses dan kode, stack tetap di log.
