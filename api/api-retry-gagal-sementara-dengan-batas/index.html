Ulangi Fetch Clincoo yang Gagal Sementara, dengan Batas Jelas

Status 429 atau jaringan putus sekejap bukan alasan loop tanpa henti. Batasi 2–3 percobaan dan tampilkan pesan.

Artikel ini tersedia dalam: Indonesia · English

Fetch ke API form atau daftar artikel kadang gagal karena jaringan goyah atau server menolak sementara. Mengulang sekali atau dua kali masuk akal. Mengulang tanpa batas membuat tombol menggantung dan menumpuk permintaan.

Bedakan error. 400 dan 401 jangan diulang: isi atau izin yang salah tidak sembuh dengan retry. 429, 503, atau TypeError jaringan boleh dicoba lagi setelah jeda singkat.

Pakai AbortController agar percobaan lama tidak menimpa yang baru. Nonaktifkan tombol Kirim selama rangkaian retry. Tampilkan “mencoba lagi…” lalu pesan gagal jika batas tercapai.

Di pratinjau Clincoo, uji dengan tab Network set Offline lalu Online. Pengunjung harus melihat status, bukan error merah di konsol. Jangan simpan kunci API di berkas JavaScript halaman.

Catat kode status di log internal jika kamu punya endpoint sendiri. Tanpa status, tim mengira CSS yang rusak padahal API menolak.
