Use stopPropagation Sparingly on Clincoo Events

stopPropagation on every click breaks Clincoo delegation and analytics. Stop bubbling only when child and parent truly conflict.

This article is available in: Indonesia · English

Clincoo templates often attach stopPropagation on a button inside a card. The click never reaches the parent, so delegation and CTA tracking stay silent.

Let the event rise. In the parent handler, read event.target.closest() to tell a button, a link, or the card surface apart. One listener is enough.

Call stopPropagation only when two handlers on the same path do opposite work, for example a card that opens details while a button opens a menu.

Do not mix in stopImmediatePropagation unless you own every script on the page. Analytics added later will never see the click.

Ask AI to delete unexplained stopPropagation calls. Paste the handler snippet, not the whole interactive file.

Clincoo renders static HTML plus the scripts you save. Bubbling is a feature; stop it only when there is a real conflict.
