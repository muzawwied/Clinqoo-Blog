Tangani keydown Escape untuk Menutup Dialog Clincoo

Dialog Clincoo yang hanya punya tombol silang sulit ditutup. Pasang keydown Escape di dokumen saat dialog terbuka.

Artikel ini tersedia dalam: Indonesia · English

Pengunjung Clincoo sering menutup overlay dengan tombol Escape. Kalau skrip hanya mendengarkan klik pada ikon silang, keyboard dan pembaca layar terhenti.

Di editor.clincoo.buzz, pasang listener keydown pada document saat dialog ditampilkan. Periksa event.key === 'Escape', lalu panggil fungsi tutup yang sama dengan tombol silang.

Lepas listener begitu dialog tertutup. Listener global yang dibiarkan hidup akan menutup dialog lain atau mengganggu input di halaman berikutnya.

Jika kamu memakai elemen dialog native, metode close() sudah merespons Escape. Jangan dobel-tangani kecuali overlay buatan sendiri.

Minta AI menempel handler Escape terpisah, bukan menulis ulang seluruh modal. Uji di pratinjau dengan Tab lalu Escape.

Pola dialog WAI-ARIA mensyaratkan Escape. Clincoo merender HTML yang kamu simpan; akses keyboard adalah bagian dari event, bukan dekorasi.
