Pakai Event input, Bukan change, untuk Draf Clincoo

Event change baru jalan saat field blur. Draf otomatis di Clincoo lebih aman jika mendengarkan input.

Artikel ini tersedia dalam: Indonesia · English

Pada form di editor.clincoo.buzz, change sering tertunda sampai pengunjung pindah field. Teks yang baru diketik belum tersimpan jika tab ditutup.

Dengarkan input pada field teks. Simpan draf setelah jeda singkat, misalnya 400 ms, supaya tidak menulis penyimpanan di setiap huruf.

Untuk select dan checkbox, change tetap tepat karena nilainya langsung final. Jangan samakan semua kontrol.

Di konsol pratinjau app.clincoo.buzz, log jenis event sekali. Pastikan draf terbarui sebelum blur.

Jika AI menempel onchange untuk autosave, minta ganti ke input plus debounce. Satu field, satu perbaikan.
