Use the input Event, Not change, for Clincoo Drafts

The change event fires on blur. Autosave drafts in Clincoo are safer when you listen for input.

This article is available in: Indonesia · English

On a form in editor.clincoo.buzz, change often waits until the visitor leaves the field. Typed text is not saved if the tab closes.

Listen for input on text fields. Save the draft after a short pause, about 400 ms, so you do not write storage on every key.

For select and checkbox, change is still right because the value is final immediately. Do not treat every control the same.

In the app.clincoo.buzz preview console, log the event type once. Confirm the draft updates before blur.

If AI pastes onchange for autosave, ask to switch it to input plus debounce. One field, one fix.
