Lepas Banyak Listener Clincoo dengan AbortController

Menghapus listener satu per satu mudah terlewat. Satu AbortController melepas seluruh event halaman Clincoo saat pindah.

Artikel ini tersedia dalam: Indonesia · English

Halaman Clincoo yang memasang resize, keydown, dan scroll pada window menumpuk listener tiap kali skrip dijalankan ulang di editor.

Buat const ac = new AbortController() di awal modul. Kirim { signal: ac.signal } ke setiap addEventListener. Saat halaman atau overlay ditutup, panggil ac.abort().

Satu abort melepas semua listener yang memakai sinyal itu. Kamu tidak perlu menyimpan referensi fungsi hanya untuk removeEventListener.

Sinyal yang sama bisa membatalkan fetch. Samakan siklus hidup event UI dan permintaan data agar tidak ada respons yang menulis DOM yang sudah hilang.

Minta AI menambahkan opsi signal, bukan menulis ulang seluruh berkas. Uji dengan buka-tutup overlay berkali-kali lalu cek jumlah listener di DevTools.

Clincoo merender ulang pratinjau. AbortController menjaga event window tidak hidup lebih lama dari halaman yang memakainya.
