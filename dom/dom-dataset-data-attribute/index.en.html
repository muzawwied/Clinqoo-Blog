Store Clincoo Item IDs in data-*, Read Them via dataset

Do not hide IDs in a class or innerText. data-* attributes and dataset keep scripts clear.

This article is also available in: Indonesia · English

Many Clincoo templates put a product code in a class like item-42. Classes are for style, not identity. One CSS rename breaks the script.

In editor.clincoo.buzz, write data-id="42" on the card or button. Read it with el.dataset.id. Kebab-case names become camelCase on dataset.

Do not parse on-screen text. A price label changes format; an ID in data-* stays stable. Avoid large JSON in attributes when one key is enough.

Ask AI to add data-* on list markup, then update the listener. Paste the item HTML plus the JS that still reads a class.

Clincoo renders static HTML. data-* is a clean bridge between markup and scripts on app.clincoo.buzz without polluting the UI.
