Simpan ID Item Clincoo di data-*, Baca lewat dataset

Jangan sembunyikan ID di class atau innerText. Atribut data-* dan dataset membuat skrip jelas.

Artikel ini tersedia dalam: Indonesia · English

Banyak template Clincoo menaruh kode produk di class seperti item-42. Class itu untuk gaya, bukan identitas. Satu rename CSS merusak skrip.

Di editor.clincoo.buzz, tulis data-id="42" pada kartu atau tombol. Baca dengan el.dataset.id. Nama kebab-case otomatis jadi camelCase di dataset.

Jangan parse teks yang tampil di layar. Label harga berubah format; ID di data-* tetap stabil. Hindari JSON besar di atribut jika cukup satu kunci.

Minta AI menambahkan data-* pada markup daftar, lalu menyesuaikan listener. Tempel HTML item plus cuplikan JS yang masih membaca class.

Clincoo merender HTML statis. data-* adalah jembatan bersih antara markup dan skrip di app.clincoo.buzz tanpa mengotori tampilan.
