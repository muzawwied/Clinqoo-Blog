Measure Clincoo Layout in requestAnimationFrame, Not a Sync Loop

Reading offsetHeight over and over in a for loop forces reflow and makes the editor feel stuck.

This article is also available in: Indonesia · English

Code that measures every card height in editor.clincoo.buzz often freezes preview when the list is long.

Batch DOM writes first, then read geometry once inside requestAnimationFrame. Do not interleave writes and reads.

If you need a number before paint, call getBoundingClientRect on the container, not on every child.

Send the loop snippet to AI and ask to split write and read phases. Reject a random setTimeout as a stand-in for rAF.

Compare preview FPS on app.clincoo.buzz before and after. Store the numbers in the release note on blog.clincoo.buzz.
