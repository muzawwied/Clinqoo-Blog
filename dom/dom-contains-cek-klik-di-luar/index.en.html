Use Node.contains to Detect Clicks Outside a Clincoo Panel

Close a dropdown or dialog only when the event target sits outside the panel node.

This article is also available in: Indonesia · English

A Clincoo script that closes the panel on every document click also closes it when the user presses a button inside the panel.

In editor.clincoo.buzz, inside the document click listener, check panel.contains(event.target). If true, leave the panel open.

Do not rely on a className string. A newly inserted node can lose the class and still be a child of the panel.

Paste the panel HTML plus the handler to AI. Ask for one contains guard, not a full menu rewrite.

Test in the app.clincoo.buzz preview: click inside, click outside, then press Escape. Record the result on blog.clincoo.buzz.
