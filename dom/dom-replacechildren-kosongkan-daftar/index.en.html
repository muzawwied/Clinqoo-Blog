Clear Clincoo Lists with replaceChildren, Not Empty innerHTML

innerHTML = '' removes children but parses HTML. replaceChildren() clears Clincoo nodes with a clear DOM API.

This article is available in: Indonesia · English

When a card list in the Clincoo preview must be fully replaced, the old habit is to write list.innerHTML = '' and then paste a new string. It works, but the browser has to parse markup, listeners on old children disappear without control, and injection risk returns if the next string comes from a form.

Use Element.replaceChildren(). With no arguments, every child is removed. With node arguments, old children are replaced in one step. There is no HTML parse, no raw string, and insert order stays under your control via createElement plus textContent.

A practical editor flow: select the container with querySelector, build new items in a DocumentFragment, then call container.replaceChildren(frag). One call replaces a removeChild loop and avoids repeated layout.

If older scripts still write innerHTML, replace the clearing step first. After the list is empty through the node API, insert children the same way as the createElement article in this category.

Test in preview: click a filter that clears results, confirm the container keeps no stale items, then refill. Open the inspector — children should be real nodes, not leftover comments or text from an HTML string.
