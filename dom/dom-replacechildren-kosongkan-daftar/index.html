Kosongkan Daftar Clincoo dengan replaceChildren, Bukan innerHTML Kosong

innerHTML = '' menghapus anak tapi memicu parse HTML. replaceChildren() mengosongkan node Clincoo dengan API DOM yang jelas.

Artikel ini tersedia dalam: Indonesia · English

Saat daftar kartu di pratinjau Clincoo perlu diganti total, kebiasaan lama adalah menulis daftar.innerHTML = '' lalu menempel string baru. Cara itu bekerja, tetapi browser harus menafsirkan markup, listener pada anak lama hilang tanpa kontrol, dan risiko injeksi kembali jika string berikutnya berasal dari form.

Pakai Element.replaceChildren(). Tanpa argumen, semua anak dihapus. Dengan argumen node, anak lama diganti sekaligus. Tidak ada parse HTML, tidak ada string mentah, dan urutan sisipan tetap kamu kendalikan lewat createElement plus textContent.

Alur praktis di editor: ambil wadah dengan querySelector, bangun item baru di DocumentFragment, lalu wadah.replaceChildren(frag). Satu panggilan menggantikan loop removeChild dan menghindari layout berulang.

Jika skrip lama masih menulis innerHTML, ganti dulu langkah pengosongan. Setelah daftar bersih lewat API node, sisipkan anak dengan cara yang sama seperti artikel createElement di kategori ini.

Uji di pratinjau: klik filter yang mengosongkan hasil, pastikan wadah tidak menyisakan item lama, lalu isi ulang. Buka inspector — anak harus node murni, bukan sisa komentar atau teks dari string HTML.
