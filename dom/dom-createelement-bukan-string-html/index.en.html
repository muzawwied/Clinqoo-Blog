Build New Clincoo Items with createElement, Not HTML Strings

Pasted HTML strings invite injection and are hard to test. createElement plus textContent is safer.

This article is also available in: Indonesia · English

Clincoo scripts that add cards via innerHTML plus a template string break when a product name contains quotes or tags.

In editor.clincoo.buzz, create an li with document.createElement('li'), set textContent and the needed class, then appendChild to the list. The node is born complete without an HTML parser.

Keep data and markup apart. textContent rejects hidden HTML. If you need a link, setAttribute('href', url) after validating an http or https scheme.

Ask AI to replace dynamic innerHTML with createElement. Paste the add-item function plus sample input that contains < and &.

Clincoo ships static sites, but client scripts still run. createElement keeps dynamic lists on app.clincoo.buzz clean.
