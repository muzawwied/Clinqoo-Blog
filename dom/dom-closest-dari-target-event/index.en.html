From a Clincoo Click Target, Climb to the Card with closest

event.target is often an icon or span inside a button. closest finds the relevant ancestor.

This article is also available in: Indonesia · English

A Clincoo list listener reads event.target.className and fails because the visitor clicked an SVG inside the button, not the button itself.

In editor.clincoo.buzz, write const card = event.target.closest('[data-card]'). If it is null, ignore the click. One selector covers icon, text, and padding.

Do not walk parentNode by hand. closest stops at the document and returns null safely. Combine it with dataset on the card.

Ask AI to replace class checks on the target with closest. Paste card markup that nests an icon plus the old handler.

Clincoo renders static cards that can have many children. closest keeps event delegation on app.clincoo.buzz accurate.
