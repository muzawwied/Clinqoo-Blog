Clone Clincoo List Rows from a template Tag, Not an innerHTML String

A template tag keeps row structure intact and avoids injection when you duplicate an item.

This article is also available in: Indonesia · English

Building row HTML from a string in editor.clincoo.buzz breaks when visitor text contains quotes.

Keep the row pattern in a template tag. Clone the content, fill textContent on slots, then append to the list.

Do not fill the template with innerHTML from input. textContent on a text node is enough for title and meta.

Ask AI to turn a template literal string into a clone from a template tag. Paste the existing list markup.

Test adding and removing rows on app.clincoo.buzz. Document the pattern on blog.clincoo.buzz.
