Salin Baris Daftar Clincoo dari tag template, Bukan innerHTML String

tag template menjaga struktur baris dan menghindari injeksi saat menggandakan item.

Artikel ini tersedia dalam: Indonesia · English

Menyusun HTML baris lewat string di editor.clincoo.buzz mudah pecah saat teks pengunjung berisi tanda kutip.

Simpan pola baris di tag template. Clone content, isi textContent pada slot, lalu append ke daftar.

Jangan mengisi template dengan innerHTML dari input. textContent pada node teks sudah cukup untuk judul dan meta.

Minta AI mengubah string template literal menjadi clone dari tag template. Tempel markup daftar yang ada.

Uji menambah dan menghapus baris di app.clincoo.buzz. Dokumentasikan pola ini di blog.clincoo.buzz.
