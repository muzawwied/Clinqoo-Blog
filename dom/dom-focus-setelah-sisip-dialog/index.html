Pindahkan Fokus Clincoo ke Dialog Setelah Node Disisip

Dialog yang muncul tanpa fokus membuat keyboard tersesat di belakang overlay.

Artikel ini tersedia dalam: Indonesia · English

Menambah dialog ke DOM di editor.clincoo.buzz tanpa focus membuat Tab tetap berjalan di halaman belakang.

Setelah append, panggil dialog.querySelector(fokus pertama).focus(). Sediakan tombol tutup yang bisa di-Tab.

Simpan node sebelumnya (document.activeElement) dan kembalikan fokus saat dialog ditutup.

Minta AI menambah pindah fokus, bukan hanya class is-open. Tempel markup dialog plus tombol pemicu.

Uji Tab dan Escape di app.clincoo.buzz. Tulis checklist singkat di blog.clincoo.buzz.
