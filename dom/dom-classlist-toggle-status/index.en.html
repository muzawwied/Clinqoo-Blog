Change Clincoo UI State with classList, Not Raw className

className overwrites every class. classList.add, remove, and toggle keep visual state intact.

This article is also available in: Indonesia · English

Clincoo page scripts often write el.className = 'active'. That one line drops layout, theme, and modifier classes already on the template.

In editor.clincoo.buzz, use el.classList.toggle('is-open') or add/remove. Class tokens stay independent. Accordion, tab, and drawer state will not break the grid.

Do not stitch class strings by hand. One missing space breaks CSS selectors. classList.contains makes branches simple without splitting strings.

Ask AI to touch only the status token, not replace the whole class attribute. Paste the element HTML plus the .is-open CSS so the suggestion stays narrow.

Clincoo runs static scripts on app.clincoo.buzz. classList keeps UI predictable when visitors open menus, filters, or modals.
