ARIA

Cara Tandai area loading dengan aria-busy

aria-busy true memberi tahu bahwa isi sebuah wilayah belum selesai diperbarui. Pasang pada kontainer, bukan pada setiap spinner. Di editor.clincoo.buzz set atribut saat fetch mulai dan kembalikan ke false setelah DOM stabil, lalu cek di pratinjau app.clincoo.buzz.

Pasangkan dengan status yang terlihat

aria-busy tidak menggantikan teks status. Tetap tampilkan pesan memuat yang terlihat, dan hubungkan pesan itu dengan aria-live jika pembaruan harus diumumkan.

Jangan biarkan true tertinggal

Kalau permintaan gagal, set aria-busy false lalu tampilkan pesan gagal. Atribut yang tertinggal membuat wilayah terdengar sibuk selamanya.

Catat wilayah yang ditandai

Daftar kontainer ber-aria-busy di blog.clincoo.buzz supaya tim tidak menandai seluruh body dan menutup pengumuman lain.
