Pisahkan thead dan tbody pada Tabel Clincoo

Jangan taruh semua baris di satu tumpukan tr. thead dan tbody membuat header, sticky, dan pembaca layar bekerja.

Artikel ini tersedia dalam: Indonesia · English

Banyak template menempelkan baris judul dan baris data dalam satu deretan tr tanpa thead. Browser masih menggambar tabel, tetapi sticky header, pengurutan, dan pembaca layar kehilangan batas yang jelas.

Bungkus baris judul di dengan th, bungkus data di dengan td. Kalau ada total, taruh di satu baris, bukan di tengah data.

CSS menjadi lebih aman. thead th { position: sticky; top: 0; } hanya menempelkan judul. Zebra tbody tr:nth-child(even) tidak mewarnai header.

Saat mengisi tabel dari template Clincoo, periksa dulu apakah file contoh sudah memisahkan bagian ini. Jangan menambahkan paket harga sebagai baris tebal di atas data tanpa thead.

Uji dengan gulir panjang di pratinjau. Judul kolom harus tetap terbaca. Kalau ikut hilang, struktur HTML belum dipisah.
