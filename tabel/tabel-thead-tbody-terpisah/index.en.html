Split thead and tbody in Clincoo Tables

Do not dump every row into one stack of tr elements. thead and tbody make headers, sticky rows, and screen readers work.

This article is available in: Indonesia · English

Many templates glue heading rows and data rows into one run of tr with no thead. The table still draws, but sticky headers, sorting, and screen readers lose a clear boundary.

Wrap the heading row in with th, wrap data in with td. Put totals in a single row, not in the middle of the data.

CSS gets safer. thead th { position: sticky; top: 0; } sticks only titles. Zebra striping on tbody tr will not paint the header.

When you fill a Clincoo template table, check that the sample already splits these parts. Do not add pricing as a bold row above the data with no thead.

Scroll a long table in preview. Column titles must stay readable. If they vanish, the HTML is not split yet.
