Check Print Preview before Sharing a Clincoo Page

Print bugs show up only after a client hits Ctrl+P. Make paper preview part of the release checklist.

This article is available in: Indonesia · English

On editor.clincoo.buzz, a page can look fine on screen and break in Print Preview.

Open Ctrl+P, choose A4, save a test PDF, fix one print rule.

Retest on app.clincoo.buzz and link an example on blog.clincoo.buzz.
