Jangan Cetak Hash Tautan Internal pada Kertas Clincoo

Tampilkan URL penuh hanya untuk tautan eksternal. Sembunyikan #id dan path relatif di media print.

Artikel ini tersedia dalam: Indonesia · English

Aturan a[href]::after { content: attr(href) } mencetak setiap jangkar. Hasilnya halaman harga penuh teks #paket dan ./syarat yang tidak bisa diketik ulang.

Di editor.clincoo.buzz, batasi pencetakan URL ke tautan yang diawali http. MDN mendukung selektor atribut sehingga kamu bisa menulis a[href^="http"]::after di blok @media print.

Tautan mailto dan tel tetap perlu nilai terlihat. Cetak alamat surel atau nomor, bukan skema mentah yang membingungkan di kertas.

Minta AI memisahkan tiga kelompok tautan: internal, eksternal, dan kontak. Tempel HTML navigasi plus CSS print yang ada.

Panduan CSS-Tricks dan dokumentasi Clincoo sama-sama menekankan versi cetak yang bisa dipakai orang, bukan dump atribut mentah.
