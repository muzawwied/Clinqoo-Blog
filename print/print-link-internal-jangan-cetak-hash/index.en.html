Do Not Print Internal Hash Links on Clincoo Paper

Print full URLs only for external links. Hide #id and relative paths in print media.

This article is available in: Indonesia · English

A blanket a[href]::after { content: attr(href) } prints every anchor. Pricing pages fill with #paket and ./syarat text that nobody can type.

In editor.clincoo.buzz, limit printed URLs to links that start with http. MDN attribute selectors let you write a[href^="http"]::after inside @media print.

mailto and tel links still need a visible value. Print the email or number, not a raw scheme that confuses readers on paper.

Ask AI to split three link groups: internal, external, and contact. Paste the navigation HTML plus the current print CSS.

MDN print guidance and Clincoo docs both want a printable page people can use, not a raw attribute dump.
