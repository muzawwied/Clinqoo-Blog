Pakai Orientasi Landscape untuk Invoice Lebar Clincoo

Kolom banyak tidak muat di A4 portrait. Set @page size landscape hanya untuk template invoice.

Artikel ini tersedia dalam: Indonesia · English

Di editor.clincoo.buzz, invoice 8 kolom terpotong di tepi kanan kertas portrait.

Tambah @page invoice { size: A4 landscape; } dan kelas pada body template itu saja.

Jangan pakai landscape untuk artikel blog. Tempel aturan @page ke AI.

Pratinjau di app.clincoo.buzz. Catat kapan landscape wajib di blog.clincoo.buzz.
