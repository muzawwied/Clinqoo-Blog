Set A4 Paper Size and Margins with @page in Clincoo

Invoice pages that hug the viewport get clipped on home printers. Set size and margin in @page.

This article is available in: Indonesia · English

On editor.clincoo.buzz, viewport-wide content often loses space on a home printer.

Add @page { size: A4; margin: 16mm; } for print media only.

Send the @page snippet to AI instead of a full rewrite.

Preview A4 on app.clincoo.buzz and blog.clincoo.buzz.
