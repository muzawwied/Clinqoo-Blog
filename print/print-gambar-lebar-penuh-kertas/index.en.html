Cap Image Width so Photos Do Not Overflow Clincoo Print

Product photos that are max-width 100% on screen can still overflow paper. Reset images in print media.

This article is available in: Indonesia · English

On editor.clincoo.buzz, a 1200px hero image wrecks the printed page.

In @media print set img { max-width: 100%; height: auto; }.

Paste the img markup to AI. Test on app.clincoo.buzz and blog.clincoo.buzz.
