Stop a Clincoo Table Splitting Mid-Row on Print

page-break-inside: avoid on table rows keeps headers and figures in one paper block.

This article is available in: Indonesia · English

On editor.clincoo.buzz, invoice tables often split: header on page 1, figures on page 2.

In @media print set thead { display: table-header-group; } and tr { break-inside: avoid; }.

Send the table snippet to AI, not a full layout rewrite.

Test the PDF on app.clincoo.buzz and link the rule on blog.clincoo.buzz.
