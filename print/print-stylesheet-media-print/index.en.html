Keep Print Rules in a media=print Stylesheet

Mixing screen and paper rules breaks both. A print file or @media print block is safer.

This article is available in: Indonesia · English

A Clincoo page that only ships screen CSS often prints navbars, buttons, and dark backgrounds that waste ink. Print rules must live apart from monitor styles.

Add a print.css link with media=print or an @media print block. Hide nav, enlarge type, and reset background color.

Do not trust the screen preview. Open the browser print dialog and check headers, margins, and table splits. Chrome and Firefox can differ on page-break.

One print.css file is easier for an AI to review than a dozen scattered rules. Ask the model to edit only that file when you tidy print layout.

Clincoo serves raw CSS. media=print is the cheapest way to keep invoices and articles readable on paper.
