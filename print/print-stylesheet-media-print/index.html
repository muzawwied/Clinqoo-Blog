Pisahkan Aturan Cetak lewat Stylesheet media=print

Campur aturan layar dan kertas merusak keduanya. File atau blok @media print lebih aman.

Artikel ini tersedia dalam: Indonesia · English

Halaman Clincoo yang hanya memakai CSS layar sering mencetak navbar, tombol, dan latar gelap yang memakan tinta. Aturan cetak harus dipisah dari tampilan monitor.

Tambah link stylesheet media=print ke print.css atau blok @media print di berkas yang sama. Sembunyikan nav, perbesar teks, dan reset warna latar.

Jangan andalkan preview layar. Buka dialog cetak browser dan cek header, margin, serta potongan tabel. Chrome dan Firefox bisa berbeda pada page-break.

Satu file print.css lebih mudah ditinjau AI daripada selusin aturan tersebar. Minta AI hanya mengedit file itu saat merapikan cetak.

Clincoo menayangkan CSS mentah. media=print adalah cara termurah agar invoice dan artikel tetap terbaca di kertas.
