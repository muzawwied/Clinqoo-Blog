Beri Nama Cabang Git Clincoo yang Pendek dan Bisa Dicari

Cabang bernama fix atau baru membingungkan seminggu kemudian. Pakai pola singkat yang menyebut tugas Clincoo.

Artikel ini tersedia dalam: Indonesia · English

Nama cabang adalah indeks kerja. Saat kamu membuka daftar cabang di repo proyek Clincoo, nama yang jelas menolong memilih cabang yang masih hidup dan menghapus yang sudah digabung. fix-2 atau cobain tidak menjelaskan apa pun setelah istirahat seminggu.

Pakai pola pendek: jenis-tugas, lalu objek. Contoh: feat-form-kontak, fix-hero-lcp, chore-gitignore. Hindari spasi dan huruf besar. GitHub Docs menganjurkan nama yang aman di URL dan mudah diketik di terminal.

Jangan masukkan tanggal panjang atau seluruh kalimat judul artikel. Jika satu cabang menampung dua tugas, pecah dulu; nama yang dipaksakan biasanya tanda commit sudah tercampur. Satu cabang, satu tujuan, satu nama.

Sebelum push, baca ulang nama. Kalau kamu sendiri ragu arti slug-nya, ganti sekarang dengan git branch -m. Cabang yang bisa dicari membuat review, revert, dan tag rilis situs Clincoo jauh lebih tenang.
