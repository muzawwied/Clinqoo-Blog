Give Clincoo Git Branches Short, Searchable Names

Branches named fix or new confuse you a week later. Use a short pattern that names the Clincoo task.

This article is available in: Indonesia · English

A branch name is an index of work. When you open the branch list on a Clincoo project repo, a clear name helps you keep live branches and delete merged ones. Names like fix-2 or try-this explain nothing after a week away.

Use a short pattern: kind of work, then the object. Examples: feat-contact-form, fix-hero-lcp, chore-gitignore. Avoid spaces and uppercase letters. GitHub Docs recommend names that stay safe in URLs and easy to type in a terminal.

Do not pack a long date or a full article title into the branch. If one branch holds two tasks, split it first; a strained name usually means mixed commits. One branch, one goal, one name.

Before you push, reread the name. If you hesitate about what the slug means, rename it now with git branch -m. Searchable branches make review, revert, and release tags for a Clincoo site far calmer.
