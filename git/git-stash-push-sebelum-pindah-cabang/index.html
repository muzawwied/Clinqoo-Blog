Simpan Kerjaan dengan git stash push sebelum Pindah Cabang

Pindah cabang dengan perubahan belum commit sering menolak atau menimpa. Simpan dulu dengan stash push yang diberi pesan.

Artikel ini tersedia dalam: Indonesia · English

Di repo situs Clincoo, git switch sering gagal karena file CSS masih kotor. Jangan reset --hard hanya agar cabang pindah.

Jalankan git status dulu. Lalu git stash push -u -m pesan singkat agar file baru ikut tersimpan dan pesannya bisa dicari.

Setelah pindah cabang dan selesai, kembali lalu git stash pop. Jika konflik, selesaikan berkas itu saja, jangan pop dua kali.

Minta AI menjelaskan beda stash push dan commit. Tolak saran yang menghapus stash list tanpa memperlihatkan isinya.

Catat pesan stash di catatan rilis internal. Pratinjau editor.clincoo.buzz tidak menggantikan riwayat Git di app.clincoo.buzz.
