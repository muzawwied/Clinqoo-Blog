Save Work with git stash push before Switching Branches

Switching branches with uncommitted changes often refuses or overwrites. Save them first with a labeled stash push.

This article is available in: Indonesian · English

In a Clincoo site repo, git switch often fails because a CSS file is still dirty. Do not reset --hard just to change branches.

Run git status first. Then git stash push -u -m with a short message so new files are included and the message is searchable.

After switching and finishing, come back and git stash pop. If there is a conflict, fix that file only, and do not pop twice.

Ask AI to explain the difference between stash push and commit. Reject advice that deletes the stash list without showing its contents.

Record the stash message in an internal release note. The editor.clincoo.buzz preview does not replace Git history on app.clincoo.buzz.
