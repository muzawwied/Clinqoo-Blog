Cek git branch -vv Sebelum Push Situs Clincoo

Cabang tanpa upstream sering ter-push ke remote yang salah. Lihat tanda kurung pelacakan dulu.

Artikel ini tersedia dalam: Indonesia · English

Sebelum push dari editor lokal ke repo Clincoo, jalankan git branch -vv. Baris cabang aktif ditandai bintang.

Kurung siku di kanan menunjukkan remote dan commit hulu, misalnya origin/main. Kosong berarti belum ada upstream.

Jika kosong, pakai git push -u origin nama-cabang sekali. Jangan git push origin main dari cabang fitur.

Angka ahead/behind memberitahu apakah perlu pull dulu. Push saat behind sering ditolak, dan force push ke main merusak riwayat.

Catat URL remote dengan git remote -v. Pastikan origin mengarah ke repo yang benar, bukan fork lama, lalu baru buka app.clincoo.buzz.
