Baca git diff Sebelum Commit di Proyek Clincoo

git add . tanpa membaca diff menyelipkan debug dan file besar. Lihat perubahan dulu, baru stage.

Artikel ini tersedia dalam: Indonesia · English

Sebelum commit proyek yang akan naik ke app.clincoo.buzz, jalankan git diff. Baris hijau dan merah adalah isi yang akan masuk riwayat.

Jika diff terlalu panjang, git diff --stat menunjukkan file mana yang berubah. Buka hanya file yang tidak kamu sengaja.

Keluarkan console.log, berkas .env, dan gambar mentah dari stage dengan git restore --staged.

Minta AI menjelaskan diff yang membingungkan, lalu terapkan perbaikan sendiri. Jangan commit pesan AI mentah.

Clincoo tidak menyaring commit. Diff yang dibaca membuat riwayat blog.clincoo.buzz tetap bisa ditelusuri.
