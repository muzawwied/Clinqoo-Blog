Run git status Before Switching Branches

Switching branches with dirty files mixes a Clincoo draft into another feature. Check status first, then stash or commit.

This article is available in: Indonesia · English

Before checkout on a project you will upload to app.clincoo.buzz, type git status. Red files are work that is not committed yet.

If the work is unfinished, git stash push -m 'hero draft' or commit on the current branch. Do not switch while carrying a random diff.

After you switch, status should be clean except ignored files. Leftover files mean you carried changes across features.

If AI suggests checkout -f, refuse. That command drops edits from editor.clincoo.buzz without asking.

Clincoo on blog.clincoo.buzz follows the same rhythm: read status, save intent, then change context.
