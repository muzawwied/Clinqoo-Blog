Jalankan git status Sebelum Pindah Cabang

Pindah cabang dengan file kotor mencampur draf Clincoo ke fitur lain. Cek status dulu, simpan atau commit.

Artikel ini tersedia dalam: Indonesia · English

Sebelum checkout di proyek yang akan diunggah ke app.clincoo.buzz, ketik git status. File merah adalah pekerjaan yang belum masuk commit.

Jika pekerjaan belum selesai, git stash push -m 'draf hero' atau commit di cabang saat ini. Jangan pindah sambil membawa diff acak.

Setelah pindah, status harus bersih kecuali file yang memang di-ignore. Kalau masih ada sisa, Anda membawa perubahan lintas fitur.

Kalau AI menyarankan checkout -f, tolak. Perintah itu membuang suntingan di editor.clincoo.buzz tanpa konfirmasi.

Clincoo di blog.clincoo.buzz mengikuti ritme yang sama: lihat status, simpan niat, baru ganti konteks.
