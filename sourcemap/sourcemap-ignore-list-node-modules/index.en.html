Add node_modules to the DevTools Ignore List when Debugging Clincoo

A stack that walks into dependencies slows stepping. An ignore list keeps focus on project files.

This article is available in: Indonesia · English

Stepping through Clincoo stops in vendor bundles. One Next click opens dozens of files that are not yours.

In DevTools Sources, add node_modules and vendor folders to the Ignore list. Keep maps on for files you edit in editor.clincoo.buzz.

Do not ignore the whole project. Only dependency paths. Test one breakpoint in page script.

Ask AI to mark folders that may be ignored. Paste the dist tree, not the whole repo.

Clincoo does not configure DevTools. An ignore list makes stacks on app.clincoo.buzz stop in code you edit.
