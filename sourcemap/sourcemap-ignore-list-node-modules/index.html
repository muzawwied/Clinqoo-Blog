Masukkan node_modules ke Ignore List DevTools saat Debug Clincoo

Stack yang masuk ke dependensi membuat langkah debug lambat. Ignore list menjaga fokus pada berkas proyek.

Artikel ini tersedia dalam: Indonesia · English

Step-through Clincoo berhenti di bundel vendor. Satu klik Next membuka puluhan file yang bukan milikmu.

Di DevTools Sources, tambah node_modules dan folder vendor ke Ignore list. Map tetap hidup untuk berkas di editor.clincoo.buzz.

Jangan ignore seluruh project. Hanya path dependensi. Uji satu breakpoint di skrip halaman.

Minta AI menandai folder yang boleh di-ignore. Tempel struktur dist, bukan seluruh repo.

Clincoo tidak mengatur DevTools. Ignore list membuat stack di app.clincoo.buzz berhenti di kode yang kamu sunting.
