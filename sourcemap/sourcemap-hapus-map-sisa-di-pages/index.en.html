Delete Leftover .map Files on Pages after a Clincoo Release

An old map can still be downloaded even when the new bundle has no comment. Clean the deploy folder.

This article is available in: Indonesia · English

A Clincoo team turns sourcemaps off in a new build, but the old app.js.map still sits in the Pages folder. Anyone who guesses the URL gets it.

After deploy from editor.clincoo.buzz, list files on the host. Delete *.map files you did not mean to publish.

Do not trust CDN cache to hide a file. A direct request to the old path still returns 200 if the file exists.

Ask AI for a dist cleanup checklist. Paste the host file list, not tokens.

Clincoo serves whatever is in the folder. A leftover map on app.clincoo.buzz is a leak of old sources.
