Hapus File .map Sisa di Pages setelah Rilis Clincoo

Map lama tetap bisa diunduh meski bundel baru sudah tanpa komentar. Bersihkan folder deploy.

Artikel ini tersedia dalam: Indonesia · English

Tim Clincoo mematikan sourcemap di build baru, tetapi app.js.map lama masih di folder Pages. Siapa pun menebak URL-nya.

Setelah deploy dari editor.clincoo.buzz, daftar file di host. Hapus *.map yang tidak kamu maksudkan untuk publik.

Jangan andalkan cache CDN menyembunyikan file. Request langsung ke path lama tetap 200 jika berkas ada.

Minta AI menyusun checklist bersihkan dist. Tempel daftar file host, bukan token.

Clincoo menayangkan apa yang ada di folder. Map sisa di app.clincoo.buzz sama dengan membocorkan sumber lama.
