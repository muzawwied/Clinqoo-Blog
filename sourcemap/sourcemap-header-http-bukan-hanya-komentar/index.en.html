Pick a SourceMap Header or a Comment, Not Both in Clincoo Production

A header and a comment together make the browser request the .map twice. One channel is enough.

This article is available in: Indonesia · English

Clincoo hosting sends a SourceMap header while the bundle still has //# sourceMappingURL. Network fills with map requests.

Pick one: a file comment for local debug, or a header to a private host. On a public app.clincoo.buzz release, turn both off.

Check the response in the editor.clincoo.buzz Network tab. Drop the header if the comment is enough, or the other way around.

Ask AI to review host config plus the last bundle line. Paste response headers only.

Clincoo serves the files and headers you set. One map channel keeps production closed.
