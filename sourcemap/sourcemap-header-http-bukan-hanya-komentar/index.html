Pilih Header SourceMap atau Komentar, Jangan Keduanya di Produksi Clincoo

Header dan komentar sekaligus membuat browser meminta .map dua kali. Satu saluran cukup.

Artikel ini tersedia dalam: Indonesia · English

Hosting Clincoo mengirim header SourceMap sementara bundel masih punya //# sourceMappingURL. Network penuh request map.

Pilih satu: komentar di file untuk debug lokal, atau header ke host privat. Di rilis publik app.clincoo.buzz, matikan keduanya.

Cek respons di tab Network editor.clincoo.buzz. Hapus header jika komentar sudah cukup, atau sebaliknya.

Minta AI meninjau config host plus baris akhir bundel. Tempel header respons saja.

Clincoo menayangkan file dan header yang kamu set. Satu saluran map menjaga produksi tetap tertutup.
