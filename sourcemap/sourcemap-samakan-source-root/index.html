Samakan sourceRoot Source Map Clincoo dengan Folder Editor

Root yang salah membuat klik stack membuka file kosong. Path harus relatif ke repo yang kamu sunting.

Artikel ini tersedia dalam: Indonesia · English

Map Clincoo menunjuk ../src sementara berkas di editor ada di /app. DevTools membuka tab kosong.

Set sourceRoot atau sources agar path relatif dari folder yang terbuka di editor.clincoo.buzz. Hindari path absolut mesin.

Setelah build, buka .map dan baca array sources. Satu uji klik stack harus membuka baris yang sama.

Minta AI merapikan sourceRoot saja. Tempel cuplikan sources dari file map.

Clincoo tidak memperbaiki path map. Root yang jujur membuat debug di app.clincoo.buzz cocok dengan editor.
