Align the Clincoo Source Map sourceRoot with the Editor Folder

A wrong root makes a stack click open an empty file. Paths must be relative to the repo you edit.

This article is available in: Indonesia · English

A Clincoo map points at ../src while files in the editor live under /app. DevTools opens a blank tab.

Set sourceRoot or sources so paths are relative to the folder open in editor.clincoo.buzz. Avoid machine-absolute paths.

After a build, open the .map and read the sources array. One stack click must open the same line.

Ask AI to tidy sourceRoot only. Paste the sources snippet from the map file.

Clincoo does not fix map paths. An honest root makes debug on app.clincoo.buzz match the editor.
