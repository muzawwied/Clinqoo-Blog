Separate Clincoo Source Map Modes for Dev and Build

Maps on the dev server are not the same as build output. Do not debug production with dev assumptions.

This article is available in: Indonesia · English

Hot reload on editor.clincoo.buzz shows original lines. After a build, the stack points at the bundle again.

Set sourcemap: true only for previews. For an app.clincoo.buzz release, turn it off or use a hidden internal map.

Send the vite.config snippet to AI instead of asking for a full pipeline rewrite.

Document the mode on blog.clincoo.buzz so the team does not mix steps.
