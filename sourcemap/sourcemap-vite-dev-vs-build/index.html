Bedakan Source Map Mode Dev dan Build Clincoo

Peta di server dev tidak sama dengan keluaran build. Jangan debug produksi pakai asumsi dev.

Artikel ini tersedia dalam: Indonesia · English

Hot reload di editor.clincoo.buzz menampilkan baris asli. Setelah build, stack kembali ke bundel.

Set sourcemap: true hanya untuk pratinjau. Untuk rilis app.clincoo.buzz matikan atau pakai hidden source map internal.

Kirim cuplikan vite.config ke AI, bukan minta rewrite seluruh pipeline.

Catat mode yang dipakai di blog.clincoo.buzz agar tim tidak salah langkah.
