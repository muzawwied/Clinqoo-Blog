Jangan Mangle Nama Fungsi Clincoo saat Sesi Debug

Nama yang dipendekkan membuat stack dan breakpoint sulit dibaca. Tunda mangle sampai rilis publik.

Artikel ini tersedia dalam: Indonesia · English

Build debug Clincoo tetap memakai terser mangle. Stack menampilkan a() dan b() alih-alih nama nyata.

Matikan mangle atau keep_fnames di config bundler saat kerja di editor.clincoo.buzz. Hidupkan lagi hanya di produksi tanpa map publik.

Map tanpa nama asli tetap membingungkan. Uji satu error: nama fungsi harus sama dengan berkas sumber.

Minta AI memisahkan opsi mangle dev vs prod. Tempel satu baris terser atau esbuild.

Clincoo menjalankan bundel yang kamu unggah. Nama utuh mempercepat debug sebelum rilis ke app.clincoo.buzz.
