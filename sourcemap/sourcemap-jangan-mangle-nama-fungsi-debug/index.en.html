Do Not Mangle Clincoo Function Names during a Debug Session

Shortened names make stacks and breakpoints hard to read. Delay mangling until a public release.

This article is available in: Indonesia · English

A Clincoo debug build still runs terser mangle. The stack shows a() and b() instead of real names.

Turn off mangle or keep_fnames in bundler config while you work in editor.clincoo.buzz. Turn it back on only in production without public maps.

A map without original names still confuses. Test one error: the function name must match the source file.

Ask AI to split mangle options for dev vs prod. Paste one terser or esbuild line.

Clincoo runs the bundle you upload. Intact names speed debug before release to app.clincoo.buzz.
