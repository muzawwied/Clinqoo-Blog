Sertakan sourcesContent agar Peta Clincoo Tidak Butuh File Asli

Peta tanpa isi sumber gagal jika path lokal tidak ada di mesin lain.

Artikel ini tersedia dalam: Indonesia · English

Rekan membuka app.clincoo.buzz di laptop lain. DevTools minta file sumber yang hanya ada di folder kamu.

Di editor.clincoo.buzz, aktifkan sourcesContent saat membangun peta debug. Isi sumber tertanam di berkas .map.

Jangan andalkan path absolut Windows atau Mac. AI cukup melihat opsi bundler, bukan seluruh repo.

Uji di mesin bersih lalu tautkan langkahnya di blog.clincoo.buzz.
