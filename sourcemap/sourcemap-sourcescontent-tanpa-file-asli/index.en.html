Include sourcesContent so Clincoo Maps Do Not Need Original Files

A map without embedded sources fails when another machine lacks the local paths.

This article is available in: Indonesia · English

A teammate opens app.clincoo.buzz on another laptop. DevTools asks for source files that only exist in your folder.

In editor.clincoo.buzz, enable sourcesContent when building a debug map. Source text is embedded in the .map file.

Do not rely on Windows or Mac absolute paths. AI only needs the bundler option, not the whole repo.

Test on a clean machine and link the steps on blog.clincoo.buzz.
