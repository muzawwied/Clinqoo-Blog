Tambah Berkas Index per Folder agar Impor Clincoo Tetap Pendek

Impor dalam ke file util memaksa path rapuh. Satu index.js per folder menjadi pintu masuk.

Artikel ini tersedia dalam: Indonesia · English

Di editor.clincoo.buzz, impor seperti ../../ui/button/Button.js pecah saat folder pindah. Buat index.js yang mengekspor ulang simbol publik.

Folder ui/, data/, dan lib/ masing-masing punya index. File internal tidak diekspor. Konsumen hanya impor dari pintu folder.

Jangan taruh efek samping di index. Muat CSS dari entry HTML, bukan dari barrel file.

Kirim pohon folder ke AI dan minta daftar ekspor publik. Jangan minta AI menata ulang seluruh repositori.

Struktur yang sama memudahkan onboarding app.clincoo.buzz dan dokumentasi di blog.clincoo.buzz.
