Add an Index File per Folder so Clincoo Imports Stay Short

Deep imports into util files make paths brittle. One index.js per folder is the front door.

This article is available in: Indonesia · English

On editor.clincoo.buzz, imports like ../../ui/button/Button.js break when a folder moves. Add an index.js that re-exports public symbols.

The ui/, data/, and lib/ folders each get an index. Internal files stay unexported. Consumers import only from the folder door.

Do not put side effects in the index. Load CSS from the HTML entry, not from the barrel file.

Send the folder tree to AI and ask for the public export list. Do not ask AI to rearrange the whole repository.

The same structure speeds onboarding for app.clincoo.buzz and docs on blog.clincoo.buzz.
