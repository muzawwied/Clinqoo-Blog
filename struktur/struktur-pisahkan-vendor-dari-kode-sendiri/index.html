Pisahkan Berkas Vendor dari Kode Sendiri di Proyek Clincoo

Mencampur pustaka pihak ketiga dengan skrip halaman membuat diff berisik. Folder vendor mempersempit review.

Artikel ini tersedia dalam: Indonesia · English

Di editor.clincoo.buzz, taruh pustaka yang tidak Anda tulis di folder vendor/. Kode halaman tetap di js/.

Jangan menyunting berkas vendor untuk perbaikan kecil. Bungkus perilakunya di modul sendiri agar upgrade aman.

Nama folder harus stabil: vendor, css, js, images. AI dan rekan tim bisa menunjuk path tanpa tebakan.

Saat commit, pisahkan perubahan vendor dari perubahan fitur. Review di blog.clincoo.buzz dan app jadi lebih cepat.

Jika stuck, kirim pohon folder ke AI dan minta file yang boleh diubah, bukan rewrite seluruh proyek.
