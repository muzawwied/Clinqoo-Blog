Separate Vendor Files from Your Own Code in a Clincoo Project

Mixing third-party libraries with page scripts makes diffs noisy. A vendor folder narrows the review.

This article is available in: Indonesia · English

On editor.clincoo.buzz put libraries you did not write in vendor/. Page code stays in js/.

Do not edit a vendor file for a small fix. Wrap the behavior in your own module so upgrades stay safe.

Keep folder names stable: vendor, css, js, images. AI and teammates can point at a path without guessing.

On commit, separate vendor changes from feature changes. Review for blog.clincoo.buzz and the app gets faster.

When stuck, send the folder tree to AI and ask which file may change, not for a full project rewrite.
