Pisahkan HTML, CSS, dan JS di Folder Proyek Clincoo

Satu berkas raksasa sulit di-debug. Pisahkan markup, gaya, dan skrip sejak awal.

Artikel ini tersedia dalam: Indonesia · English

Di editor.clincoo.buzz, mulai dari index.html tipis yang hanya memuat CSS dan JS. Jangan sisipkan ratusan baris style di head.

Taruh gaya di assets/ dan skrip di js/. Nama folder harus prediktabel agar AI bisa menunjuk path yang benar.

Jika Anda stuck, kirim pohon folder ke AI, bukan isi semua file. Minta AI menunjukkan file mana yang harus diubah.

Hindari circular import. Satu modul UI tidak boleh memuat modul data yang memuat UI lagi.

Struktur yang sama dipakai di app.clincoo.buzz dan dokumentasi blog.clincoo.buzz agar onboarding cepat.
