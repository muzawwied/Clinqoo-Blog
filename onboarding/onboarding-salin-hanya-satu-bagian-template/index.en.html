Copy One Clincoo Template Section, Not the Whole Folder

Overwriting a project with a template zip deletes the home page you already wrote.

This article is available in: Indonesian · English

Many people download a template and paste every file into the workspace. Their index.html vanishes with no warning.

In editor.clincoo.buzz, copy only the header, card, or form you need. Keep the old file as a short backup.

Preview after each section. If the layout breaks, restore one file, not the whole tree.

Ask AI to adapt one template snippet to the markup you already have. Paste both pieces.

Clincoo ships the files you save. Narrow copies keep app.clincoo.buzz yours.
