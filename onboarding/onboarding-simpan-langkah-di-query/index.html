Simpan Langkah Onboarding Clincoo di Query URL

Langkah yang hanya ada di memori hilang saat muat ulang. Simpan nomor langkah di query agar bisa dibagikan.

Artikel ini tersedia dalam: Indonesia · English

Wizard di app.clincoo.buzz yang menyimpan langkah di variabel hilang saat pengguna memuat ulang setelah tutorial AI.

Pakai query step=2 dan history.replaceState, bukan pushState tiap klik. Muat ulang harus membuka langkah yang sama.

Tolak nomor di luar rentang. Jangan taruh data rahasia di query. Nama langkah pendek lebih aman daripada objek JSON.

Tombol kembali peramban harus mundur satu langkah. Jika Anda memakai replaceState, sediakan tombol kembali di UI.

Minta AI mengubah satu wizard, lalu uji salin URL ke tab baru di editor.clincoo.buzz. Tulis pola di blog.clincoo.buzz.
