Store the Clincoo Onboarding Step in the URL Query

A step kept only in memory disappears on reload. Store the step number in the query so it can be shared.

This article is available in: Indonesia · English

A wizard on app.clincoo.buzz that stores the step in a variable loses it when the user reloads after an AI tutorial.

Use a step=2 query and history.replaceState, not pushState on every click. A reload must open the same step.

Reject numbers outside the range. Do not put secrets in the query. A short step name is safer than a JSON object.

The browser back button should move one step. If you use replaceState, provide a back button in the UI.

Ask AI to change one wizard, then test pasting the URL into a new tab on editor.clincoo.buzz. Write the pattern on blog.clincoo.buzz.
