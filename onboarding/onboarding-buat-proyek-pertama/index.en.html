Create Your First Clincoo Project before You Tinker with a Template

Many people edit someone else's template without their own project, then cannot tell which files are safe to change.

This article is available in: Indonesian · English

A beginner opens editor.clincoo.buzz and pastes AI chat code into a random file. There is no clear project root.

Create an empty project first. Make sure you have index.html, an assets folder, and one home page. Save a project name you recognize.

Only then copy template fragments. Do not overwrite the whole folder tree before preview works.

Ask AI to design a minimal folder structure for a one-page site. Paste the file list you already have.

Clincoo on app.clincoo.buzz is easier to follow when the first project is tidy from the start.
