Record Clincoo Webhook Receive Time, Not Finish Time

A finish-time clock scrambles event order. Store the timestamp when the body arrives, before the queue.

This article is available in: Indonesia · English

A handler on editor.clincoo.buzz sometimes writes the time after an image download or email send. An earlier event looks later.

Store receivedAt from the server clock when the first bytes are read. Do not use the sender clock as the only source.

Compare receivedAt with the replay window. Slow work must not reject a valid event because its stamp looks expired.

Ask AI whether the log uses Date.now() after an await. Ask for a small diff, not a queue rewrite.

Write the clock convention on blog.clincoo.buzz so the app.clincoo.buzz preview orders events like production logs.
