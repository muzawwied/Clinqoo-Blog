Tolak Webhook Clincoo yang Bukan JSON

Body teks biasa atau form-urlencoded merusak parser. Cek Content-Type sebelum JSON.parse.

Artikel ini tersedia dalam: Indonesia · English

Banyak handler Clincoo langsung memanggil JSON.parse pada request.body. Pengirim yang salah header atau bot yang mengirim HTML membuat parse gagal dan event hilang tanpa status yang jelas.

Baca header Content-Type di awal handler. Terima hanya application/json atau application/json dengan charset. Balas 415 jika jenisnya lain, lalu berhenti.

Setelah jenis benar, batasi ukuran teks sebelum parse. Tangkap SyntaxError dan balas 400 beserta event id jika ada.

Minta AI menambah pemeriksaan header saja. Tempel cuplikan handler webhook, jangan minta generate ulang seluruh situs.

Pratinjau di editor.clincoo.buzz dengan dua permintaan: JSON valid dan teks biasa. Pastikan yang kedua tidak menulis data.
