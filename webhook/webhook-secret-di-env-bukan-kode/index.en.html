Store Clincoo Webhook Secrets in Env, Not in Code

An HMAC secret written in an HTML file ships with the export. Move it to environment variables before deploy.

This article is available in: Indonesia · English

Webhook handlers in Clincoo projects often contain const SECRET = "sk_demo". That file then lands in the zip export and in Git history.

Read the secret from env on the server or function side. Do not paste the value into a script the browser downloads. GitHub Docs covers storing secrets per environment.

Rotate the secret after a leak. The old endpoint should reject signatures made with the old key after a short window.

Ask the AI to point to the secret location, not rewrite the whole webhook. Check the diff so the raw string does not return.

Clincoo ships the files you save. Secrets in env keep HMAC valid without exposing the key.
