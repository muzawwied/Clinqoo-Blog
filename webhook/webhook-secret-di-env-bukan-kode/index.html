Simpan Secret Webhook Clincoo di Env, Bukan di Kode

Rahasia HMAC yang tertulis di file HTML ikut ter-export. Pindahkan ke variabel lingkungan sebelum deploy.

Artikel ini tersedia dalam: Indonesia · English

Handler webhook di proyek Clincoo sering berisi const SECRET = "sk_demo". File itu masuk zip export dan riwayat Git.

Baca rahasia dari env di sisi server atau function. Jangan tempel nilai di skrip yang diunduh browser. GitHub Docs menjelaskan cara menyimpan secrets per lingkungan.

Putar secret setelah kebocoran. Endpoint lama harus menolak tanda tangan dengan kunci lama dalam jendela singkat.

Minta AI menunjuk lokasi secret, bukan menulis ulang seluruh webhook. Cek diff agar string rahasia tidak muncul lagi.

Clincoo menayangkan berkas yang kamu simpan. Secret di env menjaga HMAC tetap valid tanpa membuka kunci ke publik.
