Separate Clincoo Webhook Endpoints per Provider

One URL for every sender mixes secrets, schemas, and retries. Give each provider its own path.

This article is available in: Indonesia · English

Payment callbacks and form callbacks often land in the same function on a Clincoo project. One schema bug takes both down.

Create paths such as /hook/payment and /hook/form. Store each secret in env, not in the HTML file.

Log the provider name on the first line. When retries pile up, you know which queue is stuck without opening the body.

Ask AI for a table of path, secret, and schema. Do not ask AI to merge every check into one giant if.

Document the URLs on blog.clincoo.buzz so the team does not paste an old endpoint into app.clincoo.buzz.
