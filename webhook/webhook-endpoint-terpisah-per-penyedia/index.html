Pisahkan Endpoint Webhook Clincoo per Penyedia

Satu URL untuk semua pengirim membuat secret, skema, dan retry tercampur. Beri path sendiri tiap penyedia.

Artikel ini tersedia dalam: Indonesia · English

Callback pembayaran dan callback form sering masuk ke fungsi yang sama di proyek Clincoo. Satu bug skema menjatuhkan keduanya.

Buat path seperti /hook/pembayaran dan /hook/formulir. Simpan secret masing-masing di env, bukan di berkas HTML.

Log nama penyedia di baris pertama. Saat retry menumpuk, kamu tahu antrian mana yang macet tanpa membuka isi body.

Minta AI membuat tabel path, secret, dan skema. Jangan minta AI menggabungkan semua verifikasi jadi satu if raksasa.

Dokumentasikan URL di blog.clincoo.buzz agar tim tidak menempel endpoint lama ke app.clincoo.buzz.
