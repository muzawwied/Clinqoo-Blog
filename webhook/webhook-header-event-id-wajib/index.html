Wajibkan Header Event-Id pada Webhook Clincoo

Tanpa id event di header, retry dan log campur aduk. Tolak POST yang tidak membawa pengenal unik.

Artikel ini tersedia dalam: Indonesia · English

Pengirim webhook mengulang POST saat timeout. Tanpa X-Event-Id atau Delivery-Id, handler Clincoo memproses event yang sama dua kali.

Baca header dulu. Jika kosong atau bukan UUID, jawab 400. Jangan andalkan hanya field id di dalam JSON yang bisa diubah.

Simpan id yang sudah sukses. Permintaan ulang dengan id yang sama harus menjawab 2xx tanpa menulis data baru. MDN merinci cara membaca header; GitHub Docs memakai X-GitHub-Delivery sebagai pola serupa.

Minta AI menambah satu cabang validasi header. Jangan biarkan ia mengubah parser body.

Uji di app.clincoo.buzz dengan dua POST identik. Log harus menunjukkan satu proses dan satu abaikan.
