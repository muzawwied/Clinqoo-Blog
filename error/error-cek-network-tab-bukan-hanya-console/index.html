Cek Tab Network, Bukan Hanya Konsol, saat Error Clincoo

Banyak error fetch tidak muncul sebagai Exception. Buka tab Network di DevTools untuk melihat status, header, dan isi respons.

Artikel ini tersedia dalam: Indonesia · English

Skrip Clincoo yang memanggil API sering “diam” di konsol. fetch tidak melempar pada 404 atau 500, jadi kamu hanya melihat data kosong atau JSON.parse gagal.

Buka pratinjau, tekan F12, pilih Network, lalu ulangi aksi. Filter XHR atau Fetch. Klik baris merah dan baca status, Content-Type, serta Preview.

Jika status 200 tetapi isi HTML, endpoint salah atau redirect ke halaman login. Jika status 0, biasanya CORS, mixed content, atau jaringan terputus — bukan bug CSS.

Minta AI menambahkan log response.status dan cuplikan text() sebelum parse. Tempel fungsi fetch yang sekarang langsung JSON.parse(response).

Clincoo menjalankan kode yang kamu simpan. Tab Network mempersempit tebakan sebelum kamu mengubah file di editor.clincoo.buzz.
