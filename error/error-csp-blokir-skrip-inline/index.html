Baca Content-Security-Policy Saat Skrip Inline Clincoo Diblokir

Pesan 'Refused to execute inline script' bukan bug klik. Lihat header CSP di tab Network.

Artikel ini tersedia dalam: Indonesia · English

Pratinjau di editor.clincoo.buzz kadang diam tanpa stack di Console. Buka Console dan cari baris Refused to execute inline script karena Content Security Policy.

Pindah ke Network, pilih dokumen HTML, lalu header Content-Security-Policy. Catat script-src: apakah ada 'unsafe-inline' atau nonce.

Skrip di atribut onclick dan blok script tanpa nonce ditolak. Pindahkan logika ke file .js eksternal yang diizinkan host yang sama.

Jika harus inline, minta nonce dari server dan samakan dengan header. Jangan menambahkan 'unsafe-inline' hanya agar demo jalan.

Ulangi di app.clincoo.buzz dengan cache mati. Tempel pesan CSP utuh ke AI, bukan hanya 'tombol tidak jalan'.
