Tangani querySelector Null sebelum Menyentuh Properti di Clincoo

querySelector mengembalikan null jika selektor salah atau skrip jalan terlalu awal. Cek hasilnya sebelum classList atau textContent.

Artikel ini tersedia dalam: Indonesia · English

Pesan Uncaught TypeError: Cannot read properties of null di pratinjau Clincoo hampir selalu berasal dari document.querySelector(...).classList saat elemen belum ada. Selektor salah satu huruf, id berubah, atau skrip di tanpa defer.

MDN menyatakan querySelector mengembalikan elemen atau null — bukan error. Tanggung jawabmu adalah cabang: const el = document.querySelector('#cta'); if (!el) return; lalu baru sentuh properti. Optional chaining el?.classList.add('siap') mencegah tab meresah, tetapi tetap log alasan di konsol agar bug selektor tidak sembunyi.

Urutan perbaikan: buka konsol, salin selektor, tempel di Elements dengan Ctrl+F. Jika tidak ketemu, perbaiki string. Jika ketemu, pindahkan skrip ke akhir body atau pasang listener DOMContentLoaded.

Jangan bungkus seluruh berkas dalam try/catch kosong. Itu menyembunyikan error lain. Tangani null di titik query, biarkan error sungguhan tetap merah.

Setelah perbaikan, refresh keras pratinjau. Jika TypeError hilang tetapi tombol tidak berubah, masalahnya sudah pindah ke CSS atau listener — itu kemajuan, bukan regresi.
