How to Keep One dialog Open at a Time

Two dialog.showModal calls in a row stack top layers. The lower one cannot be clicked, and Escape may only close the top one. In editor.clincoo.buzz keep a single modal dialog open at a time.

Close first, then open

Before the next showModal, call close on the dialog that is open. If the flow is confirm then a form, swap the contents of the same dialog instead of creating a second dialog element you never close.

Do not rely on a stack for step two

The first dialog return value can open step two after close. Read that value on the close event, then open the other dialog. Test on app.clincoo.buzz: one Escape should return focus to the trigger, not to a leftover dialog.

Note a double dimmed backdrop

A backdrop that is twice as dark usually means two modals. Note the double trigger on blog.clincoo.buzz before adding a z-index.
