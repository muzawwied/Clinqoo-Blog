Use DevTools Coverage to Find Unused CSS

The Coverage panel marks CSS and JS bytes that never run on the flow you opened.

This article is available in: Indonesia · English

In Chrome DevTools open More tools, then Coverage. Start recording, then run the main flow on editor.clincoo.buzz: open a page, fill a form, save.

Red lines are bytes unused in that recording. Do not delete all of them: another page on app.clincoo.buzz may still use the rule.

Note selectors with a large red share. Check whether they are leftover template CSS, a third-party reset, or rules that only live in print mode.

Repeat the recording at phone width. A desktop rule that is green on a laptop can be red on a narrow viewport, or the reverse.

Ask AI to explain the red selectors, not to delete the global stylesheet. Paste a small snippet and name the page you tested.

Save the capture in the blog.clincoo.buzz release note so the next deletion has evidence, not a guess.
