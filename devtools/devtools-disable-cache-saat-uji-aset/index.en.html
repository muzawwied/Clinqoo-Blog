Disable DevTools Cache while Testing Clincoo Assets

Old CSS or images in cache mimic bugs you already fixed. Disable cache while DevTools is open.

This article is available in: Indonesia · English

You already changed style.css in the Clincoo editor, but the preview still uses the old margin. Often the browser serves a cached copy, not the file you just saved.

Open DevTools, Network tab, check Disable cache. Leave the panel open while you refresh. Without that, many browsers keep using cache even after F5.

Watch the Size column: “disk cache” or “memory cache” means the file was not downloaded again. A network 200 confirms the path is correct and the new bytes arrived.

Do not treat a random query string on every asset as a permanent fix. Cache-busting helps in production; while debugging, Disable cache is more honest.

Once the fix is visible, close DevTools so ordinary visitors still get a healthy cache. Test production separately from a debug session.
