Matikan Cache DevTools saat Menguji Aset Clincoo

CSS atau gambar lama di cache meniru bug yang sudah kamu perbaiki. Disable cache saat DevTools terbuka.

Artikel ini tersedia dalam: Indonesia · English

Kamu sudah mengganti style.css di editor Clincoo, tetapi pratinjau masih memakai margin lama. Sering kali browser menyajikan salinan cache, bukan file yang baru disimpan.

Buka DevTools, tab Network, centang Disable cache. Biarkan panel terbuka saat me-refresh. Tanpa itu, banyak browser tetap memakai cache meskipun kamu menekan F5.

Lihat kolom Size: “disk cache” atau “memory cache” berarti file tidak diunduh ulang. Status 200 dari jaringan memastikan path benar dan isi baru sampai.

Jangan andalkan query string acak di setiap aset sebagai solusi tetap. Cache-busting berguna di produksi; saat debug, Disable cache lebih jujur.

Setelah yakin perbaikan tampil, tutup DevTools agar pengunjung biasa tetap mendapat cache yang sehat. Uji produksi terpisah dari sesi debug.
