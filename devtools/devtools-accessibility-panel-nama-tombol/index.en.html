Check Clincoo Button Names in the DevTools Accessibility Panel

Icon-only controls look tidy, but screen readers need a name. The DevTools Accessibility panel shows name, role, and focus.

This article is available in: Indonesia · English

A hamburger or close icon in a Clincoo header often contains only an SVG. Visually that is enough. For the accessibility API, a button without a computed name is empty — and that fails Lighthouse plus WCAG Name, Role, Value.

Open DevTools, select the button, then the Accessibility panel (or the Accessibility pane in Chrome Elements). Under Computed Properties the Name should be a phrase such as “Open menu”, Role should be button, and Focusable should be true if Tab can reach it.

If Name is blank, add visible text, aria-label, or aria-labelledby pointing at an existing id. Do not rely on title alone; many screen readers skip it on controls.

Repeat for social icon links and form submit buttons. One inspection pass on a Clincoo preview usually finds two or three pretty but silent controls.

After names are filled, run the Lighthouse Accessibility category again. The score rises only when the name is exposed to the accessibility tree, not merely styled in CSS.
