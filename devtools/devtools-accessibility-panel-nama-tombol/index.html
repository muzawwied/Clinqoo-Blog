Cek Nama Tombol Clincoo di Panel Accessibility DevTools

Ikon tanpa teks terlihat rapi, tapi pembaca layar butuh nama. Panel Accessibility DevTools menampilkan name, role, dan fokus.

Artikel ini tersedia dalam: Indonesia · English

Tombol hamburger atau ikon tutup di header proyek Clincoo sering hanya berisi SVG. Secara visual itu cukup. Bagi API aksesibilitas, tombol tanpa nama yang dihitung dianggap kosong — dan itu gagal audit Lighthouse serta WCAG Name, Role, Value.

Buka DevTools, pilih tombol, lalu panel Accessibility (atau tab Accessibility di panel Elements pada Chrome). Lihat Computed Properties: Name harus berisi frasa seperti “Buka menu”, Role harus button, dan Focusable bernilai ya jika tombol bisa di-Tab.

Jika Name kosong, tambahkan teks terlihat, aria-label, atau aria-labelledby yang menunjuk ke id yang sudah ada. Jangan andalkan atribut title saja; banyak pembaca layar mengabaikannya pada kontrol.

Ulangi untuk tautan ikon media sosial dan tombol kirim form. Satu sesi inspeksi di pratinjau Clincoo biasanya menemukan dua atau tiga kontrol yang “cantik” tetapi bisu.

Setelah nama terisi, jalankan Lighthouse kategori Accessibility sekali lagi. Skor naik hanya jika name benar-benar terekspos ke pohon aksesibilitas, bukan hanya terlihat di CSS.
