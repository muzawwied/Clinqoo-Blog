Redirect HTTP to HTTPS Once, without a Chain on Clincoo

Visitors who type http:// should land on https:// with a single 301, not two hops.

This article is available in: Indonesia · English

On editor.clincoo.buzz, an HTTPS page can still open over http:// if the host never redirects.

Set one 301 from http to https on the same host. Do not chain http://www to http://apex then to https.

Test in a private tab: type http://app.clincoo.buzz and confirm the lock appears without a warning.

Paste the Location header to AI if a chain shows up. Record the result on blog.clincoo.buzz.
