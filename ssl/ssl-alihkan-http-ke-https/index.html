Alihkan HTTP ke HTTPS sekali, tanpa Rantai di Clincoo

Pengunjung yang mengetik http:// harus mendarat di https:// dengan satu pengalihan 301, bukan dua lompatan.

Artikel ini tersedia dalam: Indonesia · English

Di editor.clincoo.buzz, halaman yang sudah HTTPS masih bisa dibuka lewat http:// jika host tidak mengalihkan.

Set satu aturan 301 dari http ke https pada host yang sama. Jangan rantai http://www ke http://apex lalu ke https.

Uji di tab penyamaran: ketik http://app.clincoo.buzz dan pastikan gembok muncul tanpa peringatan.

Tempel header Location ke AI jika rantai terdeteksi. Catat hasil di blog.clincoo.buzz.
