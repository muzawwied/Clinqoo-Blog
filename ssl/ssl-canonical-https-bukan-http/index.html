Paksa Canonical, Sitemap, dan OG ke HTTPS Clincoo

Halaman sudah HTTPS, tapi canonical masih http://. Mesin telusur mengindeks salinan lemah.

Artikel ini tersedia dalam: Indonesia · English

Cek index.html hasil generate di blog.clincoo.buzz. link rel=canonical dan og:url harus https://blog.clincoo.buzz/...

Sitemap.xml yang masih http memecah sinyal SEO. Redirect 301 tidak memperbaiki canonical yang salah di HTML.

Ganti helper URL di generator. Jangan hardcode http di template artikel.

Tempel head halaman plus baris sitemap ke AI. Minta diff tiga file, bukan rewrite seluruh repo.

Clincoo di app.clincoo.buzz dan editor.clincoo.buzz memakai pola yang sama: satu skema, satu host.
