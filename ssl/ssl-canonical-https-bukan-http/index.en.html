Force Canonical, Sitemap, and OG to HTTPS on Clincoo

The page is already HTTPS, but canonical still says http://. Search indexes the weak copy.

This article is available in: Indonesia · English

Check generated index.html on blog.clincoo.buzz. rel=canonical and og:url must be https://blog.clincoo.buzz/...

A sitemap that still lists http splits SEO signals. A 301 does not fix a wrong canonical in HTML.

Change the URL helper in the generator. Do not hardcode http in article templates.

Paste the page head plus the sitemap line to AI. Ask for a three-file diff, not a full repo rewrite.

Clincoo on app.clincoo.buzz and editor.clincoo.buzz uses the same rule: one scheme, one host.
