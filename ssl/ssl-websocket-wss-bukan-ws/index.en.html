Use wss:// not ws:// on a HTTPS Clincoo Page

WebSockets do not auto-upgrade. ws:// on an https:// page is blocked like mixed content.

This article is available in: Indonesia · English

An HTTPS preview on editor.clincoo.buzz fails to connect live preview if the script still uses ws://.

Change the socket URL to wss:// or build it from location.protocol. Do not hardcode ws in production.

Check the Network tab WS filter: status 101, not blocked. Screenshot the error for AI.

Retest on app.clincoo.buzz and link the steps on blog.clincoo.buzz.
