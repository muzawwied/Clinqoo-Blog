Cek Rantai Sertifikat SSL Clincoo sampai Root

Gembok hijau tidak cukup jika intermediate hilang. Perangkat lama gagal membuka editor.clincoo.buzz.

Artikel ini tersedia dalam: Indonesia · English

Setelah deploy ke app.clincoo.buzz, buka halaman di perangkat lain. Jika hanya Chrome desktop yang lolos, rantai intermediate mungkin tidak terkirim.

Pakai DevTools Security atau tes eksternal. Pastikan leaf, intermediate, dan root berurutan. Jangan unggah hanya file .crt leaf.

Hosting Pages sering butuh fullchain.pem, bukan cert.pem saja. Campur urutan membuat error NET::ERR_CERT_AUTHORITY_INVALID di sebagian browser.

Kirim output rantai ke AI beserta host. Jangan minta AI menonaktifkan peringatan sertifikat di klien.

Clincoo di blog.clincoo.buzz harus membuka sama rapi di HP lama dan desktop baru.
