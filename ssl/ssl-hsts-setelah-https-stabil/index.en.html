Turn on HSTS after Clincoo HTTPS Is Stable

Strict-Transport-Security locks the browser to HTTPS. Enable it only after redirects and certificates pass tests.

This article is available in: Indonesia · English

Do not send HSTS from editor.clincoo.buzz while certificates still fail often. The browser will refuse HTTP for a long time.

After app.clincoo.buzz passes lock checks for a week, start with a short max-age, then raise it.

Include includeSubDomains only if every subdomain has a valid certificate.

Paste the HSTS header to AI for review, not the whole server config. Note it on blog.clincoo.buzz.
