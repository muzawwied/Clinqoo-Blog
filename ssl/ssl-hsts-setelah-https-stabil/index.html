Pasang HSTS setelah HTTPS Clincoo Stabil

Strict-Transport-Security mengunci browser ke HTTPS. Aktifkan hanya setelah pengalihan dan sertifikat lulus uji.

Artikel ini tersedia dalam: Indonesia · English

Jangan kirim HSTS dari editor.clincoo.buzz saat sertifikat masih sering gagal. Browser akan menolak HTTP untuk waktu lama.

Setelah app.clincoo.buzz lulus uji gembok seminggu, set max-age pendek dulu, lalu naikkan.

Sertakan includeSubDomains hanya jika semua subdomain punya sertifikat valid.

Tempel header HSTS ke AI untuk review, bukan seluruh konfigurasi server. Catat di blog.clincoo.buzz.
