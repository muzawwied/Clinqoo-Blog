Setel color-scheme pada html agar Kontrol Sistem Ikut Tema Gelap Clincoo

Token CSS saja tidak mengubah scrollbar dan form native. Properti color-scheme memberi petunjuk ke browser.

Artikel ini tersedia dalam: Indonesia · English

Tema gelap Clincoo sudah memakai custom property, tetapi input, scrollbar, dan dialog tetap putih. Browser belum tahu halaman mendukung skema gelap.

Tambahkan color-scheme: light dark pada :root atau elemen html. Saat kelas gelap aktif, setel color-scheme: dark agar kontrol native mengikuti.

Pasangkan dengan meta theme-color agar bilah status ponsel tidak kontras. Uji setelah toggle, bukan hanya pada muat pertama.

Jangan minta AI menimpa semua input dengan komponen kustom hanya karena form native terlihat terang. Perbaiki petunjuk skema dulu.

Pratinjau di editor.clincoo.buzz lalu di perangkat nyata. color-scheme merapikan sisa UI sistem yang token warna tidak jangkau.
