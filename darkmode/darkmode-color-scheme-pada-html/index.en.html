Dark mode

Set color-scheme on html so System Controls Follow Clincoo Dark Theme

CSS tokens alone do not restyle native scrollbars and forms. The color-scheme property hints the browser.

This article is available in: Indonesia · English

A Clincoo dark theme already uses custom properties, but inputs, scrollbars, and dialogs stay white. The browser does not yet know the page supports a dark scheme.

Add color-scheme: light dark on :root or the html element. When the dark class is on, set color-scheme: dark so native controls follow.

Pair it with meta theme-color so the phone status bar is not high-contrast. Test after the toggle, not only on first load.

Do not ask the AI to replace every input with a custom widget just because native forms look light. Fix the scheme hint first.

Preview in editor.clincoo.buzz and on a real device. color-scheme tidies the leftover system UI that color tokens never reach.
