Add SRI to Third-Party CDN Scripts in Clincoo

A CDN script without integrity can change without you noticing. Pin the hash before production.

This article is available in: Indonesia · English

In editor.clincoo.buzz find script tags whose src points at a CDN domain, not at a project file.

Add integrity with a sha384 or sha512 hash and crossorigin anonymous. Without crossorigin, the SRI check fails quietly in some browsers.

Do not use an unversioned URL such as latest. Pin the file version so the hash stays valid.

If the CDN replaces the file, the page will refuse the script. That is safer than running code that changed. Update the hash on purpose.

Test in the app.clincoo.buzz preview. Ask AI to compute integrity from the file you downloaded, then paste the result. Do not let AI invent a hash.
