Pakai Nama Berkas Ber-hash agar Cache CDN Clincoo Aman Diperbarui

Cache panjang pada CSS tanpa hash membuat pengunjung melihat gaya lama. Nama berkas unik menandai rilis baru.

Artikel ini tersedia dalam: Indonesia · English

Setelah deploy dari editor.clincoo.buzz, CSS lama masih tampil karena edge CDN menyimpan style.css terlalu lama. Refresh biasa tidak cukup.

Beri nama berkas dengan hash isi, misalnya app.8f3a.css. HTML merujuk nama baru. Berkas ber-hash boleh cache setahun; HTML tetap cache pendek.

Jangan cache HTML yang berisi token sesi. Aset statis saja yang immutable.

Saat minta AI menulis header, sebutkan berkas mana yang ber-hash. AI sering menyarankan no-cache pada semua aset dan itu membuang manfaat CDN.

Uji di blog.clincoo.buzz: buka tab Network, pastikan nama CSS berubah setelah rilis dan statusnya 200 sekali, lalu 304 atau disk cache.
