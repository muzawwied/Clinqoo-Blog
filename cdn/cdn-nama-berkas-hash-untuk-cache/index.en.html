Use Hashed Filenames So the Clincoo CDN Cache Can Update Safely

A long cache on unhashed CSS leaves visitors on old styles. A unique filename marks a new release.

This article is available in: Indonesia · English

After a deploy from editor.clincoo.buzz, old CSS can still show because the CDN edge cached style.css for too long. A normal refresh is not enough.

Name files with a content hash, such as app.8f3a.css. HTML points at the new name. Hashed files may cache for a year; HTML stays on a short cache.

Do not cache HTML that contains a session token. Only static assets should be immutable.

When asking AI for headers, say which files are hashed. AI often suggests no-cache on every asset, which wastes the CDN.

Test on blog.clincoo.buzz: open Network, confirm the CSS name changed after release, and that it is 200 once, then 304 or disk cache.
