Give the Clincoo Logo Alt Text the Brand Name, Not an Empty String

A header logo is identity, not decoration. Empty alt hides the brand name from screen readers.

This article is available in: Indonesia · English

Many AI generators set alt="" on the logo because they treat every header image as decorative. That is wrong when the logo is the only brand text inside the home link.

Use the same brand name as the site title, for example alt="Clincoo". Do not write "company logo" or "image 1". Screen readers and search engines need the name, not the file type.

If visible brand text already sits next to the logo, then empty alt is fine so the name is not read twice. Check the markup, not a screenshot: the text must live in HTML, not inside a PNG.

Keep the same alt spelling in the footer and article cards. Mixing Clincoo and Clinqoo in alt undoes the consistency you already enforce in copy.

Test with images disabled in preview. If the header loses its identity, the alt or nearby brand text is still missing.
