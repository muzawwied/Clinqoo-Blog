Keep Clincoo Button Radii on One CSS Token

A 4px primary button, 12px secondary, and 20px card make the brand look random. One radius token keeps corners consistent.

This article is available in: Indonesia · English

Visitors judge a brand by small repetition. If the hero CTA is fully rounded while the footer button is almost square, a Clincoo site feels like a pile of scraps, not one product.

Define --radius-sm, --radius-md, and --radius-pill on :root in editor.clincoo.buzz. Use var(--radius-md) on buttons, inputs, and cards. Do not write a new px value every time AI offers a "more modern" look.

Check computed styles in DevTools: every primary button should resolve to the same token. If one class overrides border-radius with !important, remove that override before adding another token.

Ask AI only to move existing radius values into variables, then paste one button as the example. Reject suggestions that change the logo or product photo corners — those are brand assets, not UI components.

Once the tokens exist, test the preview at narrow and wide widths. Consistent corners make pages on app.clincoo.buzz feel like one visual family even when the content differs.
