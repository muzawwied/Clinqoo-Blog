Do Not Override Branding Color Tokens with Inline Colors in Clincoo

Inline colors on one page break brand tokens. Use the same CSS variables across every template.

This article is available in: Indonesia · English

On editor.clincoo.buzz, a green button in one section and a blue button in another usually means an inline style overrode the token. Visitors see an inconsistent brand.

Define --brand and --brand-ink on :root. Buttons, links, and accents should use var(--brand), not a hex code in a style attribute.

In DevTools open Computed and find the mismatched color. If the source is a style attribute, move the value into a token class.

When asking AI for help, paste the :root block and the button class. Ask it to replace inline hex with the variable, not to invent a new palette.

Preview on app.clincoo.buzz and blog.clincoo.buzz. If one card still drifts, that page is not using the token yet.
