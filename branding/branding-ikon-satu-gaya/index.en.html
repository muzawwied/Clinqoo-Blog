Use One Icon Style Across a Clincoo Site

Outline icons mixed with filled icons make an interface feel patched. One set protects the brand.

This article is available in: Indonesia · English

A Clincoo menu uses lucide outlines, cards use emoji, and the footer uses filled SVG. Stroke scales do not match.

Pick one icon set in editor.clincoo.buzz. Store SVGs in assets/icons with a shared viewBox and the same stroke.

Do not paste AI-generated icons of mixed weight. Derive every icon from one source.

Ask AI to swap only the mismatched icon paths. Paste one official icon as the reference.

Clincoo does not tidy icons for you. One style keeps the interface consistent on app.clincoo.buzz.
