Store Clincoo Brand Colors in CSS Variables

Hex values scattered across dozens of rules are hard to change. CSS variables keep one palette source.

This article is available in: Indonesia · English

Clincoo buttons use #2b6cb0 in one file and #2563eb in another. The palette looks random.

Define --brand, --brand-ink, and --brand-muted on :root in editor.clincoo.buzz. Use var() in components.

Do not write a new hex when AI offers a "more modern color". Compare it to the brand tokens first.

Ask AI to move brand hex values into variables only. Paste :root and one button.

Clincoo renders the CSS you write. Color tokens keep the theme consistent on app.clincoo.buzz.
