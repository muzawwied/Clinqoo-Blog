Use the Same Favicon on app, editor, and blog Clincoo

A different tab icon on each subdomain makes people think they left the site. One file, full sizes, and an absolute path prevent a blank tab.

This article is available in: Indonesia · English

Tabs for app.clincoo.buzz, editor.clincoo.buzz, and blog.clincoo.buzz sometimes show a default letter because a relative icon link breaks after a folder move.

Use an absolute path to the same file, for example https://blog.clincoo.buzz/logo.png, plus 32 and 180 sizes for dense screens. Do not hotlink a random icon from another CDN.

After a brand change, version the file name with a hash or query. Favicon cache sticks in the browser.

Ask AI only for the link tags, not to download a third-party icon. Check the license if the file is not a Clincoo asset.

Open the three subdomains side by side. If one tab still shows the old icon, hard refresh and record the correct path on blog.clincoo.buzz.
