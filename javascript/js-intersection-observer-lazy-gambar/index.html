Pakai Intersection Observer untuk Lazy-load Gambar Clincoo, Bukan Listener Scroll

Listener scroll pada window memicu layout thrash. Intersection Observer lebih hemat dan sudah didukung browser modern.

Artikel ini tersedia dalam: Indonesia · English

Banyak template lama menunda gambar dengan window.addEventListener('scroll'). Setiap geser memaksa browser menghitung posisi offset, dan di halaman Clincoo yang punya banyak kartu itu terasa patah-patah.

Intersection Observer dirancang untuk pertanyaan apakah elemen ini terlihat. Kamu mendaftarkan gambar, browser memberi callback saat rasio perpotongan berubah, dan kamu baru mengisi src dari data-src. Tidak perlu hitung getBoundingClientRect di setiap frame.

Mulai sederhana: root null (viewport), rootMargin 200px supaya gambar dekat viewport mulai dimuat, threshold 0. Setelah src terpasang, panggil unobserve agar observer tidak terus hidup.

Jangan campur observer dengan innerHTML yang menulis ulang daftar. Kalau kartu diganti, amati ulang elemen baru. Kalau hanya menambah item, observe item itu saja — pola yang sama dengan delegasi event.

Untuk dukungan cadangan, atribut loading="lazy" pada img sudah cukup di browser modern. Observer berguna saat kamu butuh margin, placeholder, atau menunda iframe dan komponen lain, bukan hanya gambar.

Uji di pratinjau Clincoo dengan jaringan lambat. Pastikan gambar first-screen tetap punya src biasa agar LCP tidak menunggu observer.
