Pakai === di Skrip Clincoo, Bukan ==

== mengubah tipe diam-diam. Angka 0, string kosong, dan false bisa lolos sebagai sama.

Artikel ini tersedia dalam: Indonesia · English

Di pratinjau editor.clincoo.buzz, kondisi if (nilai == 0) ikut benar saat nilai adalah string kosong atau false.

Ganti dengan === supaya tipe ikut dibanding. Untuk tidak sama, pakai !== bukan !=.

Nilai dari input selalu string. Ubah dulu dengan Number, lalu cek Number.isNaN sebelum membandingkan.

null == undefined bernilai true, tetapi null === undefined bernilai false. Jangan samakan keduanya saat cek elemen.

Saat minta AI memperbaiki bug, tempel satu kondisi yang gagal dan nilai asli dari console.log. Minta pengganti ===, bukan rewrite seluruh file.
