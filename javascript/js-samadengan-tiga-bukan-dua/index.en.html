Use === in Clincoo Scripts, Not ==

== coerces types quietly. The number 0, an empty string, and false can pass as equal.

This article is available in: Indonesian · English

In the editor.clincoo.buzz preview, if (value == 0) is also true when value is an empty string or false.

Switch to === so the type is compared too. For inequality, use !== rather than !=.

Input values are always strings. Convert with Number, then check Number.isNaN before comparing.

null == undefined is true, but null === undefined is false. Do not treat them as the same when checking an element.

When asking AI to fix a bug, paste the failing condition and the raw console.log value. Ask for a === replacement, not a full-file rewrite.
