Use console.assert to Test Assumptions

Replace a 'el exists?' log with console.assert(el, 'submit button missing'). DevTools only shows up if the element is null.

Assert fits form and fetch handlers in editor.clincoo.buzz.

Do not let assert replace if. If empty data can be valid, branch the logic.

When you ask AI for help, paste the failing assert line plus the actual value.

Remove stale asserts before you upload to app.clincoo.buzz so the production console stays clean.
