API Pembayaran

Payment gateway QRIS bawaan Clincoo untuk situs hasil deploy-mu. Terima pembayaran tanpa mendaftar ke penyedia eksternal.

Base URL: https://app.clincoo.buzz/api/payFormat: JSONMetode QRIS

Pengenalan

Pembayaran adalah payment gateway internal Clincoo. Alurnya sederhana: situs deploy-mu memanggil API dengan pay key publik, Clincoo membuat QR QRIS lewat penyedia pembayaran di belakang layar, pembeli membayar, dan dana masuk ke saldo Pembayaran proyekmu.

Kamu tidak perlu kredensial penyedia pembayaran apa pun. Clincoo menerbitkan account_id, secret, dan pay key sendiri per proyek. Secret tidak pernah keluar dari server Clincoo.

Peran tiap kredensial

KredensialContohKegunaanBagikan?
pay_keypk_...Dipakai situs deploy untuk buat pembayaran & cek statusAman, sifatnya publik
account_idCPXXXXXXXXXXIdentitas merchant Pembayaran proyekmuBoleh
secretcps_...Internal Clincoo, untuk relasi providerJangan pernah

Alur pembayaran

1
Pembeli menekan tombol bayar di situs deploy-mu → situs memanggil Buat Pembayaran.
2
API membalas order_id + qr_image. Situs menampilkan QR-nya.
3
Situs Cek Status tiap 3–5 detik, atau menunggu Webhook payment.paid.
4
Status paid → aktifkan pesanan. Dana masuk ke saldo Pembayaran proyekmu.

Memulai

1. Aktifkan Pembayaran di dashboard

Buka proyekmu di Clincoo → Pengaturan → Pembayaran → tekan Aktifkan Pembayaran. Kredensial diterbitkan otomatis; salin pay key dari halaman itu.

2. Panggil API dari situs deploy-mu

// request pertamamu
curl -X POST https://app.clincoo.buzz/api/pay \
  -H "Content-Type: application/json" \
  -d '{
    "action": "create",
    "key": "pk_kunci_publik_proyekmu",
    "amount": 25000,
    "description": "Paket Premium"
  }'
Uji tanpa situs pun bisa: panggil lewat curl atau Postman. Endpoint publik tidak butuh login.

3. Pasang webhook (opsional tapi disarankan)

Supaya transaksi tercatat meski pembeli menutup halaman, atur URL webhook di Pengaturan → Webhook → Webhook Pembayaran. Lihat bagian Webhook.

POST Buat Pembayaran

POST/api/pay

Membuat transaksi QRIS baru. Endpoint ini publik — cukup pay key proyek, tanpa autentikasi.

Parameter (body JSON)

ParameterTipeWajibKeterangan
actionstringYaWajib "create"
keystringYaPay key publik proyekmu (berawalan pk_)
amountintegerYaNominal dalam rupiah. Min 1000, maks 100000000
descriptionstringTidakMaks 100 karakter. Tampil di deskripsi pembayaran

Contoh request

{
  "action": "create",
  "key": "pk_abc123def456ghi789jkl",
  "amount": 25000,
  "description": "Paket Premium"
}

Respon sukses

{
  "success": true,
  "order_id": "PAYM2X8K1L4QA7BZ",
  "amount": 25000,
  "qr_image": "https://api.qrserver.com/v1/create-qr-code/?size=320x320&data=000201...",
  "qr_string": "00020101021126...",
  "payment_url": "",
  "total_payment": 25415,
  "expires_at": "2026-10-04T02:30:00Z",
  "is_sandbox": false
}
FieldKeterangan
order_idID transaksi pembayaran — simpan untuk cek status & verifikasi webhook
amountNominal dasar transaksi (tanpa biaya)
qr_imageURL gambar QR QRIS — tampilkan langsung di tag <img>
qr_stringPayload QRIS mentah — opsional, kalau mau render QR sendiri
payment_urlLink pembayaran alternatif (kosong untuk QRIS)

Respon 503 dengan error: "gateway_not_ready" berarti QRIS di sisi Clincoo belum aktif sepenuhnya. Tampilkan pesan "pembayaran sedang disiapkan" dan coba lagi nanti.

GET Cek Status Pembayaran

GET/api/pay?action=status&key=...&order_id=...

Endpoint publik untuk mengecek status transaksi. Cocok untuk polling tiap 3–5 detik selama pembeli masih di halaman pembayaran.

Parameter (query string)

ParameterTipeWajibKeterangan
actionstringYaWajib status
keystringYaPay key proyekmu
order_idstringYaOrder ID dari Buat Pembayaran

Respon

{
  "success": true,
  "status": "paid",
  "amount": 25000,
  "message": ""
}
Nilai statusArti
pendingPembeli belum menyelesaikan pembayaran — terus polling
paidLunas. Dana masuk ke saldo Pembayaran proyekmu
expiredQR kedaluwarsa — buat transaksi baru

API Dashboard (Autentikasi)

Endpoint di bawah ini dipakai halaman Pembayaran Clincoo dan butuh dua hal:

1. Header Authorization: Bearer <token sesi Clincoo>
2. project_id proyekmu pada request

AksiMetode & BentukFungsi
activatePOST {action, project_id}Aktifkan Pembayaran + terbitkan account_id & pay_key
configGET ?action=config&project_id=Status aktif, pay key, dan saldo ringkas
summaryPOST {action, project_id}Saldo: available, total_paid, total_withdrawn
withdrawPOST {action, project_id, amount}Ajukan penarikan saldo (min Rp 10.000)
transactionsPOST {action, project_id}25 transaksi terakhir proyek
withdrawalsPOST {action, project_id}25 riwayat penarikan terakhir

Contoh: config

{
  "success": true,
  "active": true,
  "gateway_ready": true,
  "account_id": "CP7K2M9XQ1Z",
  "pay_key": "pk_abc123def456ghi789jkl",
  "available": 150000,
  "total_paid": 200000,
  "total_withdrawn": 50000
}
Saldo tersedia = total transaksi paid − penarikan (diproses + selesai). Status penarikan: pending → diproses tim Clincoo → done atau rejected.

Webhook

Setiap transaksi yang berubah menjadi paid memicu satu POST JSON ke URL webhook proyekmu (diatur di Pengaturan → Webhook → Webhook Pembayaran).

Payload

{
  "event": "payment.paid",
  "order_id": "PAYM2X8K1L4QA7BZ",
  "amount": 25000,
  "description": "Paket Premium",
  "status": "paid",
  "paid_at": "2026-10-02T04:15:22.101Z"
}
FieldKeterangan
eventSaat ini selalu payment.paid
order_idID transaksi — cocokkan dengan pesananmu sebelum proses
amountNominal dalam rupiah
paid_atWaktu konfirmasi (ISO 8601)

Contoh handler (Node/Express)

app.post("/webhook/bayar", express.json(), (req, res) => {
  const d = req.body;
  if (d.event === "payment.paid") {
    const pesanan = cariPesanan(d.order_id);      // HARUS milik sistemmu
    if (pesanan && !pesanan.lunas) {
      pesanan.lunas = true;                        // aktifkan pesanan
    }
  }
  res.sendStatus(200);   // balas 200 agar tidak dikirim ulang
});
Selalu verifikasi order_id ada di sistemmu dan belum lunas. Jangan aktifkan pesanan hanya dari angka amount.

Contoh Integrasi Lengkap

Alur penuh di sisi situs deploy-mu: buat QR, tampilkan, polling status, selesaikan pesanan.

async function bayarSekarang(payKey, nominal) {
  // 1) Buat pembayaran
  const buat = await fetch("https://app.clincoo.buzz/api/pay", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({
      action: "create", key: payKey,
      amount: nominal, description: "Paket Premium"
    })
  }).then(r => r.json());

  if (!buat.success) return gagal(buat.message);

  // 2) Tampilkan QR ke pembeli
  tampilkanQR(buat.qr_image);

  // 3) Polling status tiap 4 detik, maks 15 menit
  return new Promise(selesai => {
    let ulang = 0;
    const cek = setInterval(async () => {
      const st = await fetch(
        "https://app.clincoo.buzz/api/pay?action=status" +
        "&key=" + encodeURIComponent(payKey) +
        "&order_id=" + encodeURIComponent(buat.order_id)
      ).then(r => r.json());

      if (st.status === "paid")   { clearInterval(cek); selesai("sukses"); }
      if (st.status === "expired"){ clearInterval(cek); selesai("kedaluwarsa"); }
      if (++ulang > 225)         { clearInterval(cek); selesai("timeout"); }
    }, 4000);
  });
}

FAQ

Apakah pay key aman ditaruh di frontend?

Ya. Pay key hanya bisa membuat transaksi dan membaca status milik proyek itu — tidak bisa membaca saldo atau menarik dana. Aksi finansial selalu butuh sesi Clincoo.

Apakah bisa tanpa polling?

Bisa. Pasang webhook payment.paid dan proses pesanan dari server-mu. Polling tetap berguna sebagai fallback saat pembeli masih di halaman.

Kapan dana bisa ditarik?

Segera setelah transaksi paid. Minimum Rp 10.000 per penarikan, diproses oleh tim Clincoo.

QR kedaluwarsa, apa yang harus dilakukan?

Buat transaksi baru dengan action: create. Order ID lama tidak bisa dipakai ulang.
