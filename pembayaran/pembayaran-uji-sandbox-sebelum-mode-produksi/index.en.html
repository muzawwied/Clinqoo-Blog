Test Payment Sandbox before Production Mode

Switch to production keys only after the Clincoo sandbox flow passes: create, test pay, webhook, and success page.

This article is available in: Indonesia · English

Production mode charges real money. A sandbox checklist in the Clincoo payment docs is cheaper than a manual refund.

Use test keys in a separate environment. Do not mix a sandbox URL and a live key in the same file without a clear marker.

Pass four steps: create a transaction, complete a test payment, receive a verified webhook, then show the success page in the editor.clincoo.buzz preview.

Record the test transaction id in the release note. If a step fails, fix the description before asking AI to rewrite the whole checkout page.

After it passes, change the key and the URL together. A half migration — live URL with a test key — is a 401 that is hard to trace.
