Do Not Put a Payment Secret Key in the Page

A public key may live in the client. Secret keys, webhook secrets, and account tokens belong only on the server, not in Clincoo HTML.

This article is available in: Indonesia · English

Sites deployed from Clincoo are often static HTML. Anyone can view source. A secret key in a script is the same as publishing it.

Split the public key used to create an invoice in the client from the secret used to mark paid on the server. A variable named SECRET in a file uploaded to editor.clincoo.buzz is a red flag.

If an AI assistant pastes a sample with a hardcoded secret, reject that snippet. Ask for a version that reads the environment and fails closed when the variable is empty.

Check the repo and the preview before deploy. Search HTML for sk_live, whsec, and the word secret. One hit is enough to hold the release.

Rotate any key that was uploaded. Deleting the line in a later commit does not pull back a value visitors already downloaded.
