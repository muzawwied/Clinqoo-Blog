Pakai safe-area-inset agar Tombol Clincoo Tidak Tertutup Notch

Bilah bawah ponsel sering menimpa tombol simpan. Padding env(safe-area-inset-bottom) menjaga area sentuh.

Artikel ini tersedia dalam: Indonesia · English

Di pratinjau app.clincoo.buzz pada ponsel berponi, tombol simpan di tepi bawah sering tertutup bilah sistem.

Tambahkan viewport-fit=cover pada meta viewport, lalu padding-bottom: env(safe-area-inset-bottom) pada bilah aksi.

Jangan hanya menambah padding tetap 20px. Nilai env mengikuti perangkat, termasuk tepi kiri-kanan saat landscape.

Uji di DevTools device mode dan di ponsel sungguhan. Pastikan target sentuh tetap minimal 44px setelah padding.

Catat cuplikan CSS ini di blog.clincoo.buzz supaya template baru tidak mengulang tombol yang terpotong.
