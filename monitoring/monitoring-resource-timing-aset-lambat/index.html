Temukan Aset Lambat Clincoo dengan Resource Timing

Konsol Network mudah terlewat. Resource Timing mencatat durasi setiap file setelah halaman produksi terbuka.

Artikel ini tersedia dalam: Indonesia · English

Setelah deploy proyek Clincoo, halaman bisa terasa lambat meski Lighthouse lab tampak hijau. Penyebabnya sering satu font, skrip analitik, atau gambar hero yang transfer-nya panjang di jaringan pengunjung. Resource Timing API mencatat startTime, responseEnd, dan transferSize per URL tanpa harus merekam ulang tab Network.

Buka halaman produksi, lalu di konsol jalankan performance.getEntriesByType("resource"). Urutkan berdasarkan duration. File di atas 500 ms patut dicurigai: format terlalu berat, cache miss, atau domain pihak ketiga yang cold-start.

Jangan ukur di pratinjau editor saja. CDN dan cache produksi berbeda. Ulangi di perangkat HP dengan throttling 4G agar angka mendekati pengunjung nyata.

Setelah menemukan URL bermasalah, perbaiki satu aset: kompres gambar, tunda skrip non-kritis, atau pindahkan font ke preload. Ukur ulang duration. Monitoring berguna jika berubah menjadi tindakan, bukan daftar panjang yang dibiarkan.

Simpan cuplikan timing di catatan rilis. Kalau LCP naik minggu depan, kamu punya pembanding objektif, bukan perasaan “kayaknya lebih lambat”.
