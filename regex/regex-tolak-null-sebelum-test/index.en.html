Reject null Before Regex.test in Clincoo, Do Not Allow a TypeError

RegExp.test throws a TypeError if the input is null or undefined. Coerce to an empty string or return early before testing the pattern.

This article is available in: Indonesia · English

Form validation in editor.clincoo.buzz often calls /\d+/.test(value) when a field is still empty. null is not a string, so the console shows a TypeError and submit stops.

At the start of the function, if the value is null or undefined, return false or an empty string. Do not rely on a regex to normalize the type.

For a pattern with the g flag, lastIndex changes after test. Create the regex inside the function, or set lastIndex to 0 before the next check.

Write two console examples: null and an empty string. Both should fail quietly, not throw.
