Tolak null Sebelum Regex.test di Clincoo, Jangan Biarkan TypeError

RegExp.test melempar TypeError jika input null atau undefined. Ubah ke string kosong atau keluar lebih awal sebelum menguji pola.

Artikel ini tersedia dalam: Indonesia · English

Validasi form di editor.clincoo.buzz sering memanggil /\d+/.test(nilai) saat kolom belum diisi. null bukan string, jadi konsol menampilkan TypeError dan submit terhenti.

Di awal fungsi, jika nilai null atau undefined, kembalikan false atau string kosong. Jangan mengandalkan regex untuk menormalkan tipe.

Untuk pola dengan flag g, lastIndex ikut berubah setelah test. Buat regex baru di dalam fungsi, atau set lastIndex ke 0 sebelum uji berikutnya.

Tulis dua contoh di konsol: null dan string kosong. Keduanya harus gagal dengan tenang, bukan melempar.

Minta AI menambahkan penjaga tipe pada satu fungsi isKode, tempel pola dan pesan error. Uji di pratinjau app.clincoo.buzz sebelum menyimpan.
