Pakai Grup Tangkap Regex Hanya jika Hasilnya Dipakai di Clincoo

Kurung biasa menyimpan teks yang tidak kamu butuhkan. Pakai grup non-capturing jika hanya ingin mengelompokkan pola.

Artikel ini tersedia dalam: Indonesia · English

Pola form atau pencarian di workspace Clincoo sering memakai kurung untuk mengelompokkan alternatif. Setiap pasangan kurung biasa menjadi grup tangkap. Nomor grup bergeser diam-diam saat kamu menambah kurung di tengah pola.

Jika kamu hanya butuh pengelompokan, tulis (?:...) bukan (...). Grup non-capturing tidak masuk match[1] dan tidak mengacaukan replace dengan $1. Ini penting saat AI menempel pola baru ke skrip kecil di editor.clincoo.buzz.

Simpan grup tangkap hanya untuk bagian yang benar-benar diambil: kode pos, kode negara, atau slug. Beri nama dengan (?<nama>...) jika mesin JavaScript di pratinjau mendukungnya, supaya replace tetap terbaca manusia.

Uji di console: jalankan exec() pada string sah dan string hampir-sah. Bandingkan panjang array hasil. Jika ada entri kosong yang tidak kamu harapkan, kurung berlebih masih menangkap.

Clincoo tidak merapikan regex untukmu. Pola yang hemat grup lebih mudah di-review sebelum rilis ke app.clincoo.buzz, dan lebih tahan saat kamu menambah satu alternatif baru minggu depan.
