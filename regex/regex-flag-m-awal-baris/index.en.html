Use Flag m so Clincoo Regex Anchors Follow Each Line Start

Without flag m, ^ and $ bind the whole string. Flag m lets markdown lists and multiline notes match per line.

Artikel ini tersedia dalam: Indonesia · English

Clincoo forms often accept multiline notes: task lists, addresses, or markdown snippets. The pattern /^[-*] / only catches the first line unless flag m is on.

Build new RegExp('^[-*]\\s+', 'gm') and use matchAll. Flag m moves ^ and $ to line boundaries; flag g walks every match. Do not rely on String.match when you need each line index.

Test three dummies: one line, three dashed lines, and a blank line in the middle. The pattern should mark list items without swallowing the next paragraph.

Try it in the editor.clincoo.buzz console before pasting into validation. A wrong pattern can lock the submit button because test() returns false on a string that looks valid.

Clincoo runs the regex in the JS you save. Flag m keeps note processing predictable on app.clincoo.buzz without parsing HTML.
