Simpan Halaman Pagination di Query URL Clincoo

Nomor halaman yang hanya ada di memori hilang saat refresh. Taruh page di URLSearchParams proyek Clincoo.

Artikel ini tersedia dalam: Indonesia · English

Saat daftar di editor.clincoo.buzz berpindah halaman, tulis page ke URL dengan URLSearchParams. Jangan hanya mengubah variabel lokal.

Baca nilai saat muat. Jika absen atau bukan angka, pakai halaman 1. Tolak nilai di bawah 1.

Gunakan history.pushState atau replaceState supaya tombol kembali mengembalikan halaman sebelumnya di pratinjau app.clincoo.buzz.

Jangan menaruh token atau email di query. page, q, dan sort sudah cukup untuk dibagikan.

Minta AI menulis dua fungsi kecil: readPage dan writePage. Uji refresh di halaman 2 sebelum menggabungkan.
