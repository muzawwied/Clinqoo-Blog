Keep Pagination Page in the Clincoo URL Query

A page number that lives only in memory disappears on refresh. Put page in URLSearchParams for the Clincoo project.

This article is available in: Indonesia · English

When a list in editor.clincoo.buzz changes page, write page to the URL with URLSearchParams. Do not only change a local variable.

Read the value on load. If it is missing or not a number, use page 1. Reject values below 1.

Use history.pushState or replaceState so the back button restores the previous page in the app.clincoo.buzz preview.

Do not put tokens or email in the query. page, q, and sort are enough to share.

Ask AI for two small functions: readPage and writePage. Test a refresh on page 2 before merging.
