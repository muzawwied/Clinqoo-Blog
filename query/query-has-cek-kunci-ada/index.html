Cek Kunci Query Clincoo dengan has(), Jangan Andalkan get() Saja

get() mengembalikan string kosong jika kunci ada tanpa nilai. has() membedakan kunci absen dan kunci kosong.

Artikel ini tersedia dalam: Indonesia · English

Banyak skrip Clincoo memakai params.get('sort') || 'baru'. Jika URL berisi ?sort= tanpa nilai, get() menghasilkan string kosong dan fallback tidak jalan seperti yang kamu kira.

Di editor.clincoo.buzz, pakai params.has('sort') dulu. has() bernilai true jika kunci ada, meski nilainya kosong. Baru setelah itu putuskan default.

Alur praktis: jika has('sort') false, pakai default proyek. Jika true, baca get('sort') dan validasi ke daftar nilai yang diizinkan. Jangan terima sembarang string dari pengunjung.

Minta AI hanya mengganti blok baca query. Tempel fungsi has/get, bukan seluruh router. Uji tiga URL: tanpa kunci, kunci kosong, dan kunci berisi nilai.

Filter di app.clincoo.buzz harus bisa dibagikan. Perbedaan has() dan get() menjaga tautan filter tetap prediktabel setelah di-deploy.
