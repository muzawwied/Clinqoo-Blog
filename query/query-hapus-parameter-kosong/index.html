Hapus Parameter Query Clincoo yang Kosong, Jangan Biarkan Kunci Bergantung

Filter yang direset tetap menempel sebagai ?tag= di URL. Hapus kunci kosong agar tautan bersih dan cache prediktabel.

Artikel ini tersedia dalam: Indonesia · English

Setelah pengunjung menghapus filter, banyak app Clincoo menulis `?tag=` tanpa nilai. Kunci kosong tetap masuk riwayat, analytics, dan perbandingan cache. Dua URL yang semestinya sama jadi dua entri berbeda.

Pakai `params.delete('tag')` saat nilai kosong atau default. `URLSearchParams` tidak menghapus kunci hanya karena `set` menerima string kosong — kamu harus memanggil `delete` secara eksplisit.

Setelah membersihkan, tulis ulang query lewat `history.replaceState` agar bilah alamat ikut rapi tanpa reload. Jangan biarkan hash dan path berubah.

Di pratinjau Clincoo, reset semua filter lalu lihat URL. Seharusnya hanya path yang tersisa, atau hanya kunci yang masih punya nilai bermakna.

Minta AI menambahkan cabang: jika nilai falsy, delete; jika ada, set. Tempel fungsi tunggal, bukan seluruh berkas navigasi.
