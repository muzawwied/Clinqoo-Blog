Treat a Plus in a Clincoo Query as a Space, Do Not Decode by Hand

Old forms send a space as a plus. URLSearchParams already converts it. decodeURIComponent does not turn a plus into a space.

This article is available in: Indonesia · English

In editor.clincoo.buzz, a filter typed with a space sometimes returns from a form as q=halo+dunia. A script that uses decodeURIComponent leaves the plus as a plus.

Use new URLSearchParams(location.search).get('q'). This parser follows application/x-www-form-urlencoded: a plus is a space, and percent-encoding is still decoded.

Do not combine decodeURIComponent with a manual plus replace. The wrong order changes a plus that is really part of the value, such as a promo code.

When rewriting the URL, set it through params.set then history.replaceState. Do not build the string with a raw plus.

Ask AI only to replace the query reader, and paste one getQuery function. Test values with a space, a plus, and an ampersand in the app.clincoo.buzz preview before merging.
