Bangun Tautan Bagikan Filter Clincoo dari Query Saat Ini, Bukan dari State Tersembunyi

Filter yang hanya hidup di memori tidak bisa dibagikan. Serialize query ke URL sebelum tombol salin tautan.

Artikel ini tersedia dalam: Indonesia · English

Katalog Clincoo sering menyimpan filter di variabel JS. Tombol “Salin tautan” lalu mengirim path tanpa query. Penerima membuka halaman default dan mengira tautan rusak.

Sebelum menyalin, sinkronkan state ke `URLSearchParams`, tulis ke `history.replaceState`, baru ambil `location.href`. Satu sumber kebenaran: bilah alamat.

Jangan masukkan token, email, atau id sesi ke tautan bagikan. Query terlihat di riwayat, referrer, dan chat. Filter publik saja yang boleh ikut.

Uji di pratinjau: atur dua filter, salin tautan, buka tab baru. Tampilan harus sama tanpa langkah tambahan. Kalau berbeda, state belum tertulis ke URL.

Minta AI hanya menyambungkan tombol bagikan ke fungsi serialisasi query yang sudah ada. Hindari menyalin state lewat `localStorage` sebagai pengganti URL.
