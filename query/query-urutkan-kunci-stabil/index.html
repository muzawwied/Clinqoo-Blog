Urutkan Kunci Query Clincoo secara Stabil agar Tautan Bisa Dibandingkan

Urutan kunci yang acak membuat dua filter sama terlihat berbeda. Sortir kunci sebelum menulis URL.

Artikel ini tersedia dalam: Indonesia · English

`?sort=baru&tag=css` dan `?tag=css&sort=baru` menampilkan halaman yang sama, tetapi log, sitemap, dan perbandingan string menganggapnya berbeda. Di situs Clincoo yang membagikan tautan filter, urutan acak merusak analitik.

Sebelum `toString()`, salin pasangan ke array, urutkan berdasarkan nama kunci, lalu bangun `URLSearchParams` baru. Jangan mengandalkan urutan penyisipan objek biasa jika kamu merakit query dari beberapa sumber.

Tetapkan urutan kanonik di satu fungsi. Semua tombol filter dan semua tautan berbagi harus memanggil fungsi itu, bukan merangkai string di tempat masing-masing.

Uji dengan dua jalur klik berbeda di pratinjau. URL akhir harus identik karakter per karakter. Kalau berbeda, ada cabang yang belum lewat penyortir.

Minta AI hanya merapikan fungsi serialisasi query. Jangan biarkan ia mengubah logika filter atau markup kartu.
