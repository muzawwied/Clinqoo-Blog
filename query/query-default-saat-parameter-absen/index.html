Tetapkan Default Query Clincoo saat Parameter Absen, Jangan Anggap String Kosong

get() mengembalikan null jika kunci tidak ada. Bedakan absen, kosong, dan nilai default agar filter tidak salah arah.

Artikel ini tersedia dalam: Indonesia · English

`params.get('page')` mengembalikan `null` jika kunci tidak ada, dan string kosong jika kuncinya ada tanpa nilai. Banyak skrip Clincoo menulis `page || 1`, yang menyamakan keduanya dan menyembunyikan niat pengunjung.

Tulis helper: jika `get` null, pakai default; jika string kosong, putuskan secara sadar apakah itu berarti reset atau halaman pertama. Jangan andalkan truthiness semata.

Untuk angka, parse setelah cek null. `Number('')` adalah 0, yang bisa lolos validasi halaman padahal pengunjung tidak memilih apa pun.

Uji tiga URL di pratinjau: tanpa `page`, dengan `page=`, dan dengan `page=2`. Ketiganya harus menghasilkan perilaku yang kamu dokumentasikan, bukan tebakan.

Minta AI menambahkan helper baca query beserta tes mental tiga kasus itu. Jangan biarkan default tersebar di lima berkas.
