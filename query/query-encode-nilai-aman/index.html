Encode Nilai Query Clincoo dengan encodeURIComponent, Bukan Concat String Mentah

Spasi, ampersand, dan karakter non-ASCII merusak query string. encodeURIComponent menjaga nilai filter tetap utuh.

Artikel ini tersedia dalam: Indonesia · English

Banyak skrip Clincoo menulis query dengan `'?q=' + kataKunci`. Begitu pengunjung mengetik ampersand atau spasi, URL pecah: kunci baru muncul tanpa sengaja dan filter tidak lagi terbaca.

Pakai `URLSearchParams` lalu `params.set('q', kataKunci)`. API ini memanggil encoding yang benar. Kalau kamu membangun string sendiri, bungkus nilai dengan `encodeURIComponent` — bukan `escape` yang sudah usang.

Jangan encode seluruh URL. `encodeURI` membiarkan `?` dan `&` utuh, tetapi nilai parameter tetap harus di-encode terpisah. Campur keduanya hanya jika kamu paham batas masing-masing.

Uji di editor.clincoo.buzz dengan kata yang berisi spasi, tanda plus, dan huruf Indonesia. Buka pratinjau, salin URL, lalu muat ulang. Nilai harus kembali sama persis.

Minta AI hanya mengganti fungsi pembangun query. Jangan biarkan rewrite seluruh router hanya karena satu karakter rusak.
