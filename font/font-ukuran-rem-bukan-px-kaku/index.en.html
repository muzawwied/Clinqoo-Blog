Use rem Font Sizes, Not Rigid px, on Clincoo Pages

Clincoo text set in px ignores the browser text-size setting. rem follows the root size and stays readable.

This article is available in: Indonesian · English

Many templates set font-size:14px or 16px on body and headings. Pixels do not follow the user text-size preference. On a phone, already small type gets harder to read.

Use rem for text and for vertical spacing tied to readability. 1rem follows the html font-size. Headings can be 1.5rem or 2rem; body 1rem; notes 0.875rem. Leave html at the browser default unless you have a strong reason not to.

web.dev and MDN distinguish px, em, and rem. em compounds inside nested components and can balloon. rem is more predictable on a static Clincoo site with many cards and forms.

Test in preview: raise the system default font size or text zoom. Pages that use rem scale as a whole. Pages locked to px often clip or force horizontal scroll.

Relative sizing is accessibility, not only design taste. Replace px on text first; a 1px border may stay in pixels.
