Pakai size-adjust pada Fallback Font Clincoo agar Teks Tidak Loncat

Fallback sistem yang lebih lebar membuat layout Clincoo bergeser saat woff2 selesai. size-adjust menyesuaikan metrik awal.

Artikel ini tersedia dalam: Indonesia · English

font-display: swap membuat teks Clincoo langsung terbaca, tetapi Arial atau system-ui sering lebih lebar dari font kustom. Saat woff2 tiba, judul turun baris atau tombol bergeser. Itu layout shift yang terasa di HP.

Deklarasikan fallback lewat @font-face dengan src: local("Arial"), lalu descriptor size-adjust, ascent-override, dan descent-override. Naikkan atau turunkan size-adjust sampai lebar sampel judul mendekati font produksi. Simpan pasangan itu di CSS proyek, bukan di tebakan AI tiap sesi.

Jangan andalkan line-height ketat untuk menutupi loncatan. Line-height mengatur tinggi baris, bukan lebar glif. Tes dengan jaringan lambat di DevTools: disable cache, throttle Fast 3G, muat beranda Clincoo, lihat apakah heading tetap satu baris sebelum dan sesudah swap.

Kalau metrik tetap jauh, pilih fallback yang lebih dekat: Georgia untuk serif, system-ui untuk sans modern. Dokumentasikan keluarga fallback di README agar AI tidak mengganti stack saat merapikan CSS.

size-adjust adalah penyetelan sekali. Setelah cocok, preload woff2 judul tetap berguna, tetapi pengunjung dengan font yang tertahan tidak melihat tombol yang meloncat.
