Use size-adjust on Clincoo Fallback Fonts so Text Does Not Jump

A wider system fallback shifts Clincoo layout when the woff2 arrives. size-adjust tunes the first metrics.

Indonesia · English

font-display: swap makes Clincoo text readable immediately, but Arial or system-ui is often wider than the custom face. When the woff2 arrives, a heading wraps or a button shifts. That is a layout shift phones feel.

Declare the fallback with @font-face, src: local("Arial"), then size-adjust, ascent-override, and descent-override. Raise or lower size-adjust until a sample heading matches production width. Keep that pair in project CSS, not in a fresh AI guess each session.

Do not lean on a tight line-height to hide the jump. Line-height sets row height, not glyph width. Test with a slow network in DevTools: disable cache, throttle Fast 3G, load the Clincoo home page, and check that the heading stays one line before and after swap.

If metrics stay far apart, pick a closer fallback: Georgia for serif, system-ui for a modern sans. Document the stack in the README so the AI does not rewrite it while tidying CSS.

size-adjust is a one-time calibration. After it matches, preloading the heading woff2 still helps, but visitors whose font is delayed no longer see jumping buttons.
