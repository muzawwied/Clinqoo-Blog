Pakai rem untuk Ukuran Font Clincoo, Bukan Hanya Pixel Ketat

Pixel tetap tidak mengikuti zoom teks pengunjung dan merusak hierarki saat root berubah.

Artikel ini tersedia dalam: Indonesia · English

Banyak template Clincoo menulis font-size: 18px pada judul dan 14px pada label. Saat pengunjung memperbesar teks di browser, hierarki tidak ikut naik merata.

Di editor.clincoo.buzz, set html atau body ke 100% lalu pakai rem pada h1 sampai small. 1.25rem lebih mudah diskalakan daripada 20px tersebar.

Jangan mencampur rem dan px pada satu blok judul. Pilih satu skala agar AI tidak menimpa nilai acak.

Minta AI mengubah font-size judul dan paragraf ke rem. Tempel CSS tipografi, tolak ganti keluarga font.

Clincoo tidak mengonversi satuan sendiri. rem membuat app.clincoo.buzz tetap terbaca saat zoom.
