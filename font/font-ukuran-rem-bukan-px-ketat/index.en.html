Use rem for Clincoo Font Sizes, Not Only Rigid Pixels

Fixed pixels ignore visitor text zoom and break hierarchy when the root size changes.

Artikel ini tersedia dalam: English · Indonesia

Many Clincoo templates set headings to 18px and labels to 14px. When a visitor zooms text in the browser, the hierarchy does not scale evenly.

In editor.clincoo.buzz, set html or body to 100% and use rem on h1 through small. 1.25rem is easier to scale than scattered 20px values.

Do not mix rem and px in one heading block. Pick one scale so AI does not overwrite random values.

Ask AI to convert heading and paragraph font-size to rem. Paste the type CSS and reject a family change.

Clincoo does not convert units on its own. rem keeps app.clincoo.buzz readable under zoom.
