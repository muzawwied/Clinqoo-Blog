Split Clincoo Fonts with unicode-range So Downloads Stay Small

One font file for every script slows the page. Load Latin first, other scripts only when used.

This article is available in: Indonesia · English

Templates on editor.clincoo.buzz sometimes download a full font even when the text is Latin only. The first transfer gets heavy on a phone.

Split @font-face: a Latin subset with unicode-range U+0000-00FF, other subsets separate. The browser fetches only what the text uses.

Do not preload every subset. Preload only the Latin woff2 for headings. Let Arabic or CJK subsets load later.

Paste the @font-face rules to AI and ask whether unicode-range values overlap. Do not ask AI to download a licensed font.

Record the active subsets on blog.clincoo.buzz so the app.clincoo.buzz preview stays light.
