Use One Variable Font File for Two Clincoo Weights

Two separate woff2 files for regular and bold delay text. One variable font is often smaller.

This article is available in: Indonesia · English

A Clincoo page that loads regular.woff2 and bold.woff2 waits for two network rounds. Bold headings arrive late and the layout shifts.

A single variable font carries a wght axis. You still set font-weight 400 and 700, but the browser downloads one file. Keep font-display swap as in the other articles in this category.

Self-host the file in the assets folder in editor.clincoo.buzz. Do not pull an entire family from a CDN if you only use two weights. A latin subset is enough for Indonesian and English pages.

Ask AI to change @font-face to one variable source only. Paste the current font rules. Compare file size in the Network panel before and after.

One variable file plus two weights keeps the brand without delaying first text. Deploy to app.clincoo.buzz after a slow-network reload in preview.
