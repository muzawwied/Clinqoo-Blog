Pakai Font Variable Satu Berkas untuk Dua Berat Clincoo

Dua file woff2 terpisah untuk regular dan bold menunda teks. Satu font variable sering lebih hemat.

Artikel ini tersedia dalam: Indonesia · English

Halaman Clincoo yang memuat regular.woff2 dan bold.woff2 menunggu dua putaran jaringan. Judul bold muncul belakangan dan layout loncat.

Font variable satu berkas membawa sumbu wght. Kamu tetap memakai font-weight 400 dan 700, tetapi browser mengunduh satu file. Pasang font-display swap seperti artikel lain di kategori ini.

Self-host berkas di folder aset editor.clincoo.buzz. Jangan tarik seluruh keluarga dari CDN jika hanya dua berat yang dipakai. Subset latin cukup untuk halaman Indonesia dan Inggris.

Minta AI hanya mengganti @font-face menjadi satu sumber variable. Tempel aturan font yang ada. Ukur ukuran file di Network DevTools sebelum dan sesudah.

Satu berkas variable plus dua berat menjaga identitas merek tanpa menunda teks pertama. Deploy ke app.clincoo.buzz setelah reload pada jaringan lambat di pratinjau.
