Nyalakan font-optical-sizing pada Font Variabel Clincoo

Font variabel tanpa optical sizing terlihat terlalu tipis di judul besar. Set auto hanya pada berkas yang punya sumbu opsz.

Artikel ini tersedia dalam: Indonesia · English

Judul di app.clincoo.buzz memakai font variabel yang sama dengan teks isi. Pada 32px, guratan terlihat kurus karena sumbu opsz tidak aktif.

Di editor.clincoo.buzz, set font-optical-sizing: auto pada h1. Biarkan body pada none jika teks kecil sudah pas.

Cek di DevTools, Computed, apakah opsz berubah saat ukuran judul diubah. Jika tidak ada sumbu itu, jangan paksa nilai palsu.

Minta AI menambah satu properti, bukan mengganti keluarga font.

Uji zoom 200% di blog.clincoo.buzz. Clincoo tidak menyetel optical sizing sendiri.
