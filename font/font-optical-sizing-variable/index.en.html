Turn On font-optical-sizing for Clincoo Variable Fonts

A variable font without optical sizing looks too thin in large headings. Set auto only on files that expose an opsz axis.

This article is available in: Indonesia · English

Headings on app.clincoo.buzz use the same variable font as body text. At 32px the strokes look thin because the opsz axis is off.

In editor.clincoo.buzz, set font-optical-sizing: auto on h1. Leave body at none if small text already looks right.

In DevTools Computed, check whether opsz changes when the heading size changes. If that axis is missing, do not invent a value.

Ask AI to add one property, not to swap the font family.

Test 200% zoom on blog.clincoo.buzz. Clincoo does not set optical sizing on its own.
