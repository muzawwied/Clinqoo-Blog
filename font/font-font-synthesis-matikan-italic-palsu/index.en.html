Turn Off font-synthesis so Fake Italic Does Not Distort Clincoo Text

The browser invents a slanted italic when the italic file is missing. Turn off font-synthesis if you only ship the regular weight.

This article is available in: Indonesia · English

On editor.clincoo.buzz, em and i often look oddly slanted because the italic woff2 was never uploaded. That is font-synthesis, not a real italic face.

Add font-synthesis: none on body if the Clincoo font family only has a regular weight. Markup can still request italic, but metrics will not stretch.

If the brand needs a true italic, upload a separate italic file and allow synthesis only for weight. Do not leave both on without a check.

In DevTools, open Computed on a word wrapped in em. If font-style is italic but only the regular file downloaded, synthesis is still active.

When stuck, paste the @font-face snippet to AI and say the fake italic distorts headings. Do not ask AI to download a licensed font.

Record the decision on blog.clincoo.buzz so the app.clincoo.buzz preview does not invent slant again.
