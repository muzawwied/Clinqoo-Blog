Use font-display: swap so Clincoo Text Does Not Vanish

Without font-display, the browser hides text until the webfont finishes. swap shows the fallback font first.

This article is available in: Indonesian · English

In the editor.clincoo.buzz preview, a heading can stay blank for two seconds because @font-face has no font-display.

Add font-display: swap on every @font-face the page uses. Text shows immediately with the system font, then swaps when the webfont is ready.

Set a fallback font-family with close metrics, such as system-ui, so the layout shift stays small.

Ask the AI only to add font-display on the existing font blocks. Reject a new font download in the same change.

Clincoo does not set swap for you. The stylesheet declaration is what keeps text on blog.clincoo.buzz readable.
