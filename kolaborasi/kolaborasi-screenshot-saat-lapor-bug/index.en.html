Attach a Screenshot and URL when You Report a Clincoo Bug

A 'broken' report with no picture forces teammates to guess. One capture plus a URL saves a round.

This article is available in: Indonesia · English

A 'form does not work' message on a Clincoo team never names the page. Teammates open the wrong file.

Include the editor.clincoo.buzz preview URL, three reproduction steps, and a console screenshot if there is an error.

Do not send a long video for one button. A cropped image of the failing element is enough.

Ask AI to turn the report into a reproduction checklist. Paste the report text, not a full server log.

Clincoo shows what is in the file. A complete report speeds the fix on app.clincoo.buzz.
