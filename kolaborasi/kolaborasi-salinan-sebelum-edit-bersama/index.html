Salin File Produksi sebelum Menyunting Bersama di Clincoo

Edit langsung di berkas produksi menghapus cadangan. Buat salinan atau cabang dulu, lalu gabungkan setelah pratinjau aman.

Artikel ini tersedia dalam: Indonesia · English

Dua editor yang menyentuh index.html produksi di Clincoo tidak punya titik kembali jika salah satu menyimpan versi rusak. Salinan kerja adalah jaring pengaman termurah.

Di editor.clincoo.buzz, duplikasi halaman atau berkas sebelum eksperimen besar. Beri nama yang jelas seperti index-wip.html agar tidak ikut terindeks sebagai kanonik.

Jika proyek tersambung ke Git, buat cabang. GitHub Docs menjelaskan cabang isolasi perubahan sampai review selesai. Jangan mendorong langsung ke main saat rekan masih meninjau.

Setelah pratinjau lolos, salin perubahan ke berkas produksi dalam satu langkah terukur. Jangan menimpa secara diam-diam tanpa pesan ke tim.

Cadangan yang tidak pernah dibuka tetap berguna: ia membuktikan apa yang live kemarin. Simpan sampai rilis berikutnya stabil.
