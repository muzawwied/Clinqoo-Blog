Tulis Daftar Tugas Tim Clincoo di README, Bukan Hanya di Chat

Chat hilang. README yang memuat siapa mengerjakan apa tetap terlihat saat orang baru masuk.

Artikel ini tersedia dalam: Indonesia · English

Tim Clincoo membagi tugas di grup. Seminggu kemudian tidak ada yang ingat siapa menyentuh form.

Tambah bagian Tugas aktif di README proyek. Satu baris: file, pemilik, status. Perbarui saat serah terima di editor.clincoo.buzz.

Jangan salin seluruh backlog. Lima item terbuka cukup. Arsip yang selesai ke changelog singkat.

Minta AI merapikan daftar dari catatan chat. Tempel nama file dan pemilik, bukan riwayat lengkap.

Clincoo tidak menyimpan chat tim. README menjaga app.clincoo.buzz bisa dilanjutkan orang baru.
