Find Who Calls a Clincoo Function with console.trace

Utility functions are called from many places. trace prints the caller stack right now.

This article is available in: Indonesia · English

A save helper in a Clincoo project suddenly runs twice. Logging arguments does not show who called it.

Add console.trace('save') at the start of the helper. DevTools prints a stack you can click through to the source line.

Use trace only while the symptom is present. Leaving it in requestAnimationFrame floods the stack.

If the stack points to a double event, remove the old listener before binding a new one. Fix one branch, then retest preview.

Pull trace before deploy. A debug stack does not help a public site and only adds console noise.
