Show Objects with console.table, Not a Raw console.log

A raw log of object lists is hard to compare. console.table lines up columns before you ask AI for help.

This article is available in: Indonesia · English

On editor.clincoo.buzz, console.log of an object array often shows [Object] that you must expand one by one.

Switch to console.table(rows) to see id, status, and message columns in one grid.

Limit columns: console.table(rows, ['id','status']). Do not log a full payload that contains a token.

Copy that table into the AI chat with the repro steps. Do not paste a circular object that fails to stringify.

Remove the table log before release to app.clincoo.buzz. Keep this pattern on blog.clincoo.buzz so debugging stays quiet.
