How to Clear the Console Before You Repeat a Reproduction

Old logs make a new error look like a repeat. In the app.clincoo.buzz preview open the console, clear the panel, then repeat the same steps from editor.clincoo.buzz.

clear() or the Clear button, then one action

Call clear() or click Clear console. Do not clear in the middle of the steps. Start from the same state: reload if needed, then do the one click that triggers the bug.

Do not rely on clear to hide an error

clear() only tidies the view. The same error returns if the cause is still there. Preserve log can stay on during navigation, but turn it off first if you intentionally want an empty panel before the reproduction.

Copy the clean result

After the steps finish, copy only the first error. Paste it to blog.clincoo.buzz or to the help note with the page URL and the time. A clean panel makes the difference between a failed attempt and a fixed attempt obvious.
