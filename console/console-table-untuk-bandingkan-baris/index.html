Konsol

Cara Bandingkan Baris Data dengan console.table

Objek bersarang di konsol sulit dibandingkan. Di editor.clincoo.buzz panggil console.table pada array hasil fetch atau daftar blok, bukan console.log berulang.

Pilih kolom yang memang dibandingkan

Argumen kedua console.table menerima daftar nama properti. Sertakan id, status, dan judul saja supaya kolom acak tidak menutupi perbedaan.

Jangan tabelkan objek terlalu dalam

Tabel meratakan satu tingkat. Kalau nilai masih objek, petakan dulu ke string singkat. Cek hasil di pratinjau app.clincoo.buzz sebelum mengubah data asli.

Salin tabel, bukan tangkapan layar

Klik kanan baris tabel lalu salin objek. Tempel ke catatan di blog.clincoo.buzz supaya angka tidak hilang saat gambar diperkecil.
