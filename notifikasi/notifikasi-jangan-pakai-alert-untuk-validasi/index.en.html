Do Not Use alert for Clincoo Form Validation

alert freezes the page and is hard to reread. Show the message next to the field, then focus the invalid input.

This article is available in: Indonesia · English

A form in editor.clincoo.buzz sometimes calls alert when the email is empty. That dialog covers the screen and does not mark the field.

Replace it with a message element under the input. Use short text: what is wrong and an example of a valid value.

After a failed submit, call focus() on the first invalid input so the keyboard lands there.

Do not auto-dismiss an error. A success note may disappear after a few seconds; an error stays until it is fixed.

Try the flow on app.clincoo.buzz with the keyboard only. If only alert appears, replace it before deploy.
