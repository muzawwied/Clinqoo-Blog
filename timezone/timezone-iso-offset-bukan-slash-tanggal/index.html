Simpan Waktu Clincoo sebagai ISO dengan Offset, Bukan 30/09/2026

Format tanggal lokal dengan slash ambigu. ISO 8601 plus offset aman diurai di semua zona.

Artikel ini tersedia dalam: Indonesia · English

Input jadwal di editor.clincoo.buzz yang menyimpan 30/09/2026 09:00 tanpa zona akan bergeser saat dibuka di UTC.

Simpan string ISO seperti 2026-09-30T09:00:00+07:00 atau instant UTC 2026-09-30T02:00:00Z. Jangan gabung tanggal dan jam sebagai teks bebas.

Tampilkan ke pengguna lewat Intl.DateTimeFormat dengan timeZone IANA. Jangan memotong string ISO manual.

Tempel nilai tersimpan plus zona perangkat ke AI. Jangan minta AI menulis parser slash sebelum Anda pindah ke ISO.

Clincoo di app.clincoo.buzz dan blog.clincoo.buzz harus berbagi satu format waktu kanonik.
