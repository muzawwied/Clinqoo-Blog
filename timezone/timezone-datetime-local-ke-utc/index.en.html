Convert datetime-local Input to UTC before Saving Clincoo

A datetime-local value has no zone. Store it on the Clincoo backend as ISO UTC so it does not shift.

This article is available in: Indonesia · English

A schedule form on editor.clincoo.buzz sends 2026-09-30T19:00 without Z. The server reads UTC and the event slips.

Read the value, combine it with the user timeZone, then call toISOString before fetch to app.clincoo.buzz.

Paste the form payload plus the device zone to AI. Do not ask for a custom datetime-local parser.

Test one WIB slot and one other-zone slot, then document it on blog.clincoo.buzz.
