Konversi input datetime-local ke UTC sebelum Simpan Clincoo

Nilai datetime-local tanpa zona. Simpan ke backend Clincoo sebagai ISO UTC agar tidak bergeser.

Artikel ini tersedia dalam: Indonesia · English

Form jadwal di editor.clincoo.buzz mengirim 2026-09-30T19:00 tanpa Z. Server membaca sebagai UTC dan acara mundur.

Baca value, gabungkan dengan timeZone pengguna, lalu toISOString sebelum fetch ke app.clincoo.buzz.

Tempel payload form plus zona perangkat ke AI. Jangan minta parser datetime-local custom.

Uji satu slot WIB dan satu slot zona lain, dokumentasikan di blog.clincoo.buzz.
