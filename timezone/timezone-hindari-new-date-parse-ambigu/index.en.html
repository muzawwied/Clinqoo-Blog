Avoid new Date on Ambiguous Strings in a Clincoo Project

Date parsers differ across browsers. A YYYY-MM-DD string without time can shift to the previous day.

This article is available in: Indonesia · English

A Clincoo schedule page shows yesterday after parsing in a UTC zone.

Use Date.UTC or an explicit temporal value. If you only need a calendar day, store YYYY-MM-DD as a date, not local midnight.

Paste the broken string plus the device zone to AI. Do not ask for a large Date polyfill.

Reproduce on editor.clincoo.buzz with the OS zone changed.
