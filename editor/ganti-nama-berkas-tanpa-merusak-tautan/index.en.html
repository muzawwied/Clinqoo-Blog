Rename Files in the Clincoo Editor Without Breaking Links

Renaming a file in the Clincoo explorer is easy. What is often missed: every href, src, and menu link that still points at the old name.

This article is available in: Indonesia · English

The Clincoo file explorer lets you rename a file in one click. That is useful when index2.html should become about.html, or style-old.css is no longer relevant. The hard part is not the rename button — it is every link that still points at the old name.

Before you rename, search the old filename across the project. Check href values in the menu, src on images and scripts, and url() in CSS. After the new name is in place, preview every page that used to link to it.

If you use AI, state the old name and the new name explicitly. Do not ask it to “tidy filenames” without listing the links that must follow. A renamed file without an updated href becomes a 404 after deploy.

A clear filename is worth more than a clever one. about.html is safer than page-final-v3.html, as long as every link follows the change.
