Pisahkan Folder Aset dari Halaman di Editor Clincoo

Simpan gambar, font, dan CSS di folder aset tersendiri agar explorer Clincoo tetap mudah dibaca saat proyek bertambah halaman.

Artikel ini tersedia dalam: Indonesia · English

Proyek kecil sering menaruh semua file di akar: index.html berdampingan dengan logo.png, foto-hero.jpg, dan style.css. Di editor Clincoo itu masih terbaca. Begitu halaman kedua dan ketiga muncul, akar folder menjadi daftar campur aduk.

Buat folder aset yang jelas — misalnya img/, css/, atau fonts/. Pindahkan berkas non-halaman ke sana, lalu perbarui path di HTML. Explorer jadi peta, bukan tumpukan unduhan.

Saat menambah gambar baru, letakkan langsung di folder aset, jangan di akar “sementara”. File sementara yang lupa dipindah biasanya ikut ter-deploy dan membingungkan kamu tiga minggu kemudian.

Struktur folder yang rapi juga membantu AI. Kalau kamu minta asisten menyisipkan gambar, sebut path folder aset supaya output tidak menaruh file di tempat acak.
