Keep Asset Folders Separate from Pages in the Clincoo Editor

Store images, fonts, and CSS in their own asset folders so the Clincoo explorer stays readable as the project gains pages.

This article is available in: Indonesia · English

Small projects often dump every file at the root: index.html sits next to logo.png, hero.jpg, and style.css. In the Clincoo editor that still reads fine. Once a second and third page appear, the root becomes a mixed pile.

Create clear asset folders — img/, css/, or fonts/. Move non-page files there, then update the paths in HTML. The explorer becomes a map instead of a downloads dump.

When you add a new image, put it in the asset folder immediately. Do not leave it at the root “for now”. Temporary files that never move usually ship with the deploy and confuse you three weeks later.

A tidy folder layout also helps AI. If you ask the assistant to insert an image, name the asset folder so the output does not drop files in a random place.
