Urutkan Berkas Proyek di File Explorer Agar Mudah Ditemukan

Nama folder yang jelas di editor Clincoo menghemat waktu setiap kali kamu kembali ke proyek.

Artikel ini tersedia dalam: Indonesia · English

Proyek kecil cepat menjadi tumpukan file. Di file explorer Clincoo, buat folder yang artinya jelas: halaman, gaya, gambar, dan skrip. Jangan campur semuanya di akar proyek hanya karena terasa lebih cepat di lima menit pertama.

Nama berkas juga bagian dari peta. index.html untuk beranda, tentang.html untuk halaman tentang, style.css untuk gaya utama. Hindari nama seperti baru2-final.html. Enam bulan kemudian kamu tidak akan ingat mana yang final.

Setiap kali menambah halaman, taruh di folder yang sama dengan saudara-saudaranya. Pratinjau dan deploy mengikuti struktur itu. Path yang rapi di explorer adalah path yang jarang pecah setelah situs tayang.

Lima menit merapikan pohon berkas hari ini menghemat setengah jam mencari file minggu depan. Editor yang bersih membuat kepala ikut bersih.
