Jangan Menyalin File Jadi index-final-final.html

Duplikat berkas di editor Clincoo membingungkan deploy. Sunting file yang benar, bukan salinan yang menumpuk.

Artikel ini tersedia dalam: Indonesia · English

Saat takut merusak halaman, banyak orang menyalin index.html menjadi index-baru.html atau index-final-2.html. Di editor Clincoo itu terasa aman, tapi deploy hanya menayangkan berkas yang benar-benar ditautkan. Salinan liar tidak membantu pengunjung.

Lebih aman: simpan dulu, ubah file asli, lalu pratinjau. Kalau rusak, kembalikan dari isi yang kamu ingat atau tanya AI untuk memulihkan potongan yang baru diubah. Dua versi hidup bersamaan hampir selalu membuatmu menyunting yang salah.

Kalau memang butuh percobaan, buat folder percobaan dan jangan tautkan ke menu utama. Selesai mencoba, pindahkan perubahan ke file asli lalu hapus salinannya dari explorer.

Proyek yang rapi punya satu sumber kebenaran per halaman. Editor bukan folder unduhan. Semakin sedikit nama yang berakhiran final, semakin mudah situsmu dirawat.
