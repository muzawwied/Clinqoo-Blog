Cari Berkas di File Explorer, Jangan Gulir Sampai Bawah

Proyek tumbuh cepat. Biasakan cari nama file di explorer editor Clincoo sebelum membuka tab yang salah.

Artikel ini tersedia dalam: Indonesia · English

File explorer Clincoo menampilkan pohon proyek. Saat berkas masih sedikit, gulir terasa cukup. Begitu ada folder CSS, gambar, dan beberapa halaman HTML, gulir jadi tebak-tebakan.

Ketik sebagian nama file yang kamu ingat. Biasanya cukup tiga huruf unik: hero, nav, atau foot. Yang muncul adalah kandidat, bukan seluruh pohon. Buka yang tepat, tutup yang tidak perlu.

Kalau nama file tidak ketemu, kemungkinan besar file itu belum ada di proyek — bukan tersembunyi. Buat berkas baru di folder yang masuk akal, lalu tautkan dari HTML. Jangan menyalin path dari laptop di luar workspace.

Kebiasaan cari dulu menghemat tab. Editor tetap ringan, dan kamu tidak menimpa file yang salah karena kemiripan nama.
