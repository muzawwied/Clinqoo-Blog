Buka HTML dan CSS Bersamaan di Tab Editor

Satu tab untuk struktur, satu tab untuk gaya. Di Clinqoo, dua tab itu cukup untuk memperbaiki tampilan tanpa tebak-tebakan.

Artikel ini tersedia dalam: Indonesia · English

Mengubah tampilan sambil hanya membuka HTML membuatmu menebak nama kelas. Buka file HTML di satu tab dan CSS di tab sebelahnya di editor Clinqoo. Loncat antar tab saat kamu menyesuaikan warna, jarak, atau ukuran huruf.

Salin nama kelas dari HTML, tempel ke pencarian di berkas CSS. Kalau kelasnya tidak ketemu, kamu baru saja menemukan penyebab gaya yang tidak jalan — bukan karena browser nakal, tapi karena nama yang tidak cocok.

Jangan buka sepuluh tab hanya untuk merasa produktif. Dua atau tiga berkas yang sedang kamu sentuh sudah cukup. Tab lain ditutup supaya mata tidak lari ke file yang tidak relevan.

Setelah perubahan, simpan kedua file lalu buka pratinjau. HTML dan CSS yang dilihat berpasangan jauh lebih mudah dijinakkan daripada ditebak dari satu sisi saja.
