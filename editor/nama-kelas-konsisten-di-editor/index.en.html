Keep CSS Class Names Consistent in the Clincoo Editor

Mixing btnUtama, btn-utama, and tombol1 makes styles hard to trace. Pick one pattern and stick to it.

This article is available in: Indonesia · English

A CSS file in the Clincoo editor gets messy fast when class names have no rule. One button is btnUtama, another btn-utama, a third tombol1. When you search the file, nothing matches completely.

Pick one pattern — for example lowercase with hyphens: tombol-utama, kartu-layanan, menu-hp. Write that pattern in a comment at the top of style.css so you and the AI speak the same language.

When you add a new class, search first for something similar. Reusing tombol-utama is better than inventing an identical tombol-primer.

Consistent names make preview easier to fix and make AI requests sharper: change only the class you name, instead of guessing three labels for one button.
