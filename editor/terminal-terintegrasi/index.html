Terminal Terintegrasi: Perintah Penting untuk Pekerjaan Sehari-hari

Terminal Clincoo memungkinkanmu menjalankan perintah tanpa keluar dari editor. Ini perintah yang paling sering dipakai.

Artikel ini tersedia dalam: Indonesia · English

Bagi yang belum akrab, terminal terlihat menakutkan — padahal ia cuma cara menulis perintah lewat teks. Terminal terintegrasi Clincoo ada di dalam editor, jadi kamu tidak perlu berpindah aplikasi untuk menjalankan sesuatu.

Beberapa perintah paling berguna untuk harian: ls untuk melihat isi folder, cd untuk berpindah folder, mkdir membuat folder baru, dan touch membuat file kosong baru. Untuk menghapus, ada rm — gunakan dengan hati-hati karena yang terhapus tidak masuk tong sampah.

Rahasianya bukan menghafal puluhan perintah, tapi memahami polanya: perintah diikuti target. mkdir foto artinya "buat folder bernama foto". Setelah pola itu terasa wajar, sisanya hanya pencarian dan kebiasaan.

Mulailah dari satu perintah per hari. Dalam sepekan, terminal berubah dari sesuatu yang seram menjadi jalan pintas favoritmu.
