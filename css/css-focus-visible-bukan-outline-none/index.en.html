Use :focus-visible, Do Not Remove Outline in Clincoo

outline: none on every :focus hides the keyboard path. :focus-visible keeps a focus ring only when it matters.

This article is available in: Indonesia · English

Templates often set a:focus { outline: none } so mouse clicks look clean. Keyboard users then press Tab and cannot see where the caret is.

Replace that rule with :focus-visible. Set outline or box-shadow from brand color tokens so the ring works in light and dark mode.

Do not rely on color alone. A 2px thickness plus offset keeps contrast on primary buttons.

Test in editor.clincoo.buzz preview: a mouse click does not have to show the ring, but Tab must show it on links, inputs, and buttons.

Ask the AI to remove global outline: none and add :focus-visible on the open CSS file. Do not let it change layout.
