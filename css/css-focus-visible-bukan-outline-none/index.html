Pakai :focus-visible, Jangan Hapus Outline di Clincoo

outline: none pada semua :focus menghilangkan jalur keyboard. :focus-visible menjaga cincin fokus hanya saat relevan.

Artikel ini tersedia dalam: Indonesia · English

Template sering menulis a:focus { outline: none } agar klik mouse bersih. Pengunjung yang menekan Tab lalu tidak melihat di mana kursor berada.

Ganti aturan itu dengan :focus-visible. Tetapkan outline atau box-shadow dari token warna merek agar cincin terlihat di mode terang dan gelap.

Jangan andalkan warna saja. Ketebalan 2px plus offset menjaga kontras di tombol yang sudah berwarna primer.

Uji di pratinjau editor.clincoo.buzz: klik mouse tidak wajib menampilkan cincin, Tab harus menampilkannya di tautan, input, dan tombol.

Minta AI menghapus outline: none global dan menambah :focus-visible pada berkas CSS yang terbuka. Jangan biarkan ia mengubah layout.
