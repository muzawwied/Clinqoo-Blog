Set box-sizing: border-box in the Clincoo Reset

Without border-box, padding and border add to width and break columns. Set it once in the reset.

This article is available in: Indonesia · English

On editor.clincoo.buzz, width 100% plus padding often pushes a column out of its container. That is the content-box default.

Add a reset rule: *, *::before, *::after { box-sizing: border-box; }. Padding then stays inside the declared width.

Do not set border-box on only one class. Old and new components must share the same model.

Check DevTools: Computed width should match the visible box, including padding.

Test the form on app.clincoo.buzz. Note this reset on blog.clincoo.buzz so new templates do not repeat the width bug.
