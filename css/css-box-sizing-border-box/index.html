Set box-sizing: border-box di Reset Clincoo

Tanpa border-box, padding dan border menambah lebar dan merusak kolom. Pasang sekali di reset.

Artikel ini tersedia dalam: Indonesia · English

Di editor.clincoo.buzz, lebar 100% plus padding sering mendorong kolom keluar wadah. Itu default content-box.

Tambahkan aturan reset: *, *::before, *::after { box-sizing: border-box; }. Padding lalu masuk ke dalam lebar yang diumumkan.

Jangan set border-box hanya pada satu kelas. Komponen lama dan baru harus memakai model yang sama.

Cek di DevTools: Computed width harus sama dengan lebar kotak yang terlihat, termasuk padding.

Uji form di app.clincoo.buzz. Catat reset ini di blog.clincoo.buzz supaya template baru tidak mengulang bug lebar.
