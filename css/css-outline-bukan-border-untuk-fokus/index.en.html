Use Outline, Not Border, for Keyboard Focus

A border on :focus shifts layout. Outline takes no space and stays visible while tabbing.

This article is available in: Indonesian · English

On editor.clincoo.buzz, many buttons add a border on focus. That changes width and nudges neighbors.

Use outline or box-shadow for the focus ring. Outline is painted outside the box and does not affect layout size.

Do not remove outline without a replacement. Keyboard users lose their place while tabbing a long form.

Give enough contrast on the light theme. A pale gray ring on white fails on app.clincoo.buzz.

If AI suggests outline: none, ask for :focus-visible and an explicit color instead.

Test with keyboard only in preview, then write the pattern that passed on blog.clincoo.buzz.
