Use CSS Logical Margins, Not Only left-right, in Clincoo

margin-left breaks on RTL pages. margin-inline-start follows text direction.

This article is available in: Indonesia · English

Many Clincoo templates write margin-left: 1rem on an icon next to a title. That works for Indonesian, but it flips when a page uses dir="rtl" or a language that reverses inline direction.

Replace left-right pairs with margin-inline-start and margin-inline-end. For top-bottom that should follow the block flow, use margin-block-start. Logical properties follow writing-mode, not screen coordinates.

In editor.clincoo.buzz, test by temporarily adding dir="rtl" on and opening the preview. Icons, badges, and card padding should stay on the "start" edge of the text, not jump to the physical left.

Ask AI only to swap existing physical properties. Do not let it rewrite the whole stylesheet. Paste one navigation component as the example so the change stays measurable.

Logical properties make later i18n cheaper. Pages that already look clean on app.clincoo.buzz will not need a left-right patch when you add another language.
