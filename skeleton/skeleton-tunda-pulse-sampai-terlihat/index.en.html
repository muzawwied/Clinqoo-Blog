Delay Clincoo Skeleton Pulse until the Element Is Visible

Animation below the fold wastes battery and triggers useless compositing work.

This article is available in: Indonesia · English

A long list on editor.clincoo.buzz animates 40 cards including those off screen.

Use Intersection Observer: pulse only bones that are visible. Stop the animation when they leave the viewport.

Honor prefers-reduced-motion. If the user asks for less motion, show a static color.

Paste the pulse CSS to AI. Ask for a visibility gate, not a list rewrite.

Measure CPU on app.clincoo.buzz while scrolling. Record the rule on blog.clincoo.buzz.
