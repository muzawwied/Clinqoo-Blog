Lock Clincoo Skeleton Avatar Size so the Row Does Not Jump

A placeholder circle that changes diameter when the photo arrives shifts the name beside it.

This article is available in: Indonesia · English

On editor.clincoo.buzz, the avatar skeleton uses automatic width. When the image arrives, the name row shifts.

Set the same width, height, and border-radius on the bone and the final photo. Use aspect-ratio 1/1.

Do not leave img without size. An empty alt plus a fixed size prevents CLS on app.clincoo.buzz.

Paste the member-row markup to AI. Ask for size tokens, not a new component.

Measure layout shift in DevTools. Record the pattern on blog.clincoo.buzz.
