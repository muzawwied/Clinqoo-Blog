Samakan Kontras Skeleton Clincoo di Mode Gelap dan Terang

Placeholder yang hilang di tema gelap terasa seperti halaman kosong. Warna tulang harus tetap terbaca.

Artikel ini tersedia dalam: Indonesia · English

Kartu skeleton Clincoo memakai abu muda. Di mode gelap app.clincoo.buzz kotak itu nyaris menyatu dengan latar.

Di editor.clincoo.buzz, set dua token warna skeleton: terang dan gelap. Jangan hardcode #eee.

Uji kontras singkat: tulang harus terlihat tanpa menyala. Pulse hanya mengubah opacity, bukan lebar.

Minta AI memetakan token ke prefers-color-scheme. Tempel cuplikan CSS tema, bukan seluruh berkas.

Clincoo menayangkan tema yang kamu pilih. Skeleton yang kontras membuat tunggu data tetap jujur.
