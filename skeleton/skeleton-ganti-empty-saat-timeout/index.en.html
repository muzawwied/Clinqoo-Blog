Replace a Clincoo Skeleton with an Empty State when Fetch Times Out

Bones that pulse forever after a timeout look like a hang. Give an exit.

This article is available in: Indonesia · English

A list fetch on editor.clincoo.buzz fails quietly. The skeleton keeps pulsing with no retry button.

After the time limit, remove the bones. Show a short message plus Try again. Do not leave pulse running behind the error.

Separate empty data from empty error. Zero rows is not a network failure.

Ask AI for one state machine: loading, ready, timeout. Paste the fetch handler only.

Test offline mode on app.clincoo.buzz. Write the timeout branch on blog.clincoo.buzz.
