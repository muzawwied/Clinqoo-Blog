Use modulepreload for Critical Clincoo Module Files

modulepreload downloads and compiles a module before the script tag runs, so the first import does not wait its turn.

Artikel ini tersedia dalam: English · Indonesia

A Clincoo page that loads a main module and then immediately imports a layout helper often waits for two network rounds.

Add link rel=modulepreload href for files that are definitely used on the first screen. Do not preload a panel that opens only after a click.

The preload URL must match the imported specifier exactly, including the version query. One different character makes the browser download twice.

Ask AI to build the modulepreload list from static imports in the entry file, not from the whole folder. Refuse preloading every asset.

Check the waterfall on editor.clincoo.buzz. Critical files should start downloading before script parse finishes, and app.clincoo.buzz should stay light.
