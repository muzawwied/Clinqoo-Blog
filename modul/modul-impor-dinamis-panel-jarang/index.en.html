Use Dynamic Import for Clincoo Panels that Rarely Open

Static imports pull heavy panel code on the first visit. import() loads it only when the visitor opens the panel.

Artikel ini tersedia dalam: English · Indonesia

Clincoo pages often import an image editor, a color picker, and charts even when the visitor is only reading. The first file gets large.

Move the rare panel into its own file. Call import("./panel.js") inside the click, then render the result. Show a short message while the promise is pending.

Do not dynamic-import inside a loop without a cache. The browser does cache modules, but repeating promises makes the error path confusing.

Paste the import path to AI and ask to split only the panel that is not on the first screen. Do not ask AI to delete the feature.

Test on editor.clincoo.buzz with a slow network. A delayed panel must still be cancellable before it is mounted on app.clincoo.buzz.
