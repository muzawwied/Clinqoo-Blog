Pin One Clincoo Library Version with an Import Map

Two CDN script tags can load two versions of the same library. An import map points a specifier at one URL.

Artikel ini tersedia dalam: English · Indonesia

Clincoo templates sometimes import "lodash" from CDN A and "lodash" again from an old snippet. Function behavior differs and the bug is hard to trace.

Add a script type="importmap" in the head before modules. Map the specifier to one versioned URL, for example https://cdn.example/lodash@4.17.21/lodash.js. Do not mix unversioned URLs.

Import only specifiers that exist in the map. If a key is missing, the module fails before render. Log the failure. Do not silently fall back to a second copy.

Ask AI to build an import map from the imports already on the page. Refuse adding a new library the page does not use.

Save the map in editor.clincoo.buzz with the HTML so the blog.clincoo.buzz preview and app.clincoo.buzz use the same version.
