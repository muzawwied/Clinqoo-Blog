Kunci Satu Versi Pustaka Clincoo dengan Import Map

Dua tag script CDN bisa memuat dua versi pustaka yang sama. Import map menunjuk specifier ke satu URL.

Artikel ini tersedia dalam: Indonesia · English

Template Clincoo kadang mengimpor "lodash" dari CDN A dan "lodash" lagi dari cuplikan lama. Perilaku fungsi tidak sama dan bug sulit dilacak.

Tambah script type="importmap" di head sebelum modul. Petakan specifier ke satu URL berversi, misalnya https://cdn.example/lodash@4.17.21/lodash.js. Jangan campur URL tanpa versi.

Impor hanya specifier yang ada di peta. Jika kunci tidak ketemu, modul gagal sebelum render. Catat kegagalan di konsol, jangan diam-diam fallback ke salinan kedua.

Minta AI menyusun import map dari daftar impor yang sudah ada. Tolak menambah pustaka baru yang tidak dipakai halaman.

Simpan peta di editor.clincoo.buzz bersama HTML agar pratinjau blog.clincoo.buzz dan app.clincoo.buzz memakai versi yang sama.
