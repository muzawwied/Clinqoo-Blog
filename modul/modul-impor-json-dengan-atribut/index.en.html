Import JSON in a Clincoo Module with a Type Attribute, Not a Silent fetch

An import attribute with type json puts config data on the module graph. A hidden top-level fetch is hard to cancel.

Artikel ini tersedia dalam: English · Indonesia

Clincoo templates often fetch config.json outside a function. Another page that imports that file fires the network call too.

Use an import with a json type attribute for small static data, then export the result. Do not import a large JSON file that changes every visit.

If the project browser does not support import attributes yet, wrap fetch inside init and show a failure state. Do not fall back to an empty object with no message.

Ask AI to replace one config fetch with an attributed import or an explicit init. Refuse copying the JSON body into the script.

Test on blog.clincoo.buzz and app.clincoo.buzz. A JSON parse error must show in the console, not as a blank page.
