Impor JSON di Modul Clincoo dengan Atribut Tipe, Bukan fetch Diam-diam

Import atribut type json membuat data konfigurasi ikut graf modul. fetch tersembunyi di tingkat atas sulit dibatalkan.

Artikel ini tersedia dalam: Indonesia · English

Template Clincoo sering fetch file config.json di luar fungsi. Halaman lain yang mengimpor berkas itu ikut meminta jaringan.

Gunakan impor dengan atribut tipe json pada data yang statis dan kecil, lalu ekspor hasilnya. Jangan impor JSON besar yang berubah tiap kunjungan.

Jika browser proyek belum mendukung atribut impor, bungkus fetch di dalam init dan tampilkan status gagal. Jangan jatuhkan objek kosong tanpa pesan.

Minta AI mengganti satu fetch config menjadi impor beratribut atau init yang eksplisit. Tolak menyalin isi JSON ke dalam skrip.

Uji di blog.clincoo.buzz dan app.clincoo.buzz. Kesalahan parse JSON harus terlihat di konsol, bukan halaman putih.
