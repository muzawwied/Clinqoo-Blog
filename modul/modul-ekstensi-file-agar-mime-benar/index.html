Beri Ekstensi yang Benar agar Server Clincoo Mengirim MIME Modul

Modul yang dilayani sebagai text/plain atau text/html ditolak browser. Ekstensi .js atau .mjs harus dipetakan ke JavaScript.

Artikel ini tersedia dalam: Indonesia · English

Setelah deploy dari editor.clincoo.buzz, konsol kadang bilang expected a JavaScript module script. Isi berkas benar, header Content-Type salah.

Simpan modul sebagai .js atau .mjs, bukan .txt atau tanpa ekstensi. Pastikan hosting mengirim text/javascript atau application/javascript.

Jangan menyajikan modul lewat URL yang mengembalikan halaman HTML 404. Impor akan gagal parse karena menerima tag html, bukan ekspor.

Minta AI mengecek path impor terhadap nama file sungguhan. Tolak mengubah logika hanya karena MIME salah.

Di app.clincoo.buzz, buka tab Network, klik berkas modul, dan baca Content-Type sebelum mengubah kode.
