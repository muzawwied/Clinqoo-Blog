Use the Right Extension so the Clincoo Server Sends a Module MIME Type

A module served as text/plain or text/html is rejected by the browser. A .js or .mjs extension must map to JavaScript.

Artikel ini tersedia dalam: English · Indonesia

After a deploy from editor.clincoo.buzz, the console sometimes says it expected a JavaScript module script. The file body is fine; the Content-Type header is wrong.

Save modules as .js or .mjs, not .txt or with no extension. Make sure hosting sends text/javascript or application/javascript.

Do not serve a module from a URL that returns an HTML 404 page. The import fails to parse because it receives html tags, not exports.

Ask AI to check import paths against real file names. Refuse changing logic just because the MIME type is wrong.

On app.clincoo.buzz, open the Network tab, click the module file, and read Content-Type before editing code.
