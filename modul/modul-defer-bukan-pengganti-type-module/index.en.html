defer Is Not a Substitute for type=module on a Clincoo Page

defer only delays a classic script. Modules still need type=module so imports and an isolated scope actually work.

This article is available in: Indonesia · English

A script with defer waits until HTML is parsed, but its variables stay global. Two deferred files can still overwrite the same name.

type=module is deferred by default and runs after the document is parsed. You do not need to add defer on a module tag.

Imports between files are valid only in modules. A classic script that uses import fails in the console with a syntax error.

In editor.clincoo.buzz, set type=module on the page script tag, then move helpers into a separate file that exports them.

Module execution order follows the import graph, not the tag order. Do not rely on the next script to prepare a global variable.
