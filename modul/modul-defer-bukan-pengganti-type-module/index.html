Defer Bukan Pengganti type=module di Halaman Clincoo

defer hanya menunda skrip klasik. Modul tetap perlu type=module agar impor dan lingkup terisolasi berjalan.

Artikel ini tersedia dalam: Indonesia · English

Skrip dengan defer menunggu HTML selesai diurai, tetapi variabelnya tetap global. Dua file defer tetap bisa menimpa nama yang sama.

type=module juga tertunda secara bawaan dan berjalan setelah dokumen diurai. Anda tidak perlu menambah defer pada tag modul.

Impor antar berkas hanya sah di modul. Skrip klasik yang memakai import akan gagal di konsol dengan syntax error.

Di editor.clincoo.buzz, tulis type=module pada tag skrip halaman, lalu pisahkan helper ke berkas terpisah yang diekspor.

Urutan eksekusi modul mengikuti graf impor, bukan urutan tag. Jangan mengandalkan skrip berikutnya untuk menyiapkan variabel global.
