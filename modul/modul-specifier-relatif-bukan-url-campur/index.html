Pakai Specifier Relatif di Modul Clincoo, Jangan Campur URL Mutlak

Impor ./util.js mengikuti halaman. URL mutlak ke host lain pecah saat pratinjau pindah dari editor ke domain aplikasi.

Artikel ini tersedia dalam: Indonesia · English

Cuplikan Clincoo kadang mengimpor https://editor.clincoo.buzz/util.js. Di app.clincoo.buzz path itu beda asal dan sering 404.

Gunakan specifier relatif atau import map untuk berkas proyek. URL mutlak hanya untuk pustaka berversi yang memang dihosting terpisah.

Specifier relatif dihitung dari URL modul, bukan dari halaman HTML. File di dalam folder components harus naik satu tingkat dengan ../.

Minta AI mengganti impor mutlak internal menjadi relatif dan daftar path yang tidak ketemu. Jangan biarkan AI mengarang nama file.

Muat ulang pratinjau blog.clincoo.buzz setelah pindah berkas. Graf impor harus hijau sebelum Anda terbitkan.
