Use Relative Specifiers in Clincoo Modules, Do Not Mix Absolute URLs

An import of ./util.js follows the page. An absolute URL to another host breaks when preview moves from the editor to the app domain.

Artikel ini tersedia dalam: English · Indonesia

Clincoo snippets sometimes import https://editor.clincoo.buzz/util.js. On app.clincoo.buzz that path is a different origin and often 404s.

Use a relative specifier or an import map for project files. Absolute URLs are only for versioned libraries that are hosted separately on purpose.

A relative specifier is resolved from the module URL, not from the HTML page. A file inside components must go up one level with ../.

Ask AI to replace internal absolute imports with relative ones and list paths that do not resolve. Do not let AI invent file names.

Reload the blog.clincoo.buzz preview after moving a file. The import graph should be clean before you publish.
