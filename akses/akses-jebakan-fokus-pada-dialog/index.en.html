Trap Focus Inside a Clincoo Modal Dialog

A dialog without a focus trap lets Tab escape onto the hidden page behind it.

This article is available in: Indonesia · English

When a modal opens in editor.clincoo.buzz, Tab must cycle inside the dialog: title, body, close.

Prefer the native dialog element. If custom, store the last focused node and restore it on close.

Escape must close. Backdrop click may close only if a matching close button exists.

Reject an overlay that sets pointer-events none on the page behind but still allows Tab.

Test keyboard-only before you publish to app.clincoo.buzz.
