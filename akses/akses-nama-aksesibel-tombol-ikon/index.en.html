Give Clincoo Icon Buttons an Accessible Name

A button that is only SVG without text or aria-label is announced as an empty button.

This article is available in: Indonesia · English

Close, hamburger, and copy icons often have no name. The screen reader only says button.

Add an aria-label that states the action: Close dialog, Open menu, Copy link — not the SVG file name.

If visual text is visually hidden with CSS, do not use display:none or it will not be read.

Ask AI to review accessible names, not to replace the button with a clickable div.

Keep the icon label list in the app.clincoo.buzz design tokens.
