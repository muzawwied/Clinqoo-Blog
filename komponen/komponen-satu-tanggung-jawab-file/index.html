Satu File Komponen Clincoo, Satu Tanggung Jawab

Jangan campur kartu, modal, dan fetch dalam satu file. Pecah supaya debug di editor Clincoo tidak menyentuh tiga fitur sekaligus.

Artikel ini tersedia dalam: Indonesia · English

File raksasa di workspace Clincoo sulit di-review. Satu perubahan tombol merusak modal karena semuanya hidup bersama.

Pisahkan markup kartu, logika buka-tutup, dan pemanggilan API. Nama file harus menjelaskan tugas, bukan 'utils2'.

Uji tiap potongan di pratinjau editor.clincoo.buzz sebelum digabung. Kalau satu potong gagal, stack trace lebih pendek.

Minta AI memecah file, bukan menulis ulang seluruh halaman. Sertakan daftar fungsi yang harus tetap publik.

Struktur ini menjaga app.clincoo.buzz dan artikel di blog.clincoo.buzz tetap bisa dilacak per bagian.
