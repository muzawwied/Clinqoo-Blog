Mark Clincoo Accordions with Honest aria-expanded

FAQ panels that only toggle a CSS class are invisible to screen readers. Sync aria-expanded and panel ids.

This article is available in: Indonesia · English

Clincoo accordions are often a clicked heading plus a hidden div. The open class changes, but the control has no aria-expanded. Screen readers cannot tell whether a panel is open.

Use a real button, not a clickable div. Each button has aria-controls pointing at the panel id. When open, aria-expanded is true; when closed, false. Do not duplicate ids when copying blocks in editor.clincoo.buzz.

Decide whether only one panel stays open. If so, close the others and update their attributes in one function. Escape may close the active panel so the pattern matches modals.

Ask AI to add only the attributes and toggle handler. Paste one FAQ item as the example. Test with the keyboard: Enter and Space must open the same panel as a click.

An accordion that tells assistive tech the truth feels like a component, not decoration. Deploy to app.clincoo.buzz after preview confirms no panel stays open without a label.
