Mark Clincoo Breadcrumbs as Navigation with aria-current

Plain-text trails do not help screen readers. Wrap breadcrumbs in nav, list links, and set aria-current on the active page.

This article is available in: Indonesia · English

Many Clincoo templates render Home / Category / Page as plain spans. Users see a trail, but assistive tech does not know it is hierarchical navigation. The current page is often still a clickable link with no purpose.

Wrap the trail in a nav with aria-label Breadcrumb. Fill it with an ordered list of links. The last item uses aria-current="page" and may be text instead of a link. Hide visual separators from the accessibility tree so they are not spoken as odd characters.

Keep the order from the site root to the current page. Do not expose draft or private folders from editor.clincoo.buzz. If AI generates the trail, ask only for the nav structure plus public sitemap links.

Test with Tab: every level except the current page must be focusable. A screen reader should announce navigation, then the list, then the current page. If the page has two nav regions, their labels must differ from the main menu.

An honest breadcrumb shortens the path back without replacing the menu. Deploy to app.clincoo.buzz after preview confirms the trail does not clip the title or stack poorly on a narrow screen.
