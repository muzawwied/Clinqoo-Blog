Hapus Draf Clincoo dari Perangkat Bersama sebelum Logout

Kafe dan laptop kantor menyimpan pratinjau halaman klien di cache dan IndexedDB setelah tab ditutup.

Artikel ini tersedia dalam: Indonesia · English

Setelah edit di editor.clincoo.buzz di perangkat bersama, logout saja tidak selalu menghapus draf lokal.

Tambah tombol hapus data lokal: localStorage, sessionStorage, dan IndexedDB milik origin itu.

Ingatkan di UI jika halaman dibuka di mode biasa, bukan jendela pribadi.

Minta AI meninjau fungsi wipe, bukan cara menyalin seluruh origin ke USB.

Clincoo di app.clincoo.buzz dan blog.clincoo.buzz menganggap perangkat bersama sebagai risiko privasi default.
