Set a Strict Referrer-Policy on Clincoo Sites

A draft URL or a token in the query can leak to a third-party host through the Referer header.

This article is available in: Indonesia · English

A page on editor.clincoo.buzz that links to third-party analytics or fonts sends Referer by default.

Use referrer-policy: strict-origin-when-cross-origin or stricter on both the meta tag and the host header.

Do not put a token or draft id in the query string if the link can be clicked outbound.

Paste the head plus headers to AI. Ask for one policy, not a confusing list of ten values.

Clincoo on blog.clincoo.buzz and app.clincoo.buzz keeps internal URLs internal.
