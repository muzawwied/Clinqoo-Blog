Hapus Query Sensitif dari URL Clincoo setelah Login

Token di ?access= tetap ada di history, log server, dan screenshot bilah alamat.

Artikel ini tersedia dalam: Indonesia · English

Alur auth yang mendarat di app.clincoo.buzz dengan token di query harus segera diganti ke history.replaceState tanpa parameter.

Cek document.referrer dan analytics: query ikut terekam jika tidak dipangkas.

Jangan bagikan URL pratinjau editor.clincoo.buzz yang masih memuat session di query.

Tempel lokasi URL plus kode router ke AI. Minta diff kecil, bukan rewrite auth.

Clincoo di blog.clincoo.buzz mengajarkan URL bersih sebagai bagian privasi, bukan hanya SEO.
