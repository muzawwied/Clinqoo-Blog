Strip Sensitive Query Params from Clincoo URLs after Login

A token in ?access= stays in history, server logs, and address-bar screenshots.

This article is available in: Indonesia · English

An auth flow that lands on app.clincoo.buzz with a token in the query must immediately history.replaceState without the parameter.

Check document.referrer and analytics: the query is recorded if you do not strip it.

Do not share an editor.clincoo.buzz preview URL that still carries a session in the query.

Paste the URL location plus router code to AI. Ask for a small diff, not an auth rewrite.

Clincoo on blog.clincoo.buzz treats a clean URL as privacy work, not only SEO.
