Jangan Log Token atau Cookie di Konsol Clincoo

console.log token memaparkan sesi saat share screen atau saat AI membaca screenshot error.

Artikel ini tersedia dalam: Indonesia · English

Saat debug di editor.clincoo.buzz, token di console.log ikut terekam di rekaman layar dan issue tracker.

Log hanya prefix pendek atau boolean "ada token". Jangan tempel Authorization header utuh ke chat AI.

Bersihkan konsol sebelum screenshot untuk blog.clincoo.buzz atau tiket. Revoke token yang sempat bocor.

Minta AI meninjau kode log, bukan menjelaskan cara menyimpan token di localStorage tanpa batas.

Clincoo di app.clincoo.buzz memperlakukan sesi sebagai data sensitif, bukan teks debug.
