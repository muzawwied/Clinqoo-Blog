Samarkan Data Form sebelum Screenshot Bug Clincoo

Laporan bug yang berisi nama, email, atau nomor klien menyebar lebih jauh dari yang Anda kira.

Setel Referrer-Policy Ketat di Situs Clincoo

URL draf atau token di query bisa bocor ke domain luar lewat header Referer.

Hapus Query Sensitif dari URL Clincoo setelah Login

Token di ?access= tetap ada di history, log server, dan screenshot bilah alamat.

Jangan Simpan PII Klien di localStorage Clincoo

Nama, email, dan nomor telepon di localStorage ikut tercopy saat share profil browser atau backup perangkat.

Batasi Cookie Pihak Ketiga di Halaman Clincoo

Widget chat dan analitik menanam cookie lintas situs yang tidak Anda butuhkan untuk merilis halaman.

Minta Izin Kamera dan Mikrofon dengan Alasan Jelas di Clincoo

Prompt izin tanpa konteks membuat pengunjung menolak, lalu fitur rekam di halaman Anda terlihat rusak.

Hapus Draf Clincoo dari Perangkat Bersama sebelum Logout

Kafe dan laptop kantor menyimpan pratinjau halaman klien di cache dan IndexedDB setelah tab ditutup.

Kirim Analitik Clincoo tanpa Menyimpan IP Mentah

Log akses yang menyimpan IP lengkap menjadi data pribadi meski Anda hanya ingin hitung pengunjung.
