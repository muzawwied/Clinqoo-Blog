Batasi API Browser dengan Permissions-Policy di Clincoo

Halaman yang tidak merekam tetap bisa diakses kamera jika header izin terlalu longgar.

Artikel ini tersedia dalam: Indonesia · English

Tanpa Permissions-Policy, iframe atau skrip di editor.clincoo.buzz bisa meminta kamera, mikrofon, atau geolokasi.

Setel header Permissions-Policy agar camera=(), microphone=(), geolocation=() kecuali halaman itu memang butuh.

Uji di DevTools: fitur yang diblokir harus gagal jelas, bukan diam-diam.

Tempel header plus meta ke AI. Minta satu kebijakan ketat, bukan daftar API yang tidak Anda pakai.

Clincoo di app.clincoo.buzz dan blog.clincoo.buzz memberi akses perangkat hanya saat alur produk memintanya.
