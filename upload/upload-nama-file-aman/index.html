Rapikan Nama File Unggah agar Aman di Clincoo

Nama file dari perangkat pengguna bisa berisi spasi, unicode, atau path. Normalisasi sebelum disimpan.

Artikel ini tersedia dalam: Indonesia · English

File Foto dari HP (1).JPG memecah URL aset setelah deploy ke app.clincoo.buzz. Karakter spasi dan tanda kurung tidak ramah CDN.

Di editor.clincoo.buzz, turunkan nama ke huruf kecil, ganti spasi jadi tanda hubung, dan buang karakter di luar a-z 0-9 titik dan strip.

Jangan percaya path di file.name. Potong hanya basename agar ../ tidak lolos ke folder publik.

Tambahkan stempel waktu atau hash pendek jika dua unggahan memakai nama yang sama supaya berkas lama tidak tertimpa diam-diam.

Minta AI hanya menulis fungsi sanitasi nama. Tempel baris yang membaca file.name saat ini.
