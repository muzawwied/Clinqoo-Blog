Sanitize Upload Filenames in Clincoo

Filenames from user devices can include spaces, unicode, or paths. Normalize them before you store anything.

This article is available in: Indonesia · English

A file named Foto from phone (1).JPG breaks asset URLs after deploy to app.clincoo.buzz. Spaces and parentheses are unfriendly to CDNs.

In editor.clincoo.buzz, lowercase the name, turn spaces into hyphens, and drop characters outside a-z 0-9 dot and dash.

Do not trust a path inside file.name. Keep only the basename so ../ never reaches the public folder.

Add a timestamp or short hash when two uploads share a name so the older file is not silently overwritten.

Ask the AI to write only a name-sanitize function. Paste the line that currently reads file.name.
