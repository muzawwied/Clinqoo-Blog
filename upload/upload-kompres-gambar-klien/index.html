Kompres Gambar di Klien sebelum Unggah Clincoo

Foto kamera 8 MB memperlambat form. Canvas atau createImageBitmap merampingkan berkas sebelum dikirim.

Artikel ini tersedia dalam: Indonesia · English

Banyak pengguna mengunggah foto asli dari ponsel ke form di editor.clincoo.buzz. Tanpa kompresi, progress bar lama dan kuota hosting cepat habis.

Gambar file ke bitmap, gambar ulang ke canvas dengan lebar maksimal yang masuk akal, lalu canvas.toBlob dengan quality 0.8. Ganti File asli di FormData dengan blob hasil.

Jaga rasio aspek. Jangan paksa kotak jika produk butuh foto landscape. Simpan nama file asal agar log server tetap terbaca.

Tampilkan ukuran sebelum dan sesudah di pratinjau. Pengguna lebih rela menunggu kompres singkat daripada gagal di tengah unggah.

Minta AI memakai createImageBitmap plus canvas, bukan library besar. Tolak saran yang mengunggah file asli bersamaan dengan versi kompres.
