Pakai accept dan capture pada Input Unggah Clincoo

Pemilih file tanpa petunjuk menampilkan semua berkas. Atribut accept dan capture menuntun kamera atau galeri.

Artikel ini tersedia dalam: Indonesia · English

Input file kosong di form Clincoo membuka semua tipe. Pengguna lalu memilih PDF untuk slot foto. Atribut accept="image/jpeg,image/png,image/webp" memangkas daftar di banyak sistem.

accept bukan keamanan. Tetap cek type dan magic bytes di klien serta server. Beberapa peramban mengabaikan filter atau membiarkan "Semua file".

Pada ponsel, capture="environment" atau capture="user" dapat membuka kamera langsung. Pakai ini hanya jika alur memang butuh foto baru, bukan unggah dari galeri.

Tulis label yang selaras: "Foto produk (JPG atau PNG)". Jangan andalkan dialog sistem saja untuk menjelaskan aturan.

Minta AI menambah accept sesuai kebutuhan halaman. Tolak capture pada input yang juga dipakai di desktop jika itu membingungkan pengguna.
