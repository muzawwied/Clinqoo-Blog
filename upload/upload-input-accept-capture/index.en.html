Use accept and capture on Clincoo Upload Inputs

A file picker with no hint lists every file. The accept and capture attributes steer the camera or gallery.

This article is available in: Indonesia · English

A bare file input in a Clincoo form opens every type. People then pick a PDF for a photo slot. accept="image/jpeg,image/png,image/webp" trims the list on many systems.

accept is not security. Still check type and magic bytes on the client and the server. Some browsers ignore the filter or keep an All files option.

On phones, capture="environment" or capture="user" can open the camera at once. Use this only when the flow needs a new photo, not a gallery upload.

Write a matching label: "Product photo (JPG or PNG)". Do not rely on the system dialog alone to explain the rule.

Ask the AI to add accept that matches the page. Reject capture on an input also used on desktop if that confuses people.
