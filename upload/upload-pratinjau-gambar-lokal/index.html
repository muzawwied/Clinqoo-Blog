Tampilkan Pratinjau Gambar Lokal sebelum Unggah Clincoo

Pengguna baru tahu salah file setelah menunggu unggahan. Object URL memberi pratinjau instan.

Artikel ini tersedia dalam: Indonesia · English

Di editor.clincoo.buzz, unggah logo tanpa pratinjau sering terkirim file yang salah rasio. Pengunjung baru sadar setelah halaman live di app.clincoo.buzz.

Pakai URL.createObjectURL pada File dari input. Tampilkan hasilnya di elemen img di samping form sebelum FormData dikirim.

Setelah pratinjau tidak dipakai, panggil URL.revokeObjectURL agar memori browser tidak menumpuk saat pengguna memilih ulang.

Batasi pratinjau ke image/*. File PDF atau ZIP cukup tampilkan nama dan ukuran, bukan thumbnail palsu.

Minta AI Clincoo hanya menambahkan handler change dan satu img pratinjau. Jangan biarkan AI menulis ulang seluruh form unggah.
