Show a Local Image Preview before Clincoo Upload

Users only notice the wrong file after waiting for the upload. An object URL gives an instant preview.

This article is available in: Indonesia · English

In editor.clincoo.buzz, uploading a logo without a preview often sends the wrong aspect ratio. Visitors notice only after the page is live on app.clincoo.buzz.

Use URL.createObjectURL on the File from the input. Show it in an img next to the form before FormData is sent.

When the preview is no longer needed, call URL.revokeObjectURL so memory does not pile up when the user picks again.

Limit the thumbnail to image/*. For PDF or ZIP, show the name and size instead of a fake thumbnail.

Ask Clincoo AI to add only the change handler and one preview img. Do not let it rewrite the whole upload form.
