Batasi Jumlah File per Unggah di Form Clincoo

Input multiple tanpa batas membuat antrean unggah meledak. Tetapkan kuota file di klien sebelum request dikirim.

Artikel ini tersedia dalam: Indonesia · English

Atribut multiple pada input file di editor.clincoo.buzz memudahkan, tetapi tanpa kuota pengguna bisa menyeret puluhan berkas sekaligus. Server lalu menolak atau timeout tanpa pesan yang jelas.

Setelah change atau drop, baca FileList.length. Jika melebihi batas — misalnya lima foto produk — potong daftar atau tolak seluruh batch dan jelaskan kuota di teks error.

Jangan andalkan validasi server saja. Pemeriksaan di klien menghemat bandwidth dan menjaga pratinjau tetap ringan.

Tampilkan sisa kuota di dekat zona unggah: "2 dari 5 file". Angka ini lebih mudah dipercaya daripada peringatan setelah gagal.

Minta AI menambah konstanta MAX_FILES di satu skrip form. Jangan biarkan AI menghapus atribut multiple jika produk memang butuh beberapa berkas.
