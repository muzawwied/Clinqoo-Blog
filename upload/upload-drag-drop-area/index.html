Area Seret-Lepas File di Form Unggah Clincoo

Input file kecil sulit dipakai di desktop. Zona drop yang tetap punya input tersembunyi lebih ramah.

Artikel ini tersedia dalam: Indonesia · English

Tombol Pilih file di editor.clincoo.buzz cukup untuk ponsel, tetapi di desktop pengguna sering ingin menyeret berkas dari folder.

Tangani dragover dengan preventDefault agar drop tidak membuka file di tab baru. Ambil dataTransfer.files lalu jalankan validasi tipe yang sama.

Jangan buang input type=file. Zona drop adalah pelengkap; keyboard dan pembaca layar tetap memakai input asli.

Ubah border zona saat dragenter dan kembalikan di dragleave supaya status terlihat tanpa mengandalkan warna saja.

Minta AI menambah listener drop pada satu div pembungkus. Jangan biarkan AI menghapus label input yang sudah ada.
