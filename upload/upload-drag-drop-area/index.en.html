Add a Drag-and-Drop Zone to Clincoo Uploads

A tiny file input is hard to use on desktop. A drop zone that still keeps a hidden input is kinder.

This article is available in: Indonesia · English

A Choose file button in editor.clincoo.buzz is fine on a phone, but on desktop people often want to drag a file from a folder.

Handle dragover with preventDefault so the drop does not open the file in a new tab. Read dataTransfer.files and run the same type checks.

Do not remove input type=file. The drop zone is extra; keyboard and screen reader users still use the real input.

Change the zone border on dragenter and restore it on dragleave so state is visible without color alone.

Ask the AI to add drop listeners on one wrapper div. Do not let it delete the existing input label.
