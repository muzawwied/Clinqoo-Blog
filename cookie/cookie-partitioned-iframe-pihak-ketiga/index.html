Set Cookie Partitioned untuk Iframe Pihak Ketiga di Clincoo

Cookie di iframe embed tanpa Partitioned ditolak browser baru. Tambah atribut itu hanya jika embed memang butuh sesi.

Artikel ini tersedia dalam: Indonesia · English

Pratinjau app.clincoo.buzz yang menanam iframe pembayaran sering kehilangan sesi. Browser memotong cookie pihak ketiga tanpa atribut Partitioned.

Di editor.clincoo.buzz, tambahkan Partitioned pada Set-Cookie embed, bersama Secure dan SameSite=None. Jangan tempel atribut itu ke cookie sesi induk Clincoo.

Buka DevTools, tab Application, lalu muat ulang iframe. Cookie yang ditolak muncul di Network sebagai blocked, bukan sebagai bug JavaScript.

Minta AI mengubah satu baris Set-Cookie. Tempel header asli, bukan seluruh file auth.

Uji login embed di blog.clincoo.buzz setelah publish. Clincoo tidak menambahkan Partitioned otomatis.
