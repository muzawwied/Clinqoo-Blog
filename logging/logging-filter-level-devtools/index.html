Saring Level Console di DevTools saat Debug Skrip Clincoo

console.log bercampur dengan pesan browser. Saring Default levels supaya debug, warn, dan error Clincoo terlihat.

Artikel ini tersedia dalam: Indonesia · English

Saat pratinjau situs Clincoo dibuka, konsol penuh pesan ekstensi dan peringatan pihak ketiga. Pesan skrip kamu tenggelam.

Di Chrome DevTools, buka panel Console lalu filter Default levels. Matikan Verbose jika kamu hanya butuh warn dan error dari file yang kamu edit di editor.clincoo.buzz.

Tambahkan prefiks tetap seperti [clincoo] pada objek log. Kotak Filter teks DevTools bisa menyorot prefiks itu tanpa menghapus kode.

Jangan biarkan console.log produksi di halaman publik. Ganti ke console.debug untuk jejak pengembangan agar mudah dimatikan saat rilis subdomain.

Setelah perbaikan, kosongkan konsol dan muat ulang pratinjau. Log yang tersisa harus bisa dijelaskan dalam satu kalimat.
