Redaksi Query String Sebelum console.log di Clincoo

URL yang dicatat sering membawa token di query. Hapus parameter rahasia sebelum menulis ke konsol.

Artikel ini tersedia dalam: Indonesia · English

Di editor.clincoo.buzz, debug alur undangan sering menempel location.href ke console.log. Query bisa berisi token sekali pakai atau email.

Salin URL ke variabel baru, lalu hapus parameter token, code, email, dan session sebelum log. Sisakan path dan status.

Jangan log document.cookie atau header Authorization di event error. Cukup status kode dan nama endpoint.

Saat minta bantuan AI, tempel URL yang sudah di-redaksi. Jangan kirim tautan produksi utuh dari app.clincoo.buzz.

Cek ulang dengan mencari console.log(location dan console.log(window.location di proyek sebelum rilis.
