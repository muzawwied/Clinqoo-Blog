Redact the Query String Before console.log in Clincoo

Logged URLs often carry a token in the query. Strip secret parameters before writing to the console.

This article is available in: Indonesia · English

On editor.clincoo.buzz, invite-flow debugging often pastes location.href into console.log. The query can hold a one-time token or an email.

Copy the URL to a new variable, then drop token, code, email, and session before logging. Keep the path and status.

Do not log document.cookie or the Authorization header in an error event. Status code and endpoint name are enough.

When asking an AI for help, paste the redacted URL. Do not send a full production link from app.clincoo.buzz.

Recheck by searching for console.log(location and console.log(window.location before release.
