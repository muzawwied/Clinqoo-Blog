Do Not Print Session Tokens in the Clincoo Console

console.log on a session object often includes the token. Log only status and length, not the secret value.

This article is available in: Indonesia · English

While debugging login in the app.clincoo.buzz preview, people often write console.log(session) and forget to remove it.

A session object can hold a token, email, or account id. DevTools and bug recordings then keep that value.

A safe replacement log: login status, token length, and expiry time. Do not write the full token.

Before asking for help in editor.clincoo.buzz, remove secret log lines and paste only the error without an Authorization header.

Recheck by searching for token, password, and bearer in the project folder before deploy.
