Jangan Cetak Token Sesi di Konsol Clincoo

console.log pada objek sesi sering ikut membawa token. Log hanya status dan panjang, bukan nilai rahasia.

Artikel ini tersedia dalam: Indonesia · English

Saat debug login di pratinjau app.clincoo.buzz, banyak orang menulis console.log(session) lalu lupa menghapusnya.

Objek sesi bisa berisi token, email, atau id akun. Konsol DevTools dan rekaman bug lalu menyimpan nilai itu.

Log pengganti yang aman: status login, panjang token, dan waktu kedaluwarsa. Jangan tulis token utuh.

Sebelum minta bantuan di editor.clincoo.buzz, hapus baris log rahasia dan tempel hanya pesan error tanpa header Authorization.

Ulangi cek dengan mencari kata token, password, dan bearer di folder proyek sebelum deploy.
