Kolom Grid Responsif dengan minmax di Clincoo

Jangan hardcode tiga kolom. Pakai repeat(auto-fit, minmax) agar kartu merapat.

Artikel ini tersedia dalam: Indonesia · English

Kartu template di editor.clincoo.buzz pecah di layar kecil jika grid-template-columns: 1fr 1fr 1fr dipaksa.

Gunakan grid-template-columns: repeat(auto-fit, minmax(16rem, 1fr)) plus gap. Kartu turun baris tanpa media query ekstra.

Jika satu kartu melebar aneh, cek min-width pada anak. minmax kalah jika anak punya min-width lebih besar.

Kirim screenshot layout pecah ke AI bersama aturan grid. Jangan minta framework baru hanya untuk tiga kartu.

Uji di app.clincoo.buzz lalu bandingkan listing di blog.clincoo.buzz agar ritme kolom sama.
