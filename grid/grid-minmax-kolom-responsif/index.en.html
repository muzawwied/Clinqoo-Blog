Responsive Grid Columns with minmax in Clincoo

Do not hardcode three columns. Use repeat(auto-fit, minmax) so cards pack cleanly.

This article is available in: Indonesia · English

Template cards on editor.clincoo.buzz break on small screens if grid-template-columns: 1fr 1fr 1fr is forced.

Use grid-template-columns: repeat(auto-fit, minmax(16rem, 1fr)) plus gap. Cards wrap without extra media queries.

If one card stretches oddly, check min-width on children. minmax loses when a child min-width is larger.

Send a screenshot of the broken layout to AI with the grid rule. Do not ask for a new framework for three cards.

Test on app.clincoo.buzz then compare the listing on blog.clincoo.buzz so column rhythm matches.
