Bedakan justify-items dan justify-content pada Grid Clincoo

justify-content menggeser seluruh track, bukan isi sel. Kartu yang tetap menempel kiri biasanya butuh justify-items.

Artikel ini tersedia dalam: Indonesia · English

Di pratinjau editor.clincoo.buzz, grid tiga kolom sudah rata, tetapi ikon di dalam kartu tetap kiri. Mengubah justify-content tidak memindahkan ikon.

justify-content mengatur ruang di antara track. justify-items mengatur perataan isi tiap sel. Untuk ikon, pakai justify-items: center pada grid, atau justify-self pada item.

Nyalakan overlay grid di DevTools. Jika track sudah penuh, content tidak punya sisa ruang untuk digeser.

Tempel CSS grid ke AI. Minta ganti properti yang salah, bukan menulis ulang template-areas.

Uji lebar 360 dan 1200 di app.clincoo.buzz. Clincoo menyimpan CSS yang kamu tulis.
