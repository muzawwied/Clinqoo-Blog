Align Clincoo Card Titles with subgrid

Independent nested grids make card titles and buttons miss the same line. subgrid reuses the parent tracks.

Indonesia · English

Service card lists on Clincoo pages often use display:grid on the container and again on each card. Without subgrid, title heights differ so the Learn buttons land at random. Visitors scan a broken row.

subgrid lets a card borrow parent rows: one for the image, one for the title, one for the summary, one for the action. A two-line title compresses the summary instead of pushing only that card’s button down.

Set grid-template-rows: subgrid on the card and make every card span the same number of parent rows. Support exists in modern Chromium and Firefox; keep a stacked fallback inside @supports.

Test in desktop preview first, then narrow to one column. Subgrid does not replace a one-column media query on phones; it only tidies cells while cards sit side by side.

If older browsers are a client requirement, limit subgrid to new marketing pages and leave older templates on a fixed min-card height.
