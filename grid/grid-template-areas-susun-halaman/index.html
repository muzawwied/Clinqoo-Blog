Susun Halaman Clincoo dengan grid-template-areas

Angka kolom mudah tertukar saat header dan sidebar pindah di mobile. Nama area membuat susunan terbaca di CSS.

Artikel ini tersedia dalam: Indonesia · English

Di editor.clincoo.buzz layout dashboard sering memakai grid-column angka. Saat mobile, angka itu salah dan sidebar menimpa konten.

Beri nama pada anak: header, nav, main, aside. Di induk, tulis grid-template-areas dengan kutip per baris.

Di media query sempit, tulis ulang areas menjadi satu kolom. Jangan mengulang angka span yang berbeda makna.

Minta AI menggambar areas dalam komentar CSS sebelum mengubah markup. Tolak solusi yang memakai position absolute untuk sidebar.

Uji di lebar 320 dan 1024 pada pratinjau app.clincoo.buzz. Dokumentasikan peta area di blog.clincoo.buzz agar revisi berikutnya tidak menebak.
