Lay Out a Clincoo Page with grid-template-areas

Column numbers get swapped when the header and sidebar move on mobile. Named areas make the layout readable in CSS.

This article is available in: Indonesian · English

On editor.clincoo.buzz a dashboard layout often uses numeric grid-column. On mobile those numbers are wrong and the sidebar covers the content.

Name the children: header, nav, main, aside. On the parent, write grid-template-areas with one quoted row per line.

In a narrow media query, rewrite the areas into one column. Do not repeat span numbers that mean something else.

Ask AI to sketch the areas in a CSS comment before changing markup. Reject a fix that uses position absolute for the sidebar.

Test at 320 and 1024 in the app.clincoo.buzz preview. Document the area map on blog.clincoo.buzz so the next revision does not guess.
