Use srcset on Clincoo Images so Phones Do Not Download the Desktop File

A single 2400px hero hurts phones. srcset and sizes pick a width that matches the screen.

This article is available in: Indonesia · English

Clincoo heroes often use one wide JPEG. On a phone the browser still downloads that file even if only 360px is shown. The page feels slow even when CSS already sets max-width 100%.

In editor.clincoo.buzz, prepare two or three widths (for example 640, 1280, 1920) and write srcset with w descriptors. Add sizes so the browser knows display width, not only screen resolution.

Do not rely on srcset without sizes. Without sizes the browser assumes the image is as wide as the viewport and may still pick the largest file.

Ask AI to change only the hero img tag. Paste the existing markup; do not regenerate the whole gallery.

Test with DevTools throttling. Clincoo that picks a matching file keeps app.clincoo.buzz light on mobile networks.
