Pakai srcset pada Gambar Clincoo agar Ponsel Tidak Mengunduh File Desktop

Satu file hero 2400px membebani HP. srcset dan sizes memilih lebar yang sesuai layar.

Artikel ini tersedia dalam: Indonesia · English

Hero Clincoo sering memakai satu JPEG lebar. Di HP, browser tetap mengunduh file itu meski yang tampil hanya 360px. Halaman terasa lambat padahal CSS sudah max-width 100%.

Di editor.clincoo.buzz, siapkan dua atau tiga lebar (misalnya 640, 1280, 1920) lalu tulis srcset dengan descriptor w. Tambah sizes agar browser tahu lebar tampilan, bukan hanya resolusi layar.

Jangan andalkan srcset tanpa sizes. Tanpa sizes, browser mengira gambar selebar viewport penuh dan bisa tetap mengambil file terbesar.

Minta AI hanya mengubah tag img hero. Tempel markup yang ada; jangan regenerate seluruh galeri.

Uji di DevTools throttling. Clincoo yang memilih file sesuai lebar membuat app.clincoo.buzz terasa ringan di jaringan seluler.
