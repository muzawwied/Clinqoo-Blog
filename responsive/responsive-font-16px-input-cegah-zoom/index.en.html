Set Input Font to 16px so iOS Does Not Zoom a Clincoo Form

Inputs under 16px make iOS Safari zoom the page on focus. The Clincoo form shifts and is hard to dismiss.

This article is available in: Indonesia · English

Forms in editor.clincoo.buzz often use 14px type so they fit a card. On iPhone, focusing an input triggers automatic zoom.

Set font-size to at least 16px on input, select, and textarea. Do not force user-scalable=no on the viewport. That blocks zoom people need.

If the label feels large, shrink the label, not the field. Touch size stays comfortable and the page does not jump.

Test in the app.clincoo.buzz preview device mode, then on a real phone: tap an input and confirm the page scale does not change.

Paste the input CSS into AI and ask only to raise the field font. Do not ask it to lock the viewport.
