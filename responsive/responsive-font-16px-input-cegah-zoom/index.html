Set Font Input 16px agar iOS Tidak Zoom di Form Clincoo

Input di bawah 16px membuat Safari iOS memperbesar halaman saat fokus. Form Clincoo jadi bergeser dan sulit ditutup.

Artikel ini tersedia dalam: Indonesia · English

Form di editor.clincoo.buzz sering memakai font 14px agar muat di kartu. Di iPhone, fokus pada input memicu zoom otomatis.

Set font-size minimal 16px pada input, select, dan textarea. Jangan memaksa user-scalable=no di viewport. Itu menghalangi pembesaran yang dibutuhkan pengguna.

Jika label terasa besar, kecilkan label, bukan field. Ukuran sentuh tetap nyaman dan halaman tidak meloncat.

Uji di pratinjau app.clincoo.buzz dengan mode perangkat, lalu di ponsel asli: ketuk input, pastikan skala halaman tidak berubah.

Tempel aturan CSS input ke AI dan minta hanya menaikkan font field. Jangan minta mengunci viewport.
