Restyle Clincoo Cards with Container Queries, Not Viewport Width Alone

Media queries watch the window. Container queries adapt a card in a narrow sidebar even on a wide desktop.

Artikel ini tersedia dalam: Indonesia · English

Clincoo pricing grids often live in the main column and in a sidebar. A 768px media query forces two columns in a 280px sidebar and clips the text.

Set container-type: inline-size on the card wrapper, then write @container (min-width: 360px) { .card { grid-template-columns: 1fr 1fr; } }. Cards follow the parent width, not the editor window.

Do not drop viewport media queries. Use both: viewport for nav and hero, container for movable components. Keep a one-column fallback if container queries are missing.

Test in editor.clincoo.buzz by resizing the preview pane, not only the browser window. Sidebar cards should collapse to one column while the hero stays wide.

Clincoo stores the CSS you write. Container queries make components on app.clincoo.buzz safe to reuse in different layouts without a new global breakpoint.
