Ubah Tata Kartu Clincoo dengan Container Query, Bukan Hanya Lebar Viewport

Media query melihat jendela. Container query menyesuaikan kartu di sidebar sempit meski layar desktop lebar.

Artikel ini tersedia dalam: Indonesia · English

Grid harga Clincoo sering hidup di kolom utama dan di sidebar. Media query min-width 768px memaksa dua kolom di sidebar yang hanya 280px, sehingga teks terpotong.

Set container-type: inline-size pada pembungkus kartu, lalu tulis @container (min-width: 360px) { .card { grid-template-columns: 1fr 1fr; } }. Kartu mengikuti lebar induk, bukan lebar jendela editor.

Jangan buang media query viewport. Pakai keduanya: viewport untuk navigasi dan hero, container untuk komponen yang bisa dipindah. Fallback satu kolom tetap ada jika container query tidak didukung.

Uji di editor.clincoo.buzz dengan meresize panel pratinjau, bukan hanya jendela browser. Kartu di sidebar harus turun ke satu kolom sementara hero tetap lebar.

Clincoo menyimpan CSS yang kamu tulis. Container query membuat komponen di app.clincoo.buzz aman dipakai ulang di layout berbeda tanpa breakpoint global baru.
