Pakai Favicon SVG Plus PNG Cadangan di Proyek Clincoo

SVG tajam di layar padat piksel, tapi tidak semua tab mendukung. PNG cadangan menjaga ikon tetap muncul.

Artikel ini tersedia dalam: Indonesia · English

Tab pratinjau Clincoo terlihat kosong di browser lama karena hanya SVG yang di-link.

Di editor.clincoo.buzz, tautkan rel icon type image/svg+xml lalu PNG 32 sebagai cadangan.

Jangan andalkan SVG yang berisi skrip atau font eksternal. Ikon harus file datar.

Minta AI menulis dua tag link rel icon. Tempel head saja, bukan seluruh template.

Ikon tajam di app.clincoo.buzz membedakan tab editor dari tab hasil unduhan.
