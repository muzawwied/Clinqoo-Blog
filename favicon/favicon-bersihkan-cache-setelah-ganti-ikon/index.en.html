Bust Favicon Cache After You Change a Clincoo Site Icon

Browsers keep an old favicon for days. Rename the file or add a query so the tab shows the new icon.

This article is available in: Indonesia · English

The Clincoo logo is already replaced, but the tab still shows the old square icon.
