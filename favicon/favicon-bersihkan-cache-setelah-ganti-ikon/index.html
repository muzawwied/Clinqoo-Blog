Bersihkan Cache Favicon Setelah Ganti Ikon Situs Clincoo

Browser menahan favicon lama berhari-hari. Ganti nama file atau query agar tab menampilkan ikon baru.

Artikel ini tersedia dalam: Indonesia · English

Logo Clincoo sudah diganti, tapi tab masih menampilkan ikon kotak lama.

Di editor.clincoo.buzz, unggah file dengan nama baru atau tambah query versi pada href.

Jangan harap hard refresh selalu cukup. Beberapa browser mengunci favicon per origin.

Minta AI menambahkan ?v=2 pada tautan icon. Tempel satu baris head.

Tab app.clincoo.buzz yang ikonnya akurat mengurangi salah buka proyek.
