Kumpulkan Semua Ukuran Favicon Clincoo dalam Satu Folder

Ikon tersebar di root, assets, dan unggahan acak. Satu folder icons memudahkan ganti merek sekaligus.

Artikel ini tersedia dalam: Indonesia · English

Proyek Clincoo punya favicon.ico di root, png di assets, dan sisa unggahan tanpa nama.

Di editor.clincoo.buzz, buat folder icons/ dan pindahkan 32, 180, 192 ke sana. Perbarui href.

Jangan biarkan dua file bernama logo.png yang isinya berbeda. Tab akan acak.

Minta AI merapikan path ikon di head. Tempel daftar file folder, bukan seluruh repo.

Aset rapi di app.clincoo.buzz mempercepat ganti merek tanpa merusak tab lama.
