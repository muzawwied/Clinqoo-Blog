Sediakan Favicon PNG 32 dan ICO Bersamaan di Situs Clincoo

Satu file .ico lama tidak cukup untuk tab modern. PNG 32 menjaga ketajaman, ICO menjaga browser lama.

Artikel ini tersedia dalam: Indonesia · English

Tab proyek Clincoo menampilkan ikon pecah di Chrome dan kosong di Safari. Hanya ada favicon.ico 16 piksel.

Di editor.clincoo.buzz, unggah PNG 32×32 dan ICO cadangan. Tautkan keduanya di head, PNG lebih dulu.

Jangan andalkan file di root tanpa link rel. Beberapa host Clincoo tidak men-serve /favicon.ico otomatis.

Minta AI menyusun dua tag link rel icon. Tempel head halaman, bukan seluruh template.

Ikon jelas di app.clincoo.buzz membantu membedakan tab editor dan tab pratinjau.
