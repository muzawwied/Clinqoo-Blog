Ship Both a 32 PNG Favicon and an ICO on a Clincoo Site

A single old .ico is not enough for modern tabs. A 32 PNG stays sharp; an ICO covers older browsers.

This article is available in: Indonesia · English

A Clincoo project tab looks broken in Chrome and empty in Safari. Only a 16-pixel favicon.ico exists.

In editor.clincoo.buzz, upload a 32×32 PNG and a fallback ICO. Link both in head, PNG first.

Do not rely on a root file without link rel. Some Clincoo hosts do not serve /favicon.ico automatically.

Ask AI to draft two link rel icon tags. Paste the page head, not the whole template.

A clear icon on app.clincoo.buzz helps tell the editor tab from the preview tab.
