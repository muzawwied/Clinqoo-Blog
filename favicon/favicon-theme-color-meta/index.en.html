Match theme-color to the Clincoo Favicon Background

A theme-color that differs from the icon makes the Android bar feel broken. Match the background hex.

This article is available in: Indonesia · English

The Chrome Android top bar is green while the Clincoo favicon is blue. The transition feels off-brand.

In editor.clincoo.buzz, read the icon background hex then set meta name theme-color in head.

Do not leave the browser default theme-color. A random tint ruins the release feel.

Ask AI to write one theme-color tag. Paste the home page head.

A matching bar and tab on app.clincoo.buzz keep the brand intact.
