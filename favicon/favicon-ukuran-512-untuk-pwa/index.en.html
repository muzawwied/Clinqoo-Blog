Add a 512px Icon for the Clincoo PWA Splash

A manifest without 512 makes the Android splash look soft. One large PNG covers the install screen.

This article is available in: Indonesia · English

A visitor installs a Clincoo site. The splash screen shows a stretched 192 icon.

In editor.clincoo.buzz, upload a 512×512 PNG and list it in the manifest icons with 192.

Do not upscale a 32px file to 512. The splash becomes a broken square.

Ask AI to write a 512 icons entry. Paste manifest.json only.

A sharp splash into app.clincoo.buzz feels like an app, not a random page.
