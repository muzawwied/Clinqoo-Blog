Provide a Visible Close Button on a Clincoo Modal

Escape and overlay click are not enough. A visible, clearly labeled close button dismisses the dialog for every visitor.

This article is also available in: Indonesia · English

A close icon with no text makes screen readers say "button" only. Touch visitors do not always find the overlay area.

In editor.clincoo.buzz, use a button type="button" with the text Close or an aria-label that means the same. Do not rely on a div that only has onclick.

Place the button in a consistent corner, keep contrast high, and size it for a thumb on mobile. Do not pin it outside the dialog panel.

The close button must call the same close function as Escape: remove listeners, restore overflow, return focus.

Clincoo does not add dialog controls for you. A visible button makes modals on app.clincoo.buzz closable without guesswork.
