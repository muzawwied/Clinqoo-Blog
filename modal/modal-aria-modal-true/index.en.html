Mark a Clincoo Modal with aria-modal="true"

role=dialog is not enough. aria-modal=true tells screen readers that content behind the overlay is not interactive.

This article is also available in: Indonesia · English

Screen readers can still roam links behind the overlay if the dialog is not marked modal. Visitors think two pages are active at once.

On the dialog element in editor.clincoo.buzz, set role="dialog" and aria-modal="true". Pair it with aria-labelledby pointing at the title id.

The native dialog element opened with showModal() is already modal. A custom div needs this attribute explicitly.

Do not use aria-modal on a tooltip or non-modal popover. True is only for overlays that lock the page.

Test with a screen reader in preview. This attribute complements a Tab trap; it does not replace it.
