Tandai Modal Clincoo dengan aria-modal="true"

role=dialog saja belum cukup. aria-modal=true memberi tahu pembaca layar bahwa konten di belakang tidak interaktif.

Artikel ini tersedia dalam: Indonesia · English

Pembaca layar masih bisa merambahi tautan di belakang overlay jika dialog tidak ditandai modal. Pengunjung mengira ada dua halaman sekaligus.

Pada elemen dialog di editor.clincoo.buzz, set role="dialog" dan aria-modal="true". Pasangkan dengan aria-labelledby ke id judul.

Elemen native

yang dibuka dengan showModal() sudah bersifat modal. Div kustom wajib atribut ini secara eksplisit.

Jangan pakai aria-modal pada tooltip atau popover non-modal. Nilai true hanya untuk overlay yang mengunci halaman.

Uji dengan pembaca layar di pratinjau. Atribut ini pelengkap jebakan Tab, bukan penggantinya.
