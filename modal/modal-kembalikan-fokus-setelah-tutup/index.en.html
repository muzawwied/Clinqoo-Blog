Return Focus to the Trigger after the Modal Closes

Without restored focus, keyboard users land in the page body. Store the trigger element and focus it again on close.

This article is available in: Indonesia · English

On editor.clincoo.buzz, a closed modal often leaves focus on the body. Tab users must hunt for the trigger from the top.

On open, store document.activeElement. On close, return focus to that element if it is still in the document.

Do not move focus to the top of the page. The trigger is the right anchor. Hide the modal with hidden or remove it from the accessibility tree.

Ask AI to write save-and-restore focus, plus a null check. Paste only the open and close functions, not the whole app.

Test with the keyboard on app.clincoo.buzz: open, Esc, then tab once. Focus should return to the original button. Record the pattern on blog.clincoo.buzz.
