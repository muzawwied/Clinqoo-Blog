Do Not Autofocus a Clincoo Modal Input on Phones

autofocus opens the keyboard and pushes the dialog up. Move focus to the title, not the field, on narrow screens.

This article is available in: Indonesian · English

A form modal on app.clincoo.buzz that uses autofocus opens the keyboard immediately. The close button is often covered.

Below 640px, focus the dialog heading with tabindex=-1. Let the visitor tap the field themselves.

On desktop, focusing the first control still makes sense if the dialog has one action. Branch with matchMedia.

Do not ask AI to add autofocus to every input. Include the viewport width and ask for a phone versus desktop branch.

Test in the editor.clincoo.buzz preview with the device toolbar. Confirm Escape and the close button stay visible.
