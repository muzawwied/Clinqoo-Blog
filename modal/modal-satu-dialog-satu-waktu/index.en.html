Open Only One Clincoo Modal at a Time

Stacked overlays break focus and Escape. Close the old dialog before opening a new one, or stack layers on purpose.

This article is also available in: Indonesia · English

A form inside the first modal triggers a confirmation, then a second overlay stacks. Escape closes the wrong layer or nothing at all.

In editor.clincoo.buzz, keep a single active-dialog flag. Before opening a new one, close the old one and restore focus, unless you intentionally stack.

If a confirmation must sit on top of a form, handle Escape from the top layer first. Do not attach two document listeners that fight each other.

The native dialog element supports stacking, but a custom Tab trap breaks easily. Test the open-close order in preview.

One dialog at a time is easier to maintain. Clincoo does not manage a modal queue for you.
