Pindahkan Fokus ke Kontrol Pertama saat Modal Clincoo Dibuka

Modal tanpa fokus awal membiarkan keyboard di halaman belakang. Pindahkan fokus ke judul atau kontrol pertama di dalam dialog.

Artikel ini tersedia dalam: Indonesia · English

Dialog Clincoo terbuka, tetapi Tab masih berjalan di menu halaman. Pembaca layar tidak mengumumkan judul modal.

Begitu overlay tampil, panggil focus() pada elemen pertama yang masuk akal: judul dengan tabindex="-1", atau input pertama jika dialog adalah formulir.

Jangan fokus ke tombol tutup jika pengunjung harus mengisi field. Urutan tab harus mengikuti alur tugas, bukan urutan markup acak.

Elemen native dialog memindahkan fokus otomatis. Jika Anda memakai div kustom di editor.clincoo.buzz, Anda harus memindahkan fokus sendiri.

Uji dengan keyboard saja di pratinjau. Pola ini berpasangan dengan mengembalikan fokus ke tombol pemicu setelah dialog ditutup.
