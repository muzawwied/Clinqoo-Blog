Move Focus to the First Control when a Clincoo Modal Opens

A modal without initial focus leaves the keyboard on the page behind. Move focus to the title or first control inside the dialog.

This article is also available in: Indonesia · English

A Clincoo dialog opens, but Tab still walks the page menu. Screen readers never announce the modal title.

As soon as the overlay appears, call focus() on the first sensible element: a heading with tabindex="-1", or the first input if the dialog is a form.

Do not focus the close button if the visitor must fill a field. Tab order should follow the task, not random markup order.

The native dialog element moves focus for you. If you use a custom div in editor.clincoo.buzz, you must move focus yourself.

Test with the keyboard only in preview. This pattern pairs with restoring focus to the trigger button after the dialog closes.
