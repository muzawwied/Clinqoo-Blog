Set inert on the Backdrop While a Clincoo Dialog Is Open

Without inert, Tab still reaches the page behind the dialog. Mark the backdrop inert while the modal is active.

This article is available in: Indonesia · English

On editor.clincoo.buzz, a delete confirmation dialog sometimes still lets Tab reach links behind the overlay.

When the dialog opens, set inert on the main element outside the dialog, then remove inert on close. Initial focus goes to the title or the cancel button.

Do not rely on a visual overlay alone. Keyboard and screen-reader users can still activate hidden controls.

Test with Tab and Shift+Tab. Focus should cycle inside the dialog, then return to the trigger button.

If an AI suggests random tabindex values, ask for a version that uses dialog and inert, then test it on app.clincoo.buzz.
