Set inert pada Latar saat Dialog Clincoo Terbuka

Tanpa inert, Tab masih masuk ke halaman di belakang dialog. Tandai latar inert selama modal aktif.

Artikel ini tersedia dalam: Indonesia · English

Di editor.clincoo.buzz, dialog konfirmasi hapus kadang masih mengizinkan Tab ke tautan di belakang overlay.

Saat dialog terbuka, set inert pada elemen utama di luar dialog, lalu hapus inert saat tutup. Fokus awal masuk ke judul atau tombol batal.

Jangan hanya overlay visual. Pengguna keyboard dan pembaca layar tetap bisa mengaktifkan kontrol yang tersembunyi.

Uji dengan Tab dan Shift+Tab. Fokus harus berputar di dalam dialog, lalu kembali ke tombol pemicu.

Jika AI menyarankan tabindex sembarangan, minta versi yang memakai dialog dan inert, lalu uji di app.clincoo.buzz.
