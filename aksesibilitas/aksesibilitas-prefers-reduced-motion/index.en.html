Honor prefers-reduced-motion in Clincoo Animations

A spinning enter animation can cause nausea. Turn off nonessential motion when the user asks for less movement.

This article is available in: Indonesia · English

Clincoo previews on editor.clincoo.buzz often use long fades. Users with vestibular disorders feel that effect.

Wrap transitions in @media (prefers-reduced-motion: reduce) and set animation to none. State changes must still happen.

Do not rely on JS only. The CSS media query works without extra permission on app.clincoo.buzz.

Paste the animation snippet to AI. Do not ask for a spring library before you check the system preference.

Clincoo on blog.clincoo.buzz can still mark status; only decorative motion is reduced.
