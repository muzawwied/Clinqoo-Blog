Set the HTML lang Attribute so Clincoo Screen Readers Pronounce Correctly

An Indonesian page with lang=en garbles speech. Set the document language and mark foreign snippets.

This article is available in: Indonesian · English

Many Clincoo templates still use lang=en on the html element even after all copy is Indonesian. Screen readers then use an English voice engine.

Set the lang attribute on the html element to the page primary language. For the English version, use lang=en on index.en.html instead of copying the Indonesian file as-is.

If a foreign sentence appears on an Indonesian page — a product name or a quote — wrap it in a span with the matching lang. Do not mark a whole paragraph when only two words are foreign.

Language codes follow BCP 47: id for Indonesian, en for English. Avoid invented values such as indo or indonesia.

Also check lang on the 404 page and any email templates. Inconsistency on error pages is easy to miss.

Test with a screen reader or at least inspect the HTML source before release. The fix is one line and the effect is immediate.
