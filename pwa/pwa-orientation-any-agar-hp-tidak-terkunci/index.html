Set orientation any agar PWA Clincoo Tidak Mengunci Layar HP

Manifest yang memaksa portrait mengunci situs saat pengguna memutar HP. Untuk situs konten, biarkan any.

Artikel ini tersedia dalam: Indonesia · English

Manifest PWA di situs Clincoo kadang menyalin orientation: portrait dari contoh aplikasi game. Situs blog atau company profile lalu tidak bisa dibaca landscape.

Untuk situs konten, pakai orientation: any atau hapus field itu. Browser mengikuti orientasi perangkat. Portrait-primary hanya masuk akal untuk alur yang memang dirancang satu arah.

Uji setelah install di Chrome Android: buka dari ikon layar utama, putar HP, pastikan layout tidak terpotong. CSS tetap butuh media query, manifest tidak menggantikan responsive.

Jangan ubah orientation setelah pengguna sudah memasang aplikasi tanpa menjelaskan. Perubahan manifest bisa butuh install ulang agar terlihat.
