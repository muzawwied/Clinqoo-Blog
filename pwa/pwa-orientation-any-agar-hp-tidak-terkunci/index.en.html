Set orientation to any so a Clincoo PWA Does Not Lock the Phone Screen

A manifest that forces portrait locks the site when the user rotates the phone. For a content site, leave it as any.

This article is available in: Indonesia · English

A Clincoo site PWA manifest sometimes copies orientation: portrait from a game sample. A blog or company profile then cannot be read in landscape.

For a content site, use orientation: any or omit the field. The browser follows the device. portrait-primary only makes sense for a flow designed for one direction.

Test after install on Chrome Android: open from the home-screen icon, rotate the phone, and confirm the layout is not clipped. CSS still needs media queries; the manifest does not replace responsive layout.

Do not change orientation after users have installed the app without saying so. A manifest change may need a reinstall before it shows up.
