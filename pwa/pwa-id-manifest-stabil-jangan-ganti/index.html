Jaga id Manifest PWA Clincoo Tetap Stabil

Mengganti id atau start_url manifest membuat browser menganggap aplikasi baru. Pengunjung kehilangan ikon yang sudah dipasang.

Artikel ini tersedia dalam: Indonesia · English

Setelah situs Clincoo dipasang ke layar beranda, browser mengikat instalasi ke identitas manifest. Field id, atau jika kosong gabungan start_url dan scope, menjadi kunci itu. Mengganti slug start_url karena rebrand singkat memunculkan ikon kedua.

Tetapkan id eksplisit di manifest.json, misalnya path absolut yang tidak akan kamu pindah. Ubah name dan short_name sesuka merek baru. Ikon dan theme_color boleh diganti; id jangan.

Selaraskan scope dan start_url dengan folder publik di subdomain Clincoo. Scope yang lebih sempit dari start_url membuat aplikasi terbuka di luar area cache. Cek file di editor.clincoo.buzz sebelum deploy.

Jika kamu harus pindah path, rencanakan periode dua ikon dan beri tahu pengguna. Jangan andalkan AI yang menulis ulang seluruh manifest setiap generate. Tinjau diff field id secara manual.

Uji instal di Chrome pada HTTPS. Hapus instalasi lama hanya di perangkat uji, bukan di perangkat klien. Identitas yang stabil menjaga PWA terasa seperti aplikasi, bukan tautan yang terus berganti nama.
