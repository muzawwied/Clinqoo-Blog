Add Narrow and Wide Screenshots to a Clincoo PWA Manifest

Screenshots in the manifest help the browser store show a preview before a visitor installs the site.

Indonesia · English

Chrome install UI reads the screenshots field in manifest.json. Without those images the install card only shows a name and icon, so visitors hesitate to press Install.

Add two sets: form_factor narrow (phone, about 9:16) and wide (desktop, about 16:9). MDN recommends JPEG or PNG large enough not to look soft in the install panel. Keep files in the Clincoo static folder, for example /screenshots/narrow.png and /screenshots/wide.png.

Each entry needs src, sizes, type, form_factor, and label. web.dev asks for a label that describes the scene, not the filename. Maskable icons do not replace screenshots.

Do not capture editor.clincoo.buzz with the editor chrome still visible. Deploy first, open the public URL, then take the shot. Ask the AI only to add the screenshots array and two image files. Refuse a full manifest rewrite.

In Chrome Application > Manifest confirm both URLs return 200. Clincoo ships static files as saved; a 404 screenshot leaves the install card empty.

Sources: MDN screenshots, web.dev Web App Manifest, W3C Web App Manifest.
