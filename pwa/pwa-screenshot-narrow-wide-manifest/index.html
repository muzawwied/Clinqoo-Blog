Tambah Screenshot Narrow dan Wide di Manifest PWA Clincoo

Screenshot di manifest membantu toko browser menampilkan pratinjau aplikasi sebelum pengunjung memasang situs.

Artikel ini tersedia dalam: Indonesia · English

Toko Chrome dan dialog instal PWA di desktop memakai field screenshots di manifest.json. Tanpa gambar itu, kartu instal hanya menampilkan nama dan ikon, sehingga pengunjung ragu menekan Pasang.

Tambahkan dua set: form_factor narrow (ponsel, rasio sekitar 9:16) dan wide (desktop, rasio sekitar 16:9). MDN merekomendasikan JPEG atau PNG yang cukup besar agar tidak pecah di panel instal. Letakkan file di folder statis proyek Clincoo, misalnya /screenshots/narrow.png dan /screenshots/wide.png.

Contoh entri memakai src, sizes, type, form_factor, dan label. web.dev menekankan label yang menjelaskan isi layar, bukan nama file. Ikon maskable tidak menggantikan screenshot; keduanya tugas berbeda.

Jangan pakai tangkapan editor.clincoo.buzz yang masih menampilkan bingkai editor. Deploy dulu, buka URL publik, lalu potong layar. Minta AI hanya menambah array screenshots dan dua file gambar. Tolak rewrite seluruh manifest.

Uji di Chrome Application > Manifest bahwa URL gambar merespons 200. Clincoo menayangkan file statis apa adanya; screenshot yang 404 membuat kartu instal tetap kosong.
