Confirm before skipWaiting so a PWA form is not lost

skipWaiting swaps the service worker immediately and can reload a page mid-form. Ask for confirmation first.

This article is available in: Indonesia · English

On editor.clincoo.buzz, a new service worker often calls skipWaiting as soon as it installs. A page with an open form then reloads.

Show a new-version banner. Do not call skipWaiting inside install. Save the form draft to memory or IndexedDB before the user agrees.

After the user presses Reload, send a message so the worker can skipWaiting, then listen for controllerchange only once.

Ask AI to explain skipWaiting versus clients.claim. Refuse a snippet that reloads with no button.

Test on the app.clincoo.buzz preview with a half-filled form. A new version must not wipe text that was not submitted.
