Sediakan Halaman Fallback Offline di Service Worker Situs Clincoo

Saat navigasi gagal karena jaringan putus, tampilkan halaman fallback yang sudah di-cache, bukan error browser kosong.

Artikel ini tersedia dalam: Indonesia · English

Pengunjung situs Clincoo yang membuka tautan dalam saat sinyal putus sering melihat halaman error bawaan browser. Itu terasa seperti situs rusak, padahal yang hilang hanya jaringan.

Buat file offline.html sederhana di workspace editor.clincoo.buzz: judul jelas, satu paragraf penjelasan, dan tautan kembali ke beranda. Cache file itu saat service worker terpasang.

Di event fetch, jika permintaan adalah navigasi dan fetch jaringan gagal, kembalikan cache offline.html. Jangan pakai fallback ini untuk aset CSS atau gambar agar halaman yang sudah ter-cache tetap utuh.

Uji di DevTools dengan mode Offline. Buka URL yang belum di-cache: fallback harus muncul. Buka halaman yang sudah di-cache: konten asli harus tetap tampil.

Minta AI Clincoo menambah handler fetch navigasi saja, bukan menulis ulang seluruh worker. Fallback yang sopan menjaga kepercayaan di app.clincoo.buzz saat kereta masuk terowongan.
