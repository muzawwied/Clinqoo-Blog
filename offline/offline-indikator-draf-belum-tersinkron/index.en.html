Show an Unsynced-Draft Indicator while Offline on Clincoo

A draft in localStorage is easy to miss if the UI never marks it as not sent yet. Give it a clear badge.

This article is available in: Indonesia · English

Offline mode in editor.clincoo.buzz can store typing in localStorage, then the user closes the tab believing the server already received it.

Add UI status: Saved on device -- not synced. Flip to Synced only after the POST/PUT fetch returns ok.

When back online, flush the queue. On failure, keep the badge and a Retry send button.

Test with DevTools Offline. Type, drop the network, refresh. The badge must remain.
