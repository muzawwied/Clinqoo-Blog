Respect Save-Data and Weak Networks on a Clincoo Site

Before a full offline drop, many Clincoo users sit on 2G. Detect saveData and effectiveType, then defer heavy assets.

This article is available in: Indonesia · English

Offline mode often starts as a network that is only almost dead. Hero video and large galleries on a Clincoo site hang the tab before an offline banner can appear.

Read navigator.connection when it exists. If saveData is true or effectiveType is slow-2g or 2g, skip video autoplay and do not prefetch below-the-fold images.

This API is not standard in every browser. Wrap it in a feature check. Do not assume connection always exists in editor.clincoo.buzz.

Test with DevTools Network throttling. Ask AI to add one small helper that marks the body with a save-data class, then CSS disables the video background.

Clincoo does not adapt payloads by network. Respecting Save-Data keeps a site on app.clincoo.buzz readable before it goes fully offline.
