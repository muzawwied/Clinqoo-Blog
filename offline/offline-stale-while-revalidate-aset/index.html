Pakai Stale-While-Revalidate agar Aset Clincoo Cepat saat Hampir Offline

Tampilkan cache dulu, perbarui di belakang. Strategi ini menjaga CSS dan gambar Clincoo tetap tampil saat jaringan lambat.

Artikel ini tersedia dalam: Indonesia · English

Menunggu jaringan sebelum menampilkan CSS membuat situs Clincoo terlihat kosong. Saat sinyal hampir putus, cache yang sudah ada lebih berguna daripada spinner.

Di service worker, untuk request stylesheet, font, dan gambar: jika cache ada, kembalikan segera. Di belakang, fetch jaringan dan tulis ulang cache. Itu pola stale-while-revalidate.

Jangan terapkan pola ini pada HTML halaman yang sering berubah tanpa versi. Untuk dokumen, network-first plus fallback offline lebih aman.

Beri nama cache dengan versi, misalnya clincoo-static-v2, agar aktivasi worker baru bisa menghapus cache lama. Minta AI Clincoo hanya mengubah cabang fetch aset statis.

Clincoo tidak memilih strategi cache untukmu. Stale-while-revalidate di editor.clincoo.buzz membuat app.clincoo.buzz terasa cepat meski jaringan mulai goyah.
