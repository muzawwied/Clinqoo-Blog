Cache Halaman Statis Clincoo agar Tetap Terbuka Offline

Service worker yang men-cache HTML, CSS, dan aset inti membuat situs Clincoo tetap terbaca saat jaringan putus.

Artikel ini tersedia dalam: Indonesia · English

Situs Clincoo yang hanya mengandalkan jaringan langsung kosong saat kereta masuk terowongan. Pengunjung mengira halaman rusak, padahal file sudah pernah diunduh.

Daftarkan service worker dari editor.clincoo.buzz untuk cache-first pada index.html, stylesheet, dan logo. Jangan cache API atau form POST.

Versikan nama cache. Saat CSS berubah, buka cache baru lalu hapus yang lama di event activate agar pengunjung tidak melihat gaya basi.

Uji di DevTools: set Offline, muat ulang, pastikan beranda dan CSS masih muncul. Kalau hanya HTML yang tersimpan, layout akan pecah.

Minta AI menulis worker sempit: precache daftar file, fetch dengan fallback cache, tanpa menyentuh skrip pembayaran. Pratinjau dulu di app.clincoo.buzz.

Clincoo tidak memasang service worker otomatis. Cache statis yang disengaja menjaga halaman tetap berguna offline tanpa menyimpan data sensitif.
