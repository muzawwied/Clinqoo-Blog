Jangan Simpan Token Sesi di localStorage untuk Mode Offline Clincoo

Draf offline boleh di perangkat. Token login tidak boleh. localStorage bisa dibaca skrip lain di origin yang sama.

Artikel ini tersedia dalam: Indonesia · English

Mode offline di editor.clincoo.buzz sering menyimpan draf ke localStorage atau IndexedDB. Jangan ikut menyimpan access token, refresh token, atau kunci sesi di tempat yang sama.

localStorage bisa dibaca JavaScript mana pun di origin itu. Satu skrip pihak ketiga atau cuplikan yang disisipkan XSS langsung mengambil token tanpa perlu membuka jaringan.

Simpan hanya isi draf dan id antrian. Autentikasi tetap di cookie HttpOnly yang dikirim browser saat online kembali. Jika token harus ada di klien, pakai memori tab, bukan penyimpanan permanen.

Cek Application panel di DevTools. Jika kunci token muncul di Local Storage, pindahkan. Uji juga mode offline: draf tetap ada, sesi tidak tersalin ke file cadangan.
