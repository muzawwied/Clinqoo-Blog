Do Not Store Session Tokens in localStorage for Clincoo Offline Mode

Offline drafts may live on the device. Login tokens must not. localStorage is readable by any script on the same origin.

This article is available in: Indonesia · English

Offline mode in editor.clincoo.buzz often stores drafts in localStorage or IndexedDB. Do not store access tokens, refresh tokens, or session keys in the same place.

localStorage is readable by any JavaScript on that origin. One third-party script or an XSS snippet can take the token without touching the network.

Store only the draft body and a queue id. Keep authentication in an HttpOnly cookie that the browser sends when the network returns. If a token must exist on the client, keep it in tab memory, not durable storage.

Check the Application panel in DevTools. If a token key appears in Local Storage, move it. Test offline mode too: the draft remains, the session is not copied into a backup file.
