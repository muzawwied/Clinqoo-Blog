Simpan Konten Besar Clincoo di IndexedDB, Bukan localStorage

localStorage cepat penuh dan memblokir tab. IndexedDB lebih cocok untuk draf panjang dan antrean offline Clincoo.

Artikel ini tersedia dalam: Indonesia · English

Artikel yang sudah ada menyarankan localStorage untuk draf. Itu cukup untuk judul pendek. Isi halaman utuh, gambar base64, atau antrean formulir akan menabrak kuota dan membekukan tab.

Buka database IndexedDB bernama clincoo-offline dengan object store drafts. Simpan objek {id, updatedAt, body}. Operasi asynchronous tidak memblokir UI di editor.clincoo.buzz.

Tangani kuota: jika request gagal dengan QuotaExceededError, hapus draf terlama atau minta pengguna mengekspor. Jangan diam-diam membuang data terbaru.

Uji dengan Application > IndexedDB di DevTools. Minta AI Clincoo menulis pembungkus put/get saja, bukan mengganti seluruh alur simpan yang sudah jalan.

Clincoo tidak menyediakan database klien bawaan. IndexedDB membuat draf di app.clincoo.buzz selamat saat jaringan putus jauh lebih lama daripada sesi localStorage.
