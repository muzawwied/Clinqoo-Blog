Dengarkan Event online dan offline di Pratinjau Clincoo

Mengecek navigator.onLine sekali saat muat melewatkan putus jaringan di tengah edit. Dengarkan event window.

Artikel ini tersedia dalam: Indonesia · English

Draf di editor.clincoo.buzz tetap menampilkan tombol terbitkan saat jaringan putus. Pengguna baru sadar setelah fetch gagal.

Pasang listener window untuk event offline dan online. Saat offline, kunci aksi yang butuh server dan tampilkan status di dekat toolbar.

navigator.onLine bisa true di jaringan captive portal. Anggap gagal fetch sebagai sinyal kedua, bukan satu-satunya sumber.

Jangan simpan token di localStorage hanya karena offline. Antrian draf cukup berisi id lokal dan waktu.

Uji dengan mode offline DevTools sebelum unggah ke app.clincoo.buzz. Catat hasilnya di blog.clincoo.buzz.
