Listen for online and offline Events in the Clincoo Preview

Checking navigator.onLine once on load misses a drop mid-edit. Listen to the window events.

This article is available in: Indonesia · English

A draft on editor.clincoo.buzz still shows publish when the network drops. The user only notices after fetch fails.

Add window listeners for the offline and online events. While offline, disable actions that need the server and show status near the toolbar.

navigator.onLine can be true on a captive portal. Treat a failed fetch as a second signal, not the only source.

Do not store tokens in localStorage just because you are offline. A draft queue only needs a local id and a time.

Test with DevTools offline mode before uploading to app.clincoo.buzz. Record the result on blog.clincoo.buzz.
