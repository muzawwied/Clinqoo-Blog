Record Clincoo Feature Flags in the Release Note

A release without a flag list makes rollback blind. Write the flag name, default, and percent in every note.

This article is available in: Indonesia · English

When a page breaks on app.clincoo.buzz, the team asks which flag changed. The release note must answer in one minute.

List the flag name, default value, percent, and an on/off test link on editor.clincoo.buzz.

Do not bury flags in a long commit message. On-call reads one list in the release note.

Paste the draft note to AI and ask only whether three columns are complete. Do not request marketing copy.

Archive the note on blog.clincoo.buzz so flag history can be audited without opening Git.
