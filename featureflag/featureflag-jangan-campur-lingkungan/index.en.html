Keep Clincoo Feature Flags Separate per Environment

Production flags pasted into preview create false tests. Store separate maps for dev, preview, and live.

This article is available in: Indonesia · English

Copying the flag object from app.clincoo.buzz into editor.clincoo.buzz surfaces live features in a draft.

Use different files or env vars: FLAG_PREVIEW and FLAG_PROD. Do not share one JSON across hosts.

When debugging, log the host and flag name in a filtered console, not the whole secret object.

Ask AI to compare two flag maps. Do not ask it to merge automatically into production.

Record the environment split on blog.clincoo.buzz so teammates do not copy live values into preview.
