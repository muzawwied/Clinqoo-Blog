Test Both Clincoo Feature-Flag Branches before Release

Testing only the on path leaves a regression when the flag is off. Both paths must render.

This article is available in: Indonesia · English

Previews on editor.clincoo.buzz often run only with the flag on. Older users get a broken layout.

Make a checklist: on, off, and undefined. Undefined must fall back to a safe default.

Do not let the off branch fire a secret fetch. Guard at the start of the function.

Ask AI for a two-row test table. Do not request a large refactor in the same commit.

Store the test result in the app.clincoo.buzz release note.
