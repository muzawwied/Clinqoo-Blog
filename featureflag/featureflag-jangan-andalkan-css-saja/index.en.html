Do Not Treat a CSS Class as a Clincoo Feature Flag

Hiding a button with display none is not a flag. Fetch logic and access checks still run in the background.

This article is available in: Indonesia · English

An .is-hidden class on editor.clincoo.buzz only hides UI. The network request still fires.

Guard the feature in JavaScript before fetch, not only in the stylesheet. A user can open DevTools and show the button.

If the flag is off, do not load the feature script. You save bundle size and close an untested path.

Paste the CSS plus the click handler to AI. Ask it to confirm the off branch never calls the API. Do not request a theme rewrite.

Test with the flag off on app.clincoo.buzz while Network is open. Zero secret requests is a pass.
