Jangan Andalkan Kelas CSS Saja sebagai Feature Flag Clincoo

Menyembunyikan tombol dengan display none bukan flag. Logika fetch dan hak akses tetap berjalan di belakang layar.

Artikel ini tersedia dalam: Indonesia · English

Kelas .is-hidden di editor.clincoo.buzz hanya menyembunyikan UI. Permintaan jaringan tetap terkirim.

Guard fitur di JavaScript sebelum fetch, bukan hanya di stylesheet. Pengguna bisa membuka DevTools dan menampilkan tombol.

Jika flag off, jangan muat skrip fitur. Hemat bundle dan tutup jalur yang tidak diuji.

Tempel CSS plus handler klik ke AI. Minta pastikan cabang off tidak memanggil API. Jangan minta rewrite tema.

Uji dengan flag off di app.clincoo.buzz sambil membuka tab Network. Nol permintaan rahasia adalah lulus.
