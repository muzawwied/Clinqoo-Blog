Set a Safe Default when a Clincoo Feature Flag Is Undefined

Undefined is not off. Declare an explicit fallback so preview and production do not break silently.

This article is available in: Indonesia · English

On editor.clincoo.buzz, a flag that is not registered is often read as undefined, not false.

Write a getFlag(name, safeDefault) helper. Do not compare to true without a fallback.

The default must disable risky features: payments, share links, project deletion.

Paste the helper to AI and ask it to check the undefined branch only. Do not request a config rewrite.

Test three values on app.clincoo.buzz: true, false, and a key you deleted on purpose.
