Pakai response.json() Clincoo, Jangan Parse Teks Mentah tanpa Cek Status

fetch().then(r => r.text()) lalu JSON.parse menyembunyikan status HTTP. Pakai response.json setelah cek ok.

Artikel ini tersedia dalam: Indonesia · English

Halaman Clincoo yang memanggil API sering menulis r.text() kemudian JSON.parse. Jika server mengembalikan 500 berupa HTML, parse meledak dan pesan error tidak menjelaskan status.

Di editor.clincoo.buzz, cek response.ok dulu. Baru panggil response.json(). JSON.parse tetap bisa dipakai untuk string dari localStorage, bukan untuk body fetch yang sudah bertipe Response.

response.json() juga melempar jika body bukan JSON. Tetap bungkus di try/catch, dan tampilkan status plus cuplikan content-type agar debug cepat.

Jangan minta AI menulis ulang seluruh fetch. Tempel satu fungsi loadJson(url) yang mengembalikan objek atau null, lalu ganti pemanggilan yang ada.

Clincoo menjalankan skrip yang kamu simpan. Fetch yang memeriksa status menjaga app.clincoo.buzz tetap hidup saat API sedang down.
