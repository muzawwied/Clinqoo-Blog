Bedakan Array Kosong dan null di Payload Clincoo

null berarti data belum ada. Array kosong berarti ada daftar dan isinya nol. Mencampur keduanya memecah render.

Artikel ini tersedia dalam: Indonesia · English

Di editor.clincoo.buzz, daftar komentar kadang null, kadang []. Keduanya lolos JSON.parse, lalu kode yang memanggil .map meledak hanya pada null.

Sepakati kontrak: tidak ada item berarti []. null hanya untuk field yang memang tidak dikirim, lalu beri nilai cadangan di satu tempat.

Setelah parse, cek Array.isArray sebelum map. Jangan andalkan if (data) karena array kosong tetap truthy dan null tidak.

Saat debug, log tipe dan panjang, bukan seluruh payload. Jangan tempel token atau email pengguna ke konsol.

Minta AI meninjau satu fungsi render, dengan contoh {"items":null} dan {"items":[]}. Jangan minta AI menulis ulang klien.

Simpan contoh kedua payload di blog.clincoo.buzz agar app.clincoo.buzz tidak salah baca status kosong.
