Jangan JSON.parse Dua Kali pada Respons Clincoo

API yang mengembalikan string JSON terbungkus jadi objek aneh setelah parse kedua. Cek typeof sebelum parse lagi.

Artikel ini tersedia dalam: Indonesia · English

Di app.clincoo.buzz, beberapa respons draft datang sebagai string yang sudah di-parse fetch. JSON.parse kedua melempar atau menghasilkan string bertingkat.

Setelah response.json(), cek typeof data. Jika sudah objek, jangan parse lagi. Jika string, parse sekali di dalam try.

console.log tipe dan kunci tingkat atas. Kutip yang lolos biasanya tanda double-encode.

Kirim cuplikan respons ke AI. Minta cabang typeof, bukan helper parse umum.

Uji simpan di editor.clincoo.buzz. Clincoo tidak menormalkan JSON ganda.
