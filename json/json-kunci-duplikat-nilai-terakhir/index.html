Waspadai Kunci JSON Duplikat di Respons Clincoo — Nilai Terakhir yang Menang

JSON.parse diam-diam memakai nilai terakhir jika kunci dobel. Cek payload sebelum percaya angka.

Artikel ini tersedia dalam: Indonesia · English

Respons debug di editor.clincoo.buzz kadang digabung manual. Kunci id muncul dua kali, dan yang terbaca bukan yang pertama.

JSON.parse mengikuti nilai terakhir untuk kunci duplikat. Jangan asumsikan parser menolak objek itu.

Sebelum parse, cari kunci berulang dengan pemindaian teks longgar, atau bandingkan jumlah kunci setelah parse dengan jumlah kemunculan di string.

Tempel cuplikan JSON ke AI dan minta daftar kunci duplikat. Jangan tempel token atau surel pengguna.

Simpan contoh payload buruk di blog.clincoo.buzz agar tim app.clincoo.buzz tidak salah baca harga atau status.
