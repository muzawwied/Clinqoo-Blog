Tulis Pesan Commit yang Menjelaskan Mengapa di Proyek Clincoo

Commit berjudul update atau wip memaksa rekan menebak. Satu baris subjek plus alasan singkat mempercepat tinjauan.

Artikel ini tersedia dalam: Indonesia · English

Proyek Clincoo yang diedit AI menghasilkan banyak file. GitHub Docs meminta subjek singkat yang menjelaskan mengapa, bukan hanya file mana yang berubah.

Contoh buruk: update css. Contoh baik: Perkecil h1 hero agar tidak menabrak logo di 320px. Baris tubuh boleh menyebut file, tetapi subjek harus berupa hasil yang diinginkan.

Satu commit per masalah. Jangan campur perbaikan kontras dengan rewrite navigasi. Rollback menjadi mustahil jika pesan dan diff tidak sejalan.

Setelah AI menulis, baca diff lalu tulis pesan sendiri. Jangan biarkan asisten mengisi subjek generik.

Jika bekerja berdua, setujui prefiks singkat seperti fix: atau a11y: hanya jika seluruh tim memakainya secara konsisten.

Sumber: GitHub Docs About commits, GitHub Docs About Git, Pro Git contributing and commit guidelines.
