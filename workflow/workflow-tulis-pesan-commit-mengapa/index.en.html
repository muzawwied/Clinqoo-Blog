Write Commit Messages that Explain Why on Clincoo Projects

Commits titled update or wip force teammates to guess. A short subject plus a reason speeds review.

Indonesia · English

Clincoo projects edited by AI touch many files. GitHub Docs ask for a short subject that explains why, not only which files changed.

Bad example: update css. Better: Shrink the hero h1 so it does not hit the logo at 320px. The body may list files, but the subject should state the intended result.

One commit per issue. Do not mix a contrast fix with a nav rewrite. Rollback fails when the message and the diff disagree.

After the AI writes, read the diff and write the message yourself. Do not let the assistant fill a generic subject.

If two people work together, agree on short prefixes such as fix: or a11y: only when the whole team uses them consistently.

Sources: GitHub Docs About commits, GitHub Docs About Git, Pro Git contributing and commit guidelines.
