One Clincoo Pull Request for One Intent

A PR that changes layout, copy, and an endpoint at once is hard to review. Split by intent before asking to merge.

This article is available in: Indonesia · English

On editor.clincoo.buzz, mixed changes make a long diff. The reviewer cannot tell which part to reject.

Split PRs: one for copy, one for style, one for the handler. The PR title names the result the user sees.

If AI edits three files for one typo, revert the files you did not ask for. Do not ship them in the same PR.

Ask AI for the touched files and the reason for each. Reject a rewrite that does not answer that intent.

Link the PR to a note on blog.clincoo.buzz. Test each PR on app.clincoo.buzz before merging.
