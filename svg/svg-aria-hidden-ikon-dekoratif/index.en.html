Mark Decorative SVGs with aria-hidden in Clincoo

Ornamental icons that screen readers announce break the flow. Hide decoration; name what matters.

This article is available in: Indonesia · English

Inline header icons in Clincoo are often announced as a bare svg or a path with no meaning. Assistive-tech visitors lose the button context when the icon and the visible text are spoken twice.

If the SVG only decorates text that already explains the control, add aria-hidden="true" and role="presentation" on the svg element. Do not rely on an empty title. Preview in editor.clincoo.buzz, then check with a screen reader or the Accessibility pane in DevTools.

An SVG that stands alone as a button or a status needs an accessible name. Use a title inside the svg or aria-label on the parent button. One name only. Do not stack title, aria-label, and hidden text together.

When you ask AI for help, paste the full icon markup and say which icons are decorative. Reject a full header rewrite. Change access attributes only, then check contrast and tap size in the phone preview.

Clincoo renders the HTML you save. Truly decorative icons should stay silent for screen readers; icons that carry meaning need a short name.
