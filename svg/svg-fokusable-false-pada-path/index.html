Matikan Fokus pada Path SVG Ikon Clincoo

Path di dalam tombol ikon bisa jadi target Tab. Tandai fokusable=false agar fokus tetap di tombol.

Artikel ini tersedia dalam: Indonesia · English

Ikon SVG di tombol Clincoo kadang menerima fokus sendiri. Pengguna keyboard berhenti di path, bukan di kontrol.

Tambah focusable="false" pada svg dekoratif, plus aria-hidden="true" jika ikon tidak membawa arti sendiri.

Uji Tab di editor.clincoo.buzz. Urutan harus lompat antar tombol, bukan masuk ke dalam gambar.

Minta AI menandai svg tanpa focusable di komponen tombol. Jangan minta rewrite seluruh sprite.

Clincoo di app.clincoo.buzz terasa rapi jika ikon tidak mencuri fokus.
