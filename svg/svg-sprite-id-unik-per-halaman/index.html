Pakai ID Unik pada Sprite SVG Halaman Clincoo

ID symbol yang bentrok membuat ikon salah atau hilang. Beri prefiks per halaman atau komponen.

Artikel ini tersedia dalam: Indonesia · English

Dua sprite yang sama-sama memakai id="icon-check" membuat merujuk ke definisi pertama di dokumen. Ikon di footer tiba-tiba memakai glif header.

Di editor.clincoo.buzz, prefiks setiap symbol: icon-nav-check, icon-form-check. MDN mensyaratkan id unik di satu dokumen HTML, termasuk isi SVG inline.

Jika kamu menyisipkan sprite lewat komponen berulang, generate id saat render atau pakai satu sprite global di layout. Jangan tempel file SVG utuh di setiap kartu.

Minta AI memindai semua id= di berkas halaman. Tempel cuplikan sprite dan daftar agar tabrakan terlihat.

Dokumentasi SVG MDN dan editor Clincoo menekankan sprite hemat request, tetapi hanya jika referensi href tidak ambigu di app.clincoo.buzz.
