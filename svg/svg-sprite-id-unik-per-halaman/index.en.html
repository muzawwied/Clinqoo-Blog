Use Unique IDs on Clincoo Page SVG Sprites

Clashing symbol IDs make icons wrong or missing. Prefix IDs per page or component.

This article is available in: Indonesia · English

Two sprites that both use id="icon-check" make point at the first definition in the document. Footer icons suddenly reuse the header glyph.

In editor.clincoo.buzz, prefix every symbol: icon-nav-check, icon-form-check. MDN requires unique ids in one HTML document, including inline SVG.

If you inject a sprite through a repeated component, generate ids at render time or keep one global sprite in the layout. Do not paste a full SVG file into every card.

Ask AI to scan every id= on the page. Paste the sprite snippet and the list so collisions show up.

MDN SVG docs and the Clincoo editor treat sprites as a request-saving tool only when href targets stay unambiguous on app.clincoo.buzz.
