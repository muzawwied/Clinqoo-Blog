Set width and height on Clincoo SVG so the layout does not jump

An SVG without width and height shifts the text below it after the icon loads.

This article is available in: Indonesia · English

On editor.clincoo.buzz, an SVG icon that only has viewBox often arrives at zero height, then jumps after CSS applies.

Add width and height attributes that match the display size, or aspect-ratio in CSS. Do not remove viewBox.

Ask AI to keep both attributes when minifying the path. Send the svg tag snippet, not only the path.

Test the preview on app.clincoo.buzz with a cold cache. Note the icon size on blog.clincoo.buzz.
