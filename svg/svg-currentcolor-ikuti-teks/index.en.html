Color Clincoo SVG Icons with currentColor so They Follow Text

Hard-coded hex fills freeze icons when a theme or button state changes. currentColor follows the parent color.

This article is available in: Indonesia · English

Inline icons in Clincoo templates often ship with fill=#111827. When you restyle a button or turn on dark mode, the icon stays black and contrast breaks.

Remove hard fills on paths, or set fill=currentColor on the svg. Then set color on the parent button or link. The icon follows text, including :hover and :disabled.

Do not mix currentColor with a leftover fill on the same child. One color source is enough. For two-tone icons, use opacity or a class, not a hidden hex in markup.

Preview primary buttons, footer links, and card icons. If they shift with the text color, the rule works. Save, then repeat on the social icon set.

currentColor tidies CSS and visual accessibility. Icons that inherit contrast with text pass color audits more easily.
