Warnai Ikon SVG Clincoo dengan currentColor agar Mengikuti Teks

Hardcode fill hex membuat ikon macet saat tema atau status tombol berubah. currentColor mengikuti color induk.

Artikel ini tersedia dalam: Indonesia · English

Ikon inline di template Clincoo sering membawa fill=#111827. Saat kamu mengganti warna tombol atau mengaktifkan mode gelap, ikon tetap hitam. Pengunjung melihat kontras yang pecah.

Hapus fill keras pada path, atau set fill=currentColor pada svg. Lalu atur color di tombol atau tautan induk. Ikon akan mengikuti teks, termasuk :hover dan :disabled.

Jangan campur currentColor dengan fill tetap di anak yang sama. Satu sumber warna cukup. Jika ikon punya dua nada, bedakan lewat opacity atau kelas, bukan hex tersembunyi di markup.

Uji di pratinjau: tombol primer, tautan footer, dan ikon di kartu. Jika semua berganti bersama teks, aturan berhasil. Simpan, lalu ulangi pada set ikon sosial.

currentColor merapikan CSS dan aksesibilitas visual. Ikon yang kontrasnya ikut teks lebih mudah lolos audit warna.
