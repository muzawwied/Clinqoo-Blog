Sertakan README di Setiap ZIP Cadangan Clincoo

ZIP tanpa catatan cepat menjadi teka-teki. Satu file README di dalam arsip menjelaskan kapan dan mengapa cadangan dibuat.

Artikel ini tersedia dalam: Indonesia · English

Nama berkas bertanggal membantu, tetapi tiga bulan kemudian kamu lupa apakah ZIP itu dibuat sebelum ganti template atau sesudah generate AI. Catatan di luar arsip mudah terpisah. Letakkan README.txt di akar ZIP.

Isi minimal: tanggal ISO, URL proyek Clincoo, alasan cadangan (rilis, sebelum AI, sebelum hapus halaman), dan daftar file yang sengaja diubah. Satu paragraf cukup. Jangan tempel seluruh diff.

Tambahkan cara uji pulih: ekstrak ke folder kosong, buka index.html di pratinjau, cek logo dan satu formulir. Jika langkah itu gagal, ZIP tidak boleh menggantikan proyek hidup.

Simpan checksum di baris terakhir README. Saat file diunduh ulang dari cloud, bandingkan hash sebelum menimpa workspace.

Kebiasaan ini merapikan kerja tim. Orang lain bisa memulihkan tanpa menelepon kamu hanya untuk menanyakan "ZIP yang mana yang aman".
