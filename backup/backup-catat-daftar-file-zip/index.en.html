Write Down the File List inside a Clincoo Backup ZIP

An archive without an index is hard to audit. List important paths so restore is not a guess.

This article is available in: Indonesia · English

In an emergency, opening a 40 MB ZIP just to find index.html wastes time. There is no content note.

After downloading from app.clincoo.buzz, list the core paths: index.html, css/, images/, main pages.

Keep the note in the project README, not in AI chat. Conversation history gets truncated.

Update the list with every new backup. Do not rely on memory for the hero filename.

Clincoo does not show a ZIP manifest. A human note speeds selective restore.
