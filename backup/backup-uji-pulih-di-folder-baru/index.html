Uji Pulih Cadangan Clincoo di Folder Baru, Bukan di Proyek Hidup

ZIP yang belum pernah diekstrak ke folder kosong bisa pecah diam-diam. Uji pulih sebelum kamu butuh darurat.

Artikel ini tersedia dalam: Indonesia · English

Banyak cadangan Clincoo hanya diunduh lalu disimpan. Saat halaman rusak, ZIP ternyata tidak lengkap atau path di dalamnya berbeda. Uji pulih sekarang, bukan saat panik.

Buat folder baru di luar proyek hidup. Ekstrak ZIP ke sana, buka index.html, dan cek folder assets. Jangan timpa editor yang sedang dipakai.

Periksa tiga hal: index.html ada di akar arsip, gambar masih merujuk path relatif yang benar, dan ukuran file masuk akal. ZIP 2KB hampir pasti gagal.

Beri nama cadangan dengan tanggal. final.zip saling menimpa. Setelah uji pulih berhasil, catat tanggal itu di README singkat proyek.

Ulangi uji setelah ganti template atau generate AI besar. Cadangan lama tidak menjamin cadangan baru utuh. Satu ekstraksi sukses lebih berharga daripada sepuluh ZIP yang tidak pernah dibuka.
