Back Up Clincoo before You Delete a Page

Deleting a page folder cannot be undone in the editor. Download a ZIP first, then drop the path.

This article is available in: Indonesia · English

Stuck developers delete pricing/ or blog/ because the layout looks messy. Client copy vanishes with it.

Download a ZIP from app.clincoo.buzz before deleting a folder in editor.clincoo.buzz.

Delete one path only. Do not empty the whole workspace because one page looks bad.

If unsure, rename the folder to _arsip-harga first. Restore from the ZIP if the call was wrong.

Clincoo renders the files that remain. A backup before delete is the only undo.
