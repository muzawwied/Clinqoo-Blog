Cadangkan Clincoo sebelum Hapus Halaman

Hapus folder halaman tidak bisa dibatalkan di editor. Unduh ZIP dulu, baru buang path.

Artikel ini tersedia dalam: Indonesia · English

Developer yang stuck menghapus harga/ atau blog/ karena tampil berantakan. Teks klien ikut hilang.

Unduh ZIP dari app.clincoo.buzz sebelum menghapus folder di editor.clincoo.buzz.

Hapus satu path saja. Jangan kosongkan seluruh workspace karena satu halaman jelek.

Jika ragu, ganti nama folder jadi _arsip-harga dulu. Pulih dari ZIP jika keputusan salah.

Clincoo merender file yang masih ada. Cadangan sebelum hapus adalah satu-satunya undo.
