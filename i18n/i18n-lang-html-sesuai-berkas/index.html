Samakan Atribut lang HTML dengan Berkas index atau index.en

File Indonesia memakai lang=id. File Inggris memakai lang=en. Jangan salin satu nilai ke kedua berkas.

Artikel ini tersedia dalam: Indonesia · English

Halaman dua bahasa di proyek Clincoo biasanya hidup sebagai pasangan index.html dan index.en.html. Mesin telusur dan pembaca layar membaca atribut lang pada elemen html, bukan nama folder. Jika kedua berkas masih bertuliskan lang="id", versi Inggris terdengar seperti Indonesia bagi teknologi bantu.

Periksa baris pertama setelah DOCTYPE. Berkas Indonesia harus lang="id". Berkas Inggris harus lang="en". Jangan andalkan switcher saja: switcher hanya menuntun manusia ke URL lain, sementara crawler membuka tiap file secara terpisah.

Atribut lang juga memengaruhi hyphenation, kutipan, dan pengucapan. Kesalahan kecil ini sering lolos pratinjau visual karena desain tidak berubah. Buka kedua URL, lihat source, dan pastikan nilai lang berbeda.

Jika kamu menambah locale ketiga nanti, ulangi pola yang sama: satu berkas, satu kode bahasa BCP 47 yang jujur. Jangan menumpuk beberapa lang di satu dokumen kecuali kutipan singkat memakai lang pada elemen inline.

Setelah mengubah lang, uji switcher, hreflang, dan judul tab. Konsistensi antara berkas, meta, dan tautan antar-bahasa lebih penting daripada menambah bendera di header.
