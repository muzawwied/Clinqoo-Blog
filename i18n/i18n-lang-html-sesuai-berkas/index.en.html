Match the HTML lang Attribute to the index or index.en File

The Indonesian file uses lang=id. The English file uses lang=en. Do not copy one value into both files.

This article is available in: Indonesia · English

Bilingual pages in a Clincoo project usually live as a pair of index.html and index.en.html files. Search engines and screen readers read the lang attribute on the html element, not the folder name. If both files still say lang="id", assistive technology treats the English version as Indonesian.

Check the first line after the DOCTYPE. The Indonesian file must use lang="id". The English file must use lang="en". Do not rely on the language switcher alone: it only guides people to another URL, while crawlers open each file on its own.

The lang attribute also affects hyphenation, quotation marks, and pronunciation. This small mistake often survives a visual preview because the design does not change. Open both URLs, view source, and confirm the lang values differ.

If you add a third locale later, repeat the same pattern: one file, one honest BCP 47 language code. Do not stack several lang values on one document unless a short quotation uses lang on an inline element.

After changing lang, test the switcher, hreflang, and the tab title. Consistency among the file, metadata, and cross-language links matters more than adding flags in the header.
