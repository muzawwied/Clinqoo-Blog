Use Named Imports so Tree-Shaking the Clincoo Bundle Actually Works

A default import from a barrel file often pulls the whole library. Ask for a narrow function path.

This article is available in: Indonesia · English

A barrel index.js that re-exports everything hides which symbols editor.clincoo.buzz actually uses.

Replace a DefaultLib import from a large package with import { usedFn } from an official subpath.

After a preview build, search the output for unused function names. If they remain, tree-shaking failed.

Paste the import snippet to AI and ask for a side-effect-free alternative. Reject a new bundler plugin in the same commit.

Record the import pattern that stays under budget in the app.clincoo.buzz README and link an example on blog.clincoo.buzz.
