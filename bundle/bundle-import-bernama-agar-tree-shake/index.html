Pakai Import Bernama agar Tree-Shake Bundle Clincoo Berhasil

Import default dari barrel file sering menarik seluruh pustaka. Minta path fungsi yang sempit.

Artikel ini tersedia dalam: Indonesia · English

Barrel index.js yang mengekspor semuanya membuat bundler di editor.clincoo.buzz kehilangan petunjuk mana yang dipakai.

Ganti import DefaultLib dari paket besar dengan import { fungsiDipakai } dari subpath resmi.

Setelah build pratinjau, cari nama fungsi yang tidak dipanggil di file hasil. Jika masih ada, tree-shake gagal.

Tempel potongan import ke AI dan minta alternatif side-effect-free. Tolak saran yang menambahkan plugin bundler baru di commit yang sama.

Catat pola import yang lolos budget di README app.clincoo.buzz dan contohnya di blog.clincoo.buzz.
