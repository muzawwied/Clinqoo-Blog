Do Not Split the Clincoo Bundle into Tiny Chunks

A hundred 2 KB files cost more HTTP handshakes than one 40 KB file.

This article is available in: Indonesia · English

Dynamic-importing every button on editor.clincoo.buzz sounds modern, but a request waterfall slows LCP on a slow network.

Keep modules that always load together in one chunk. Split only rare or very heavy screens.

In the preview Network tab, count JS files above 1 KB. If dozens appear before first paint, roll back.

Ask AI for a chunk map, not a lazy() wrapper on every component.

Store an initial-request cap in the app.clincoo.buzz release note and link the audit on blog.clincoo.buzz.
