Jangan Pecah Chunk Bundle Clincoo sampai Terlalu Kecil

Seratus file 2 KB menambah handshake HTTP lebih mahal daripada satu file 40 KB.

Artikel ini tersedia dalam: Indonesia · English

Dynamic import setiap tombol di editor.clincoo.buzz terdengar modern, tetapi waterfall request memperlambat LCP di jaringan lambat.

Gabungkan modul yang selalu dibuka bersama. Pecah hanya layar yang jarang atau sangat berat.

Di tab Network pratinjau, hitung jumlah JS di atas 1 KB. Jika puluhan file muncul sebelum first paint, mundur.

Minta AI mengusulkan peta chunk, bukan menambahkan lazy() di setiap komponen.

Simpan batas jumlah request awal di catatan rilis app.clincoo.buzz dan tautkan audit di blog.clincoo.buzz.
