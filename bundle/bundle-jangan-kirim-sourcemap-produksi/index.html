Jangan Kirim Source Map ke Produksi Bundle Clincoo

File .map membocorkan source dan menambah megabyte pada unduhan pertama.

Artikel ini tersedia dalam: Indonesia · English

Source map berguna di pratinjau editor.clincoo.buzz, bukan di domain publik app.clincoo.buzz.

Matikan generation map untuk build produksi atau unggah map ke penyimpanan privat yang hanya dibuka saat debug.

Cek Network: jika ada permintaan .map 200 dari pengunjung anonim, anggap itu kebocoran.

Jangan minta AI mengaktifkan source map agar error produksi terlihat lebih cantik. Minta logging terstruktur saja.

Dokumentasikan kebijakan map di blog.clincoo.buzz supaya anggota tim tidak menghidupkannya lagi saat panik.
