Fail Clincoo CI when the Bundle Budget Grows without a Reason

A budget that lives only in the README will be broken in silence. Put a gate in the pipeline.

This article is available in: Indonesia · English

Every pull request to app.clincoo.buzz should compare asset size with the previous baseline commit.

If growth is above a threshold (for example 10 KB gzip), CI stays red until the PR describes why.

Do not rely on a manual Lighthouse run on a laptop. Run the size check on the same runner every time.

If AI adds a library, ask for an estimated byte delta first. Reject the merge when the delta is missing.

Publish the budget chart on blog.clincoo.buzz so editor.clincoo.buzz is not treated as unlimited.
