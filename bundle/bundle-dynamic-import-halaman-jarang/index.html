Pakai Dynamic Import untuk Halaman Clincoo yang Jarang Dibuka

Jangan masukkan wizard, modal berat, atau panel admin ke bundle beranda.

Artikel ini tersedia dalam: Indonesia · English

Beranda app.clincoo.buzz tidak perlu membawa editor markdown atau pemilih ikon sampai pengguna membukanya.

Ganti import statis dengan import() di event klik atau rute. Pastikan ada fallback loading yang singkat.

Cek tab Coverage di DevTools setelah pratinjau. Byte yang tetap abu-abu adalah kandidat pecah chunk.

Tempel coverage ke AI dan minta daftar modul yang aman di-lazy-load. Tolak saran yang memindahkan CSS kritis ke chunk lambat.

Ukur LCP sebelum dan sesudah. Simpan angka di catatan rilis blog.clincoo.buzz.
