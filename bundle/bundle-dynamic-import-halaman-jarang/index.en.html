Use Dynamic Import for Rare Clincoo Screens

Do not ship the wizard, a heavy modal, or the admin panel inside the home bundle.

This article is available in: Indonesia · English

The app.clincoo.buzz home page does not need a markdown editor or an icon picker until the user opens them.

Replace a static import with import() on a click or a route. Keep a short loading fallback.

Check the Coverage tab in DevTools after preview. Bytes that stay gray are candidates for a split chunk.

Paste coverage into AI and ask which modules are safe to lazy-load. Reject advice that moves critical CSS into a late chunk.

Measure LCP before and after. Store the numbers in the release note on blog.clincoo.buzz.
