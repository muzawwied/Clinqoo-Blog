Cek Modul Ganda di Bundle Clincoo lewat DevTools

Dua salinan lodash atau runtime yang sama merusak budget tanpa terlihat di source.

Artikel ini tersedia dalam: Indonesia · English

Buka pratinjau editor.clincoo.buzz, tab Network, filter JS. Urutkan menurut ukuran. Nama chunk yang mencurigakan sering menyimpan duplikat.

Gunakan visualizer bundler atau pencarian string versi pustaka di file hasil build. Dua versi React atau date library adalah alarm.

Perbaiki lewat resolusi tunggal di package manager, bukan dengan menghapus fitur secara acak.

Kirim output duplikat ke AI beserta lockfile singkat. Minta satu perintah perbaikan, bukan rewrite seluruh config.

Ulangi ukur transfer di app.clincoo.buzz setelah lockfile terkunci.
