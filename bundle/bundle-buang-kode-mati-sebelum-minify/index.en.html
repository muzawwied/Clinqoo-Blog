Drop Dead Code from the Clincoo Bundle before You Minify

Minify shrinks letters, not features nobody calls. Delete dead branches first.

Old flags and test helpers often linger in editor.clincoo.buzz source and ship because something still imports them.

Find exports that nobody imports. Delete the file instead of commenting out the call.

Coverage in preview marks functions that never turn green. Those are delete candidates, not compress candidates.

Send the orphan export list to AI. Ask for a per-file delete patch, not a folder rewrite.

Measure app.clincoo.buzz transfer again after dead branches are gone. Record the delta on blog.clincoo.buzz.
