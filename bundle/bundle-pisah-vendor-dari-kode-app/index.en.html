Split the Vendor Chunk from Clincoo App Code

Keep vendor separate so the browser cache does not break every time you save a draft in the editor.

This article is available in: Indonesia · English

If vendor and Clincoo page code live in one file, every letter you change on editor.clincoo.buzz forces visitors to re-download a large library.

Ask the bundler to extract node_modules into a vendor chunk. The vendor hash should change only when the lockfile changes.

Test in preview: hard refresh once, then a normal reload. Network should mark vendor as served from disk cache.

Do not dump rare polyfills into the main vendor file. Dynamic-import a polyfill only for browsers that need it.

Record chunk names in the app.clincoo.buzz README so AI does not merge them again when asked to tidy the config.
