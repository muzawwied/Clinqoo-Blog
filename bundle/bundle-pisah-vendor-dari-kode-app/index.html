Pisahkan Chunk Vendor dari Kode Aplikasi Clincoo

Pisah vendor agar cache browser tidak pecah setiap kali Anda menyimpan draf di editor.

Artikel ini tersedia dalam: Indonesia · English

Jika vendor dan kode halaman Clincoo berada di satu file, setiap huruf yang diubah di editor.clincoo.buzz memaksa pengunjung mengunduh ulang pustaka besar.

Minta bundler mengekstrak node_modules ke chunk vendor. Hash vendor hanya berubah saat lockfile berubah.

Uji di pratinjau: hard refresh sekali, lalu muat ulang biasa. Network harus menandai vendor dari disk cache.

Jangan campur polyfill langka ke vendor utama. Dynamic import polyfill hanya untuk browser yang membutuhkannya.

Catat nama chunk di README app.clincoo.buzz supaya AI tidak menggabungkan semuanya lagi saat diminta merapikan config.
