Debounce Clincoo Autosave so Timers Do Not Stack

Every keystroke that resets setTimeout without clearTimeout stacks saves. One debounce timer is enough.

This article is available in: Indonesia · English

On editor.clincoo.buzz, autosave sits on input. Each letter creates a new timeout while the old one still lives.

Keep the timer id in a module variable. clearTimeout before a new setTimeout. Do not use an interval for autosave.

Send the input handler to AI, not the whole editor. Ask for one 600ms debounce pattern.

Test on app.clincoo.buzz: type quickly and confirm only one request after you stop. Note it on blog.clincoo.buzz.
