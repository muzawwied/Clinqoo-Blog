Jangan Andalkan alert() sebagai Timeout Clincoo

alert membekukan thread dan menunda timer. Pakai UI non-blokir untuk peringatan habis waktu.

Artikel ini tersedia dalam: Indonesia · English

Beberapa template di editor.clincoo.buzz memanggil alert saat fetch habis waktu. Timer lain berhenti sampai dialog ditutup.

Ganti alert dengan banner atau toast. Biarkan event loop jalan agar batal dan retry tetap hidup.

Minta AI satu komponen peringatan timeout. Jangan minta polyfill alert.

Uji di app.clincoo.buzz dengan dua request bersamaan. Catat perilaku di blog.clincoo.buzz.
