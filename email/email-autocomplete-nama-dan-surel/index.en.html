Use autocomplete on Name and Email Fields in Clincoo Forms

The right autocomplete values let a password manager fill name and email. Do not leave fields anonymous.

This article is available in: Indonesia · English

Clincoo contact forms often only have a name and a type. The browser then guesses, or refuses to fill. Visitors retype an address they already stored.

Set autocomplete="name" on the name input and autocomplete="email" on type="email". Wire labels with for and id so screen readers and text clicks work.

Do not set autocomplete="off" just because autofill breaks a layout. Fix the CSS; turning off fill hurts mobile users.

Test in Chrome and Firefox with a profile that has a saved contact. If values never appear, check a colliding name attribute or script that overwrites value on load.

A form that is easy to complete yields fewer empty messages. Clincoo renders the HTML you write; these standard attributes need no library.
