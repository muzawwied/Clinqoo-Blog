Rate-limit Clincoo Email Form Resubmits So They Do Not Look Like Spam

Repeated send clicks create duplicate mail. Lock the button and show a short countdown.

This article is available in: Indonesia · English

Contact forms on app.clincoo.buzz are often clicked twice because the network feels slow. The inbox fills with identical copies.

After a valid submit, disable the button for 20–30 seconds and change the label to Sending. Do not clear fields before a success status.

Store the last send timestamp in sessionStorage, not only a memory variable, so a refresh cannot send again immediately.

Ask AI to review the submit handler: is preventDefault present, and is the button locked while pending? Do not ask AI to send a test mail to a real address.

Write the resend limit on blog.clincoo.buzz so visitors know a second message is not lost, only delayed.
