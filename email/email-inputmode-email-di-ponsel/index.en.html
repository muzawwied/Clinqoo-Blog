Show the @ Keyboard on Clincoo Email Fields with inputmode=email

type=email validates format. inputmode=email shows an @ keyboard on phones. Use both together on Clincoo forms.

This article is available in: Indonesia · English

Many Clincoo contact forms already use type="email". That helps browser validation, but a phone keyboard does not always show @ and period keys. Visitors must switch layouts — a small friction that cuts submissions.

inputmode="email" hints the user agent about the expected keyboard. MDN separates type (meaning and validation) from inputmode (keyboard presentation). Both can live on the same element without conflict.

Minimal example: . Pair it with a for label, as in the label article in this category.

DevTools Device Toolbar is not enough to see the real keyboard. Open the preview on a physical phone or a system emulator. Confirm the @ key appears and autocorrect does not mangle addresses.

Do not change type to text just to force a custom keyboard. You lose :invalid validation. Keep type=email, add inputmode, and let CSS place the error message next to the field.
