Tutup Tab File yang Tidak Sedang Kamu Sentuh

Tab menumpuk di editor Clincoo membuat fokus pecah. Sisakan hanya berkas yang benar-benar kamu ubah.

Artikel ini tersedia dalam: Indonesia · English

File explorer Clincoo memudahkan membuka banyak berkas. Masalahnya muncul saat sepuluh tab tetap terbuka padahal kamu hanya merapikan satu heading. Mata meloncat, dan perubahan tersimpan di file yang salah.

Biasakan menutup tab setelah selesai dengan satu bagian. Sisakan HTML dan CSS yang sedang berpasangan, atau satu skrip yang sedang kamu uji. Tab lain bisa dibuka lagi dalam dua klik dari explorer.

Kalau suatu file perlu jadi pengingat, tulis catatan singkat di komentar, jangan biarkan tabnya hidup seharian. Tab adalah ruang kerja, bukan papan pengumuman.

Editor yang ramping terasa lebih cepat meski kodenya sama. Kamu menyelesaikan satu halaman, bukan merawat museum tab.
