Write the Session Target in an HTML Comment Before You Start

Before editing in Clinqoo, write one line about what should get done. The next session will not start in confusion.

This article is available in: Indonesia · English

Opening the editor with no target lets you tweak colors for an hour. Put a short comment above the body: today replace the hero copy and check the phone menu. That is a fence.

Do only what is written. If a new idea appears, add it to the comment as a queue item instead of doing it now. Save, preview the main target, then end the session.

Tomorrow you read that comment and know where to start. Clinqoo stores files; the comment stores intent. You need both so the project does not spin in place.

Delete or replace the comment when the target is done so it does not mislead you. A living work trail beats a wish list that never gets checked.
