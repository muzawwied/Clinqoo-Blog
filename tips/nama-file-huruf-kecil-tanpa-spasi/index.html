Beri Nama File Huruf Kecil dan Tanpa Spasi

Spasi dan huruf besar-kecil yang acak sering merusak tautan setelah deploy. Rapikan nama di editor Clinqoo.

Artikel ini tersedia dalam: Indonesia · English

Di laptop, foto saya.jpg terlihat biasa. Di web, spasi jadi %20 dan huruf besar-kecil bisa membedakan file. Setelah deploy Clinqoo, gambar pecah sering karena nama di HTML tidak sama persis dengan nama di folder.

Pakai pola sederhana: huruf kecil, strip sebagai pemisah, ekstensi yang jelas. Contoh: hero-beranda.jpg, style.css, kontak.html. Hindari spasi, tanda kurung, dan emoji di nama berkas.

Kalau sudah terlanjur, ganti nama di file explorer lalu perbarui setiap tautan. Simpan, pratinjau, baru deploy. Satu putaran ini lebih murah daripada menjelaskan ke teman kenapa fotonya kosong.

Nama rapi juga memudahkan pencarian di explorer dan di chat AI. Kamu menyebut file yang sama dengan orang lain tanpa terjemahan.
