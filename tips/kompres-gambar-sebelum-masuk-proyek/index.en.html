Compress Images Before They Enter the Project

A hero image still the size of a camera photo makes Clinqoo preview feel heavy. Shrink it first, then upload.

This article is available in: Indonesia · English

A static site on Clinqoo stays fast as long as the assets are reasonable. Photos straight from a phone often weigh several megabytes. One hero image can make preview and the first visit feel slow.

Before the image hits the file explorer, shrink the resolution toward what the screen actually shows — about 1200 pixels wide is enough for most banners. Save as JPEG or WebP at medium quality, not the raw file.

Use a clear name without spaces, then link a relative path from the HTML. After you save, open preview on a phone. If scrolling still stutters, the image is still too large.

Deploy does not fix a heavy photo. Cleaning assets early makes the site feel tidy from the first shared link.
