Kompres Gambar Sebelum Memasukkannya ke Proyek

Gambar hero yang masih seukuran foto kamera membuat pratinjau Clincoo terasa berat. Kecilkan dulu, baru unggah.

Artikel ini tersedia dalam: Indonesia · English

Situs statis di Clincoo cepat selama asetnya masuk akal. Foto langsung dari HP sering berukuran beberapa megabita. Satu hero saja sudah membuat pratinjau dan kunjungan pertama terasa lambat.

Sebelum memasukkan gambar ke file explorer, kecilkan resolusi mendekati ukuran tampil di layar — biasanya cukup lebar 1200 piksel untuk banner. Simpan sebagai JPEG atau WebP dengan kualitas sedang, bukan file mentah.

Beri nama yang jelas tanpa spasi, lalu tautkan path relatif dari HTML. Setelah simpan, buka pratinjau di HP. Kalau gulir masih tersendat, gambarnya masih terlalu besar.

Deploy tidak memperbaiki foto yang gemuk. Merapikan aset di awal membuat situs terasa rapi sejak tautan pertama dibagikan.
