Pakai keepalive pada Fetch Clincoo saat Halaman Ditutup

Fetch biasa dibatalkan saat unload. Opsi keepalive menjaga beacon analitik dan simpan draf singkat tetap terkirim.

Artikel ini tersedia dalam: Indonesia · English

Pengunjung menutup tab sebelum fetch selesai. Request analitik atau simpan draf di Clincoo hilang karena konteks dokumen sudah dihancurkan.

Tambahkan keepalive: true pada fetch yang dipicu visibilitychange atau pagehide. MDN mendokumentasikan batas ukuran body yang kecil; jangan pakai opsi ini untuk unggah file besar.

web.dev menyarankan kombinasi fetch keepalive atau sendBeacon untuk data singkat saat halaman pergi. Pilih satu jalur agar tidak dobel hit.

Di editor.clincoo.buzz, pisahkan fungsi telemetry dari fungsi simpan form utama. Form utama tetap menunggu respons; beacon cukup fire-and-forget.

Uji dengan menutup pratinjau segera setelah aksi. Server harus tetap menerima POST kecil. Pola ini menstabilkan metrik di app.clincoo.buzz tanpa menahan navigasi.
