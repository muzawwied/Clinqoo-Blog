Use keepalive on Clincoo Fetch When the Page Unloads

A normal fetch is canceled on unload. The keepalive option lets short analytics beacons and draft saves still leave.

This article is also available in: Indonesia · English

A visitor closes the tab before fetch finishes. Analytics or draft-save requests on Clincoo vanish because the document context is already gone.

Add keepalive: true on fetch calls triggered by visibilitychange or pagehide. MDN documents a small body size limit; do not use this option for large uploads.

web.dev suggests fetch keepalive or sendBeacon for short data when the page leaves. Pick one path so you do not double-hit.

In editor.clincoo.buzz, split telemetry from the main form save. The main form still awaits a response; a beacon can be fire-and-forget.

Test by closing preview right after the action. The server should still receive the small POST. This keeps metrics on app.clincoo.buzz stable without blocking navigation.
