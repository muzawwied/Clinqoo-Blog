Cek res.ok Sebelum res.json di Fetch Clincoo

HTTP 400 tetap bisa diparse sebagai JSON. Status harus dicek dulu.

Artikel ini tersedia dalam: Indonesia · English

Fetch di editor.clincoo.buzz sering dianggap sukses hanya karena promise tidak reject. Status 400 dan 500 tidak melempar otomatis.

Setelah const res = await fetch(url), cek if (!res.ok) lalu baca teks error. Baru panggil res.json() saat status 2xx.

Tampilkan pesan ke pengguna dari body error, bukan hanya Failed to fetch. Failed to fetch biasanya jaringan atau CORS.

Tempel status, URL, dan potongan body ke AI. Jangan minta AI menambah retry agresif sebelum Anda baca status.

Samakan penanganan di app.clincoo.buzz dan catatan di blog.clincoo.buzz supaya draf dan produksi tidak beda diam-diam.
