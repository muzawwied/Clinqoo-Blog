Body Respons Fetch Clincoo Hanya Bisa Dibaca Sekali

response.json() mengunci stream. Pemanggilan text() atau json() kedua melempar error body already used.

Artikel ini tersedia dalam: Indonesia · English

Logger Clincoo memanggil response.text() untuk debug, lalu kode bisnis memanggil response.json(). Promise kedua ditolak karena body adalah stream sekali baca.

MDN Response menjelaskan bodyUsed. Setelah json(), clone() sudah terlambat. Clone sebelum baca jika dua konsumen membutuhkan payload yang sama.

Di editor.clincoo.buzz, baca sekali ke konstanta data, lalu log salinan itu. Jangan membaca ulang objek Response.

GitHub docs tentang fetch di Actions juga memperlakukan body sebagai stream. Pola yang sama berlaku di browser statis Clincoo.

Uji cabang sukses dan error. Pesan body already used hilang jika satu fungsi parse menjadi sumber data tunggal untuk UI di app.clincoo.buzz.
