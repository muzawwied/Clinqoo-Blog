How to Attribute a Licensed Image

An Unsplash photo, a licensed icon, or someone else's illustration is not free to use just because it shows in preview. If the license asks for credit, put it on the site you publish from app.clincoo.buzz.

Check the terms before download

Read whether credit is required, whether edits are allowed, and whether commercial use is allowed. Save the download page URL in the project notes. Do not rely on the filename alone.

Write a clickable credit

One footer line is enough: creator name, source, and link. Example: Photo by Name via Unsplash. Place it near the privacy-policy link so visitors find it without a long scroll.

Do not drop it while cleaning CSS

When you polish layout in editor.clincoo.buzz, make sure the credit block is not deleted with it. If you swap the image, update the credit line in the same commit.
