Clincoo Project Storage and Backup Policy

Where project files live, what automatic backup means, and the limits if you delete a file yourself.

This article is available in: Indonesia · English

Files you write in the Clincoo editor live in your account project space. Backups exist to recover from service incidents, not to replace a save habit. Last updated: 18 September 2026.

Source of truth

The file you save in the editor is the version the platform holds. Do not rely on an unsaved tab.

Platform backup

Technical backups help recover infrastructure incidents. They are not a time machine for every keystroke you undo yourself.

User deletion

If you delete a file or project, treat that content as gone from the workspace. Export first if you still need it.

Practical advice

Save often, connect GitHub when you can, and download a copy before a large rewrite. Write halo@clincoo.buzz for service incidents, not to restore files you deleted on purpose.
