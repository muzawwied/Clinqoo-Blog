Kebijakan Penyimpanan Proyek dan Cadangan Clincoo

Di mana berkas proyek tinggal, apa artinya cadangan otomatis, dan batas tanggung jawab jika kamu menghapus file sendiri.

Artikel ini tersedia dalam: Indonesia · English

Berkas yang kamu tulis di editor Clincoo tinggal di ruang proyek akunmu. Cadangan ada untuk memulihkan gangguan layanan, bukan untuk mengganti kebiasaan simpan. Terakhir diperbarui: 18 September 2026.

Sumber kebenaran

File yang kamu simpan di editor adalah versi yang dipegang platform. Jangan mengandalkan tab yang belum disimpan.

Cadangan platform

Cadangan teknis membantu memulihkan insiden infrastruktur. Itu bukan mesin waktu untuk setiap ketikan yang kamu batalkan sendiri.

Penghapusan oleh pengguna

Kalau kamu menghapus file atau proyek, anggap isi itu hilang dari ruang kerja. Ekspor lebih dulu jika masih dibutuhkan.

Saran praktis

Simpan sering, hubungkan GitHub bila ada, dan unduh salinan sebelum merombak besar. Tanya halo@clincoo.buzz hanya untuk gangguan layanan, bukan untuk memulihkan file yang sengaja dihapus.
