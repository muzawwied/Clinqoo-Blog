Preload Font Kritis Judul di Situs Clincoo

Font judul yang terlambat membuat LCP tertahan. Preload satu file woff2 yang benar-benar dipakai hero Clincoo.

Artikel ini tersedia dalam: Indonesia · English

Judul hero sering jadi elemen LCP. Kalau keluarga font masih diunduh setelah CSS selesai, teks tampil dengan fallback dulu lalu loncat. Di workspace Clincoo, simpan satu berkas woff2 untuk bobot yang dipakai judul, bukan seluruh keluarga.

Tambahkan tautan preload di head halaman yang memakai judul itu: rel="preload" as="font" type="font/woff2" crossorigin, lalu href ke file di folder assets. Tanpa crossorigin, browser bisa mengunduh font dua kali. Jangan preload italic, extra-bold, atau file yang tidak muncul di lipatan pertama.

Pasangkan dengan @font-face yang memakai font-display: swap dan src lokal. Preload tanpa @font-face yang cocok hanya membuang bandwidth. Cek di Network pratinjau bahwa permintaan font dimulai sebelum gambar hero besar.

Setelah deploy subdomain Clincoo, ukur lagi di HP. Kalau LCP tetap gambar, preload font tidak merugikan asalkan hanya satu file. Kalau LCP teks judul, preload yang tepat memangkas jeda fallback.

Hapus preload yang tidak terpakai saat kamu ganti merek atau turunkan judul ke sistem font. Preload usang tetap dihitung sebagai sumber prioritas dan bisa menunda CSS.
