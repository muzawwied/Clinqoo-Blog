Use content-visibility on Long Sections of a Clincoo Site

A long page forces the browser to lay out content that is not visible yet. content-visibility: auto defers that work.

This article is available in: Indonesia · English

Service or docs pages on blog.clincoo.buzz and client sites often have many sections below the fold. The browser still measures all of them on load.

On sections far below, add content-visibility: auto and contain-intrinsic-size so the scrollbar does not jump. Do not use it on the hero or LCP content.

Test in the DevTools Performance panel. Initial render time should drop, and hero text stays visible immediately. If the guessed height is wrong, the page jumps while scrolling.

This does not replace lazy images or a light stylesheet. Use it after image dimensions and fonts are settled, and only on long lists or blocks.
