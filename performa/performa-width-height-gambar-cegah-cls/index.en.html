Set Image width and height so Clincoo Layout Does Not Jump

An image without dimensions forces the browser to guess height. That empty slot becomes a layout jump when the file finishes.

This article is available in: Indonesia · English

On an app.clincoo.buzz page, a jumping hero is usually an image without width and height. The browser cannot reserve space.

Set width and height to the intrinsic ratio, then cap display with max-width: 100% and height: auto.

Do not use a full-page PNG screenshot for a small icon. The file size also holds back LCP.

For images below the fold, add loading=lazy, but still set dimensions so CLS does not arrive later.

When asking AI for help, send the img tag and file size, not only a note that the page feels slow.
