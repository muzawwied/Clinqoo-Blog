Isi width dan height Gambar agar Layout Clincoo Tidak Melompat

Gambar tanpa ukuran memaksa browser menebak tinggi. Slot kosong itu menjadi lompatan layout saat berkas selesai diunduh.

Artikel ini tersedia dalam: Indonesia · English

Di halaman app.clincoo.buzz, hero yang melonjak biasanya gambar tanpa width dan height. Browser tidak bisa menyiapkan ruang.

Tulis width dan height sesuai rasio intrinsik, lalu batasi tampilan dengan CSS max-width: 100% dan height: auto.

Jangan pakai gambar screenshot PNG penuh halaman untuk ikon kecil. Ukuran berkas ikut menahan LCP.

Untuk gambar di bawah lipatan, tambahkan loading=lazy, tetapi tetap isi ukuran agar tidak ada CLS belakangan.

Saat minta bantuan AI, kirim tag img dan ukuran berkas, bukan hanya keluhan halaman terasa lambat.
