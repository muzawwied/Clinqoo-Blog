Isi width dan height Gambar Clincoo supaya Layout Tidak Loncat

Gambar tanpa ukuran cadangan merusak CLS. Tulis width dan height intrinsik sebelum unggah ke workspace.

Artikel ini tersedia dalam: Indonesia · English

Hero dan foto produk di situs Clincoo sering muncul setelah teks. Tanpa cadangan ruang, judul dan tombol terdorong ke bawah saat file selesai dimuat. Pengunjung yang hampir menekan CTA malah mengenai tautan lain.

Tulis atribut width dan height sesuai piksel asli file. Browser menghitung rasio aspek dan menyiapkan kotak kosong. CSS boleh men-set max-width: 100% dan height: auto; rasio dari atribut tetap dipakai.

Jangan andalkan hanya min-height tebakan. Nilai yang salah tetap membuat loncatan. Cek dimensi di properti file sebelum masuk workspace, lalu tempel angka yang sama ke markup di editor.clincoo.buzz.

Gambar dekoratif di bawah lipatan boleh lazy-load, tetapi tetap butuh ukuran. Lazy tanpa width/height menunda loncatan, bukan menghapusnya. Utamakan LCP hero yang sudah punya kotak cadangan.

Setelah rilis, buka pratinjau HP dan hard refresh. Jika teks tidak bergeser saat gambar muncul, atribut sudah bekerja. Halaman yang tenang terasa lebih cepat meski berat file sama.
