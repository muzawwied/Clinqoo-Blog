Jangan Taruh Catatan Kaki Markdown di Hero Clincoo

Footnote di hero merusak alur baca HP. Simpan catatan di akhir halaman atau jadikan tautan biasa.

Artikel ini tersedia dalam: Indonesia · English

Banyak draf Clincoo menempel catatan kaki di kalimat hero supaya terlihat ilmiah. Di HP, angka superscript kecil sulit diketuk dan membawa pengunjung ke dasar halaman sebelum pesan utama selesai.

Markdown footnote cocok untuk definisi di artikel panjang, bukan untuk CTA. Kalau sumber wajib disebut di hero, tulis tautan biasa dengan judul yang jelas, misalnya dokumentasi Clincoo atau MDN.

Uji di pratinjau editor.clincoo.buzz: ketuk angka catatan. Jika lompatannya memutus alur, pindahkan catatan ke bagian Sumber di akhir halaman.

Screen reader membacakan referensi dua kali: di kalimat lalu di daftar footnote. Hero yang sudah padat jadi lebih berisik.

Clincoo merender Markdown ke HTML apa adanya. Jaga hero tetap satu pesan, satu tindakan. Catatan kaki bukan dekorasi judul.
