Don't Put Markdown Footnotes in the Clincoo Hero

Footnotes in the hero break mobile reading flow. Keep notes at the end of the page or use a normal link.

Indonesia · English

Many Clincoo drafts drop footnotes into the hero to look scholarly. On a phone the tiny superscript is hard to tap and sends people to the footer before the main message lands.

Markdown footnotes suit definitions in long articles, not a CTA. If a source must appear in the hero, use a normal link with a clear title such as Clincoo docs or MDN.

Test in the editor.clincoo.buzz preview: tap the footnote mark. If the jump breaks the story, move the note into a Sources block at the bottom.

Screen readers announce the reference twice: in the sentence and again in the footnote list. A crowded hero gets noisier.

Clincoo ships whatever Markdown you save. Keep the hero to one message and one action. A footnote is not title decoration.
