Bungkus Nama Properti dengan Code Span di Markdown Clincoo

Nama CSS dan fungsi yang menempel di kalimat biasa sulit dipindai. Pakai code span, bukan blok kode.

Artikel ini tersedia dalam: Indonesia · English

Di draf blog.clincoo.buzz, penulis sering menaruh box-sizing atau fetch sebagai teks biasa. Pembaca tidak langsung melihat bahwa itu nama teknis.

Bungkus satu nama dengan backtick: `box-sizing`, `localStorage`, `index.html`. Blok kode hanya untuk cuplikan lebih dari satu baris.

Jangan pakai heading hanya untuk menonjolkan nama properti. Heading untuk struktur, code span untuk token.

Pratinjau ID dan EN di editor.clincoo.buzz. Pastikan backtick tidak berubah jadi kutipan lurus.

Jika AI menulis ulang draf, minta ia mempertahankan code span dan tidak mengubah nama properti.
