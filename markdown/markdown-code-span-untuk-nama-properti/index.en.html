Wrap Property Names in a Code Span in Clincoo Markdown

CSS and function names in plain sentences are hard to scan. Use a code span, not a code block.

This article is available in: Indonesia · English

In a blog.clincoo.buzz draft, writers often leave box-sizing or fetch as plain text. Readers do not immediately see that it is a technical name.

Wrap a single name in backticks: `box-sizing`, `localStorage`, `index.html`. Use a code block only for a snippet longer than one line.

Do not use a heading just to highlight a property name. Headings are structure; code spans are tokens.

Preview ID and EN in editor.clincoo.buzz. Make sure backticks do not become straight quotes.

If an AI rewrites the draft, ask it to keep code spans and not rename properties.
