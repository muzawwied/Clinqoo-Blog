Check Markdown Heading ids before Creating Clincoo Anchor Links

#section links break when headings change. Keep heading slugs stable before using them in a menu or table of contents.

This article is available in: Indonesian · English

Clincoo Markdown drafts often link to subheadings. When the title changes, the old hash points at nothing.

After preview renders, inspect the heading and note the generated id. Match table-of-contents hrefs to that id, not a guessed slug.

Avoid headings that differ only by punctuation. Similar titles can collide or produce slugs that are hard to type on a phone.

If you need a stable anchor, set an explicit HTML id on the heading and do not rely on the auto generator while you tidy the draft.

Test anchor links in the narrow preview. A sticky Clincoo header must not cover the target; add scroll-margin-top on headings.
