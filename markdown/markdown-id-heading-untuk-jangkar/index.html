Cek id Heading Markdown sebelum Membuat Tautan Jangkar Clincoo

Tautan #bagian pecah jika heading berubah. Pastikan slug heading stabil sebelum dipakai di menu atau daftar isi.

Artikel ini tersedia dalam: Indonesia · English

Draf Markdown di Clincoo sering memakai tautan jangkar ke subjudul. Saat judul diubah, hash lama mengarah ke kosong.

Setelah merender pratinjau, inspeksi heading dan catat atribut id yang dihasilkan. Samakan teks tautan daftar isi dengan id itu, bukan dengan tebakan slug.

Hindari heading yang hanya berbeda tanda baca. Dua judul serupa bisa menghasilkan id bentrok atau slug yang sulit diketik di HP.

Jika kamu butuh jangkar yang tidak berubah, tambahkan id HTML eksplisit pada heading dan jangan andalkan generator otomatis saat merapikan draf.

Uji tautan jangkar di pratinjau sempit. Header sticky Clincoo tidak boleh menutupi target; beri scroll-margin-top pada heading.
