Batasi Kedalaman Daftar Bersarang di Draf Markdown Clincoo

Daftar tiga tingkat merusak lebar HP. Dua tingkat biasanya cukup untuk panduan.

Artikel ini tersedia dalam: Indonesia · English

Draf Markdown di workspace Clincoo sering menumpuk sub-poin sampai empat tingkat. Di layar ponsel, indentasi makan lebar dan pembaca kehilangan hierarki.

Pakai paling banyak dua tingkat. Kalau butuh rincian, pecah menjadi heading H3 plus daftar datar. CommonMark memperlakukan indentasi ketat; campuran tab dan spasi mematahkan pratinjau.

GitHub Docs menyarankan daftar pendek dan heading yang jelas. Itu selaras dengan outline HTML yang dihasilkan Clincoo setelah konversi.

Minta AI meratakan satu daftar bersarang: turunkan jadi dua tingkat, jangan ubah tautan. Tempel ke editor.clincoo.buzz dan cek lebar sempit.

Panduan yang dangkal lebih mudah dipelihara dan lebih aman dibaca di app.clincoo.buzz dari HP.
