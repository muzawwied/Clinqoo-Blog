Limit Nested List Depth in Clincoo Markdown Drafts

Three-level lists break phone width. Two levels are usually enough for a guide.

This article is available in: Indonesia · English

Markdown drafts in a Clincoo workspace often nest bullets four levels deep. On a phone, indentation eats width and readers lose the hierarchy.

Use two levels at most. If you need detail, split into an H3 heading plus a flat list. CommonMark treats indentation strictly; mixed tabs and spaces break preview.

GitHub Docs favor short lists and clear headings. That matches the HTML outline Clincoo emits after conversion.

Ask AI to flatten one nested list: drop to two levels, do not change links. Paste into editor.clincoo.buzz and check the narrow width.

Shallow guides are easier to maintain and safer to read on app.clincoo.buzz from a phone.
