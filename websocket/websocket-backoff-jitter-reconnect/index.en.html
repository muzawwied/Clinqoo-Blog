Add Jitter to Clincoo WebSocket Reconnect Backoff

Reconnects that fire together after a drop create a thundering herd on Clincoo. Randomize the backoff delay.

This article is available in: Indonesia · English

On editor.clincoo.buzz, live sockets often drop together when an office network blinks. If every client waits 1 second and reconnects, the API is overwhelmed.

Use delays of 1s, 2s, 4s, then add 0–400 ms of random jitter. Cap attempts, for example at 6, then show a retry button.

Do not reset the counter when another message arrives. Reset only after the connection has stayed open for a few seconds.

Paste the reconnect function to AI and ask for a case test: drop at second 0, 3 clients, without jitter versus with jitter. Do not ask AI to open a real socket.

Record the attempt cap on blog.clincoo.buzz so app.clincoo.buzz preview does not reconnect forever.
