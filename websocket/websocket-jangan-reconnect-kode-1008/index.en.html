Do Not Reconnect a Clincoo WebSocket on Close Code 1008

Code 1008 means policy rejected the socket. Auto-retry only floods the server logs.

This article is available in: Indonesia · English

On editor.clincoo.buzz the close event carries code and reason. Codes 1000 or 1001 may be scheduled again. Code 1008 (policy violation) must not.

If the code is 1008 or a custom 4001, stop backoff, show a safe reason, and ask the user to sign in again on app.clincoo.buzz.

Do not put the token in the socket query string. A header or a first auth message is easier to revoke when the session dies.

Paste the onclose handler to AI and ask for a table: code, may reconnect, UI text. Do not ask AI to open a real socket.

Record the code list on blog.clincoo.buzz so preview does not retry a connection that was rejected on purpose.
