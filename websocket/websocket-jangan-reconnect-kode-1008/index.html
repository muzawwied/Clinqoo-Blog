Jangan Reconnect WebSocket Clincoo pada Close Code 1008

Kode 1008 berarti kebijakan menolak sambungan. Mengulang otomatis hanya membanjiri log server.

Artikel ini tersedia dalam: Indonesia · English

Di editor.clincoo.buzz, event close membawa code dan reason. Kode 1000 atau 1001 boleh dijadwalkan ulang. Kode 1008 (policy violation) tidak boleh.

Jika code 1008 atau 4001 buatan server, hentikan backoff, tampilkan reason yang aman, dan minta pengguna masuk ulang di app.clincoo.buzz.

Jangan kirim token di query string soket. Header atau pesan auth pertama lebih mudah dicabut saat sesi mati.

Tempel handler onclose ke AI dan minta tabel: code, boleh reconnect, teks UI. Jangan minta AI membuka soket sungguhan.

Catat daftar kode di blog.clincoo.buzz agar pratinjau tidak mengulang sambungan yang memang ditolak.
