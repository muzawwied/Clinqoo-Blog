Keyboard

How to Avoid Preventing Every keydown

A document keydown listener that always calls preventDefault freezes Tab and stops forms from submitting. In editor.clincoo.buzz prevent the default only for the combination you actually handle.

Check the target and the combo first

Ignore the event when the target is an input, textarea, or select, unless the shortcut is meant for that field. Compare event.key, not keyCode. Call preventDefault only after the condition matches, for example Ctrl plus a letter the browser does not use.

Do not capture Tab globally

Tab is the focus order. Swallowing it forces a mouse. If a panel needs a focus trap, keep it inside that panel, not on the whole page. Test on app.clincoo.buzz with the keyboard only.

Remove the listener when the panel closes

A leftover listener keeps eating keys on the next page. Remove it when the component unmounts, and note the symptom on blog.clincoo.buzz if Tab is still stuck after release.
