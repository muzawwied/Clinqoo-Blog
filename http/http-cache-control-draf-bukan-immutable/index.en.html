Do Not Use Cache-Control: immutable on Clincoo Draft HTML

immutable lets the CDN keep draft HTML. After a save in the editor, preview still shows the old version.

This article is available in: Indonesia · English

Draft HTML on editor.clincoo.buzz changes on every save. immutable or a long max-age keeps a copy at the edge.

Use Cache-Control: no-store on HTML that carries a token or draft body. Static assets (CSS, logo) may use a long max-age plus a hashed filename.

If preview does not change, open DevTools Network, read the response headers, then purge the CDN. Do not assume 'the browser is broken'.

Send a header screenshot to AI. Do not ask AI for a new service worker before you check Cache-Control.

Clincoo on app.clincoo.buzz splits cache rules for dynamic HTML and hashed assets.
