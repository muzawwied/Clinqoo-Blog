Jangan Cache-Control: immutable pada Draf HTML Clincoo

immutable membuat CDN menahan HTML draf. Setelah simpan di editor, pratinjau masih menampilkan versi lama.

Artikel ini tersedia dalam: Indonesia · English

HTML halaman draf di editor.clincoo.buzz berubah setiap simpan. Header immutable atau max-age panjang menahan salinan di edge.

Pakai Cache-Control: no-store pada HTML yang memuat token atau isi draf. Aset statis (CSS, logo) boleh max-age panjang plus hash nama file.

Jika pratinjau tidak berubah, buka DevTools Network, lihat header respons, lalu purge CDN. Jangan tebak 'browser rusak'.

Kirim screenshot header ke AI. Jangan minta AI menulis service worker baru sebelum Anda cek Cache-Control.

Clincoo di app.clincoo.buzz memisahkan cache HTML dinamis dan aset hashed.
