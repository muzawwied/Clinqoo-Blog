Bedakan Gagal Jaringan dan Status HTTP di Clincoo

TypeError dari fetch bukan 500. Jangan tampilkan pesan server saat kabel putus.

Artikel ini tersedia dalam: Indonesia · English

Di editor.clincoo.buzz, fetch yang gagal karena offline melempar TypeError. Status 500 tetap resolve. Mencampur keduanya membuat pengguna salah arah.

Bungkus fetch di try/catch. Catch = jaringan atau CORS. Then + status >= 400 = jawaban server. Tampilkan teks berbeda.

Cek navigator.onLine hanya sebagai petunjuk, bukan bukti. Online true tidak menjamin app.clincoo.buzz terjangkau.

Tempel stack TypeError utuh ke AI. Jangan minta AI menyamakan semua gagal jadi 'server down'.

Clincoo di blog.clincoo.buzz tidak memanggil API; di aplikasi, pemisahan error ini menjaga pesan tetap jujur.
