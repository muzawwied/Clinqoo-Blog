Use PUT or PATCH to Update a Clincoo Draft, Not Repeated POST

POSTing to the create URL on every save twins the draft. An update needs a method that targets the same resource.

This article is available in: Indonesia · English

A save button on editor.clincoo.buzz that always POSTs to /drafts creates a new row on app.clincoo.buzz.

Once the draft has an id, send PUT or PATCH to /drafts/:id. POST is only for the first create.

If the API only accepts POST, send the same id field and ask the server to upsert. Do not guess from the page title.

Paste two save logs (create then update) to AI. Do not ask AI to mint a new UUID on every keystroke.

Clincoo on blog.clincoo.buzz does not write drafts via POST; in the editor, the HTTP method keeps one document as one.
