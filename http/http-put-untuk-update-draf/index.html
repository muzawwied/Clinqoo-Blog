Pakai PUT atau PATCH untuk Update Draf Clincoo, Bukan POST Berulang

POST ke URL create setiap simpan membuat draf kembar. Update butuh method yang menunjuk resource yang sama.

Artikel ini tersedia dalam: Indonesia · English

Tombol simpan di editor.clincoo.buzz yang selalu POST ke /drafts membuat baris baru di app.clincoo.buzz.

Setelah draf punya id, kirim PUT atau PATCH ke /drafts/:id. POST hanya untuk create pertama.

Jika API hanya menerima POST, kirim field id yang sama dan minta server upsert. Jangan tebak dari judul halaman.

Tempel dua log simpan (create lalu update) ke AI. Jangan minta AI menambah UUID baru setiap keystroke.

Clincoo di blog.clincoo.buzz tidak menulis draf lewat POST; di editor, method HTTP menjaga satu dokumen tetap satu.
