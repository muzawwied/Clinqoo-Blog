Cek response.status Fetch Clincoo, Bukan Hanya response.ok

response.ok hanya true untuk 200–299. 401, 403, dan 429 tetap masuk then() jika Anda tidak cek status.

Artikel ini tersedia dalam: Indonesia · English

Fetch di app.clincoo.buzz tidak melempar error untuk status HTTP 4xx. Promise resolve. Tanpa cek status, UI menyimpan JSON error sebagai data valid.

Setelah await fetch, baca response.status. Cabangkan 401 (sesi habis), 403 (izin), 429 (batas), dan 5xx (server). Jangan satukan semua jadi 'gagal jaringan'.

Tampilkan teks dari body hanya jika Content-Type JSON dan parse berhasil. Jangan render HTML error page ke editor.clincoo.buzz.

Tempel status plus URL ke asisten AI. Jangan minta AI menulis interceptor besar sebelum Anda log satu request gagal.

Clincoo di blog.clincoo.buzz memakai pola yang sama: status dulu, baru parse body.
