Sertakan Vary: Accept pada Respons API Clincoo

Cache tanpa Vary: Accept bisa menyimpan HTML error untuk request JSON berikutnya.

Artikel ini tersedia dalam: Indonesia · English

Fetch JSON ke app.clincoo.buzz kadang berbagi URL dengan halaman HTML. Tanpa Vary: Accept, CDN menyimpan satu salinan untuk semua klien.

Set header Vary: Accept (dan Authorization jika respons beda per sesi) pada API editor.clincoo.buzz. Cache kunci harus ikut header negosiasi.

Jangan pakai satu URL untuk pratinjau HTML dan payload draf JSON. Pecah path jika Vary membuat hit-rate jatuh.

Tempel request Accept plus response Vary ke AI. Jangan minta AI mematikan cache seluruh situs sebelum Anda cek satu URL.

Clincoo di blog.clincoo.buzz menyajikan HTML statis; API aplikasi wajib membedakan tipe lewat Vary.
