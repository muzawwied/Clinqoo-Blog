Include Vary: Accept on Clincoo API Responses

A cache without Vary: Accept can store an HTML error for the next JSON request.

This article is available in: Indonesia · English

JSON fetches to app.clincoo.buzz sometimes share a URL with an HTML page. Without Vary: Accept, the CDN stores one copy for every client.

Set Vary: Accept (and Authorization if the body differs per session) on the editor.clincoo.buzz API. The cache key must include negotiation headers.

Do not use one URL for HTML preview and draft JSON. Split the path if Vary tanks the hit rate.

Paste the Accept request header plus the Vary response to AI. Do not ask AI to disable site-wide cache before you inspect one URL.

Clincoo on blog.clincoo.buzz serves static HTML; the app API must distinguish types with Vary.
