Jangan Log Header Authorization Fetch Clincoo

console.log(request) sering ikut menampilkan Bearer token. Token bocor di screenshot debug.

Artikel ini tersedia dalam: Indonesia · English

Saat debug di editor.clincoo.buzz, logging objek Request ikut membawa header Authorization. Screenshot lalu masuk chat AI.

Log method, URL path, dan status saja. Redaksi Authorization, Cookie, dan token query sebelum tempel ke mana pun.

Jangan kirim header Authorization ke app.clincoo.buzz lewat URL. Pakai header, bukan ?token=.

Jika AI minta 'tempel request lengkap', potong bagian rahasia dulu. Prompt yang aman lebih berguna daripada token bocor.

Clincoo di blog.clincoo.buzz tidak memakai sesi pengguna; di editor, token tetap rahasia.
