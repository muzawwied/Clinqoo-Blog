Jangan Retry POST Clincoo Tanpa Kunci Idempoten

Mengulang POST saat timeout bisa menduplikasi draf. Pakai kunci unik per aksi simpan.

Artikel ini tersedia dalam: Indonesia · English

Timeout di editor.clincoo.buzz mendorong pengguna menekan Simpan lagi. Server app.clincoo.buzz mungkin sudah menulis draf pertama.

Kirim header Idempotency-Key atau field requestId UUID per klik simpan. Server menolak duplikat dengan status yang sama.

GET dan PUT idempoten boleh diulang. POST create tidak, kecuali server mengakui kunci yang sama.

Tempel dua log request dengan id yang sama ke AI. Jangan minta AI menambah retry otomatis pada semua POST.

Clincoo di blog.clincoo.buzz tidak membuat resource lewat POST; di aplikasi, kunci idempoten mencegah draf kembar.
