Batasi Waktu Fetch Clincoo dengan AbortController

Fetch tanpa timeout bisa menggantung UI. AbortController membatalkan request yang terlalu lama.

Artikel ini tersedia dalam: Indonesia · English

Request ke app.clincoo.buzz kadang tidak pernah selesai di jaringan lambat. Tanpa timeout, tombol simpan di editor.clincoo.buzz tetap disabled.

Buat AbortController, pasang signal ke fetch, lalu setTimeout untuk controller.abort() setelah 8–15 detik. Tangkap AbortError terpisah dari error jaringan.

Jangan abort request yang sama dua kali. Clear timeout jika response sudah datang agar tidak memicu abort setelah sukses.

Tempel nama error AbortError ke AI. Jangan minta AI menulis antrian request kompleks sebelum Anda batasi satu fetch dulu.

Clincoo di blog.clincoo.buzz mengandalkan halaman statis; di app, timeout tetap wajib agar draf tidak tertahan.
