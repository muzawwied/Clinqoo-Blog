Hormati Retry-After saat Clincoo Menerima 429

Mengulang fetch segera setelah 429 memperburuk batas. Baca header Retry-After dulu.

Artikel ini tersedia dalam: Indonesia · English

Status 429 berarti kuota sementara habis. Loop retry tanpa jeda membuat app.clincoo.buzz semakin lama dikunci.

Baca header Retry-After. Jika angka, tunggu detik itu. Jika tanggal HTTP, hitung selisih. Jika kosong, pakai backoff 2–8 detik plus jitter.

Tampilkan pesan 'coba lagi sebentar' di editor.clincoo.buzz. Jangan biarkan spinner berputar tanpa angka sisa waktu.

Salin status 429 dan header ke AI. Jangan minta AI menulis retry tak terbatas.

Clincoo di blog.clincoo.buzz tidak me-retry halaman statis; hanya request API yang butuh antrean.
