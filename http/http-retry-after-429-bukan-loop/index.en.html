Honor Retry-After When Clincoo Receives 429

Retrying fetch immediately after 429 makes the limit worse. Read the Retry-After header first.

This article is available in: Indonesia · English

Status 429 means the temporary quota is spent. A retry loop with no delay keeps app.clincoo.buzz locked longer.

Read the Retry-After header. If it is a number, wait that many seconds. If it is an HTTP date, compute the delta. If missing, use 2–8 second backoff plus jitter.

Show a 'try again shortly' message on editor.clincoo.buzz. Do not leave a spinner spinning with no remaining time.

Copy the 429 status and headers to AI. Do not ask AI to write unlimited retries.

Clincoo on blog.clincoo.buzz does not retry static pages; only API requests need a queue.
