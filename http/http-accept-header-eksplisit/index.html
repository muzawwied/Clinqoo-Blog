Set Header Accept Secara Eksplisit pada Fetch Clincoo

Tanpa Accept, server bisa mengirim HTML error page. Parse JSON lalu gagal diam-diam.

Artikel ini tersedia dalam: Indonesia · English

Template di editor.clincoo.buzz sering fetch tanpa header Accept. Server mengembalikan halaman HTML 404, lalu JSON.parse melempar.

Kirim Accept: application/json pada request API app.clincoo.buzz. Jika response Content-Type bukan JSON, jangan parse sebagai objek draf.

Jangan mengandalkan browser default. Default Accept terlalu longgar dan menerima HTML.

Tempel header request plus Content-Type response ke AI. Jangan minta AI menulis parser HTML untuk endpoint JSON.

Clincoo di blog.clincoo.buzz menyajikan HTML; API aplikasi harus tetap JSON murni.
