Set an Explicit Accept Header on Clincoo Fetch

Without Accept, the server may send an HTML error page. JSON.parse then fails quietly.

This article is available in: Indonesia · English

Templates on editor.clincoo.buzz often fetch without an Accept header. The server returns an HTML 404 page, then JSON.parse throws.

Send Accept: application/json on app.clincoo.buzz API requests. If the response Content-Type is not JSON, do not parse it as a draft object.

Do not rely on the browser default. The default Accept is too loose and accepts HTML.

Paste the request headers plus the response Content-Type to AI. Do not ask AI to write an HTML parser for a JSON endpoint.

Clincoo on blog.clincoo.buzz serves HTML; the app API should stay pure JSON.
