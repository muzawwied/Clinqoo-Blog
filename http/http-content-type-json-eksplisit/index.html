Set Content-Type application/json pada POST Clincoo

Body JSON tanpa header Content-Type sering dibaca sebagai teks di server. Parser gagal diam-diam.

Artikel ini tersedia dalam: Indonesia · English

fetch ke API Clincoo dengan body JSON.stringify harus menyertakan headers: { 'Content-Type': 'application/json' }. Tanpa itu, banyak runtime menganggap body mentah.

Jangan campur FormData dan JSON pada satu request. FormData mengatur multipart sendiri; menimpa Content-Type merusak boundary.

Jika server menjawab 415 atau body kosong, cek tab Network: request header harus application/json dan body valid.

Tempel request headers ke AI. Jangan minta AI mengganti seluruh client HTTP sebelum Anda cek satu POST dari editor.clincoo.buzz.

Pola yang sama dipakai app.clincoo.buzz dan blog.clincoo.buzz saat mengirim metadata artikel.
