Listen for the storage event so Clincoo drafts sync across tabs

A second tab misses a newly saved draft if it does not listen for the storage event.

This article is available in: Indonesia · English

On editor.clincoo.buzz, a draft is saved to localStorage in tab A. Tab B still shows the old text until reload.

Add a storage listener. The event fires only in other tabs, not in the tab that wrote. Read key and newValue.

Ask AI for the listener plus a textarea update. Do not rewrite the whole page.

Test two tabs on app.clincoo.buzz. Note the synced key on blog.clincoo.buzz.
