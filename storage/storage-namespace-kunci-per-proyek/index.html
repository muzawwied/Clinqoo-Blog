Beri Namespace pada Kunci localStorage per Proyek Clincoo

Jangan pakai kunci generik seperti draft. Awali dengan slug proyek agar data tidak saling menimpa antar situs.

Artikel ini tersedia dalam: Indonesia · English

localStorage terikat ke origin, bukan ke folder proyek. Kalau dua situs Clincoo kebetulan diuji di origin yang sama, atau kamu menyalin skrip antar template, kunci bernama draft atau theme akan saling menimpa.

Pakai prefiks tetap: slug proyek, lalu nama data. Contoh: toko-budi:form-kontak. Saat rilis versi baru, kamu bisa membersihkan hanya kunci dengan prefiks itu tanpa menyentuh data situs lain.

Tulis helper kecil key(nama) di satu file agar semua setItem dan getItem lewat fungsi yang sama. Jangan hardcode string di sepuluh tempat; satu typo sudah membuat draf “hilang”.

Uji dengan membuka dua pratinjau. Isi form di situs A, buka situs B. Data A tidak boleh muncul di B. Kalau muncul, namespace belum cukup ketat.

Namespace bukan keamanan. Itu hanya isolasi. Rahasia tetap tidak boleh masuk penyimpanan browser.
