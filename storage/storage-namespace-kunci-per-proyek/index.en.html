Storage

Namespace localStorage Keys per Clincoo Project

Do not use generic keys like draft. Prefix with the project slug so sites do not overwrite each other.

This article is available in: Indonesia · English

localStorage is bound to the origin, not the project folder. If two Clincoo sites share an origin during preview, or you copy a script between templates, keys named draft or theme will collide.

Use a stable prefix: project slug, then the data name. Example: toko-budi:form-kontak. On a new release you can wipe only keys with that prefix.

Write a small key(name) helper so every setItem and getItem goes through one function. Do not hardcode the string in ten places.

Test with two previews. Fill a form on site A, open site B. A’s data must not appear on B.

A namespace is isolation, not security. Secrets still do not belong in the browser.
