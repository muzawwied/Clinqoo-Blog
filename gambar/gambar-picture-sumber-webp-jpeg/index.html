Pakai picture agar Hero Clincoo Punya WebP dan Cadangan JPEG

src tunggal memaksa semua browser mengunduh format yang sama. picture memberi WebP dulu, JPEG jika tidak didukung.

Artikel ini tersedia dalam: Indonesia · English

Banyak halaman Clincoo masih memakai satu atribut src pada hero. Browser lama atau klien email yang menyalin HTML tidak selalu mengerti WebP. Elemen picture menumpuk source type="image/webp" di atas img JPEG sehingga pengunjung modern hemat byte tanpa merusak cadangan.

Tulis urutan dari format paling efisien ke cadangan. Browser memilih source pertama yang didukung. Jangan menaruh JPEG di atas WebP — itu meniadakan manfaat kompresi.

Sertakan width dan height pada img di dalam picture agar slot tidak loncat. sizes dan srcset tetap berlaku per source jika kamu punya beberapa lebar.

Uji di pratinjau Clincoo lalu di tab Network produksi: pastikan tipe MIME yang terunduh sesuai browser. Jika yang muncul tetap JPEG di Chrome, cek path source atau header server.

Simpan kedua file di folder assets yang sama agar path relatif tidak pecah saat kamu salin halaman.
