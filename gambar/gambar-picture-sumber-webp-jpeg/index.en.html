Use picture so Clincoo Heroes Have WebP plus JPEG Fallback

A single src forces every browser to download the same format. picture serves WebP first and JPEG when needed.

Indonesia · English

Many Clincoo pages still use one src on the hero. Older browsers or clients that copy HTML do not always understand WebP. The picture element stacks a source type="image/webp" above a JPEG img so modern visitors save bytes without breaking fallback.

Write sources from the most efficient format to the fallback. The browser picks the first supported source. Do not put JPEG above WebP — that cancels the compression win.

Keep width and height on the inner img so the slot does not jump. sizes and srcset still apply per source when you have several widths.

Test in Clincoo preview and then on the production Network tab: the downloaded MIME type should match the browser. If Chrome still fetches JPEG, check the source path or server headers.

Store both files in the same assets folder so relative paths stay intact when you copy a page.
