Check Image Src 404s before You Publish

Open Network in the editor.clincoo.buzz preview DevTools, filter Img, reload. Status 404 means the path or file name is wrong.

Match letter case with the assets folder.

Prefer a path relative to the HTML file that embeds the image.

If AI invents a file name, match it against the folder list.

Once the path is correct, then think about compression and srcset.
