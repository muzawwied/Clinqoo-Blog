Cek Src Gambar 404 sebelum Publish

Buka Network di DevTools pratinjau editor.clincoo.buzz, filter Img, muat ulang. Status 404 artinya path atau nama file salah.

Samakan huruf besar-kecil dengan folder aset. Hosting app.clincoo.buzz membedakan Hero.png dan hero.png.

Utamakan path relatif dari berkas HTML yang memuat gambar.

Kalau AI mengarang nama file, cocokkan dengan daftar folder.

Setelah path benar, baru pikirkan kompresi dan srcset. Gambar yang 404 tidak bisa dioptimasi.
