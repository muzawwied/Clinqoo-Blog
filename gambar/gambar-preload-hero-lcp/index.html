Preload Gambar Hero Clincoo agar LCP Tidak Tertahan CSS

Hero yang baru ditemukan setelah CSS selesai menahan LCP. Preload file hero di head halaman Clincoo.

Artikel ini tersedia dalam: Indonesia · English

Gambar hero sering menjadi elemen LCP. Jika browser baru melihat src setelah stylesheet selesai, unduhan hero terlambat. Di halaman Clincoo yang menonjolkan foto besar, tambahkan tautan preload di head agar permintaan hero mulai bersama HTML.

Tulis dengan URL yang sama persis seperti src gambar hero. Jika kamu memakai srcset, sertakan imagesrcset dan imagesizes agar browser memilih kandidat yang sama. Preload ke file yang berbeda dari yang ditampilkan justru membuang bandwidth.

Jangan preload semua gambar. Cukup satu kandidat LCP per halaman. Preload berlebih bersaing dengan CSS dan font. Pasangkan dengan fetchpriority="high" pada img hero dan loading="eager", sementara gambar di bawah lipat tetap lazy.

Ukur ulang di pratinjau dan Lighthouse setelah deploy. LCP yang turun tanpa CLS naik berarti preload mengenai file yang tepat. Jika LCP tetap tinggi, cek kompresi WebP dan atribut width-height sebelum menambah preload lain.
