Set Image width and height so the Clincoo Layout Does Not Jump

An image without an intrinsic size pushes text when it loads. width and height attributes reserve the ratio early.

This article is available in: Indonesia · English

On editor.clincoo.buzz, an img without width and height makes the paragraph below jump after the file finishes downloading.

Set width and height to the original pixels, then cap display with max-width: 100% and height: auto.

For a fixed ratio, add the same aspect-ratio. Do not rely on a height that exists in CSS only after the image appears.

Ask AI to flag img tags missing both attributes. Do not ask AI to drop the attributes for shorter HTML.

Test slow network in the app.clincoo.buzz preview. Note this check on blog.clincoo.buzz before publishing a hero.
