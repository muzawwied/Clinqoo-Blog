Isi atribut sizes Gambar Clincoo sesuai Lebar Kontainer

srcset tanpa sizes membuat browser menebak lebar tampilan. Tulis sizes agar hero dan kartu mengunduh file yang pas.

Artikel ini tersedia dalam: Indonesia · English

Hero Clincoo dengan tiga file di srcset tetap mengunduh yang terbesar jika sizes kosong. Ponsel membayar bandwidth yang tidak dipakai.

Tulis sizes sesuai tata letak: 100vw untuk hero penuh, (min-width: 48rem) 33vw untuk kartu tiga kolom. Angka itu memberitahu browser lebar slot sebelum layout selesai.

Selaraskan nama file di srcset dengan lebar nyata, misalnya 800w dan 1600w. Jangan klaim 2400w untuk foto 900px.

Uji di editor.clincoo.buzz dengan throttle jaringan. Di tab Network, pastikan perangkat sempit memilih sumber yang lebih kecil.

Minta AI hanya menambahkan sizes dan merapikan srcset, bukan mengganti seluruh markup gambar. Pratinjau LCP setelah perubahan.

Clincoo tidak menghitung sizes otomatis. Atribut yang jujur terhadap kontainer memangkas unduhan tanpa merusak ketajaman.
