Set Clincoo Image sizes to Match Container Width

srcset without sizes makes the browser guess display width. Write sizes so hero and cards download the right file.

This article is available in: Indonesia · English

A Clincoo hero with three files in srcset still downloads the largest one when sizes is empty. Phones pay for unused bandwidth.

Write sizes to match layout: 100vw for a full-bleed hero, (min-width: 48rem) 33vw for three-column cards. That number tells the browser the slot width before layout finishes.

Align srcset filenames with real widths, such as 800w and 1600w. Do not claim 2400w for a 900px photo.

Test in editor.clincoo.buzz with network throttle. In the Network tab, confirm a narrow device picks the smaller source.

Ask AI only to add sizes and tidy srcset, not to rewrite the whole image markup. Preview LCP after the change.

Clincoo does not compute sizes for you. An attribute that matches the container cuts downloads without softening sharpness.
