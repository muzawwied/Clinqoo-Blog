Reject Global Stylesheet Rewrites from Clincoo AI

AI likes to rewrite all CSS. Ask for a specific selector so brand and existing layout stay intact.

This article is available in: Indonesia · English

One tidy the CSS request in editor.clincoo.buzz can wipe Clincoo brand color tokens.

Reply: do not rewrite the file. Change only the selector that touches the symptom. Paste the related CSS block.

If AI returns the whole file, cut it down to a diff. Apply it by hand in preview.

Check contrast, type, and hero spacing after the paste. Roll back if the logo or buttons shift.

Save a one selector rule in the team notes on blog.clincoo.buzz.
