Tolak Rewrite Stylesheet Global dari Saran AI Clincoo

AI suka menulis ulang seluruh CSS. Minta selektor spesifik agar brand dan layout lama tetap utuh.

Artikel ini tersedia dalam: Indonesia · English

Satu permintaan rapikan CSS di editor.clincoo.buzz bisa menghapus token warna brand Clincoo.

Balas: jangan rewrite file. Ubah hanya selektor yang menyentuh gejala. Tempel blok CSS terkait.

Jika AI mengembalikan file utuh, potong ke diff. Terapkan manual di pratinjau.

Cek kontras, font, dan spasi hero setelah tempel. Rollback jika logo atau tombol bergeser.

Simpan aturan satu selektor di catatan tim blog.clincoo.buzz.
