Set Boundaries for the AI before It Writes Code

Say which files may be touched, which may not, and how large a change is allowed.

This article is available in: Indonesia · English

The Clinqoo AI assistant works more cleanly when limits are clear in the first message. Name files it may edit, files it may only read, and whether it may add new files.

Example: read index.html and style.css; do not change script.js; propose only CSS rules for menu spacing. That limit stops the AI from tearing down structure you already tested.

If the answer crosses the line, refuse briefly and repeat the rule. Do not accept a full file just because it feels complete.

Boundaries are not an insult to the AI. They keep the project yours while the assistant stays useful.
