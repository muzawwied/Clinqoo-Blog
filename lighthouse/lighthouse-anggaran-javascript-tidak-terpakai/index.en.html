Cut Unused JavaScript That Drags a Clincoo Lighthouse Score

The coverage panel is more honest than deleting the hero image just for the score.

This article is available in: Indonesia · English

Open Coverage in DevTools on the editor.clincoo.buzz preview, reload, then inspect red bytes in the JS files.

Split scripts that only run on admin pages or rare modals. Do not ship all of them in the home page head.

Record the three files with the largest unused remainder before adding a new library.

Paste the coverage snippet to AI and ask for one dynamic import. Reject a rewrite of the whole bundle.

Store the JS budget in the app.clincoo.buzz release note and link before-and-after on blog.clincoo.buzz.
