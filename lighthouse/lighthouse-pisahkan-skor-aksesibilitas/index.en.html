Separate the Clincoo Lighthouse Accessibility Score from Performance

A green performance score does not cover failed contrast, labels, or button names.

This article is available in: Indonesia · English

Run the Accessibility category in Lighthouse on the same editor.clincoo.buzz page. Do not read only the performance number.

Fix text contrast, accessible names on icon buttons, and empty input labels. One of these failures blocks keyboard users.

Retest with Tab after the fix. An automated audit does not catch a confusing focus order.

Paste the failure list to AI and ask for a fix order starting with the most blocking item. Reject advice that only raises the score with hidden aria.

Link the accessibility result on blog.clincoo.buzz, separate from the app.clincoo.buzz LCP note.
