Lock Clincoo CLS with Image Dimensions and Ad Slots

Layout shift often comes from images without width and height, or slots that appear late.

This article is available in: Indonesia · English

Open the Lighthouse audit on the editor.clincoo.buzz preview, then select the CLS metric. The shifting element is usually an image, a font swap, or a banner inserted after paint.

Add width and height on the hero image, or aspect-ratio in CSS. Do not let the browser guess the height after the download finishes.

If there is a third-party slot, reserve a box with min-height before the script runs. An empty slot is better than pushed content.

Paste the CLS element snippet to AI and ask for one CSS change. Reject advice that deletes the whole grid layout.

Record the CLS threshold in the app.clincoo.buzz release note and link before-after proof on blog.clincoo.buzz.
