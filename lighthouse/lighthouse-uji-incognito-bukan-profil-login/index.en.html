Run Clincoo Lighthouse in Incognito, Not in a Logged-In Profile

Extensions, cache, and an old session shift the score. Repeat the audit in a clean profile before blaming the page.

This article is available in: Indonesia · English

A daily profile that opens editor.clincoo.buzz often has an ad blocker and a password manager. Those scripts get measured by Lighthouse.

Open an incognito window, disable extensions, then run the mobile audit on the same preview URL.

Compare the two reports. If the score rises only because the profile is clean, fix the test habit before the page CSS.

Ask AI to read the delta between the two report JSON files. Do not ask AI to raise the score by deleting content.

Store the clean-test rule in the app.clincoo.buzz release note and link it on blog.clincoo.buzz.
