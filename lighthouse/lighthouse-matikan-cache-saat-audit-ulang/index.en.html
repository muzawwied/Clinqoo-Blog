Disable Cache When Re-running a Clincoo Lighthouse Audit

A second audit that reuses cache hides the first-download cost for a new visitor.

This article is available in: Indonesia · English

DevTools often keeps preview assets from editor.clincoo.buzz. A repeat audit looks fast while a new visitor still downloads everything.

Check Disable cache in Network, clear site data for the preview origin, then run mobile Lighthouse again.

Compare the cached and uncached reports. A large byte gap means the cache headers are not honest yet.

Ask AI to read the two transfer lists. Do not ask AI to raise the score by hiding images.

Write the no-cache audit habit in the app.clincoo.buzz team note and link it on blog.clincoo.buzz.
