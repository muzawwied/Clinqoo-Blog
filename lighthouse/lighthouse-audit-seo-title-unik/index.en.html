Audit Clincoo Lighthouse SEO: Unique Title and Meta Description

The SEO score fails when the title is copied from a template or the description is empty on every preview.

This article is available in: Indonesia · English

Open the SEO category in Lighthouse on the editor.clincoo.buzz preview URL. Check the title, meta description, and index status.

Give a title that names the page, not only the Clincoo brand. The one-sentence description must differ from other pages.

Make sure the canonical points to blog.clincoo.buzz or the production domain, not a temporary URL that should not be indexed.

Paste the HTML head to AI and ask for title differences across pages. Reject advice that repeats the same keywords.

Store a short SEO checklist on blog.clincoo.buzz and link it from the app.clincoo.buzz release note.
