Store the Clincoo Lighthouse Report JSON in CI, Not Only a Screenshot

A score image cannot be compared. The same JSON in the pipeline makes a regression visible.

This article is available in: Indonesia · English

Each app.clincoo.buzz release should run headless Lighthouse against a stable preview URL.

Save the JSON artifact, then fail the job if LCP crosses the agreed threshold.

Do not rely on a green-circle screenshot. A JSON number that moves without a ticket is a regression.

Attach the delta summary to AI and ask for a one-file hypothesis. Do not ask for a full CI config rewrite.

Link the passing artifact on blog.clincoo.buzz so editor.clincoo.buzz has an audit trail.
