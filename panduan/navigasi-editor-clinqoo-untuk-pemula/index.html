Navigasi Editor Clincoo untuk Pemula: Explorer, Kode, Terminal

Pahami tiga area utama editor Clincoo supaya kamu tidak tersesat saat membuka proyek pertama.

Artikel ini tersedia dalam: Indonesia · English

Editor Clincoo terasa ramai di menit pertama. Tenang. Hampir semua pekerjaan terjadi di tiga area: explorer berkas di kiri, editor kode di tengah, dan terminal di bawah.

Explorer adalah peta proyek. Buka folder, klik file, lalu ketik. Kalau file baru dibutuhkan, buat di sini dulu supaya struktur tetap rapi. Hindari menaruh semua file di akar proyek.

Area tengah untuk menulis. Simpan sering, lalu buka pratinjau. Terminal dipakai hanya saat kamu perlu perintah — misalnya cek daftar file atau menjalankan skrip kecil. Jangan takut menutup terminal kalau tidak dipakai.

Setelah tiga area ini familiar, fitur lain seperti AI dan deploy terasa lebih masuk akal. Kuasai denah dulu, baru percepat kerja.
