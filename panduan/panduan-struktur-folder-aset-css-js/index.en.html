Tidy the Asset, CSS, and JS Folder Structure in a Clincoo Project

Files piled in the root make preview and deploy hard to trace. Separate pages, styles, scripts, and images.

This article is available in: Indonesia · English

A new project in editor.clincoo.buzz often puts style.css, app.js, and logo.png next to index.html. That is fine for one page and messy after about and contact exist.

Use a simple pattern: pages at the root or one folder per route, CSS in assets/css, JS in assets/js, images in assets/img. File names stay lowercase with hyphens.

Relative links must follow folder depth. From /kontak/index.html the logo is ../assets/img/logo.png. Check in preview, not only in the editor.

Do not copy the whole template into a new folder. Move one kind of file, refresh, then continue. A tidy tree also helps when you ask AI: name the exact path.
