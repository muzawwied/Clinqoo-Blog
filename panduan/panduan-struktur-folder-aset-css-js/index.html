Rapikan Struktur Folder Aset, CSS, dan JS di Proyek Clincoo

File menumpuk di root membuat pratinjau dan deploy sulit dilacak. Pisahkan halaman, gaya, skrip, dan gambar.

Artikel ini tersedia dalam: Indonesia · English

Proyek baru di editor.clincoo.buzz sering menaruh style.css, app.js, dan logo.png sejajar dengan index.html. Itu cukup untuk satu halaman, kacau setelah ada tentang dan kontak.

Pakai pola sederhana: halaman di root atau folder tiap rute, CSS di assets/css, JS di assets/js, gambar di assets/img. Nama file huruf kecil dan tanda hubung.

Tautan relatif harus mengikuti kedalaman folder. Dari /kontak/index.html, logo ada di ../assets/img/logo.png. Cek di pratinjau, bukan hanya di editor.

Jangan salin seluruh template ke folder baru. Pindahkan satu jenis file, refresh, lalu lanjut. Struktur yang rapi juga memudahkan saat minta bantuan AI: sebut path yang tepat.
