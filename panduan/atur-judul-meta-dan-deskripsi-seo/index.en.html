Set Meta Titles and SEO Descriptions in a Clinqoo Project

How to write the title and meta description in Clinqoo HTML so the browser tab and search snippet do not look like a draft.

This article is available in: Indonesia · English

Many first sites go live with a tab title of "Untitled" or an empty description. Two lines in <head> are enough to tidy the first impression. Clinqoo does not rewrite that text for you — you write it.

Open the page HTML file, usually index.html. Find <title>. Fill it with the site name plus one purpose phrase, for example "Studio Awan — Design Portfolio". Keep it under 60 characters so search results do not truncate it harshly.

Add a meta description of one or two sentences. Say what the visitor gets, not a keyword list. Example: "Packaging and brand identity work for small businesses." A comfortable length is about 140–160 characters.

Match the tab title with the heading in the page hero. If they diverge, visitors feel they opened the wrong link. After editing, preview in Clinqoo and deploy again.

Repeat for About and Contact. Each page may have its own title. Do not copy the home title into every file.
