CSS Not Showing Up? The Debug Checklist Developers Actually Use

Styles refuse to change even after you save. Here is the practical checklist developers run before giving up.

This article is available in: Indonesia · English

You change a color in CSS, save, preview — nothing moves. Do not panic. Almost always the cause is one of four: the stylesheet is not linked, a class name is mistyped, a selector loses specificity, or the browser is caching.

Start simple. In the HTML, confirm the link stylesheet points to the right file with a relative path. Open preview, right-click → Inspect → Network tab, filter CSS, and check that the file loads with status 200.

If the file is loading, check class spelling. Case matters. Then in Inspect, select the problem element: look in the Styles panel whether your rule is crossed out. If it is, another selector is stronger.

Finally, hard refresh (Ctrl+Shift+R). In the Clincoo editor, save both files, open preview again. Nine out of ten "CSS does nothing" cases end with these steps.
